**What would you like to be added**:

I would like to introduce a new Scheduling Goodput metric for Kueue's Cluster and Local Queues  to provide visibility into scheduling performance by tracking the lifecycle of individual workloads.

**Why is this needed**:
Scheduling Goodput is one of the critical metrics (see e.g. https://medium.com/@kinjaldand/maximizing-ml-efficiency-why-throughput-is-only-half-the-story-d807f236fd0f) explaining infrastructure reliability and scheduler efficiency.  It measures the ratio of active processing time to the total time workload spent in the system, exposing the information about the jobs stuck in long queuing cycles. It is defined by the following formula:

*Scheduling Goodput = Duration in Running State / Total Lifetime (Finished - Created)*

A value near 1.0 represents an ideal scenario where a workload begins execution almost immediately upon creation, implying high throughput and surplus capacity. Conversely, a value approaching 0.0 indicates a critical bottleneck where the workload's lifetime is entirely dominated by queuing.

Use case examples:
1. SLA monitoring and system tuning - a platform team hosts multiple distinct research groups on a single cluster. By comparing the goodput of several queues, the admin is able to fine-tune the fair sharing policies.
2. Evaluating the scheduling performance changes - admin compares p90 goodput before and after the rollout of topology-aware scheduling. If the metrics drops significantly, it may indicate that the placement policies are too rigid.

***Proposed Implementation Details***

Cluster Queue Metric:
 * Name: `kueue_scheduling_goodput`
 * Type: histogram
 * Labels: `cluster_queue`: the name of the ClusterQueue
`priority_class`: the priority class name
`replica_role`: one of leader, follower, or standalone

Local Queue Metric: 
 * Name: `kueue_local_queue_scheduling_goodput`
 * Type: histogram
 * Labels: `name`: the name of the LocalQueue
`namespace`: the namespace of the LocalQueue
`priority_class`: the priority class name
`replica_role`: one of leader, follower, or standalone
