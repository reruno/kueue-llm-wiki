## Description

<!-- Please use this template for documentation-related issues -->

**What would you like to be documented or improved**:

One can set the fairSharing.weight on both cohort and cluster queue level. However, it is unclear what the differences are. Would setting the weight on the cluster queue be additive as one goes up the cohort hierarchy? What are the best practices for setting the fairSharing.weight? Do people normally set it on both cohort and cluster queue? Does kueue look at the weights top down or bottom up in the cohort tree? Does it consider the cluster queue weights first or the cohorts?

It looks like most of the logic comes from: https://github.com/kubernetes-sigs/kueue/blob/v0.16.5/pkg/scheduler/fair_sharing_iterator.go#L63-L97. If I understand it correctly, I have to set the weight on both clusterQueue and cohort. If I only set on cluster queue, cohort's weight will default to 1, which means it will be equally divided amongst the cohorts.

**Location** (URL, file path, or section if applicable):
- fairSharing spec on cluster queue: [ClusterQueueSpec](https://kueue.sigs.k8s.io/docs/reference/kueue.v1beta2/#kueue-x-k8s-io-v1beta2-ClusterQueueSpec)
- fairSharing spec on cohort: [CohortSpec](https://kueue.sigs.k8s.io/docs/reference/kueue.v1beta2/#kueue-x-k8s-io-v1beta2-CohortSpec)

The descriptions under the fairSharing field are nearly identical.
