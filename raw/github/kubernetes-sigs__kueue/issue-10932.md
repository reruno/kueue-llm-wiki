## Description

### What happened?

In `charts/kueue/templates/manager/manager.yaml`, both the livenessProbe and readinessProbe `periodSeconds` fields reference `.Values.controllerManager.{liveness,readiness}Probe.initialDelaySeconds` instead of `.periodSeconds`.

**livenessProbe (line ~57):**
```yaml
periodSeconds: {{ .Values.controllerManager.livenessProbe.initialDelaySeconds }}
```
Should be:
```yaml
periodSeconds: {{ .Values.controllerManager.livenessProbe.periodSeconds }}
```

**readinessProbe (line ~77):**
```yaml
periodSeconds: {{ .Values.controllerManager.readinessProbe.initialDelaySeconds }}
```
Should be:
```yaml
periodSeconds: {{ .Values.controllerManager.readinessProbe.periodSeconds }}
```

### What did you expect to happen?

With default values:
- livenessProbe periodSeconds should be **20** (gets **15** instead)
- readinessProbe periodSeconds should be **10** (gets **5** instead)

### Additional context

This bug exists on `main` branch as well as the v0.17.2 release chart.

### Environment

- Kueue version: v0.17.2 (also on main)
- Installation method: Helm
- Kubernetes version: 1.30
