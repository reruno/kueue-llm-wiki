## Description

### What happened?

In `charts/kueue/templates/kueueviz/clusterrole.yaml` line 33:
```yaml
  - apiGroups: ["kueue.x-k8s.io"]
    resources: ["workloadpriorityclass"]
    verbs: ["get", "list", "watch"]
```

The Kubernetes RBAC `resources` field requires the **plural** form. The Kueue CRD defines `plural: workloadpriorityclasses`. The main controller RBAC in `templates/rbac/role.yaml` correctly uses `workloadpriorityclasses`.

As written, this rule silently matches no resources, so the KueueViz backend has no access to `WorkloadPriorityClass` objects.

### What did you expect to happen?

```yaml
  - apiGroups: ["kueue.x-k8s.io"]
    resources: ["workloadpriorityclasses"]
    verbs: ["get", "list", "watch"]
```

### Environment

- Kueue version: v0.17.2
- Installation method: Helm
- Kubernetes version: 1.30
