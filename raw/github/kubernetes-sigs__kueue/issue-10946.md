## Description

**What happened**:

The Workload corresponding to RedisCleanup Job does not allocate resources for the Job.

**What you expected to happen**:

The quota allocated in the Workload covers all operations. Similarly as we currently cover the k8s submitter Job.

**How to reproduce it (as minimally and precisely as possible)**:

I haven't tested this myself, but there is configuration which triggers the rediscleanup job creation in RayCluster, eg.: https://github.com/ray-project/kuberay/blob/e3790d555b59c3a7a59f41fc0c6f8616ec5b9a45/ray-operator/apis/ray/v1/raycluster_types.go#L110
