## Description

**What happened**:

When user over-configures `kueue.x-k8s.io/queue-name` in a LWS's leader|worker template, the pods stay in SchedulingGated state, and cannot be evicted upon preemption by other preemptors.

**What you expected to happen**:

- Kueue to reject the LWS's creation when `kueue.x-k8s.io/queue-name` in found a LWS's leader|worker template, when LWS integration is enabled
- Or, tolerate with the user's setting, and ensure scheduling/eviction works as expected

**How to reproduce it (as minimally and precisely as possible)**:

```yaml
apiVersion: leaderworkerset.x-k8s.io/v1
kind: LeaderWorkerSet
metadata:
  name: tas-kueue-lws
  namespace: default
  labels:
    kueue.x-k8s.io/queue-name: local-queue
spec:
  replicas: 1
  leaderWorkerTemplate:
    size: 3
    leaderTemplate:
      metadata:
        labels:
          app: tas-kueue-lws
          kueue.x-k8s.io/queue-name: user-queue # over-configured field by user
        annotations:
          kueue.x-k8s.io/podset-preferred-topology: "kubernetes.io/hostname"
      spec:
        containers:
        - name: leader
          image: registry.k8s.io/e2e-test-images/agnhost:2.53
          args: ["pause"]
          resources:
            requests:
              nvidia.com/gpu: 1
            limits:
              nvidia.com/gpu: 1
        restartPolicy: Always
    workerTemplate:
      metadata:
        labels:
          app: tas-kueue-lws
          kueue.x-k8s.io/queue-name: user-queue # over-configured field by user
        annotations:
          kueue.x-k8s.io/podset-preferred-topology: "kubernetes.io/hostname"
      spec:
        containers:
        - name: worker
          image: registry.k8s.io/e2e-test-images/agnhost:2.53
          args: ["pause"]
          resources:
            requests:
              nvidia.com/gpu: 1
            limits:
              nvidia.com/gpu: 1
```

After applying this yaml, the 3 pods stay in SchedulingGated state:

```console
⇒  k get po
NAME                READY   STATUS            RESTARTS   AGE
tas-kueue-lws-0     0/1     SchedulingGated   0          25s

tas-kueue-lws-0-2   0/1     SchedulingGated   0          25s
```

```console
⇒  k patch workload leaderworkerset-tas-kueue-lws-0-1caf5 --type=merge -p '{"spec":{"active":false}}'
```
