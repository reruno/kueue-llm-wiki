## Description

**What would you like to be cleaned**:

I would like to make sure we are not using the "pause" as default image for e2e tests in functions like MakeJob.

I would propose to just replace ["pause"](https://github.com/kubernetes-sigs/kueue/blob/3b4f8ffe1ee9b0fab6f1c6d680e8f37b90bacd20/pkg/util/testingjobs/tfjob/wrappers_tfjob.go#L83) with some image which does not exist, like "dummy_non_existing_image". Then e2e tests would fail fast. For integration and unit tests it will not matter what is there.

**Why is this needed**:

Using "pause" "works", but it requires pulling the image, and we should be using k8s stack, ie using "agnhost" for testing whenever possible. Because it "works" it is very easy to miss that on review.  One place was recently fixed here: https://github.com/kubernetes-sigs/kueue/pull/10999
