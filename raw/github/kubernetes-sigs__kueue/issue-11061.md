## Description

One of my coworkers has created a linter for skills (https://github.com/stbenjam/skillsaw).

When I try to run this, it seems we are not following standards for skills.

```
kehannon@kehannon-thinkpadp1gen4i:~/Work/kueue$ podman run -v $(pwd):/workspace ghcr.io/stbenjam/skillsaw cmd/experimental/agent/skills/

Scanned:
  Repo type: unknown
  Plugins:   0
  Skills:    0
  Rules run: 8
```

It seems that each skill should be a separate folder with a SKILLS.md file.
