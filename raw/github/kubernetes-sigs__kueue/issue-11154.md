**What would you like to be cleaned**:

I would like to introduce a standardized approach to testing controller filters, something like I saw here https://github.com/kubernetes-sigs/kueue/pull/11001/changes#diff-cd56bbdf4f98d72342fbc3870464f604980ae13051629ae67a695e1bb1d7845aR930 looks like a potential candidate for such a standardized approach, but we can continue discussion.

**Why is this needed**:

Currently we keep reinventing the wheel, for example we have:
- non_tas_usage_controller_test.go TestNonTasUsageReconcilerDelete, TestNonTasUsageReconcilerUpdate, etc
- pod_termination_controller_test.go - TestNodeEventsPredicateDelete, TestNodeEventsPredicateUpdate etc

However, many controllers don't test even filters. This is likely due to making non-trivial decisions about the approach to the testing. With the standardized approach we could encourage more developers to add more tests with a clear guideline.
