## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
Flavor node selectors should be able to handle things like value wildcards. 

**Why is this needed**:
Today the flavor node selectors can only match hard lists where its a distinct key value pair like "foo:bar". 
It cannot match to for instance just the key and make the value a wildcard. 

While taints and tolerations can use operators like Exists.
