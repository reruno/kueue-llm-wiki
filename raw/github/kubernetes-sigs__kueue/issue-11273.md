**What would you like to be cleaned**:

We should work with the maintainers and communities of the projects we depend on to keep their key dependencies up-to-date.

In particular we should make sure `k8s API` and `controller-runtime` are up-to-date. I consider up-to-date when k8s api is >= 0.35, and controller-runtime is >= 0.23.2

- [ ] KubeRay: https://github.com/ray-project/kuberay/issues/4842
- [x] JobSet - already up to date: https://github.com/kubernetes-sigs/jobset/blob/main/go.mod
- [x] LWS - already up-to-date: https://github.com/kubernetes-sigs/lws/blob/main/go.mod
- [ ] SparkOperator: https://github.com/kubeflow/spark-operator/issues/2945
- [ ] AppWrapper: https://github.com/project-codeflare/appwrapper/issues/403
- [ ] Kubeflow Trainer v1: https://github.com/kubeflow/trainer/issues/3517
- [x] Kubeflow Trainer v2: already up to date: https://github.com/kubeflow/trainer/blob/master/go.mod
- [ ] MPIOperator: https://github.com/kubeflow/mpi-operator/issues/804

**Why is this needed**:

So that Kueue is not blocked updating our dependencies due to a third party project.
