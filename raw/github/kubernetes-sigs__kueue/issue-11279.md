**What happened**:
Part of LQ's API `.status.fairSharing.weightedShare` is not used anywhere. 

Currently the only fair sharing mechanism that works on LQ level is Admission Fair Sharing. However, in the API there's `weightedShare` field, which is only used by the preemption-based Fair Sharing - not implemented for LQs.

In the past we had a unified FairSharingStatus API which was not ideal. It contained both `weightedShare` and `admissionFairSharingStatus` fields. The first one was only used by LQ, and the second one only by CQ and Cohort. However, after this PR https://github.com/kubernetes-sigs/kueue/pull/7793 separated LQ's fair sharing status from CQ's/Cohort's we no longer need `weightedShare` in LQ's API
