**What happened**:
When a Node has capacity to host only one pod, and a workload has two podsets (each with one pod), it can happen that the workload is admitted by TAS.

**What you expected to happen**:
I would expect this unit test [c49b9bc](https://github.com/kubernetes-sigs/kueue/commit/c49b9bcf16252422255c82f8314bf9fc874f090d) to pass but its failing (the workload is admitted).

I think we probably should account the for these already scheduled pods of the first podset in the `addAssumedUsage` function (see the commented line in the above commit, if we uncomment it, the test will pass).
