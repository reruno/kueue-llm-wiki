## Description

The Navbar.jsx in kueueviz renders all navigation buttons in a single horizontal row with no responsive behaviour. On mobile viewports or narrow browser windows the buttons overflow and overlap the Kueue logo, making navigation unusable.
Fix is to use MUI display breakpoints to show horizontal buttons on md and above, and collapse into a hamburger menu with a dropdown on smaller screens.
