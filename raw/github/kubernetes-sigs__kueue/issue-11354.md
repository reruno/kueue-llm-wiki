## Description

When building or running the documentation site, Hugo prints the following deprecation warning:

```text
WARN  deprecated: .Language.LanguageDirection was deprecated in Hugo v0.158.0 and will be
removed in a future release. Use .Language.Direction instead.
… +20 lines
```

The documentation site should no longer use the deprecated `.Language.LanguageDirection` field. It should use `.Language.Direction` instead, so future Hugo versions do not break the build when the deprecated field is removed.
