## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

A new MultiKueue dispatcher mode (alpha, default-off feature gate
`MultiKueueCrossClusterPreemption`) that, when an incoming workload at
the manager finds sibling clusters full of borrowed work, evicts a
borrower on a sibling worker so the incoming workload can be admitted
there. Mirrors single-cluster Kueue's `ReclaimWithinCohort` cross-cluster
via the External-dispatcher extension point. Honors hierarchical cohorts,
fleet-aggregated DRS with per-CQ and per-Cohort `FairSharing.weight`, and
per-(flavor, resource) `LendingLimit`/`BorrowingLimit`. No new CRDs.

**Why is this needed**:

Operators that split workloads across per-tenant or per-environment
worker clusters need per-tenant quota guarantees that hold across
cluster boundaries. Today MultiKueue treats each worker as a black
box: a workload admits at the manager only if some worker has free
quota, and there is no mechanism to evict a sibling cluster's borrower
— even when single-cluster Kueue would do it locally via
`ReclaimWithinCohort`. A guaranteed-tier customer's workload can be
blocked indefinitely while a borrower on a sibling cluster finishes
naturally.

The closest related work, after auditing existing KEPs and issues:

- **KEP-8692 (#10766 / #10784)** — composable MultiKueue dispatcher.
  Explicitly lists *Cross-cluster preemption scheduling* under
  Non-Goals; this is the gap that work leaves open.
- **#6790** — addresses the worker → manager eviction propagation
  half. This proposal is the manager → worker initiation half. They
  coexist; neither subsumes the other.
- **KEP-8303** — independent feature gate; coordinates concurrent
  worker-side preemptions. Joint mode is supported (validated by
  integration test).

**Completion requirements**:

This enhancement requires the following artifacts:

- [ ] Design doc (KEP)
- [ ] API change: new dispatcher mode constant in
      `Configuration.MultiKueue.DispatcherName`; new feature gate
      `MultiKueueCrossClusterPreemption`.
- [ ] Docs update.

Working alpha prototype with 18 unit tests + 5 integration scenarios:
[`up/multikueue-cross-cluster-preemption`](https://github.com/ningziwen/kueue/tree/up/multikueue-cross-cluster-preemption).
