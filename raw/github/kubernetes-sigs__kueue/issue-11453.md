## Description

**What happened**:

The AllAtOnce dispatcher compares `group.local.Status.NominatedClusterNames, nominatedWorkers` and if they differ then it sends an update to the `group.local.Status.NominatedClusterNames`.

However, I think since `nominatedWorkers` are determined based on iterating over the map keys then there is no guarantee on their order. From the golang docs: "When iterating over a map with a range loop, the iteration order is not specified and **is not guaranteed to be the same from one iteration to the next.**": https://go.dev/blog/maps

So, I think we should sort the list of `nominatedWorkers` before comparing or setting.

**What you expected to happen**:

Requests are only set if the "set" of workers is changed.
