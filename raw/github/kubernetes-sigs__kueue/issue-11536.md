**What would you like to be cleaned**:

I would like to improve execution time for CI for integration tests.

Currently we have two shards "baseline" and "extended", each taking around 25min. The proposal is to introduduce a third shard. That would improve the runtime of a single shard to around 18min probably (TBD)

**Why is this needed**:

Integration tests are currently the longest for CI jobs, their performance is important because:
1. practically speaking for most features they are the most useful type of tests to be executed on CI. For unit tests you can quickly run all in IDE, for e2e they are rarely affected, but integration tests are picking often on non-trivial interactions - so quick feedback is very useful for developers
2. as the longest raking jobs they impact the release process
