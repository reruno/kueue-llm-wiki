## Description

I was going through the kueueviz frontend code and tested a few error states. When a WebSocket error event gets passed to ErrorMessage.jsx the whole component crashes. I looked into it and the component is calling error.split('\n') directly which only works if error is a plain string. If anything else gets passed in like an actual Error object or a WebSocket event, split is not a function on it and it throws.
I think the fix is to check what type error is first and convert it to a string before calling split. I would like to pick this up if no one else is working on it.
