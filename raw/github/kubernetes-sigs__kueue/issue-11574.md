## Description

I was looking at useWebSocket.js and noticed the onmessage handler calls JSON.parse(event.data) with nothing around it. I tested this by sending a plain text message and the UI just froze completely. If the server sends anything that is not valid JSON like a ping or an empty frame it throws and takes down the whole UI with it.
I think wrapping it in a try catch and setting an error state in the catch block would fix this. Happy to open a PR if this is not being worked on.
