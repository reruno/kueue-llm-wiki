The Prow timeline also shows that `should allow to preempt the lower priority group` was running in the same time window, which matches the root cause fixed by #11572: the preemption test used Kubernetes `PriorityClass`, allowing native scheduler preemption to interfere with unrelated pod group tests.

#11572 replaced the test-only Kubernetes `PriorityClass` usage with Kueue `WorkloadPriorityClass`, and it has also been cherry-picked to `release-0.17` via #11601. So the root cause for this issue should be covered by the existing fix.

so, closing as fixed by #11572 / #11601. @mimowo
