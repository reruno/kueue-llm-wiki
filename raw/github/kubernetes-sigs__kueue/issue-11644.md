**What would you like to be added**:
We would like to be able to breakdown by flavor the next metrics:
a) `kueue_admitted_active_workloads`
b) `kueue_pending_workloads`

**Why is this needed**:
This ask comes from customer wanting to measure pending demand on Kueue scheduler stratified by flavor. This is because mixed flavor workloads are sent to Kueue at the moment.
