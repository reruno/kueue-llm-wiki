## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

I would like to make the `pull-kueue-test-e2e-k8s-main-was` fully on-demand 

Currently the CI job runs on PRs which did't opt-for it, eg https://github.com/kubernetes-sigs/kueue/pull/11575

We could just make it opt-in, so that people who need it can comment on their PR: 
`/test pull-kueue-test-e2e-k8s-main-was`

I checked with LLMs and they say removing `skip_if_only_changed` from their config should do the trick

**Why is this needed**:

Even though the Job is not blocking merges, but:
- it is a resource-intensive job, grabbing machines from other previous CI jobs
- it might be confusing for people who are not very familiar with CI jobs (I was confused intiailly)
