**What would you like to be cleaned**:

We need to stabilize the build. Ideally if we solve all the pending flakes.

The list of flakes: https://github.com/kubernetes-sigs/kueue/issues?q=is%3Aissue%20state%3Aopen%20label%3Akind%2Fflake


Sometimes the failures are outside of our control, like transient network issues (GH, dockerhub, etc connectivity). I think we can still mitigate the problems by retries.

**Why is this needed**:

The project is going to continue growing and getting new features (and we will have many like WAS-integration, MultiKueue, DRA, TAS) only if we make development smooth.
