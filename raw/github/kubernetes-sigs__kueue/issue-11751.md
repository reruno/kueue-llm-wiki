## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

I would like to rewrite the existing e2e tests for TAS Node HotSwap to use k8s Job instead of JobSet and move them to the baseline suite.

These test anyway are using only 1 replica, and only change parallelism.

The tests: https://github.com/kubernetes-sigs/kueue/blob/main/test/e2e/tas/extended/hotswap_test.go

**Why is this needed**:

* The "extended" suite for TAS is one of the longest suites, while "baseline" is very fast. This is because extended requires installation of all integrations. This way we can have better time balance.
* Testing locally is faster.
