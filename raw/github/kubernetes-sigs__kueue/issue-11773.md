**What would you like to be cleaned**:

Introduce the on-demand CI job pull-kueue-test-large-scale-scheduling-perf-main based on periodic-kueue-test-large-scale-scheduling-perf-main

Follow the pattern for pull-kueue-test-e2e-k8s-main-was and periodic-kueue-test-e2e-k8s-main-was

**Why is this needed**:

To allow running the perf tests on pull request we suspect may be impacting the large-scale perf. These are usually complex PRs, so getting perf feedback after merge could result in complicated revert or hotfixing.
