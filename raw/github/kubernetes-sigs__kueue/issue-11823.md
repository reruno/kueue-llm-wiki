<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
A new ClusterQueue status field: EffectiveResourceGroups.
The field will be added alongside spec.ResourceGroups with the split of responsibilities:
* spec.ResourceGroups - manually set by the user to define ClusterQueue quota in default configuration,
* status.EffectiveResourceGroups - a field representing the de-facto quota as interpreted by the Kueue system, to be used in automated quota management configurations.

**Why is this needed**:
To accommodate MultiKueue automated quota management configuration https://github.com/kubernetes-sigs/kueue/issues/9988.

**Completion requirements**:
status.EffectiveResourceGroups implemented and used by Kueue as the source of truth on effective quota **at least for** automated quota management configurations.
