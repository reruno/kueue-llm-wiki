## Description

**What happened**:
When loading or refreshing the KueueViz dashboard, all resource and workload counters (ClusterQueues, LocalQueues, Workloads) briefly display `0` before flashing to their actual values a split-second later.

This happens because `Dashboard.jsx` unconditionally sets `loading` to `false` during the initial mount, before the WebSocket connection has retrieved any data (`kueueData` is still `null`). Additionally, `namespacesError` is used within this `useEffect` block but is missing from its dependency array.

**What you expected to happen**:
The dashboard should display a loading spinner while the WebSocket connection is pending, and only show the widgets once the data has finished loading.

**How to reproduce it (as minimally and precisely as possible)**:
1. Run KueueViz locally.
2. Navigate or refresh the Dashboard page.
3. Observe all widgets briefly show `0` before updating to their actual counts.

**Anything else we need to know?**:
The fix is to only set `loading` to `false` once `kueueData` is successfully received or if an error is encountered, and to properly add `namespacesError` to the dependency array. Happy to open a PR for this!
