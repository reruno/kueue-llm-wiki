**What would you like to be added**:
Consider ways to group workers' resource flavors together when aggregated on the manager cluster to allow for more efficient quota management at the Manager Cluster level.

**Why is this needed**:
A follow-up to https://github.com/kubernetes-sigs/kueue/issues/9988.
We want to consider possible ways to make MultiKueue quota assignment more efficient when automation is enabled, instead of defaulting to a single, global resource flavor.
