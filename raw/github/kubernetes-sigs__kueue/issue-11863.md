## Description

**What would you like to be cleaned**:

In order to allow the upgrade of k8s dependencies to 1.36 (#10936), due to a regression in k8s validation semantics (https://github.com/kubernetes/kubernetes/issues/139281), we added a hack to add a `JobSuspended = True` condition to Jobs in MultiKueue adapter (#10946, specifically [this code](https://github.com/kubernetes-sigs/kueue/blob/a4b8a8d65721a4cf47d0d12a69d849e863d359e5/pkg/controller/jobs/job/job_multikueue_adapter.go#L140-L155)).

As already state in the comment above the `if` block, this block can be removed once the k8s-side fix (https://github.com/kubernetes/kubernetes/pull/139329) is released. This fix has been already cherry-picked in k8s (https://github.com/kubernetes/kubernetes/pull/139329), and is expected in 1.36.2.

**Why is this needed**:

To avoid maintaining the hacky code.
