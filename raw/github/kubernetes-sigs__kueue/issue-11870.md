## Description

**What happened**:

Some `periodic-kueue-test-large-scale-scheduling-perf-main` runs appear to undercount workload admission latency.
- https://prow.k8s.io/view/gs/kubernetes-ci-logs/logs/periodic-kueue-test-large-scale-scheduling-perf-main/2054851762128424960
  - `averageTimeToAdmissionMs: 39715` for the large class
  - `920/4000` large workloads in `wlStates.csv` have `ms to admitted < 1000`
- https://prow.k8s.io/view/gs/kubernetes-ci-logs/logs/periodic-kueue-test-large-scale-scheduling-perf-main/2055939367192498176
  - `averageTimeToAdmissionMs: 43317` for the large class
  - `808/4000` large workloads in `wlStates.csv` have `ms to admitted < 1000`

**What you expected to happen**:

The test should report the actual time each workload spent waiting for admission.
