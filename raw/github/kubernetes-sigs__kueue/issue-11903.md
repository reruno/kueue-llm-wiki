## Context                                                                                                                                                                                                       
                                                                                                                                                                                                                   
  Two DRA sub-features are currently Alpha in Kueue 0.18:                                                                                                                                                          
  - `KueueDRAIntegrationExtendedResource` — auto-discovers DRA-backed extended resources via DeviceClass `extendedResourceName`                                                                                    
  - `KueueDRAIntegrationPartitionableDevices` — counter-based quota for partitionable devices (MIG profiles)                                                                                                       
                                                                                                                                                                                                                   
  The base `KueueDRAIntegration` gate graduated to Beta in 0.18. This issue tracks Beta graduation for the two Alpha sub-features.                                                                       
                                                                                                                                                                                                                   
  KEP: [keps/2941-DRA](https://github.com/kubernetes-sigs/kueue/tree/main/keps/2941-DRA)                                                                                                                           
                                                                                                                                                                                                                   
  ## Upstream Kubernetes Status                                                                                                                                                                                    
                                                                                                                                                                                                                   
  | K8s Feature | K8s 1.36 Status | K8s 1.37 Target |                                                                                                                                                              
  |-------------|----------------|-----------------|                                                                                                                                                               
  | `DRAExtendedResource` (KEP-5004) | Beta default-on | GA |                                                                                                                                                  
  | `DRAPartitionableDevices` (KEP-4815) | Beta default-on | Beta |                                                                                                                                                
                                                                                                                                                                                                                   
  Both upstream features are Beta default-on in K8s 1.36, making them stable enough for Kueue Beta graduation.
