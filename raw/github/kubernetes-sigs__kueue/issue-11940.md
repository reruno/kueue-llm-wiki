**What would you like to be cleaned**:

Looking at the provided logs (https://storage.googleapis.com/kubernetes-ci-logs/pr-logs/pull/kubernetes-sigs_kueue/11928/pull-kueue-test-e2e-extended-shard-0-main-1-36/2062452419870068736/artifacts/run-test-e2e-extended-1.36.1/e2e-top.yaml), the six Ray-related tests alone take about 14 minutes.

- Should run a rayjob if admitted (2m15.535954647s)
- Should run a rayservice with InTreeAutoscaling (2m0.401872899s)
- Should run a RayCluster on worker if admitted (1m12.163941139s)
