## Description

> I installed kueue-priority-booster using the following command:
> 
> ```shell
> helm upgrade -i kueue-priority-booster oci://registry.k8s.io/kueue/charts/kueue-priority-booster \
>   --namespace kueue-system \
>   --wait --timeout 300s \
>   --create-namespace
> ```
> 
> If this role is required for `kueue-priority-booster` to work properly, shouldn't it be part of the chart rather than something we need to add manually?

We can add Make target for priority booster to generate Helm charts automatically like kueue-manager: https://github.com/kubernetes-sigs/kueue/blob/728699689481048615fc6b20a42cf616be478c35/Makefile#L151-L153

But, I think that it is out of scope in this PR.
