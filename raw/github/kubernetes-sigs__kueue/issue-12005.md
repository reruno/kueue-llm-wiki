## Description

**What happened**:

TAS does not consider resources excluded by `excludeResourcePrefixes` or transformed by `transformations` when calculating node capacity.
TAS may schedule pods to nodes with insufficient remaining resources.

#8865 seems to address this issue, but TAS still ignores resources used by admitted workloads.

related: #8838 

**What you expected to happen**:

TAS should consider all resource requests of admitted workloads for node capacity tracking, including resources excluded or transformed.
