**What would you like to be added**:
kueue can support sparkapplication  dynamicAllocation  feature ,maybe kueue's ElasticJobs or other feature can support it 
**Why is this needed**:
In production environments，sparkapplication typically enable dynamic scaling (dynamicAllocation) to adapt to fluctuating task demands
**Completion requirements**:
- sparkapplication support dynamicAllocation 
- kueue waitforPodsReady just check min numbers of sparkapplication executor pod (sparkapplication.spec.executor.instances),No validation is performed for dynamically scaled-out pods.
- Dynamically scaling pods trigger Kueue queuing, while existing pods remain unaffected.
