**What would you like to be cleaned**:

The idea for test/e2e/sequential/baseline /default_config_test.go was to use `util.UpdateKueueConfigurationAndRestart(ctx, k8sClient, defaultKueueCfg, kindClusterName)` only once, for all tests in the file. 

For that we should use BeforeAll at the Describe level.

THis is follow up to https://github.com/kubernetes-sigs/kueue/pull/11373

**Why is this needed**:

- to optimize the time taken by the tests, now they run BeforeEach for each test in HA mode
- to make sure the certa and visibility server tests run under the default confguration - currently this is not ensured
