## Description

  **What happened**:

  ```
 [BeforeSuite]` in the Core Controllers integration test suite failed with `unexpected EOF` while installing CRDs onto the envtest control plane:

  unable to install CRDs onto control plane: unable to create CRD instances:
  unable to create CRD "cohorts.kueue.x-k8s.io": Post
  "https://127.0.0.1:41695/apis/apiextensions.k8s.io/v1/customresourcedefinitions": unexpected EOF
```

  **What you expected to happen**:

  CRD installation should succeed and all tests should run.

  **How to reproduce it (as minimally and precisely as possible)**:

  Not reproducible locally. Observed in CI under load: https://prow.k8s.io/view/gs/kubernetes-ci-logs/pr-logs/pull/kubernetes-sigs_kueue/11927/pull-kueue-test-integration-shard-2-main/2064813811763777536

  The PR under test (#11927) does not touch CRD installation, suite setup, or the core controller suite.

  **Anything else we need to know?**:

  The envtest API server dropped the connection (`unexpected EOF`) during a POST to create the `cohorts.kueue.x-k8s.io` CRD. This is likely resource pressure on the CI node. A retry around CRD installation in `test/integration/framework/framework.go` or an increased API server startup timeout would mitigate this.

  - Kubernetes version (use `kubectl version`): envtest (CI)
  - Kueue version (use `git describe --tags --dirty --always`): main (shard-2, job `pull-kueue-test-integration-shard-2-main`)
  - Cloud provider or hardware configuration: Prow CI
