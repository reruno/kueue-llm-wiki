## Description

MultiKueue has either KubeConfig support via Secret or Path. The safest option is to use ClusterProfile which is the recommendation for production.

The support of Path reads directly from a file and is not recommended for production.

I think we should consider deprecated Path and either require ClusterProfile or Secret.
