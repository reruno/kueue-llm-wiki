## Description

**What happened**:
I wanted to check what are available commands for running e2e tests and I found that `make help` doesn't mention e2e tests at all.

**What you expected to happen**:
`make help` should mention what are available options to run e2e tests

**How to reproduce it (as minimally and precisely as possible)**:

```bash
make help | grep e2e
```

```bash
$ make help | grep e2e

  test-e2e-kueueviz-local   Run end-to-end tests for kueueviz without running kueue tests.
  test-e2e-kueueviz         Run end-to-end tests for kueueviz without running kueue tests.
  kueue-populator-test-e2e  Run e2e tests for kueue-populator.
  verify-e2e-common-test    e2e-common shell helper tests after generation
  e2e-common-test           Run e2e-common shell helper tests.
  npm-depcheck              Verify frontend and e2e npm dependencies.
```
