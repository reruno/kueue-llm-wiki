## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**: 

Various configuration files under the E2E test suites, specifically `test/e2e/config/extended/controller_manager_config.yaml`, contain redundant configuration blocks that are duplicated across other testing files.

I would like to refactor these manifests using Kustomize (bases/patches/components) to centralize the shared fields and isolate only the environment-specific differences.

**Why is this needed**: 
* **Easy Maintainability:** If we change a common setting or flag, we currently have to update it across multiple duplicate files. Centralizing them removes this risk.
* **Reduction of Configuration Drift:** Ensures our various E2E test setups stay aligned with upstream definitions.

**Comments**:
This was briefly discussed as a fast-follow task in a recent [PR](https://github.com/kubernetes-sigs/kueue/pull/12230#discussion_r3450034261) . If the maintainers agree with using Kustomize here, I'm happy to open a PR to implement this cleanup!
