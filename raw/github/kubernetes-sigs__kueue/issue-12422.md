**What would you like to be added**:
 Track areas where the [scheduler-library](https://github.com/kubernetes-sigs/scheduler-library) can improve Kueue's admission accuracy by verifying scheduling feasibility against actual cluster state.

**Why is this needed**:
Today Kueue admits based on aggregate quota without checking whether pods can actually schedule on nodes. This causes workloads to hold quota while pods sit Pending until WaitForPodsReady times out.

  The scheduler-library gives Kueue access to the kube-scheduler's filter and score plugins in simulation mode. Different Kueue components can use different parts of it:

  - **Node resource capacity** — quota fits but no single node is big enough
  - **DRA device allocation** — counters exist but devices aren't allocatable on specific nodes
  - **Gang placement across PodSets** — quota fits for all PodSets but some can't schedule
  - **Preemption** — freed quota doesn't mean freed schedulable capacity
  - **Cordoned/unschedulable node exclusion** — not excluded from feasibility checks
