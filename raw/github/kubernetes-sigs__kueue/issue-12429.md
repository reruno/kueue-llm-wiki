**What would you like to be cleaned**:

Integration tests sometimes use ConsistentDuration to prove a workload is not admitted. I think using 300ms would be sufficient for all tests. If not, then we can introduce LongConsistentDuration=1s.

**Why is this needed**:

I think it is rather wasteful to wait 1s for most cases, because if a workload was to be admitted, then it would happen usually within 100ms.
