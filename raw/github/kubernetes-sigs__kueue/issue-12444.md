### Comment by [@mbobrovskyi](https://github.com/mbobrovskyi) — 2026-06-24T06:58:31Z

Yes, because we’re trying to fetch `KIND_VERSION` from the dependencies list before running go mod download.

https://github.com/kubernetes-sigs/kueue/blob/fefb31a40508e4447d509ed77598e1fb15e92e4b/Makefile-deps.mk#L24

This is a lazy variable, and we hit `net/http: TLS handshake timeout` when it tries to download the dependencies.

So I think we should add a `gomod-download-tools` target for each target, and add retry to `cd $(TOOLS_DIR) && $(NETWORK_INSTALL_RETRY) $(GO_CMD) mod download` to make sure the dependencies are downloaded first.
