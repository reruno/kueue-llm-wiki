**What happened**:

`make verify` fails at the `verify-skills-lint` target on macOS with:

```
  Error: preparing container ... for attach: lsetxattr .git/objects/pack/...: permission denied
  make[1]: *** [verify-skills-lint] Error 126
```
  
After getting past that error, the skillsaw container cannot write its output:

  `PermissionError: [Errno 13] Permission denied: '/out/skillsaw-summary.html'`

**What you expected to happen**:

`make skills-lint` and `make verify` should work on macOS (Darwin arm64) the same way they do on Linux.

**How to reproduce it (as minimally and precisely as possible)**:

```bash
  # On macOS with podman or docker running
  make skills-lint
  # or
  make verify
```
