## Description

## Description 
The upstream container builds pull builder and runtime base images by floating tag. A registry compromise or tag reassignment would silently alter the build output. OpenSSF Scorecard reports Pinned-Dependencies: 1/10 for kubernetes-sigs/kueue. 

Dockerfile

```
ARG BUILDER_IMAGE=golang:1.26
ARG BASE_IMAGE=gcr.io/distroless/static:nonroot
FROM --platform=${BUILDPLATFORM} ${BUILDER_IMAGE} AS builder
FROM ${BASE_IMAGE}
USER 65532:65532
```

### Fix

Pin all FROM lines to @sha256 digests and let dependabot's docker ecosystem (already configured) maintain them.
