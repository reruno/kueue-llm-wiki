## Description

## Description 
The optional KueueViz dashboard frontend (node:26-slim based) is deployed with no runAsNonRoot, no readOnlyRootFilesystem, no allowPrivilegeEscalation:false, no capability drop, and no seccompProfile — in both the kustomize base and the Helm default values. The backend kustomize base has the same gap (Helm defaults are hardened). Neither workload has liveness/readiness probes.

### Remediation

Populate the frontend Helm defaults to match the backend (runAsNonRoot: true, seccompProfile RuntimeDefault, readOnlyRootFilesystem: true, allowPrivilegeEscalation: false, drop ALL) and mirror into config/components/kueueviz/*-deployment.yaml. Add httpGet liveness/readiness probes on the serving port for both workloads.
