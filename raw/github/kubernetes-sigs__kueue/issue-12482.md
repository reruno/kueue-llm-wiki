## Description

Visibility default settings are insecure and a potential security issue.

The recommended approach for production is to use CertManager if you want secure visibility. 

https://owasp.org/www-project-kubernetes-top-ten/2022/en/src/K06-broken-authentication

## Fix

Flip the default: enable the apiservice_insecure_removal.yaml + apiservice_cainjection_patch.yaml patches in config/default/kustomization.yaml and set Helm enableCertManager default to true (or use the internal cert controller to populate spec.caBundle)
