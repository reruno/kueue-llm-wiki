### Comment by [@reruno](https://github.com/reruno) — 2026-06-25T10:33:58Z

I think the problem is how we parse the RAY_VERSION from the hack/testing/ray/Dockerfile file
Makefile
```
RAY_VERSION := $(shell grep '^FROM' "${TESTING_DIR}/ray/Dockerfile" | cut -d: -f2)
```

hack/testing/ray/Dockerfile file
```
FROM rayproject/ray:2.55.1@sha256:830824adfdac9a8ec241f19a4ebab4db92092301781c21b1b720c2d08b8264eb
```

Maybe we should update the parsing logic of ray version in makefile and it will fix this problem
