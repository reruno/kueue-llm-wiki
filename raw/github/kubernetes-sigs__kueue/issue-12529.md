## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
A user with privileges to manage `Cohort` objects (or an attacker compromising such an account) can permanently deadlock the Kueue controller by applying a cyclic hierarchy. Because the deadlock occurs within a periodic routine holding the cache's Read Lock (`RLock()`), all cluster workload admission, requeuing, and queue updates halt entirely, causing a severe, persistent Denial of Service.

### Data Flow
- **pkg/cache/scheduler/cache.go:534**: c.hm.UpdateCohortEdge updates the internal hierarchy manager graph with the user-provided Cohort parent, potentially creating a cycle.
- **pkg/cache/scheduler/cache.go:535**: cohort.updateCohort() checks for cycles and returns ErrCohortHasCycle if one is detected.
- **pkg/cache/scheduler/cache.go:537**: The function returns early on error WITHOUT reverting the edge created in step 1, persisting the cyclic graph in the controller's memory.
- **pkg/cache/scheduler/clusterqueue.go:503**: During Workload updates or periodic ResyncGaugeMetrics, reportActiveWorkloads() iterates c.Parent().PathSelfToRoot() with no cycle protection, leading to an infinite loop that permanently hangs the controller.

### Reproduction
**Preconditions**: Kueue controller must be deployed and running.
**Steps**:
1. Create a `Cohort` named 'cohort-b'.
2. Create a `Cohort` named 'cohort-a' with `spec.parentName: cohort-b`.
3. Create a `ClusterQueue` named 'cq1' with `spec.cohortName: cohort-a`.
4. Update 'cohort-b' to have `spec.parentName: cohort-a`, creating a cycle.
5. Wait for the Kueue controller's periodic metrics routine (`ResyncGaugeMetrics`) to execute (within 1 minute), or trigger a workload event.

### Vulnerable Code
```
534: 	c.hm.UpdateCohortEdge(cohortName, apiCohort.Spec.ParentName)
535: 	err := cohort.updateCohort(apiCohort, oldParent)
536: 	if err != nil {
537: 		return err
538: 	}
```

### Remediation
Revert the graph edge in the Hierarchy Manager if `cohort.updateCohort` returns an error, and additionally protect `reportActiveWorkloads` from cycles.

Suggested Fix:
```go
	// In pkg/cache/scheduler/cache.go
	err := cohort.updateCohort(apiCohort, oldParent)
	if err != nil {
		// Revert the edge
		if oldParent != nil {
			c.hm.UpdateCohortEdge(cohortName, oldParent.GetName())
		} else {
			c.hm.UpdateCohortEdge(cohortName, "")
		}
		return err
	}
```
Similar protection should be added in `pkg/cache/queue/manager.go`.
