## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
An attacker who claims the `mpijob` package on PyPI can achieve arbitrary code execution on the machines of users or CI/CD pipelines that attempt to run the provided example and install the missing dependency. This can lead to the compromise of Kubernetes credentials (`kubeconfig`) and other sensitive local data.

### Data Flow
- **site/static/examples/python/sample-mpijob.py:5**: The example script instructs Python to import the `mpijob` package.
- **site/static/examples/python/requirements.txt**: The `mpijob` package is not listed in `requirements.txt` and is not a built-in Python module.
- **PyPI Package Registry**: The `mpijob` package namespace is unregistered on PyPI and can be claimed by an attacker.
- **Victim Environment**: When a user runs the script, encounters a `ModuleNotFoundError`, and runs `pip install mpijob` to resolve it, the attacker's malicious code is executed.

### Reproduction
**Preconditions**: A Python environment with `pip` installed. The `mpijob` package must not be locally defined or installed.
**Steps**:
1. Run `python site/static/examples/python/sample-mpijob.py`.
2. Observe the `ModuleNotFoundError: No module named 'mpijob'` error.
3. Note that `mpijob` is missing from `requirements.txt`.
4. Verify on PyPI that the `mpijob` package namespace is currently unclaimed (e.g., curling `https://pypi.org/pypi/mpijob/json` returns a 404).
5. An attacker can register this package with a malicious `setup.py` that executes upon installation.

### Vulnerable Code
```
import mpijob.models as models
```

### Remediation
Remove the unregistered `mpijob` import and replace it with the officially maintained SDK package, or vendor the necessary CRD models locally.

Suggested Fix:
```
Replace `import mpijob.models as models` with the correct official SDK (e.g., `from kubeflow.training import models` if applicable) and update `requirements.txt` to include the verified dependency.
```
