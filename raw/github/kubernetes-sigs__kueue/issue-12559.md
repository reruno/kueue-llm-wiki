## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
A single malformed Pod (lacking labels) in a target namespace can persistently crash the Kueue importer tool, effectively creating a Denial of Service (DoS) that prevents administrators from importing any Pods in that namespace.

### Data Flow
- **cmd/importer/pod/process.go:68**: ListPods fetches Pod objects from the Kubernetes API. Pods without labels have their Labels map set to nil.
- **cmd/importer/pod/import.go:63**: oldLq, found := p.Labels[controllerconstants.QueueLabel] evaluates safely on a nil map, setting found to false.
- **cmd/importer/pod/import.go:65**: Because found is false, addLabels(...) is called with the uninitialized p.Labels map.
- **cmd/importer/pod/import.go:118**: Assignment to the nil p.Labels map causes a runtime panic, crashing the importer CLI tool.

### Reproduction
**Preconditions**:
The Kueue importer configuration matches Pods using a method that doesn't strictly require labels (e.g., matching via priorityClassName in a mapping file). A Kubernetes namespace exists to run the importer against.

**Steps**:
1. Create a Pod in the target namespace that has the required priorityClassName but explicitly omit all metadata.labels.
2. Execute the importer CLI tool against the namespace (e.g., importer import --namespace default --queuemapping-file mapping.yaml).
3. The Check phase will validate the Pod successfully because read operations on a nil map are safe.
4. The Import phase will attempt to attach the queue label to the Pod and panic.

### Vulnerable Code
```
p.Labels[controllerconstants.QueueLabel] = queue
```

### Remediation
Initialize the Pod's Labels map if it is nil before attempting to add or copy labels into it.

Suggested Fix:
```
func addLabels(ctx context.Context, c client.Client, p *corev1.Pod, queue string, addLabels map[string]string) error {
	if p.Labels == nil {
		p.Labels = make(map[string]string)
	}
	p.Labels[controllerconstants.QueueLabel] = queue
	p.Labels[constants.ManagedByKueueLabelKey] = constants.ManagedByKueueLabelValue
	maps.Copy(p.Labels, addLabels)
```
