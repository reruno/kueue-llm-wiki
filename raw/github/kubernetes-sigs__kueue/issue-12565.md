## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
Users relying on `--dry-run` to safely preview changes, test RBAC permissions, or validate scripts will unintentionally mutate production state. This can lead to unwanted workloads being admitted or stopped, causing resource exhaustion or disruption of critical jobs.

### Data Flow
- **cmd/kueuectl/app/resume/resume.go:41**: The --dry-run flag is added to the resume command globally via flags.AddDryRunFlag(cmd)
- **cmd/kueuectl/app/resume/resume_localqueue.go:131**: In the Run method for localqueue, an empty metav1.PatchOptions{} is instantiated
- **cmd/kueuectl/app/resume/resume_localqueue.go:137**: The empty PatchOptions (missing the DryRun field) is passed to the Patch API call, mutating the server state regardless of the user's --dry-run flag

### Reproduction
**Preconditions**:
The user must have a Kueue LocalQueue configured and running on the cluster. The user must also have kueuectl installed and configured to connect to the cluster.

**Steps**:
1. Create a LocalQueue named 'test-queue'.
2. Hold/Stop the LocalQueue.
3. Run `kueuectl resume localqueue test-queue --dry-run=client` or `--dry-run=server`.
4. Observe that despite the dry-run flag, the LocalQueue is actually resumed on the cluster.

### Vulnerable Code
```go
opts := metav1.PatchOptions{}
	patch := client.MergeFrom(lqOriginal)
	data, err := patch.Data(lq)
	if err != nil {
		return err
	}
	lq, err = o.Client.LocalQueues(o.Namespace).
		Patch(ctx, o.LocalQueueName, types.MergePatchType, data, opts)
```

### Remediation
Retrieve the dry-run strategy from the command options and populate the `PatchOptions.DryRun` field appropriately, or return early if the strategy is `client`.

Suggested Fix:
```go
Add a DryRunStrategy field to LocalQueueOptions, populate it in Complete() using dryrun.GetStrategy(cmd), and in Run():
if o.DryRunStrategy != dryrun.Client {
    opts := metav1.PatchOptions{}
    if o.DryRunStrategy == dryrun.Server {
        opts.DryRun = []string{metav1.DryRunAll}
    }
    // ... perform patch ...
}
```
