## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
An attacker with permissions to manage workloads or queues, or simply an edge-case system state, can cause a persistent Denial of Service (DoS) for the Kueueviz dashboard. Administrators attempting to view the affected queues will experience a complete UI crash, hindering their ability to monitor and manage the system.

### Data Flow
- **apis/kueue/v1beta2/localqueue_types.go:117**: Kueue API defines `Resources []LocalQueueResourceUsage` with the `json:"resources,omitempty"` tag.
- **cmd/kueueviz/backend/handlers/api_handlers.go:78**: The backend API marshals the Kueue resource. Due to `omitempty`, if the `resources` array for a flavor is empty, it is entirely omitted from the JSON output.
- **cmd/kueueviz/frontend/src/LocalQueueDetail.jsx:93**: The frontend receives the parsed WebSocket message. `queue.status.flavorsUsage` contains a flavor object that lacks the `resources` property, making it `undefined`.
- **cmd/kueueviz/frontend/src/FlavorTable.jsx:33**: The `FlavorTable` component invokes `.map()` directly on `flavor.resources` without optional chaining. This throws a TypeError and crashes the React component tree.

### Reproduction
**Preconditions**:
1. The Kueueviz backend and frontend must be running.
2. A LocalQueue or ClusterQueue must exist where a flavor has been recorded in `status.flavorsUsage` or `status.flavorsReservation`, but the `resources` slice for that flavor is empty.

**Steps**:
1. Intercept the WebSocket message for a LocalQueue or manually manipulate a LocalQueue object in Kubernetes to have an empty `resources` list inside `status.flavorsUsage`.
2. Navigate to the Kueueviz dashboard and open the detail page for the affected LocalQueue.
3. Observe that the dashboard crashes completely, displaying a white screen, and the browser console logs a `TypeError`.

```go

```

### Remediation
Use optional chaining (`?.`) when mapping over the `resources` array to safely handle cases where it is `undefined`.

Suggested Fix:
```go

```
