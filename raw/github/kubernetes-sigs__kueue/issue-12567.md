## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
Users can execute arbitrary code in the cluster via the submitter pod on nodes that should be restricted to them (e.g., bypassing node-based tenant isolation or GPU quota restrictions) because Kueue fails to persist the admission constraints.

### Data Flow
- **pkg/controller/jobs/rayjob/rayjob_controller.go:275**: When SubmitterPodTemplate is nil, getSubmitterTemplate returns a new, unattached PodTemplateSpec object.
- **pkg/controller/jobs/rayjob/rayjob_controller.go:219**: RunWithPodSetsInfo calls getSubmitterTemplate and receives this local, unattached struct.
- **pkg/controller/jobs/rayjob/rayjob_controller.go:221**: podset.Merge applies Kueue's admission constraints (nodeAffinity, tolerations, etc.) to the local struct.
- **pkg/controller/jobs/rayjob/rayjob_controller.go:224**: The function returns without assigning the mutated struct back to j.Spec.SubmitterPodTemplate, causing the constraints to be lost.

### Reproduction
**Preconditions**:
1. Kueue and Kuberay are installed.
2. A LocalQueue and ClusterQueue are configured with strict NodeAffinity or Tolerations that restrict where workloads can run.

**Steps**:
1. Submit a RayJob with `submissionMode: K8sJobMode` and leave `submitterPodTemplate` undefined.
2. Wait for Kueue to admit the Workload.
3. Inspect the created RayJob resource and the resulting submitter Job.

### Vulnerable Code
```go
submitterPod := getSubmitterTemplate(j)
info := podSetsInfo[expectedLen-1]
if err := podset.Merge(&submitterPod.ObjectMeta, &submitterPod.Spec, info); err != nil {
	return err
}
```

### Remediation
Persist the generated submitter template back to the RayJob spec.

Suggested Fix:
```go
if j.Spec.SubmissionMode == rayv1.K8sJobMode {
	submitterPod := getSubmitterTemplate(j)
	info := podSetsInfo[expectedLen-1]
	if err := podset.Merge(&submitterPod.ObjectMeta, &submitterPod.Spec, info); err != nil {
		return err
	}
	if j.Spec.SubmitterPodTemplate == nil {
		j.Spec.SubmitterPodTemplate = submitterPod
	}
}
```
