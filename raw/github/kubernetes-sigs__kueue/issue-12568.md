## Description

_Note: This issue was initially flagged by an automated AI security scan and has been manually triaged by a human_

### Impact
An attacker with pod creation permissions can deliberately crash the administrator's importer tool by exploiting the race window between the Check and Import phases, hindering cluster administration and migrations.

### Data Flow
- **cmd/importer/main.go:132**: pod.Check is called, running ListPods to enumerate existing pods and safely verifying that their corresponding ClusterQueues exist in the cache.
- **cmd/importer/main.go:140**: pod.Import is called, which invokes ListPods AGAIN, fetching a completely fresh list of Pods.
- **cmd/importer/pod/import.go:90**: For any Pod created between the Check and Import phases, Import blindly indexes importCache.ClusterQueues without verifying if the key exists, relying on the stale Check validation.
- **cmd/importer/pod/import.go:176**: If the new Pod points to a LocalQueue with an invalid/missing ClusterQueue, the cache returns nil. The nil pointer is passed into admitWorkload, where cq.Name triggers a panic.

### Reproduction
**Preconditions**:
A LocalQueue exists that targets a non-existent ClusterQueue (e.g., the ClusterQueue was deleted). The importer tool configuration maps a label to this LocalQueue.

**Steps**:
1. Start the importer tool against the namespace.
2. Once the initial `Check` phase completes its pod listing but before the `Import` phase processes pods, rapidly create a new Pod matching the flawed LocalQueue.
3. The `Import` phase will list the newly created Pod.
4. The code retrieves the LocalQueue from cache but finds a `nil` ClusterQueue, passing it to `admitWorkload` where it panics on dereference.

### Vulnerable Code
```go
if err := admitWorkload(ctx, c, wl, importCache.ClusterQueues[string(lq.Spec.ClusterQueue)]); err != nil {
```

### Remediation
Validate the existence of the ClusterQueue in the cache during the Import phase, instead of relying on the temporally-disconnected Check phase.

Suggested Fix:
```go
cq, ok := importCache.ClusterQueues[string(lq.Spec.ClusterQueue)]
if !ok {
	return false, fmt.Errorf("cluster queue not found in cache: %s", lq.Spec.ClusterQueue)
}
if err := admitWorkload(ctx, c, wl, cq); err != nil {
```
