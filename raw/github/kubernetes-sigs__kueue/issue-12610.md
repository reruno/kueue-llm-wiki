## Description

**What would you like to be documented or improved**:

The example `shared-quota-sample-job.yaml` runs a timed sleep using `args: ["sleep", "300"]` with the `agnhost:2.53` image. However, `agnhost` does not have a `sleep` subcommand. Without an explicit `command` override, Kubernetes runs `/agnhost sleep 300`, which immediately crashes the Pod with:

```
Error: unknown command "sleep" for "app"
```

The fix is to override the entrypoint so the shell's built-in `sleep` is used instead:

```yaml
command: ["/bin/sh"]
args: ["-c", "sleep 300"]
```

**Steps to reproduce**:
1. Apply the example: `kubectl create -f site/static/examples/admin/shared-quota-sample-job.yaml`
2. Observe the Pod enters an `Error` state
3. Check logs: `kubectl logs <pod-name>` → `Error: unknown command "sleep" for "app"`
