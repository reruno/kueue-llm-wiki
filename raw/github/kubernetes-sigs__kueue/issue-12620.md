**What would you like to be cleaned**:

Deprecate and eventually drop the Kubeflow trainer V1 integration. 

The remainig question is **when** we drop the support. I believe tentatively 0.20 is ok, but we may re-consider based on user feedback.

**Why is this needed**:

Kubeflow Trainer v1 itself is no longer maintained: https://www.kubeflow.org/docs/components/trainer/legacy-v1/, and so it no longer receives dependency updates which puts Kueue at risk, see discussion in https://github.com/kubernetes-sigs/kueue/issues/11273
