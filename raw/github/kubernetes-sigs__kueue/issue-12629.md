## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
Expand the Custom Metric Labels mechanism (KEP-7066) for workload labels.

**Why is this needed**:
To allow breaking down workload metrics by custom labels. This will allow metrics like: `kueue_admitted_active_workloads ` or `kueue_pending_workloads ` to provide summaries broken down by e.g. flavor or priority, by setting them as values of workload labels.

**Completion requirements**:

* KEP-7066 is amended to include Workload Labels,
* Support for custom metric labels is added to at least the following metrics:
   - [ ] `kueue_admitted_active_workloads `
   - [ ] [optional] `kueue_pending_workloads`

This enhancement requires the following artifacts:

- [ ] Design doc
- [ ] API change
- [ ] Docs update
