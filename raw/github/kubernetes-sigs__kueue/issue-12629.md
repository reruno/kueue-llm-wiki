<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
Expand the Custom Metric Labels mechanism (KEP-7066) for workload labels.

**Why is this needed**:
To allow breaking down workload metrics by custom labels. This will allow metrics like: `admitted_active_workloads ` or `kueue_pending_workloads ` to provide summaries broken down by e.g. flavor or priority, by setting them as values of workload labels.

**Completion requirements**:

* [x] KEP-7066 is amended to include Workload Labels,
* [x] POC: Support for workload custom metric labels is added to `kueue_admitted_active_workloads `
* [ ] Cluster queue metrics support:
   - [x] `pending_workloads`: https://github.com/kubernetes-sigs/kueue/issues/13586
   - [ ] `workloads_admitted_total`: https://github.com/kubernetes-sigs/kueue/issues/13589
 * [x] Local queue metrics support:
