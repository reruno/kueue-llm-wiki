## Description

We would like to build a Grafana dashboard to monitor Kueue pending workloads following the official documentation:

https://kueue.sigs.k8s.io/docs/tasks/manage/monitor_pending_workloads/pending_workloads_in_grafana/

However, the guide assumes that Grafana is deployed inside the Kubernetes cluster, where it can directly access the Kubernetes API using the Infinity datasource.

Our setup is different:

- We use Grafana Cloud with Prometheus as the datasource.
- We already use Kueue metrics such as kueue_pending_workloads in our existing dashboards.

The Prometheus metrics provide the number of pending workloads, but they do not expose the information available through the Visibility API, such as the position of each workload in the ClusterQueue/LocalQueue.

Is there a recommended way to build the equivalent dashboard when using Grafana Cloud? Specifically, is there a supported approach for exposing the Kueue Visibility API to Grafana Cloud, or is there another recommended solution for visualizing pending workload positions?
