## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

A script which collects execution times from successful builds and sets the perf test thresholds accordingly.

I imagine it would fit the normal distribution (mean, std dev), and propose the threshold corresponding to some low percentile, say that only 1 in million builds would fail by a random chance.

Currently the perf tests are calibrated semi manually - people check a couple of last builds and set the value based on mean + some movable value.

**Why is this needed**:

To automate the process of setting thresholds for perf tests.
