**What would you like to be cleaned**:

Decomission the RayService DeferRayServiceFinalizationForRedisCleanup  fix with a more generic fix for FinishOrphanedWorkloads

See discussion under the PR: https://github.com/kubernetes-sigs/kueue/pull/12778

**Why is this needed**:

To avoid the solution based on Skip which has two issues:
1. it is not generic, and some other integrations could be affected by premature workload deletion too
2. it may be problematic in the future if the RayService needs to execute some code while the RayService is being deleted
