## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

Currently we use the following:

```golang
	ConsistentDuration      = 1 * time.Second
	ShortConsistentDuration = 100 * time.Millisecond
```
Waiting 1s is really too long as most controllers would make the change in just 10ms actually. Maybe this is needed for some very slow controllers. I would like to propose:
```golang
        LongConsistentDuration = 1100 * time.Millisecond 
	ConsistentDuration      = 300 * time.Millisecond
	ShortConsistentDuration = 100 * time.Millisecond
```
We may also introduce `        LongConsistentDuration = 1100 * time.Millisecond` in cases where the controller may use 1s backoff / requeue delay. TBD

**Why is this needed**:

To optimize the build times, without compromising the test coverage.
