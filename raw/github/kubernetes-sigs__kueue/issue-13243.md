**What would you like to be added**:

Support Ray autoscaling for MultiKueue.

**Why is this needed**:

> Context: I am trying to implement Ray autoscaling support for MultiKueue in my fork to unblock our use cases.

https://github.com/kubernetes-sigs/kueue/pull/12885 adds support for propagating manager-driven elastic RayCluster worker replicas from the manager cluster to the worker cluster. At the same time, it also sets `enableInTreeAutoscaling` to nil when the manager cluster copies the spec to the worker cluster and states:

> Because scaling is manager-driven, the remote copy must not run the in-tree Ray
autoscaler (which would otherwise fight the manager by editing replicas on the
worker cluster); the adapter clears enableInTreeAutoscaling on the remote copy
of an elastic RayCluster.

However, manager-driven pattern blocks the use cases of Ray autoscaling (e.g. online / offline inference, colocate training / eval in the same RayCluster).
