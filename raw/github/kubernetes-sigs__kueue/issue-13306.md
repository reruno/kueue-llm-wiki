## Description

**What would you like to be added**:
A KEP for `scheduler-library` and WAS integrations in Kueue.

**Why is this needed**:
We managed to finish the most basic node-only integration with `scheduler-library` for 0.19 and I think it's high time to create a document where we can create a shared vision of what's going to happen in this area.

There are many WAS-related workstream currently open and in general I think we should streamline the communication around that (beyond the umbrella issue https://github.com/kubernetes-sigs/kueue/issues/8871).

**Completion requirements**:
- A KEP is written that describes the already merged integrations, the open initiatives in the community and outlines the north-star vision of WAS in Kueue.

- [x] Design doc
