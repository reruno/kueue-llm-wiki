### Comment by [@mbobrovskyi](https://github.com/mbobrovskyi) — 2026-07-22T16:15:08Z

We already have the pull-requests: write permission configured for this job:
https://github.com/kubernetes-sigs/kueue/blob/624849c9e07329b6dd64da6e327f3c7156da39a7/.github/workflows/release-utils.yml#L461

So I suspect this is caused by a restriction in the repository settings.

Gemini propose:

1. Enable the Repository Setting
  - Go to your repository home page on GitHub.
  - Click Settings (top navigation tab).
  - In the left sidebar, click Actions → General.
  - Scroll down to Workflow permissions.
  - Check the box for "Allow GitHub Actions to create and approve pull requests".
  - Click Save.
