## Description

## Summary

Add a reviewer skill that detects cases where a Go `context.Context` parameter is deliberately silenced (for example, `_ = ctx`) rather than being used for structured logging or propagated to context-aware operations.

## Rationale

The `ctx-structured-logging` skill entry was removed from the reviewer skills index. Retaining equivalent guidance would help reviews identify missed opportunities to preserve request/reconciliation context in logs and downstream calls, while allowing intentional exceptions to be documented.

## Affected areas

- `cmd/experimental/skills/reviewer/`
- `cmd/experimental/skills/reviewer/README.md`

## Proposed behavior

Document a reviewer skill that:
- flags `_ = ctx` (and equivalent unused-context suppression) in relevant Go code;
- asks whether the context should be passed to context-aware APIs or used for structured logging;
- avoids reporting cases where intentionally discarding the context is necessary and clearly justified.

## Acceptance criteria

- A new skill document describes the trigger, rationale, review guidance, and known exceptions.
- The skill is listed in `cmd/experimental/skills/reviewer/README.md`.
- The guidance is specific enough to avoid treating every unused context parameter as an automatic defect.
