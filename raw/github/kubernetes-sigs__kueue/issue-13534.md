## Description


**What would you like to be added**:

After https://github.com/kubernetes-sigs/kueue/pull/13261 I would like to add tests: (unit and e2e, separate PRs for sure, which demonstrate the new integration brings value already.

I think we should already see difference in these scenarios:
1. Workload has Pods requesting "hostPort" conflicting with some other Pods on a Node
2. DRA can avoid Nodes which don't meet the requested claim precisely. For example we skip nodes which don't have enough mem left.

part of https://github.com/kubernetes-sigs/kueue/issues/10548

**Why is this needed**:

For now the existing tests show that the SchedulerLibrary is on par with build-in Kueue TAS, but we could show that the new integration brings more accurate assignments already.
