## Description

**What would you like to be added**:

After https://github.com/kubernetes-sigs/kueue/pull/13261 we now have a basic integration of TAS and WAS.

I think it is time to start perf testing. I would like to see:
1. unit test Benchmark https://github.com/kubernetes-sigs/kueue/issues/13148 adopted to the library, as tested in the PR actually https://github.com/kubernetes-sigs/kueue/pull/13261#issue-4937456117, but make it easily selectable (maybe two benchmark cases based on the FG)?
2. a new config in https://github.com/kubernetes-sigs/kueue/tree/main/test/performance/scheduler/configs, we could call it "tas_was" for example

This is part of https://github.com/kubernetes-sigs/kueue/issues/8871

**Why is this needed**:

To learn about performance of Kueue-TAS and Kueue-TAS-WAS.

TAS is perfomance critical so we need to see how much slower it gets, and which parts require optimizations
