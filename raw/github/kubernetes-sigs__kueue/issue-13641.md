## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
Add support for custom StatefulSet resizing (e.g., scaling replicas from 3 to 5) while preserving job queueing semantics, resolving the TODO in `pkg/controller/jobs/statefulset/statefulset_webhook.go`.

**Why is this needed**:
Currently, Kueue's StatefulSet webhook only allows scaling down to zero (suspending) or scaling up from zero (resuming). Distributed inference or data processing workloads often use StatefulSets and need the ability to dynamically resize (scale out/in) without being fully suspended and requeued from zero. (This touches on the gap identified in issue #3279).
