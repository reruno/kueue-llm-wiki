## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

Global Scheduler Configuration API. 

As the fundational work I expect configuration to:
- PrioritySortingWithinCohort - we cannot drop it as this would break some envs: https://github.com/kubernetes-sigs/kueue/issues/9402
- Interval for async requeue of inadmissible workloads - currently 1s but this is too fast for large deployments, to compensate for the recently dropped https://github.com/kubernetes-sigs/kueue/pull/14089

**Why is this needed**:

To allow configuring scheduler behavior on large deployments without feature gates. This will allow to stop using Feature gates as configuration knobs.

### Comment by [@apullo777](https://github.com/apullo777) — 2026-08-12T01:57:24Z

Yes, I think refill is a good concrete consumer for this. #13729 already has `defaultRefillBudget = 8` with a TODO to move it into the Kueue Configuration API, so there's a real knob waiting for it.

And +1 to @kannon92's point about real defaults. @amy already asked for a 0/2/4/8 budget sweep with cycle-time measurements on #13729, so that should give us some data to choose the default rather than guessing.

One API question I'd keep in mind: the refill budget is currently a single per-cycle count, so one cohort's backlog can consume all of it before others get a chance. I don't think #13729 needs to solve that, but if this becomes a public config field, this seems like the right place to decide whether a single global value is the API we want or whether it eventually needs some scope.
