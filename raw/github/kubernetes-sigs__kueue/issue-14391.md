## Description

**What would you like to be cleaned**:

I added `scheduler-library` integration enabled TAS tests as a Makefile target some time ago:
https://github.com/kubernetes-sigs/kueue/blob/0e28ec3c0b3fcebbee52799e46683eeb9aae8598/hack/make/test.mk#L318-L341

The extended tests are already sharded the same way as the regular TAS tests.

We should add them to the presubmits (especially since now there's a lot more traction in that part of the codebase). For reference, [here](https://github.com/kubernetes/test-infra/blob/be53e5885863880b05e87ebf166957fe84ee58ee/config/jobs/kubernetes-sigs/kueue/kueue-presubmits-main.yaml#L942-L1064) is the current TAS test setup for presubmits on main.

We should also add this to the [presubmits](https://github.com/kubernetes/test-infra/blob/be53e5885863880b05e87ebf166957fe84ee58ee/config/jobs/kubernetes-sigs/kueue/kueue-presubmits-release-0-19.yaml) and [periodics](https://github.com/kubernetes/test-infra/blob/be53e5885863880b05e87ebf166957fe84ee58ee/config/jobs/kubernetes-sigs/kueue/kueue-periodics-release-0-19.yaml) for release 0.19 (not 0.18, because this feature is not present on 0.19).

**Why is this needed**:

To catch regressions.
