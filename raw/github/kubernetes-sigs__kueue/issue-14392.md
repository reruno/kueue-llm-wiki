## Description

**What would you like to be added**:

The `FailureRecoveryPolicy` is in alpha for quite a while now, while being in use by multiple parties. The feature is clearly useful.

Currently the feature hinges on a single label:
https://github.com/kubernetes-sigs/kueue/blob/0e28ec3c0b3fcebbee52799e46683eeb9aae8598/pkg/controller/constants/constants.go#L61-L62

And hard-codes the timeout to 1 minute:
https://github.com/kubernetes-sigs/kueue/blob/0e28ec3c0b3fcebbee52799e46683eeb9aae8598/pkg/controller/failurerecovery/pod_termination_controller.go#L97

Before graduating, we should understand what level of configurability is required.

**Why is this needed**:

To progress the feature's maturity.
