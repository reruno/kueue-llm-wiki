## Description

**What would you like to be added**:

Add Kubernetes 1.37 to the e2e (and envtest) test matrix once a `kindest/node:v1.37.x` image is published.

When the image exists, this is: add `1.37.<patch>` to `E2E_K8S_VERSIONS` in `hack/make/test.mk`, bump `E2E_KIND_VERSION` in `hack/testing/e2e-common_test.sh`, optionally move `E2E_K8S_VERSION`/`ENVTEST_K8S_VERSION` to `1.37`, extend the support matrix in `README.md`, and add the matching `-main-1-37` presubmit/periodic jobs in kubernetes/test-infra.

**Why is this needed**:

The matrix currently stops at 1.36 (`E2E_K8S_VERSIONS ?= 1.34.8 1.35.5 1.36.1`), so nothing exercises Kueue against 1.37. 1.37 is at rc.0 with GA targeted for ~2026-08-26; the e2e jobs create their clusters from `kindest/node:vX.Y.Z` images, and Docker Hub currently publishes those only through `v1.36.1`, and there is no `kindest/node:v1.37` yet, so adding 1.37 to the matrix today would fail cluster creation. This issue tracks doing it as soon as the image lands, so 1.37 coverage follows the release closely rather than drifting behind it.

I'm happy to pick this up once the image is available. I have a 1.37 cluster to validate against.
