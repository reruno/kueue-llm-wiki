## Description

**What happened**:

`metrics.RecordPodSchedulingGateRemovalSeconds` observes the duration it is handed without clamping it:

```go
PodSchedulingGateRemovalSeconds.WithLabelValues(labels...).Observe(latency.Seconds())
```

The caller, `pkg/util/pod.RecordPodSchedulingGateRemovalSeconds`, computes that duration from the controller's own clock and the persisted `WorkloadAdmitted` condition transition time:

```go
latency := cl.Now().Sub(cond.LastTransitionTime.Time)
```

`LastTransitionTime` is written by whichever replica handled the admission and comes back through the apiserver. Skew between the apiserver and the controller, a leader transition, or a wall-clock adjustment can make the transition time appear later than `Now()`, and the observation is then negative.

The same comparison is already recognised elsewhere in the file. `ReportWorkloadEvictionLatency` clamps it, and says why:

```go
// LastTransitionTime comes from the API object (apiserver clock). This path compares it to the
// controller's clock.Now(), so skew between apiserver and controller (or delayed watch delivery)
// can make the transition time appear after "now" and yield a negative duration. Clamp to zero.
seconds := max(0, latency.Seconds())
```

**What you expected to happen**:

`kueue_pod_scheduling_gate_removal_seconds` never observes a negative value, for the same reason `kueue_workload_eviction_latency_seconds` does not.

A negative observation has no meaning for a latency histogram, and it makes the classic histogram's `_sum` decrease, which breaks `rate()` over that series.

**How to reproduce it (as minimally and precisely as possible)**:

Reachable whenever the controller clock is behind the apiserver clock at the moment a Pod's Kueue scheduling gate is removed. In a unit test it reproduces directly by handing `pkg/util/pod.RecordPodSchedulingGateRemovalSeconds` a fake clock whose `Now()` precedes the `WorkloadAdmitted` transition time.

**Anything else we need to know?**:

Suggested fix, matching the existing helper:

```go
seconds := max(0, latency.Seconds())
PodSchedulingGateRemovalSeconds.WithLabelValues(labels...).Observe(seconds)
```

plus a fake-clock regression case where `Now()` precedes the admitted condition transition time.

Deliberately kept out of #14419, which fixes a label cardinality panic on the same helper. This is a separate behavioural change and folding it in would widen what that PR asks a reviewer to reason about.
