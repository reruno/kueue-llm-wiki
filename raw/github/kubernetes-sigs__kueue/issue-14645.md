## Description

## Summary

Add a unit test for the defensive negative-delta path in `Assignment.ComputeTASNetUsage`.

## Rationale

`ComputeTASNetUsage` ignores a topology domain when the new domain count is less than or equal to the count already represented by the previous admission. Current replacement behavior is expected to produce equal or increased counts, but the `count < 0` path is defensive code and needs direct test coverage.

## Affected area

- `pkg/scheduler/flavorassigner/flavorassigner_test.go`
- `Assignment.ComputeTASNetUsage`

## Acceptance criteria

- Add a test where a topology domain in the new assignment has fewer pods than the same domain in the previous admission.
- Verify that `ComputeTASNetUsage` does not add TAS usage for that domain.
- Keep the test focused on the per-domain net-usage calculation.
