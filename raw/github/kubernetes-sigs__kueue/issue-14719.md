## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

Allow `PodSet.minCount` `>= 0` (today `+kubebuilder:validation:Minimum=1`). Align with `PodSet.count` (`Minimum=0`).

**Why is this needed**:

`Count` may be 0, so `Count=0` + `MinCount=0` is currently rejected. Needed for partial scaleup of ElasticWorkloadSlices ([#12100](https://github.com/kubernetes-sigs/kueue/issues/12100)).
