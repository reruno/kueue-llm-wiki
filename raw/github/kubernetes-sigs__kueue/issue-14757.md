## Summary

Remove `cmpopts.EquateEmpty()` from the `TestAssignment_ComputeTASNetUsage` comparison so the test explicitly verifies empty versus nil TAS usage expectations.

## Rationale

`cmpopts.EquateEmpty()` can treat a nil `workload.TASUsage` and an empty `workload.TASUsage{}` as equivalent. The test should assert the intended representation directly.

## Affected area

- `pkg/scheduler/flavorassigner/flavorassigner_test.go`
- `TestAssignment_ComputeTASNetUsage`

## Required changes

- Update the `cmp.Diff` call in `TestAssignment_ComputeTASNetUsage` to compare TAS usage without `cmpopts.EquateEmpty()`.
- Update test expectations as needed so they explicitly represent the expected empty or non-empty TAS usage.
- Run the focused test.
