## Description

## Summary

Kueue currently targets the Kubeflow Trainer TrainJob v2.2+ API shape. If a cluster installs a v2.1 TrainJob CRD, Kueue can start successfully but later fails to apply the expected runtime patch. The failure is not clear at setup time.

Validate the installed TrainJob CRD during Kueue setup. Also update `trainjobs.md` to state that Kubeflow Trainer v2.2.0 is the minimum supported version.

## Rationale

Trainer changed the API shape within the same GVK. Kueue does not intend to support both the v2.1 and v2.2+ shapes. Setup-time validation must detect an incompatible CRD and report an actionable error instead of allowing a later silent or opaque failure.

## Affected areas

- Kubeflow Trainer integration setup and CRD discovery or validation logic.
- TrainJob documentation in `trainjobs.md`.

## Acceptance criteria

- At setup, Kueue validates that the installed TrainJob CRD supports the API shape required by Kueue.
- If the CRD is incompatible, Kueue reports a clear, actionable error that identifies the required Kubeflow Trainer version or API shape.
- `trainjobs.md` states that Kubeflow Trainer v2.2.0 is the minimum supported version.
- Tests cover the compatible and incompatible CRD cases.
