## Description

**What would you like to be cleaned:**

The queue layer keeps pending workloads in three buckets (active, inadmissible, inflight), plus a mirror that counts their scheduling hashes for the pending-scheduling-hashes metric. Every time a workload moves between buckets, the code must update the bucket and the mirror as two separate calls, for example:
```
    p.schedulingHashes.moveActiveToInflight(wl)
    p.inflight[workloadKey(wl)] = wl
```

This pairing is repeated by hand at about ten places in `pkg/cache/queue/pending_workloads.go`. Wrap each move in a single helper that updates both, so the buckets and the mirror can't be changed independently.

**Why is this needed:**

The mirror is only correct if it moves in lockstep with the buckets. Today nothing enforces that except each call site remembering to make both calls. One forgotten call silently skews the metric.
