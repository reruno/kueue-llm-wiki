## Description

## Summary

Replace callback functions that construct Kubernetes API objects in `pkg/controller/core/indexer/indexer_test.go` with well-structured test wrapper functions.

## Rationale

The current inline callbacks make test object construction harder to read and reuse. Kueue already provides test construction utilities that should be used or extended for this purpose.

## Affected areas

- `pkg/controller/core/indexer/indexer_test.go`
- `pkg/util/testingjobs`
- `pkg/util/testing/v1beta2/wrappers.go`

## Required changes

- Identify the inline callback functions in the indexer tests that construct Kubernetes objects.
- Use existing wrappers from `pkg/util/testingjobs` or `pkg/util/testing/v1beta2/wrappers.go` where they fit.
- Add or improve wrappers when the existing utilities do not support the required test objects.
- Keep the tests clear and preserve their current coverage.

## Acceptance criteria

- Indexer tests do not use inline callback functions solely to construct Kubernetes objects where a structured wrapper can provide the construction.
- The relevant wrapper utility supports the required object setup.
- The updated tests retain equivalent assertions and coverage.
