## Description

## Summary

Add a scale-down test case for the elastic job ungater.

## Required change

Extend `TestReconcile` in `pkg/controller/elasticjobs/elastic_job_ungater_test.go` with a workload where the requested PodSet count is less than the admitted PodSet count:

```text
wl.spec.count < wl.status.admission.count
```

Verify that the ungater uses the granted admission count correctly after the workload scales down.

## Rationale

PR #14835 changes the ungater quota cap to use `status.admission` counts. A scale-down scenario is needed to protect that behavior.

## Affected area

- `pkg/controller/elasticjobs/elastic_job_ungater_test.go`
- Related logic: `pkg/workload/podsetscounts.go`

## Acceptance criteria

- `TestReconcile` includes a scale-down workload fixture where the requested count is less than the admission count.
- The test verifies the expected gated and ungated pod behavior for that fixture.
- The test prevents regressions in admission-count handling after scale-down.
