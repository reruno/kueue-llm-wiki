## Description

## Summary

Add a bounded timeout when MultiKueue integration test suites stop their controller manager during teardown.

## Rationale

The `stopAndTeardown` helpers stop the manager before `envtest` teardown. The manager stop can wait indefinitely. A timeout keeps test cleanup bounded while preserving the required shutdown order.

## Affected areas

- `test/integration/multikueue/scheduler/suite_test.go`
- `test/integration/multikueue/tas/suite_test.go`
- `test/integration/multikueue/suite_test.go`

## Required changes

In each affected `stopAndTeardown` helper:

1. Create a context with `context.WithTimeout(c.ctx, util.LongTimeout)`.
2. Defer the cancellation function.
3. Pass the timeout context to `c.fwk.StopManager(ctx)`.
4. Call `c.fwk.Teardown()` after the manager stop.

## Acceptance criteria

- Each MultiKueue `stopAndTeardown` helper bounds `StopManager` with `util.LongTimeout`.
- Each helper calls `Teardown` only after `StopManager` returns.
- The cleanup behavior remains consistent across the scheduler, TAS, and base MultiKueue suites.
