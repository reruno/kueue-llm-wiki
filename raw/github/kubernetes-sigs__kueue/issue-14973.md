## Description

**What would you like to be added**:

I'd like to have a user-facing configuration API, which allows to override the default QPS/Burst settings for the REST client used for the manager-worker connection in MultiKueue.

**Why is this needed**:

We ran a basic benchmark which highlighted that the connection between the manager and worker clusters is heavily throttled, which makes scheduling extremely slow in a bursty environment.

We measured processing a burst of **1000** workloads, which took **~15 minutes** to get fully admitted across 10 worker clusters (but the number of worker clusters is not very relevant here).

I noticed that the requests are throttled and we do not have any way to override the QPS/Burst settings for the manager-worker connection (they default to 5/10 AFAIR, which is very low):
```go
// In `client-go` `rest` package
type Config struct {
	...
	// QPS indicates the maximum QPS to the master from this client.
	// If it's zero, the created RESTClient will use DefaultQPS: 5
	//
	// Setting this to a negative value will disable client-side ratelimiting
	// unless `Ratelimiter` is also set.
	QPS float32

	// Maximum burst for throttle.
	// If it's zero, the created RESTClient will use DefaultBurst: 10.
	Burst int
}
```

I created a PoC fix by hard-coding higher values, which brought the processing down to **~1.5 minutes**:
```
--- a/pkg/controller/admissionchecks/multikueue/multikueuecluster.go
+++ b/pkg/controller/admissionchecks/multikueue/multikueuecluster.go
@@ -231,6 +231,9 @@ func newClientWithWatch(ctx context.Context, config *clientConfig, options clien
                return nil, err
        }
 
+       restConfig.QPS = 500
+       restConfig.Burst = 500
+
        directClient, err := client.NewWithWatch(restConfig, options)
        if err != nil {
                return nil, err
```

@kshalot We can add `ClientConnection *ClientConnection` under `MultiKueue` in `KueueConfiguration`, reusing the existing [`ClientConnection`](https://github.com/kubernetes-sigs/kueue/blob/main/apis/config/v1beta1/configuration_types.go#L459-L468) struct.
If omitted, it can default to Kueue's standard settings ([`QPS: 300, Burst: 500`](https://github.com/kubernetes-sigs/kueue/blob/main/apis/config/v1beta1/defaults.go#L44-L45)). We can follow [`cmd/kueue/main.go#L252-L257`](https://github.com/kubernetes-sigs/kueue/blob/main/cmd/kueue/main.go#L252-L257) as an example to share a single `flowcontrol.RateLimiter` across all API types to each worker cluster.
