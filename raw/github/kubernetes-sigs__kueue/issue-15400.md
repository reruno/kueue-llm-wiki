## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

We'd like to always add `kueue-x-k8s.io/workload` annotation to Pod template.
The annotation was introduce as part of https://github.com/kubernetes-sigs/kueue/pull/3228.

**Why is this needed**:

As we discussed in https://github.com/kubernetes-sigs/kueue/pull/15398#discussion_r3976349826, today the `kueue-x-k8s.io/workload` annotation is used under the hood for the core Kueue features like TopologyAwareScheduling, SchedulerLibraryIntegrations, and WaitForPodsReadyUnscheduledTimeout.

So, I think it's time to always add these annotations to Pods.
