## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

Currently ListChildWorkloads has two responsibilities:
- listing workloads 
- silently skipping workloads which are "foreign" to avoid finalizing foreign workloads

Instead I think we should break this function into two:
- ListChildWorkloads - lists all child workloads
- CanFinalizeWorkload(wl *kueue.Workload) bool - checks if the actual finalization can be performed

**Why is this needed**:

To make the responsibilities cleaner. It is confusing that the function listing child workloads needs to know about finalization of them.
