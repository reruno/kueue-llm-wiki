## Description

**What would you like to be cleaned**:

Refactor `TestDeviceClassHandlerSkipsReservedWorkloads` in `pkg/controller/core/workload_controller_dra_test.go` into separate tests for each DeviceClass event type:

- `TestDeviceClassHandler_Create`
- `TestDeviceClassHandler_Update`
- `TestDeviceClassHandler_Delete`
- `TestDeviceClassHandler_Generic`

Use the event-handler test structure in `pkg/controller/unscheduledpods/tracker_test.go` as the reference.

**Why is this needed**:

The current test verifies the handler through a recording queue, but it does not explicitly verify each DeviceClass event path. Separate tests will make the event-handler behavior clear and provide regression coverage for Create, Update, Delete, and Generic events.

**Affected areas**:

- `pkg/controller/core/workload_controller_dra_test.go`
- DeviceClass event-handler test coverage

**Acceptance criteria**:

- Each DeviceClass event type has a dedicated test.
- Each test verifies that pending workloads are requeued and workloads with reserved quota are skipped, where applicable.
- The tests follow the established event-handler testing pattern from `pkg/controller/unscheduledpods/tracker_test.go`.
