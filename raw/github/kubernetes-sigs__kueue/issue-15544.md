## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

Right now, `newTASFlavorSnapshot` takes flavor fields in a few different ways:
- `TopologyName` and `Tolerations` are passed as regular arguments.
- `NodeLabels` is passed as an option

It would be much cleaner to just pass `c.flavor` (or `flavorInformation`) directly into `newTASFlavorSnapshot` instead of passing each field one by one.

**Why is this needed**:

All of these fields come from the same flavor object anyway. Passing `c.flavor` directly keeps things consistent and avoids having to change the constructor and update a bunch of test files every time we need another flavor field in the snapshot.
