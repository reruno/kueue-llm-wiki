## Description

### What would you like to be added?

Add `test-e2e-was-future-*` Makefile targets to run singlecluster e2e tests (`baseline/`, `extended/`, `wasapi/`) against Kubernetes `main` with WAS enabled, aliasing or replacing `test-e2e-k8s-main-was`

### Why is this needed?

To align future Kubernetes compatibility testing targets with the e2e test reorganization proposal from #14622
