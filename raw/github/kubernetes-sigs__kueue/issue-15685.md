## Description

**What would you like to be added**:

Optimize TAS leader PodSet feasibility evaluation. Avoid recomputing leader feasibility for every preemption simulation. Track whether a PodSet is the leader and cache the PodSet matcher where possible.

Affected area: `pkg/cache/scheduler/tas_flavor_snapshot.go`.

**Why is this needed**:

The current leader-feasibility path evaluates all snapshot nodes with leader constraints during each preemption simulation. This can reduce TAS scheduler performance. Complete this work before the Kueue 0.20 release.
