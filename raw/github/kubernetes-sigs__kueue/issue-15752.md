## Description

**What would you like to be cleaned**:

Add a `Clone()` method to the `RuntimePatchWrapper` test helper in `pkg/controller/jobs/trainjob/trainjob_controller_test.go`. The method must return `*RuntimePatchWrapper` and deep-copy the wrapped `kftrainerapi.RuntimePatch`, so callers can use chained wrapper methods such as `.Clone().Obj()`.

Requested by @tenzen-y in [the review comment](https://github.com/kubernetes-sigs/kueue/pull/15750#discussion_r4041337374). Related PR: https://github.com/kubernetes-sigs/kueue/pull/15750.

**Why is this needed**:

The promoted `kftrainerapi.RuntimePatch.DeepCopy()` method returns `*kftrainerapi.RuntimePatch`. That result does not expose the wrapper's `Obj()` method. A wrapper-level `Clone()` method keeps the fluent test-helper API type-safe.
