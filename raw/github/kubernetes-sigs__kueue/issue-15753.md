## Description

**What would you like to be cleaned**:

Split TAS scheduler unit tests into these files:

- `pkg/scheduler/scheduler_tas_test.go` for internal Kueue TAS tests.
- `pkg/scheduler/scheduler_tas_schedlib_test.go` for tests that use `SchedulerLibraryIntegration` and Scheduler Library feasibility checks.

Move Scheduler Library-only helpers with the Scheduler Library tests. Keep common helpers in the appropriate shared test location.

**Why is this needed**:

The current file mixes internal TAS and Scheduler Library test cases. The split will reduce file size and make tests easier to find and maintain.

Acceptance criteria:
- [ ] Internal Kueue TAS tests remain in `pkg/scheduler/scheduler_tas_test.go`.

- [ ] Relevant tests remain covered.
