## Description

**What happened**:

Preferred-topology placement can select a parent domain with capacity only in child domains that Required topology spreading bans. The descent returns no eligible children, but the scheduler can publish an incomplete assignment without a failure reason.

**What you expected to happen**:

The scheduler reports placement failure when no eligible child domains remain.

**How to reproduce it (as minimally and precisely as possible)**:

Use preferred topology. Ensure parent capacity exists only in child domains that a Required spreading rule excludes.

**Anything else we need to know?**:

Required change: update `pkg/cache/scheduler/tas_flavor_snapshot.go` so a nil result from `updateCountsToMinimumGeneric` after `filterOutBannedDomains` fails placement. Add regression coverage.

### Comment by [@reruno](https://github.com/reruno) — 2026-09-28T16:45:43Z


topology spreading works only when podset required topology is present and the rule is inside of spreading rules 

```
      if !useBalancedPlacement {
		fitLevelIdx, currFitDomain, reason = s.findLevelWithFitDomains(state.requestedLevelIdx, state)
		if len(reason) > 0 {
			return nil, nil, reason
		}
	}
```

`currFitDomain` is domains at level `podset-required-topology` that can fit our podset group. 

`findLevelWithFitDomains` already contains `filterOutBannedDomains` that removes domains that are banned by spreading rules. 

So here 
```
        currFitDomain = s.updateCountsToMinimumGeneric(currFitDomain, state.count, state.leaderCount, state.shape(), state.unconstrained, true)
	currentLevelIdx := fitLevelIdx
	for ; currentLevelIdx < min(len(s.domainsPerLevel)-1, state.sliceLevelIdx) && !useBalancedPlacement; currentLevelIdx++ {
		// If we are "above" the requested slice topology level and we don't run the balanced placement algorithm,
		// we're greedily assigning pods/slices to all domains without checking what we've assigned to parent domains.
		lowerDomains := s.lowerLevelDomains(currFitDomain)
		lowerDomains = s.filterOutBannedDomains(lowerDomains, state.spreadRules)
		sortedLowerDomains := s.sortedDomains(lowerDomains, state.unconstrained, state.spreadRules)
		currFitDomain = s.updateCountsToMinimumGeneric(sortedLowerDomains, state.count, state.leaderCount, state.shape(), state.unconstrained, true)
	}
```

`s.filterOutBannedDomains(lowerDomains, state.spreadRules)` will not do anything because higher domain `currFitDomain` is already filtered by `filterOutBannedDomains` in `findLevelWithFitDomains`, this is why it is no op.
