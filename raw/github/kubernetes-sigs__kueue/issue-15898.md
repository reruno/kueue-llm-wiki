## Description

**What would you like to be cleaned**:

`hack/testing/prometheus/Dockerfile` pins the Prometheus server image by digest (`quay.io/prometheus/prometheus:v3.9.1@sha256:...`) and is tracked by Dependabot via `.github/dependabot.yml`. `PROMETHEUS_OPERATOR_VERSION ?= v0.89.0` in `hack/make/test.mk` is a separate hardcoded value, not tracked by Dependabot, and used to derive `PROMETHEUS_OPERATOR_BUNDLE`, `PROMETHEUS_OPERATOR_IMAGE`, and `PROMETHEUS_CONFIG_RELOADER_IMAGE` in `hack/testing/e2e-common.sh`.

Derive `PROMETHEUS_OPERATOR_VERSION` from the Dockerfile (or otherwise pin it the same way the Dockerfile is pinned) so Dependabot bumps stay in sync instead of the two versions drifting apart over time.

**Why is this needed**:

Follow-up from #15611, discussion: https://github.com/kubernetes-sigs/kueue/pull/15611#discussion_r4016190210
