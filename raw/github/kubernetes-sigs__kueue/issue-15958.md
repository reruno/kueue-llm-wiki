## Description

**What happened**:

`kueuectl version` always looks up the `kueue-controller-manager` Deployment in the hardcoded `kueue-system` namespace. Passing `-n` / `--namespace` (an inherited parent flag) has no effect, so installs outside `kueue-system` only print the client version and silently omit the controller manager image.

**What you expected to happen**:

When `--namespace` is explicitly set, `kueuectl version` should look for the controller manager Deployment in that namespace. When it is not set, it should keep the current default of `kueue-system`.

**How to reproduce it (as minimally and precisely as possible)**:

1. Install Kueue in a non-default namespace, e.g. `kueue`.
2. Run:

```shell
kueuectl version -n kueue
```

3. Observe that only `Client Version` is printed even though the Deployment exists in `kueue`.

**Anything else we need to know?**:

Code reference: `cmd/kueuectl/app/version/version.go` uses a constant `kueueNamespace = kueue-system` and never reads the namespace flag / client-config namespace override.
