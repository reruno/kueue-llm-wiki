## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

`hack/tools/code-generator/generate.sh` contains a wrapper that intercepts `go install` calls and redirects them through `hack/tools/` to ensure `golang.org/x/tools v0.49.0` is used instead of the version pinned by `k8s.io/code-generator@v0.37.0` (`v0.47.0`), which cannot type-check Go 1.27's `math/rand/v2` (generic methods).

The wrapper can be removed once `hack/tools/go.mod` is upgraded to `k8s.io/code-generator@v0.38.x`, which will ship with a `golang.org/x/tools` version that supports Go 1.27 generic methods (already available in the kubernetes/kubernetes master branch: `staging/src/k8s.io/code-generator/go.mod`).

**Why is this needed**:

The workaround is a temporary compatibility shim introduced when bumping Go to 1.27. Keeping it longer than necessary adds complexity to the codegen script. Once the upstream release is available and `hack/tools/go.mod` is updated, the wrapper should be removed.
