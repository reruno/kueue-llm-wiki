## Description

**What would you like to be cleaned**:

Extend the test-wrapper API for managed-jobs namespace selectors. Add a reusable match-expression wrapper so tests can construct requirements with chained calls, then pass them to `MakeManagedJobsNamespaceSelector().MatchExpressions(...)`.

Update the affected test fixtures to use the reusable wrapper where applicable.

Requested by @tenzen-y in https://github.com/kubernetes-sigs/kueue/pull/16016#discussion_r4074518998. Related PR: https://github.com/kubernetes-sigs/kueue/pull/16016.

AI disclosure: CodeRabbit AI opened this issue on behalf of @tenzen-y.

**Why is this needed**:

The wrapper keeps selector fixtures consistent and avoids repeated inline `metav1.LabelSelectorRequirement` literals.

Acceptance criteria:
- Provide a reusable match-expression test wrapper with chained setters for key, operator, and values.
- Support passing one or more wrapped expressions to `ManagedJobsNamespaceSelectorWrapper.MatchExpressions`.
- Add unit tests for the new wrapper behavior.
- Refactor applicable webhook tests to use the wrapper without changing selector semantics.
