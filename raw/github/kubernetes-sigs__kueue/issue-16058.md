**What happened**:
When a release is published via the /publish-release ChatOps command (in .github/workflows/release-utils.yml), the krew-release.yml workflow does not trigger, so the krew plugin index is never updated for releases cut through the automated release bot.

**What you expected to happen**:
The krew-release workflow should run after every non-prerelease is published, regardless of whether it was published manually via the GitHub UI or via /publish-release.
