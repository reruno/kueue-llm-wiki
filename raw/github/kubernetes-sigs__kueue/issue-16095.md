## Description

**What happened**:

PR https://github.com/kubernetes-sigs/kueue/pull/15983 failed `pull-kueue-test-integration-shard-2-main`. The `core` integration suite reported 1 failed spec and 93 passed specs. The failed spec is `Scheduling hash freshness across LimitRange changes / places a raw-identical workload by its new effective resources after a defaultRequest change` in `test/integration/singlecluster/controller/core/workload_hash_freshness_test.go`.

**What you expected to happen**:

The integration check passes. After the `LimitRange` CPU `DefaultRequest` changes from 3 to 1, the second raw-identical workload is admitted on the small flavor while the first keeps its large-flavor assignment.
