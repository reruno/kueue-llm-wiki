## Description

**What would you like to be cleaned**:

Refactor `cmd/kueuectl/app/list/list_workload.go` so `kueuectl list workload --for` separates pagination into a helper, handles the label-selector search and owner-reference fallback in an explicit `--for` conditional, and keeps result printing separate. Update `cmd/kueuectl/app/list/list_workload_test.go` to cover pagination and both search phases, including a user-supplied `kueue.x-k8s.io/job-uid` selector. Preserve the behavior fixed in [PR #16040](https://github.com/kubernetes-sigs/kueue/pull/16040): the fallback runs at most once, and a selector with no matches returns without hanging.

**Why is this needed**:

The current loop mixes pagination, fallback, and printing. Its implicit state makes similar regressions more likely. See the [review](https://github.com/kubernetes-sigs/kueue/pull/16040#pullrequestreview-5289240557). Requested by @mbobrovskyi in [this comment](https://github.com/kubernetes-sigs/kueue/pull/16040#issuecomment-5810249995).
