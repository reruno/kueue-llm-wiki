## Description

**What happened**:

On [PR #16124](https://github.com/kubernetes-sigs/kueue/pull/16124), @mimowo posted [`/set-release-note` with `NONE`](https://github.com/kubernetes-sigs/kueue/pull/16124#issuecomment-5811704370). The bot replied [`❌ Actor mimowo is not authorized.`](https://github.com/kubernetes-sigs/kueue/pull/16124#issuecomment-5811712841).

**What you expected to happen**:

A maintainer can set the release note with `/set-release-note` without an authorization error.

**How to reproduce it (as minimally and precisely as possible)**:

1. As a maintainer, comment `/set-release-note` followed by `NONE` on a Kueue pull request.
2. Observe the bot response. Investigate why the command denies an authorized maintainer.

**Anything else we need to know?**:

@mimowo [requested this issue](https://github.com/kubernetes-sigs/kueue/pull/16124#issuecomment-5811726604). Filed by CodeRabbit AI on behalf of @mimowo. Verify the command's maintainer authorization check and allow maintainers to set the release note. This PR concerns an unreleased feature, so `NONE` is the intended release note here.
