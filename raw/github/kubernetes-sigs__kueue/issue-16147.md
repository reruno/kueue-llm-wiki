## Description

**What would you like to be cleaned**:
Replace the `rejectAll` boolean returned by `NewCandidateFilters` in `pkg/scheduler/preemption/config/filters/factory.go` with an error that identifies which candidate filter failed to build. Update the caller in `pkg/scheduler/preemption/config/evaluator.go` and the related tests. Preserve the intended candidate-selection behavior.

**Why is this needed**:
A build failure currently returns `(CandidateFilters{}, true)` and silently skips the selector. The caller cannot tell whether the scope, ClusterQueue selector, workload selector, or priority filter failed. An explicit error will identify the failure before ConfigurablePreemptions graduates to beta.
