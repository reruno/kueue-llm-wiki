## Changes by Kind

### Bug or Regression

- MultiKueue now cleans up remote objects for evicted elastic workloads so they can be re-admitted from the manager-cluster specification. (#16178, @kevin85421)
- Scheduling: Fixed a bug where workloads could remain pending when a ClusterQueue has podsquota, even though preempting lower-priority workloads would make them fit. WithElasticJobsViaWorkloadSlicesWithPartialReplicaScaleUp enabled, preemption now uses the partially admitted replica count when sizing workload-slice replacements. (#16200, @apullo777)
- TAS: Fixed a bug where a Node or TAS ResourceFlavor change requeued inadmissible Workloads in every ClusterQueue instead of only the ClusterQueues that use that flavor. (#16152, @sohankunkerkar)
- TAS: Fixed a bug where a Workload with non-adjacent members of the same PodSet group (`kueue.x-k8s.io/podset-group-name`) could crash kueue-controller-manager or remain pending when preemption was required for admission. (#16273, @apullo777)
