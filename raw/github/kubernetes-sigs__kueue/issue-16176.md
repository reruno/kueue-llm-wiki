## Description

**What would you like to be cleaned**:

Refactor the WaitForPodsReady integration tests in `test/integration/singlecluster/controller/jobs/job/job_controller_test.go` and `test/integration/singlecluster/controller/jobs/mpijob/mpijob_controller_test.go`. Use timeouts of at most 1 second in tests that expect eviction. Use long timeouts in tests that do not expect eviction. Reserve medium timeouts for a small group of tests that require them. Adjust polling and assertions so the tests remain reliable.

**Why is this needed**:

Current test timeouts include 8-second and 10-second values in the Job tests and a 30-second value in the MPIJob tests. Shorter eviction timeouts can reduce integration-test runtime without reducing coverage.
