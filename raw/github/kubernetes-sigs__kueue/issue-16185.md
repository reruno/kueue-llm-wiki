## Description

**What happened**:

`kueuectl delete workload --all` lists Workloads once and deletes only that page. The API server can return a continue token when the list is larger than one page. The command ignores it, so Workloads on later pages stay.

**What you expected to happen**:

`--all` should delete every Workload in the namespace (or every namespace with `-A`), including ones that come back on later list pages.

**How to reproduce it (as minimally and precisely as possible)**:

Have more Workloads than fit in one list page, then:

```shell
kueuectl delete workload --all --yes
```

Only the first page is deleted. The rest are left in place, and the command exits 0.

**Anything else we need to know?**:

`getAllWorkloads` in `cmd/kueuectl/app/delete/delete_workload.go` calls `List` once and never follows `list.Continue`. `kueuectl list` already walks continue tokens.
