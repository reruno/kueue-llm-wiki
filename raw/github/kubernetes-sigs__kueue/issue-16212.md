## Description

**What would you like to be cleaned**:

Investigate whether `pkg/workloadslicing.PreviousAdmittedPodSetCounts` can reuse `pkg/workload.ExtractGrantedPodSetCounts` instead of building counts from `workload.NewInfo(...).TotalRequests`. If feasible, simplify the implementation and update tests. Preserve the baseline for the latest admitted predecessor, including finished slices, and the nil/error behavior when no predecessor exists.

**Why is this needed**:

Reusing the helper could avoid duplicate pod-count logic. Confirm that it preserves reclaimed-pod subtraction and in-place scale-down behavior before changing the implementation; otherwise document the difference and retain the current calculation. Cover these cases in tests.

Follow-up to [PR #16206](https://github.com/kubernetes-sigs/kueue/pull/16206) and [the review discussion](https://github.com/kubernetes-sigs/kueue/pull/16206#discussion_r4104771743). Requested by @mimowo in [this comment](https://github.com/kubernetes-sigs/kueue/pull/16206#issuecomment-5834383525). Filed by CodeRabbit AI.
