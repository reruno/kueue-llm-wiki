## Description

**What would you like to be cleaned**:

In `pkg/controller/admissionchecks/multikueue/clusterqueue_test.go`, move the message-truncation and stale `ObservedGeneration` checks from `TestCQReconciler_UpdateQuotaAutomationCondition` and `TestCQReconciler_UpdateQuotaAutomationConditionUpdatesObservedGeneration` into cases in the `TestCQReconcile` table. Keep assertions that the stored condition message is truncated and its `ObservedGeneration` matches the ClusterQueue generation after a spec update with unchanged condition content.
