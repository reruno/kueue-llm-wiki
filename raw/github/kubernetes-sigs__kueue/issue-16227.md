## Description

**What would you like to be cleaned**:

Add `workload.ExtractGrantedPodSetCountsAfterReclaim(wl)` in `pkg/workload/podsetscounts.go`. Start with `ExtractGrantedPodSetCounts(wl)`; if it returns nil, return nil. Otherwise cap each granted count at `podSetsCountsAfterReclaim(wl)[name]`. Use the helper in `workloadslicing.PreviousAdmittedPodSetCounts` in `pkg/workloadslicing/workloadslicing.go` instead of constructing `workload.Info` to read `TotalRequests`. Keep predecessor selection and lookup error behavior unchanged. Add tests for partial grants, reclaimed pods, in-place scale-down, and no admission.

**Why is this needed**:

The baseline must account for both granted capacity and reclaimed pods. Using unadjusted granted counts can under-request the scale-up increment and leave pods gated. A dedicated helper avoids constructing `workload.Info` for a count map while retaining the reclaim-adjusted baseline.

Requested by @mimowo in [this review comment](https://github.com/kubernetes-sigs/kueue/pull/16206#discussion_r4104771743). Follow-up to [PR #16206](https://github.com/kubernetes-sigs/kueue/pull/16206).
