## Description

**What would you like to be cleaned**:

Add `WorkloadLevelWaitForPodsReady` gate-off cases to the wait-for-pods-ready annotation integration tests for Job (including elastic Job), LeaderWorkerSet, and StatefulSet under `test/integration/singlecluster/controller/jobs/`. Cover annotation creation and updates where applicable. Verify that disabling the gate prevents propagation to the Workload. Follow the gate-off test pattern used for `AdmissionGatedBy`.

**Why is this needed**:

The current annotation integration tests cover the enabled gate but do not verify disabled-gate behavior. This leaves feature-gate behavior untested.
