## Description

**What would you like to be cleaned**:

Change both missing-PodSet log messages in `pkg/scheduler/flavorassigner/flavorassigner.go` from `log.V(1)` to `log.V(2)`: the assignment lookup in `TotalRequestsFor` and the replaced workload slice lookup. Keep the existing log messages and PodSet context. Done when both messages use V(2).

**Why is this needed**:

These scheduler diagnostic messages belong at V(2) under the [Kubernetes logging guidance](https://github.com/kubernetes/community/blob/main/contributors/devel/sig-instrumentation/logging.md). Follow up on [PR #16290](https://github.com/kubernetes-sigs/kueue/pull/16290) and its two review threads: [assignment lookup](https://github.com/kubernetes-sigs/kueue/pull/16290#discussion_r4124404861) and [replaced slice lookup](https://github.com/kubernetes-sigs/kueue/pull/16290#discussion_r4124406370).

Requested by @tenzen-y in [this comment](https://github.com/kubernetes-sigs/kueue/pull/16290#issuecomment-5873918189). This issue was drafted with CodeRabbit AI assistance.
