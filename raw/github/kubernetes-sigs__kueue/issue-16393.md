## Description

**What happened**:

The Workloads page (`cmd/kueueviz/frontend/src/Workloads.jsx`) uses `<Alert severity="info">` on line 85 to show an empty-state message when no workloads are found. However, `Alert` is not included in the MUI import on line 17.

When a user opens the Workloads page and no workloads exist (either globally or in the selected namespace), React throws a runtime error because `Alert` is undefined, and the page crashes instead of showing the friendly "No workloads found" message.

The sibling `LocalQueues.jsx` page has the same empty-state pattern but correctly imports `Alert`.

**What you expected to happen**:

The page should display an info message like "No workloads found in any namespace" when the workloads list is empty.

**How to reproduce it (as minimally and precisely as possible)**:

1. Start KueueViz against a cluster with no submitted workloads.
2. Navigate to the Workloads page.
3. The page crashes with a reference error instead of showing the empty-state message.

**Environment**:
- Kueue version: main
