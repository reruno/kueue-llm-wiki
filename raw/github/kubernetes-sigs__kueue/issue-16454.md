**What would you like to be cleaned**:

The `ensure_milestone` function in `hack/releasing/milestone_pull.sh`:

https://github.com/kubernetes-sigs/kueue/blob/36c42c8dfc10abcf90b15fa9c7cba6e28038b471/hack/releasing/milestone_pull.sh#L147-L179

attempts to create the next minor's GitHub milestone directly in `kubernetes-sigs/kueue` via the GitHub API. This step fails with HTTP 404 for release managers who run the script from their personal fork, because creating milestones in the upstream repository requires write access that contributors do not have.

The milestone is created automatically by the Prow milestone_applier plugin once the test-infra mapping PR is merged, so this step is redundant.

**Why is this needed**:

Removing the dead code eliminates a confusing 404 failure on every minor/major release run and makes the script honest about what it actually does: open the test-infra PR that drives the milestone creation.
