## Description

**What happened**:

In `pkg/scheduler/flavorassigner/flavorassigner.go`, `AssignFlavors` uses decimal PodSet indexes and `PodSetGroupName` values in the same key namespace. A numeric group name can collide with an ungrouped PodSet index. `orderedgroups.Insert` then merges unrelated requests and seeded flavors.

**What you expected to happen**:

Grouped and ungrouped PodSets remain separate. Use distinct key namespaces, such as `group/` and `podset/`, or an equivalent typed key.

**How to reproduce it (as minimally and precisely as possible)**:

Use spec order `leader, other, worker`, with leader and worker in group `"1"` and other ungrouped. With second-pass admission order `leader, worker, other`, the group and other's spec index both produce key `"1"`.

Acceptance criteria: add regression coverage in `pkg/scheduler/flavorassigner/flavorassigner_test.go` for numeric group-name collisions in first- and second-pass assignment. Verify that unrelated PodSets retain their own flavors and expected assignment order.
