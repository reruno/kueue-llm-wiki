## Description

**What would you like to be added**:

Show the Pods of pod group Workloads in the KueueViz workloads dashboard.

The dashboard matches Pods to a Workload by the Workload's `kueue.x-k8s.io/job-uid` label and the Pod's `controller-uid` label. Pod group Workloads have no `job-uid` label and their Pods have no `controller-uid` label, so the dashboard cannot match them and shows no Pods.

Pod group Pods carry the `kueue.x-k8s.io/pod-group-name` label, and the Workload name equals the group name (except for prebuilt Workloads). The dashboard could also index Pods by that label and look up Workloads without a job UID by name.

**Why is this needed**:

Users running plain Pod groups see an empty Pods list for their Workloads in the dashboard.
