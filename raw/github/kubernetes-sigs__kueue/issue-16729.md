## Description


/area tas

**What would you like to be added**:

A metric that reports the outcome of TAS failed node replacement (`TASFailedNodeReplacement`), for example a counter per ClusterQueue with a `result` label: the node was replaced, no replacement was found, or the Workload was evicted because more nodes failed.

Today a successful replacement is only logged at `V(3)`, and both eviction cases are counted as the same `kueue_evicted_workloads_total{reason="NodeFailures"}` series.

**Why is this needed**:

Operators cannot tell how often failed node replacement avoids an eviction, or whether evictions are caused by missing spare capacity or by several nodes failing at once.
