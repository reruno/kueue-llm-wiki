## Description

**What would you like to be added**:

Support elastic SparkApplication jobs through the existing `ElasticJobsViaWorkloadSlices` mechanism.

- Enable opt-in through `kueue.x-k8s.io/elastic-job: "true"` when the required feature gates are enabled.
- Integrate Spark dynamic allocation with WorkloadSlices for executor scale-up and scale-down.
- Keep the driver running during executor scaling. Admit additional executors before they consume quota, and release quota only after removed executors stop.
- Reuse existing slice ownership, lifecycle, and cleanup behavior.

Affected areas: `pkg/controller/jobs/sparkapplication/`, shared elastic job integration where needed, SparkApplication tests, and `site/content/en/docs/tasks/run/kubeflow/sparkapplications.md`.

WorkloadResize and new partial-preemption algorithms are out of scope. Keep this integration independent of the broader partial-preemption work in #16233 and #975.

**Why is this needed**:

SparkApplication integration currently rejects dynamic allocation. Reusing WorkloadSlices enables elastic Spark jobs without introducing a second elasticity mechanism.
