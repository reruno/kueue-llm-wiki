## Description

**What happened**:

`supportedPrebuiltWlJobGVKs` in `pkg/controller/jobframework/validation.go` lists TFJob, PaddleJob, PyTorchJob and XGBoostJob as job kinds that may reference a prebuilt Workload, but it omits JAXJob.

JAXJob has a MultiKueue adapter (`kubeflowjob.NewMKAdapter`, registered in `jaxjob_controller.go`) that creates the remote job through `SetMultiKueueMeta`, which sets the `kueue.x-k8s.io/prebuilt-workload-name` label. The worker cluster's JAXJob webhook runs `ValidateJobOnCreate`, which rejects any job that references a prebuilt Workload when its GVK is not in the allowlist:

```
metadata.labels[kueue.x-k8s.io/prebuilt-workload-name]: Forbidden: Is not supported for "kubeflow.org/v1, Kind=JAXJob"
```

So a JAXJob dispatched through MultiKueue is expected to be rejected on the worker cluster.

**What you expected to happen**:

JAXJob should be in the allowlist alongside the other Kubeflow training jobs. The fix is a one-line addition to `supportedPrebuiltWlJobGVKs`.

**How to reproduce it (as minimally and precisely as possible)**:

At the `ValidateJobOnCreate` level, on `main` (62b18cb):

1. In `TestValidateJobOnCreate` (`pkg/controller/jobframework/validation_test.go`), add a case with a job that has `PrebuiltWorkloadLabel("workload-name")`, `gvk: kftraining.SchemeGroupVersion.WithKind(kftraining.JAXJobKind)`, and no expected error.
2. Run `go test ./pkg/controller/jobframework/ -run 'TestValidateJobOnCreate$'`.

The case fails with the `Forbidden: Is not supported for "kubeflow.org/v1, Kind=JAXJob"` error above. The same check passes for TFJob.

I have not reproduced this end to end with real MultiKueue manager and worker clusters.

**Anything else we need to know?**:

Why existing tests did not catch it: `TestValidateJobOnCreate` had no JAXJob case. I also did not find a JAXJob case in `test/integration/multikueue` or `test/e2e/multikueue`; the integration suites only list `kubeflow.org/jaxjob` as an enabled framework.

A fix with a regression test is ready and will follow as a PR.
