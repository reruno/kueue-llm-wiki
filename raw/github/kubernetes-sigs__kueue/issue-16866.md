## Description

Running `snyk` on kueue repo I get a few vulnerabilities reported. I've been just excluding them from our fork but curious if we should actually resolve them.

```
 ✗ [Low] Use of Password Hash With Insufficient Computational Effort 
   Path: pkg/cache/scheduler/was/virtual_pods.go, line 60 
   Info: The SHA1 hash (used in crypto.sha1.New) is insecure. Consider changing it to a secure hash algorithm

 ✗ [Low] Use of Password Hash With Insufficient Computational Effort 
   Path: pkg/controller/admissionchecks/provisioning/controller.go, line 1011 
   Info: The SHA1 hash (used in crypto.sha1.New) is insecure. Consider changing it to a secure hash algorithm

 ✗ [Low] Use of Password Hash With Insufficient Computational Effort 
   Path: pkg/controller/jobframework/workload_names.go, line 110 
   Info: The SHA1 hash (used in crypto.sha1.New) is insecure. Consider changing it to a secure hash algorithm
```
