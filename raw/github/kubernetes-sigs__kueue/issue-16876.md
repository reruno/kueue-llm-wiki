## Description

**What would you like to be cleaned**:

Add or generalize a testing helper in `test/util/behavioral/queues.go` to set a LocalQueue's `spec.stopPolicy`. The existing `UnholdLocalQueue` helper only sets `None`.

Replace the duplicate get/patch/retry blocks for `Hold` and `HoldAndDrain` in `test/integration/singlecluster/controller/core/localqueue_pending_metrics_test.go`.

Acceptance criteria:
- The helper reads the latest LocalQueue and retries API updates using the existing Ginkgo/Gomega patterns.
- Both stop-policy scenarios use the helper and remain separate `ginkgo.It` cases.
- Existing pending-metric assertions remain unchanged.

**Why is this needed**:

A shared helper removes duplicate API update logic and keeps retry behavior consistent.
