**What would you like to be documented or improved**:

Our KubeRay guide mentions 1.1.0, but this is N-6, we don't really need to support that deep. 

Even for core k8s we only support only N-3, so I would imagine a similar policy for Kueue.

For some sub-features we may have a more granular table.

If the APIs don't change much we could probably do that. But I think saying "Kueue can support N-3" releases of KubeRay may put us down a tough path.

Our latest example was Trainer where we only in fact supported 2.3 for the latest Kueue and anyone using 2.2 or 2.1 had major issues.
