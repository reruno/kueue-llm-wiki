**What would you like to be added**:
Mark the steps in the release issue as completed when the manual scripts succeed. We already have this for GitHub Actions: https://github.com/kubernetes-sigs/kueue/issues/13359. We should do the same for scripts that are run manually, such as `./hack/releasing/prepare_pull.sh`.

**Why is this needed**:
To show every member of the release team and the community which step is currently being done.
