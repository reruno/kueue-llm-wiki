## Description

**What happened**:

The Status column on the KueueViz Workloads page, and in the workloads table on the LocalQueue detail page, shows the type of the first condition in `status.conditions` (`workload.status?.conditions?.[0]?.type`). The first condition is usually `QuotaReserved`, so most workloads show "QuotaReserved" whether they are pending, admitted or finished. A pending workload with `QuotaReserved=False` also shows "QuotaReserved".

**What you expected to happen**:

The column shows the workload's actual status, the same way `kueuectl list workload` does with `workload.Status` in `pkg/workload`: Finished, then Admitted, then QuotaReserved, otherwise Pending.

**How to reproduce it (as minimally and precisely as possible)**:

1. Run KueueViz and submit a job that gets admitted and finishes.
2. Open the Workloads page. The Status column shows "QuotaReserved".

**Anything else we need to know?**:

The code is in `cmd/kueueviz/frontend/src/Workloads.jsx` and `cmd/kueueviz/frontend/src/LocalQueueDetail.jsx`. I have a fix with tests ready.

**Environment**:
- Kueue version: main
