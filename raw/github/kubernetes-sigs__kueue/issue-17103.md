## Description

**What happened**:

The KueueViz workload details page shows an error for any Workload whose LocalQueue was deleted. `fetchWorkloadDetails` in `cmd/kueueviz/backend/handlers/workloads.go` looks up the LocalQueue to find the ClusterQueue name and returns `error fetching local queue <name>` when it is not found. Kueue keeps such Workloads, so they stay in the list but cannot be opened.

**What you expected to happen**:

The details page still loads. The ClusterQueue comes from `status.admission` when the Workload is admitted, otherwise it shows "Unknown", as it already does for a Workload without a queue name.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create a LocalQueue and submit a job to it.
2. Delete the LocalQueue.
3. Open the workload details page in KueueViz. It shows the error instead of the details.

**Anything else we need to know?**:

I have a fix with unit tests ready. Other errors from the LocalQueue lookup are still returned.

**Environment**:
- Kueue version: main
