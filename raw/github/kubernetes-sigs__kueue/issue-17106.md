## Description


**What would you like to be cleaned**:

The "NoSchedule or NoExecute" taint effect check is defined once in
[`utiltaints.IsSchedulingTaint`](https://github.com/kubernetes-sigs/kueue/blob/1147a5d3dbab87b5d769f4df436058f859f898f4/pkg/util/taints/taints.go#L31-L34),
but three places re-implement it inline:

1. Flavor assignment: [`flavorassigner.go#L858-L860`](https://github.com/kubernetes-sigs/kueue/blob/1147a5d3dbab87b5d769f4df436058f859f898f4/pkg/scheduler/flavorassigner/flavorassigner.go#L858-L860)
2. TAS node controller, `hasSchedulingTaints`: [`node_controller.go#L433-L437`](https://github.com/kubernetes-sigs/kueue/blob/1147a5d3dbab87b5d769f4df436058f859f898f4/pkg/controller/tas/node_controller.go#L433-L437)
3. TAS node controller, `classifyTaints`: [`node_controller.go#L788`](https://github.com/kubernetes-sigs/kueue/blob/1147a5d3dbab87b5d769f4df436058f859f898f4/pkg/controller/tas/node_controller.go#L788)

Replace them with `utiltaints.IsSchedulingTaint`. No behavior change.

**Why is this needed**:

Which taint effects Kueue evaluates should be defined in one place.
