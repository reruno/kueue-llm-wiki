**What would you like to be cleaned**:

The release-notes binary from `kubernetes/release` is pinned to `v0.20.1` (released 2026-02-26) in `.github/workflows/release-utils.yml`. 

https://github.com/kubernetes-sigs/kueue/blob/4f8aa9cc71dbfca891b7aec97149ecc80407ff2f/.github/workflows/release-utils.yml#L249-L253

The latest available version is `v0.22.0` (released 2026-09-23).                                                                                                                 
                                                                                                                                                            
Additionally, `hack/releasing/sync-notes.sh` passes `--required-author=""` to release-notes, which was removed in a newer version of the tool:                

```                                                                                                                                                            
WARN No subcommand specified, running "generate"
FATA unknown flag: --required-author
```                                                                                                     
                                                                                                                                                            
**Why is this needed**:

Using an outdated binary means we miss bug fixes and improvements in the release-notes tool. The `--required-author` flag removal is a breaking change that prevents `sync-notes.sh` from running locally with any version newer than what is pinned in CI.
