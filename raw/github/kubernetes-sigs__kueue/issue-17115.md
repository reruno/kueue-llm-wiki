## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

The parent checkbox on `.github/ISSUE_TEMPLATE/NEW_RELEASE.md` line 34 is never automatically checked:

https://github.com/kubernetes-sigs/kueue/blob/4f8aa9cc71dbfca891b7aec97149ecc80407ff2f/.github/ISSUE_TEMPLATE/NEW_RELEASE.md?plain=1#L34-L38

When `/wait-for-prod-images` succeeds (the last sub-step), the parent step remains unchecked and requires manual action.

Add a step marker `<!-- step:wait-for-prod-images -->` to line 34:

```
- [ ] Promote images and Helm Charts to production: <!-- step:wait-for-prod-images -->
```

**Why is this needed**:

The "Promote images and Helm Charts to production" parent step is the only top-level release checklist item that is never automatically checked by the release automation – the release manager must check it manually after `/wait-for-prod-images` succeeds. All other top-level steps that consist solely of ChatOps sub-steps are checked automatically. Making this step consistent reduces the chance of a release issue being left with an unchecked box that does not reflect the actual state.
