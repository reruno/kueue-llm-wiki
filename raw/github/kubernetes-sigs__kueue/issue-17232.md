## Description

**What happened**:

Some KueueViz pages build a link from a name that can be missing, so the link points to a page that does not exist:

- Dashboard: for a workload that is not admitted, the ClusterQueue column shows "N/A" linked to `/cluster-queue/undefined`.
- Workload detail: when the ClusterQueue is not known, it shows "Unknown" linked to `/cluster-queue/Unknown`.
- ClusterQueues list and ClusterQueue detail: a ClusterQueue without a Cohort gets an empty link to `/cohort/` (or `/cohort/undefined`).

**What you expected to happen**:

When the name is missing, the page shows plain text and no link.

**How to reproduce it (as minimally and precisely as possible)**:

1. Run KueueViz with a pending workload and a ClusterQueue that has no Cohort.
2. On the dashboard, click "N/A" in the ClusterQueue column. It opens `/cluster-queue/undefined`.
3. Open the ClusterQueue detail page. The Cohort field holds an empty link.

**Anything else we need to know?**:

The code is in `Dashboard.jsx`, `WorkloadDetail.jsx`, `ClusterQueues.jsx` and `ClusterQueueDetail.jsx` under `cmd/kueueviz/frontend/src`. I have a fix with tests ready.

**Environment**:
- Kueue version: main
