## Description

**What happened**:

On the KueueViz ResourceFlavor detail page, "Node Labels" and "Node Taints" always show "None", even when the flavor sets `spec.nodeLabels` and `spec.nodeTaints`.

`ResourceFlavorDetail.jsx` reads `details.nodeLabels` and `details.nodeTaints`. `fetchResourceFlavorDetails` in `cmd/kueueviz/backend/handlers/resource_flavors.go` sends `details` with only `tolerations` and `taints`, so neither key the page reads is present.

**What you expected to happen**:

The page shows the flavor's node labels and node taints.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create a ResourceFlavor with `spec.nodeLabels` and `spec.nodeTaints`.
2. Open its detail page in KueueViz. Both sections show "None".

**Anything else we need to know?**:

I have a fix with a unit test ready.

**Environment**:
- Kueue version: main
