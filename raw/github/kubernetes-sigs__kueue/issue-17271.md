## Description

**What happened**:

On the KueueViz dashboard, the tooltip of a preempted workload should link the preemptor's UID to its workload page. No link is shown.

- `Dashboard.jsx` looks for `(UID: <uid>)` in the eviction message, but Kueue writes `(UID: <uid>, JobUID: <job-uid>)` (`preemptionMessage` in `pkg/scheduler/preemption/preemption.go`), so the pattern never matches.
- The backend `workloads_by_uid` map in `workloads_dashboard.go` holds only the workload name, so even with a match the link would go to `/workload/<name>`, which does not match the `/workload/:namespace/:workloadName` route.

**What you expected to happen**:

The preemptor UID in the tooltip links to `/workload/<namespace>/<name>`.

**How to reproduce it (as minimally and precisely as possible)**:

1. Run KueueViz and let a higher priority workload preempt another one.
2. On the dashboard, hover over "Evicted" in the Preempted column. The UID is plain text.

**Anything else we need to know?**:

I have a fix with tests ready.

**Environment**:
- Kueue version: main
