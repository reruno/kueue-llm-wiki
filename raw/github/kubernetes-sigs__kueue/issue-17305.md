## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:
Split SchedulerSimulator into:
- SchedulerSimulator (all methods except FindFeasibleNodes),
- FeasibilitySimulator (with FindFeasibleNodes).

For the was impl, ideally, the two interfaces will use the same impl of wasSimulator, just set up with different config by the factory.

For reference see this draft: #17078

**Why is this needed**:
So far, the simulator is used etiher for feasibility or for scheduling.
This split would also reduce the default simulator impl to just feasibility sim.
