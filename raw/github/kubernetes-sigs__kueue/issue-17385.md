## Description

**What happened**:

For a RuntimeClass event, `resourceUpdatesHandler` passes a `MatchingFields` with `WorkloadRuntimeClassKey` to `queueReconcileForPending` ([workload_controller.go#L1948](https://github.com/kubernetes-sigs/kueue/blob/bb201e17bd1cf47909aad100b0f6aaaa92bd3efd/pkg/controller/core/workload_controller.go#L1948)), which appends a second `MatchingFields` with `WorkloadQuotaReservedKey` ([#L1957](https://github.com/kubernetes-sigs/kueue/blob/bb201e17bd1cf47909aad100b0f6aaaa92bd3efd/pkg/controller/core/workload_controller.go#L1957)). `MatchingFields.ApplyToList` replaces `ListOptions.FieldSelector` ([options.go#L776-L780](https://github.com/kubernetes-sigs/controller-runtime/blob/v0.25.2/pkg/client/options.go#L776-L780)), so the second option drops the RuntimeClass filter and `List` returns every pending workload in the cluster. Each one that needs DRA processing gets a reconcile request, and each other admissible one goes through `AddOrUpdateWorkload` again. Besides real changes, this runs once per RuntimeClass at each start of kueue-controller-manager and at every informer resync, about every 10 hours by default.

**What you expected to happen**:

Only the pending workloads whose PodSets use that RuntimeClass are processed.

**How to reproduce it (as minimally and precisely as possible)**:

The test below creates three pending DRA workloads, one with RuntimeClass `kata`, one with `gvisor` and one without, and sends a create event for `kata`. All three get a reconcile request on main (bb201e17b), v0.20.2 and v0.19.9.

package core

import (
	"testing"

	nodev1 "k8s.io/api/node/v1"
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"sigs.k8s.io/controller-runtime/pkg/event"

	kueue "sigs.k8s.io/kueue/apis/kueue/v1beta2"
	qcache "sigs.k8s.io/kueue/pkg/cache/queue"
	schdcache "sigs.k8s.io/kueue/pkg/cache/scheduler"
	"sigs.k8s.io/kueue/pkg/controller/core/indexer"
	"sigs.k8s.io/kueue/pkg/features"
	utiltesting "sigs.k8s.io/kueue/pkg/util/testing"
	utiltestingapi "sigs.k8s.io/kueue/pkg/util/testing/v1beta2"
)

func TestRuntimeClassEventListsOnlyItsWorkloads(t *testing.T) {
	// DRA workloads, so that each listed workload shows up as a reconcile request.
	features.SetFeatureGateDuringTest(t, features.KueueDRAIntegration, true)
	ctx, _ := utiltesting.ContextWithLog(t)
	ps := func(rc string) *utiltestingapi.PodSetWrapper {
		p := utiltestingapi.MakePodSet(kueue.DefaultPodSetName, 1).ResourceClaimTemplate("gpu", "tmpl")
		if rc != "" {
			p = p.RuntimeClass(rc)
		}
		return p
	}
	cl := utiltesting.NewClientBuilder().
		WithIndex(&kueue.Workload{}, indexer.WorkloadQuotaReservedKey, indexer.IndexWorkloadQuotaReserved).
		WithIndex(&kueue.Workload{}, indexer.WorkloadRuntimeClassKey, indexer.IndexWorkloadRuntimeClass).
		WithObjects(
			utiltestingapi.MakeWorkload("uses-kata", "ns1").Queue("lq").PodSets(*ps("kata").Obj()).Obj(),
			utiltestingapi.MakeWorkload("uses-gvisor", "ns2").Queue("lq").PodSets(*ps("gvisor").Obj()).Obj(),
			utiltestingapi.MakeWorkload("no-runtimeclass", "ns3").Queue("lq").PodSets(*ps("").Obj()).Obj(),
		).Build()
	cqCache := schdcache.New(cl)
	h := &resourceUpdatesHandler{r: NewWorkloadReconciler(cl, qcache.NewManagerForUnitTests(cl, cqCache), cqCache, &utiltesting.EventRecorder{})}
	q := &utiltesting.MockTypedRateLimitingInterface{}

	h.Create(ctx, event.CreateEvent{Object: &nodev1.RuntimeClass{ObjectMeta: metav1.ObjectMeta{Name: "kata"}, Handler: "kata"}}, q)

	if len(q.Items) != 1 {
		t.Errorf("reconcile requests = %v, want only ns1/uses-kata", q.Items)
	}
}

**Anything else we need to know?**:

Passing both keys in one `MatchingFields`, as `deviceClassHandler.reconcileWorkloads` does ([#L2171-L2176](https://github.com/kubernetes-sigs/kueue/blob/bb201e17bd1cf47909aad100b0f6aaaa92bd3efd/pkg/controller/core/workload_controller.go#L2171-L2176)), makes the test pass. The LimitRange path is not affected, because `client.InNamespace` sets `ListOptions.Namespace`. Open PR #16731 adds `queueReconcileForReserved`, which appends a second `MatchingFields` the same way, so with it a RuntimeClass event would also reconcile every reserved workload in the cluster that isn't admitted yet.
