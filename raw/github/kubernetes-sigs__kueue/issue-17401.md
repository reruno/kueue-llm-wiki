## Description

<!-- Please only use this template for submitting enhancement requests -->
**What would you like to be added**:

A built-in MultiKueue `CapacityProvider` for Dynamic Quota Orchestration (DQO, #12382). For a manager ClusterQueue, the provider finds the related worker ClusterQueues and adds up their quotas. It writes the sum to `CapacityProvider.status.capacity`. DQO then writes the manager quota to `ClusterQueue.status.effectiveQuotas`.

This is a follow-up to [KEP-12382](https://github.com/kubernetes-sigs/kueue/tree/main/keps/12382-dynamic-quota-orchestration). It lists MultiKueue worker capacity as a built-in provider (Story 1) and leaves the provider API to a separate KEP.

**Why is this needed**:

This is the Alpha2 stage of #9988. In Alpha1, the MultiKueue controller writes the sum to the manager `ClusterQueue.spec`. A controller should not change the `spec` that users own. With DQO, the controller writes only to `status`.

KEP-9988 and KEP-12382 both plan this change for the Alpha2 stage of KEP-9988.
