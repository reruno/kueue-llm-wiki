**What would you like to be added**:

This is a follow up under the umbrella issue: https://github.com/kubernetes-sigs/kueue/issues/975 to support Partial Preemption for RayJobs / Clusters. For RayServices this is being tracked as https://github.com/kubernetes-sigs/kueue/issues/12146 ; however, for training and data workloads on Ray we will also need to support RayJobs and by extension RayClusters

**Why is this needed**:

As part of #14589 changes will need to be introduced to the Ray Controller so that Partial Preemption works across the Ray stack with Kueue. 

**Completion requirements**:

An Alpha gated feature that allows RayClusters to be partially preempted while continuing to run.
