## Description

**What happened**:

KueueViz keys some rows by name only, but Workload and LocalQueue names are only unique within a namespace.

- Dashboard: expanded rows are tracked by `workload.metadata.name`. With all namespaces selected, expanding one workload also expands every workload with the same name in another namespace. Both rows also share the same React key.
- ClusterQueue detail: the "Local Queues Using This Cluster Queue" rows are keyed by `queue.name`, so two LocalQueues with the same name in different namespaces share a React key.

**What you expected to happen**:

Each row is identified by namespace and name. Expanding a workload expands only that workload.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create a workload named `wl` in `ns-a` and another named `wl` in `ns-b`.
2. Open the dashboard with all namespaces selected and expand the `ns-a` row. The `ns-b` row expands too.

**Anything else we need to know?**:

I have a fix with a test ready.

**Environment**:
- Kueue version: main
