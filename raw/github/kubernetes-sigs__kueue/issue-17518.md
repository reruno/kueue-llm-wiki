**Which test is flaking?**:

**Anything else we need to know?**:

The ClusterQueue keeps its `resource-in-use` finalizer, so `AfterEach` cannot delete it.
This looks like the same teardown race as #15921, which #15927 fixed in the integration suite: the spec only waits for the Variant Workloads to be created, not for one of them to be admitted.
