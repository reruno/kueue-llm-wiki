## Description

**What happened**:

The "Owner Reference" section on the KueueViz workload detail page, and the owner reference in the Workloads page tooltip, always show "N/A".

Both read `workload.ownerReferences`, but owner references are under `metadata.ownerReferences`. The events table on the detail page also uses `event.name` as the row key, which is under `metadata` as well.

**What you expected to happen**:

The page shows the owning Job's API version, kind, name and UID.

**How to reproduce it (as minimally and precisely as possible)**:

1. Submit a Job to a LocalQueue.
2. Open its workload detail page. API Version, Kind, Name and UID all show "N/A".
