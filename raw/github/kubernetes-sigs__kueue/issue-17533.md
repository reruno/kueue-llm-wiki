**What would you like to be cleaned**:

`fetchResourceFlavorDetails` in `cmd/kueueviz/backend/handlers/resource_flavors.go` fetches the ResourceFlavor, then `getNodesForFlavor` fetches the same ResourceFlavor again only to read `spec.nodeLabels`. Pass the node labels from the first read instead.

**Why is this needed**:

It removes one read per update, and the nodes on the page always match the flavor shown on the same page, even if the flavor changes between the two reads.
