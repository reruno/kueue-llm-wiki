## Description

**What happened**:

"Pod Sets Count" on the KueueViz workload detail page, and in the Workloads page tooltip, shows `spec.podSets[0].count`, which is the pod count of the first pod set, not the number of pod sets. A workload with two pod sets of 1 and 4 pods shows "1".

**What you expected to happen**:

"Pod Sets Count" shows the number of pod sets. The total pod count is shown separately, as the dashboard already does.

**How to reproduce it (as minimally and precisely as possible)**:

1. Submit a workload with more than one pod set, for example a JobSet with two replicated jobs.
2. Open its workload detail page. "Pod Sets Count" shows the first pod set's pod count.
