## Description

**What happened**:
After bumping the `scheduler-library` version in https://github.com/kubernetes-sigs/kueue/pull/17551, we lost granular unschedulability reasons for `PodPlacement`. The `scheduler-library` now does not populate `PodResults` unless the pod group is schedulable or can do preemptions.

**What you expected to happen**:
We'd want granular results, like "0/2 nodes are available: 2 Insufficient cpu."
