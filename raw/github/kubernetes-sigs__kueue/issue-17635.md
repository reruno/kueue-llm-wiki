**What would you like to be added**:
Graduate KueueDRAIntegrationConsumableCapacity to Beta, enabled by default in v0.21. This includes:
- Separate quota for each capacity dimension of a DeviceClass, for example memory and cores.
- A log line when RequestPolicy rounding raises a capacity request.
- KEP-2941 and docs updates for Beta.

**Why is this needed**:
Kueue added consumable capacity as Alpha in v0.19 (#11726). Upstream DRAConsumableCapacity is Beta and on by default since Kubernetes 1.36, and targets GA in 1.38 (kubernetes/enhancements#5075). Kueue should be Beta before upstream goes GA. Today, a device that publishes memory and compute can't have separate quota for each.
