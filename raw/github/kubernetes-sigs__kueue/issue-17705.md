## Description

**What would you like to be cleaned**:

In `pkg/dra`, skip invalid ResourceSlice pools, as the DRA allocator does, and share one eligible-pools helper between the CEL availability and counter paths (`claims.go` and `counters.go`).

Acceptance criteria:
- Both paths use the same eligibility checks for complete, valid pools at the highest observed generation, grouped by driver and pool name.
- Add regression coverage for invalid pools and retain stale/incomplete-pool coverage.
- Preserve slice and device order for overlapping CEL requests.

**Why is this needed**:

PR #17649 excludes stale and incomplete pools from CEL availability checks. This follow-up aligns invalid-pool handling with the allocator and prevents eligibility checks from diverging between CEL and counters.
