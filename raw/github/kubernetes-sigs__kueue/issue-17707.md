## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

Add `cohort` (alias: `co`) and `topology` (alias: `topo`) to `kueuectl` pass-through commands (`get`, `describe`, `edit`, `patch`, `delete`).

Currently in `cmd/kueuectl/app/passthrough/passthrough.go`, `passThroughTypes` only defines:
- `workload` (`kwl`, `kueueworkload`, `kueueworkloads`)
- `clusterqueue` (`cq`)
- `localqueue` (`lq`)
- `resourceflavor` (`rf`)

`Cohort` and `Topology` are both core CRDs under `kueue.x-k8s.io`, but attempting to run:

    kueuectl get cohort
    kueuectl describe topology

fails with:

    Error: unknown command "cohort" for "kueuectl get"

**Why is this needed**:

Users using `kueuectl` expect to inspect and manage all first-class Kueue resources consistently instead of having to switch back to raw `kubectl` specifically for cohorts and topologies.
