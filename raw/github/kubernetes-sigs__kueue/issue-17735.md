## Description

### What would you like to be cleaned:

Refactor .github/workflows/sync-dependabot.yaml to separate dependency generation from the write-capable push step.

Run generation with the PR’s bumped dependency versions and without write credentials.
Use a trusted push job that validates the PR, head commit, and generated changes.
Do not execute PR-controlled code in the write-capable job.
Keep Hugo sync and make manifests update-helm working. Verify that generated changes reach the correct PR branch.

### Why is this needed:

Reduce write-token exposure while preserving dependency sync behavior. This is a security-hardening follow-up, not a fix for a confirmed read-only token failure.

Requested by @mbobrovskyi in https://github.com/kubernetes-sigs/kueue/pull/17729#discussion_r4376750354, following discussion in #17729.
