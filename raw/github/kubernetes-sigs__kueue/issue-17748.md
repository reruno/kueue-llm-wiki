**What would you like to be added**:

A KEP (Kueue Enhancement Proposal) under `keps/` that defines the design for generating SLSA build-time provenance attestations for Kueue release artifacts.

The design doc should cover:
- Which artifacts are attested (staging container images, GitHub release binaries, Helm chart)
- The signing mechanism and identity (e.g., cosign keyless via Sigstore OIDC)
- Where attestations are stored (GitHub attestation store, OCI registry, release asset)
- The trust model and SLSA build level achievable under the current CI/CD setup
- How consumers verify provenance
- Whether release candidates are covered
- Interaction with kpromo (which already handles promotion-time provenance for registry.k8s.io images)

**Why is this needed**:

This is a required artifact for tracking issue kubernetes-sigs/kueue#1466 (Generate SLSA Attestations with new releases). A design doc is required before implementation to align on scope, tooling choice, and trust model.
