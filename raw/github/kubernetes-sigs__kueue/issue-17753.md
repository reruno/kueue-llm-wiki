**What would you like to be added**:

Graduate `KueueDRADeviceFeasibility` (Alpha in v0.20, #15577) to Beta, per the KEP-2941 Beta criteria:

- [ ] Count devices per node, not only feasibility.
- [ ] Release a preempted Workload's devices in the simulation.
- [ ] Cache ResourceSlices and DeviceClasses across cycles.
- [ ] e2e tests with kube-scheduler placement.
- [ ] Enable the gate by default.

**Why is this needed**:

The check tells whether one Pod fits on a node, not how many, so TAS can over-admit device Pods. Preemption also can't free devices, so some Workloads stay queued.
