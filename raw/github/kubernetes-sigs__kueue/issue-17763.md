## Description

**What would you like to be cleaned**:

In `test/integration/singlecluster/kueuectl/passthrough_test.go`, register deferred cleanup immediately after object creation. Cover the ClusterQueue, ResourceFlavor, Cohort, and Topology cases, including aliases. Reuse the suite's cleanup helpers and tolerate `NotFound` after the tested delete command succeeds.

Acceptance criteria: cleanup runs after get or patch assertion failures, successful delete checks still pass, and repeated cases do not fail with `AlreadyExists` from leaked objects.

**Why is this needed**:

These cluster-scoped objects use fixed names. The current test deletes them only after the get and patch assertions pass. A failure can leave objects behind and affect later cases or reruns.
