## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

Skip the DRA CEL availability check on the MultiKueue manager, as the TAS device check already does for a ClusterQueue with a MultiKueue admission check.

**Why is this needed**:

The manager checks CEL selectors against its own ResourceSlices. A manager without the devices never reserves quota, so MultiKueue never dispatches the Workload. I reproduced it in envtest on main: the Workload stays at `QuotaReserved=False`, reason `DRAResourcesUnresolved`, "0 device(s) match in the cluster but 2 requested". It reserves quota once a matching ResourceSlice exists.

Counter-based quota still reads ResourceSlices on the manager, so this skip doesn't remove that need.
