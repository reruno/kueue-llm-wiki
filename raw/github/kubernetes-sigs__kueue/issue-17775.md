## Description

**What happened**:

A ClusterQueue can set `spec.cohortName`, and a Cohort can set `spec.parentName`, to a Cohort that has no Cohort object. Kueue treats such a Cohort as implicit (`pkg/cache/hierarchy/manager.go`). KueueViz lists only Cohort objects, so implicit Cohorts are missing from the Cohorts page, and opening one, for example from the Cohort link on a ClusterQueue page, shows an error.

**What you expected to happen**:

Implicit Cohorts are listed with their ClusterQueues, and their detail page loads.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create a ClusterQueue with `spec.cohortName: team` and no Cohort named `team`.
2. Open the Cohorts page in KueueViz. `team` is not listed.
3. Open `/cohort/team`. The page shows "error fetching cohort team".

**Anything else we need to know?**:

I have a fix with tests ready.

**Environment**:
- Kueue version: main
