## Description

**What happened**:

The tree view on the KueueViz Cohorts page starts from Cohorts without a listed parent. Cohorts whose `spec.parentName` values form a cycle are not reachable from any of them, so the tree view drops those Cohorts and their children. Kueue allows such a cycle to exist and reports it, so it is useful to still see it in the UI.

**What you expected to happen**:

Every Cohort appears in the tree view.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create Cohort `a` with `parentName: b` and Cohort `b` with `parentName: a`.
2. Open the Cohorts page and switch to the tree view. Neither Cohort is shown.

**Anything else we need to know?**:

I have a fix with tests ready.

**Environment**:
- Kueue version: main
