## Description

**What happened**:

The "Local Queues Using This Cluster Queue" table on the KueueViz ClusterQueue page shows only the LocalQueue name. LocalQueues in different namespaces often share a name, for example `user-queue` in every team namespace, so the rows cannot be told apart without hovering the link.

**What you expected to happen**:

Each row shows the LocalQueue as `namespace/name`.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create LocalQueues named `user-queue` in two namespaces, both pointing to one ClusterQueue, and submit a job to each.
2. Open the ClusterQueue page. Both rows show `user-queue`.

**Anything else we need to know?**:

I have a fix with a test ready.

**Environment**:
- Kueue version: main
