**What would you like to be added**:
Graduate PriorityBoost (Alpha since v0.17) to Beta, per KEP-7990. #12927 already lists it as "Ready to Beta". The hold there was waiting on Configurable Preemptions, which shipped a Boosted priority mode in v0.20.

- [x] Fix the requeue gap. A boost change on an admitted Workload without a WorkloadPriorityClass doesn't requeue pending Workloads. In envtest, a same-priority Workload preempts in under a second with a WorkloadPriorityClass, and it's still pending after 45s without one.
- [ ] Write the KEP decisions on preemption cost, anti-flapping and a maxPriorityBoost cap.
- [ ] Add integration tests for LowerOrNewerEqualPriority with boost.
- [ ] Add a docs page and enable the gate by default.

**Why is this needed**:

Users edit spec.priority by hand today (#14698), and the annotation is the supported way to do that.
