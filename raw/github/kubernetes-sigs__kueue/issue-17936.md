### What would you like to be added/modified?

The StatefulSet reconciler still carries a fallback in `findWorkload()` to query legacy workload names (without owner UID) when the primary name isn't found:
- `pkg/controller/jobs/statefulset/statefulset_reconciler.go:253` (`// TODO(#9497, v0.20): Remove legacy fallback.`)

Since Kueue is now on v0.21+, we can drop this legacy fallback:
1. Simplify `findWorkload()` to only query the workload name using the STS UID, avoiding redundant API `Get` calls when no workload exists yet.
2. Remove the legacy fallback test cases in `statefulset_controller_test.go`, `statefulset_reconciler_test.go`, and `statefulset_webhook_test.go` that were scheduled for removal in v0.20.

I have a patch ready for this.
