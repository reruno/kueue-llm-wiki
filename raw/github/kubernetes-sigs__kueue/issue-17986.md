## Description

**What would you like to be cleaned**:

After https://github.com/kubernetes-sigs/scheduler-library/pull/65 is merged and Kueue includes a scheduler-library revision containing it, migrate the gang scheduling plugin test in `pkg/cache/scheduler/was/scheduler_simulator_test.go` to the public simulator interface.

Use `NewWASSimulatorFactory`, `NewSimulator`, and `ScheduleWorkload` instead of calling `newWASSchedulerConfig` and `RunPlacementFeasiblePlugins` directly.

Acceptance criteria:
- Verify through `ScheduleWorkload` that a PodGroup with fewer Pods than `MinCount` is rejected.
- Preserve regression coverage that detects a disabled `GangScheduling` plugin.
- Remove the replaced low-level test setup.

Keep the current test approach, with the requested rename, until both prerequisites are met.

**Why is this needed**:

Test observable simulator behavior without coupling the test to a package-private configuration function and scheduler framework internals.
