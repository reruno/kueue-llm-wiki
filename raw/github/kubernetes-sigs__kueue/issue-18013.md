## Description

**What happened**:

On the ResourceFlavor detail page, taints and tolerations are built from every field, but the API omits empty optional fields:

- a flavor taint without a value, such as `node-role.kubernetes.io/control-plane:NoSchedule`, shows `node-role.kubernetes.io/control-plane=undefined (NoSchedule)`
- a toleration with `operator: Exists` and no key shows `undefined (Exists): undefined`
- a node taint without a value shows `key= (NoSchedule)`

The toleration value is never shown.

**What you expected to happen**:

Labels that skip empty fields, in the same format as `kubectl describe`: `key=value:Effect`, `key:Effect`, `op=Exists`.

**How to reproduce it (as minimally and precisely as possible)**:

1. Create a ResourceFlavor with `nodeTaints: [{key: spot, effect: NoSchedule}]` and `tolerations: [{operator: Exists}]`.
2. Open `/resource-flavor/<name>` in KueueViz.
