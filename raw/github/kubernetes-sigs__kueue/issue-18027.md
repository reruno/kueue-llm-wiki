FYI i asked my ai assistant and it proposed:
1. reuse a prebuilt DRA driver image - the image is now prebuilt- registry.k8s.io/dra-example-driver/dra-example-driver:v0.5.0
2. download a pinned Helm release binary instead of compiling Helm - Removes most of the observed 65–126 seconds spent building Helm. Helm is needed to install the DRA driver. This would benefit other E2E jobs too.
3. raise CPU requests and limits from 3300m to 6600m; keep RAM at 10Gi.

I guess we could start with 1 and 2, and see if we need (3.), wdyt? Any other ideas?

### Comment by [@henry3260](https://github.com/henry3260) — 2026-10-30T10:33:07Z

+1 to starting with 1 and 2:

1. `registry.k8s.io/dra-example-driver/dra-example-driver:v0.5.0` exists and matches our pin. This saves ~2 min per DRA job, and multikueue-dra currently builds the image 3 times. We can fall back to building from source if a tag isn't published yet.
2. For Helm, download the release binary using the version from `hack/tools/go.mod`, so dependabot still tracks it.

With both I'd expect ~8-9 min, so (3) may not be needed.
