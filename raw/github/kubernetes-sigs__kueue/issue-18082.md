## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

The `certsReady` channel in `cmd/kueue/main.go`, the `setupFinished` parameter of `cert.ManageCerts`, and the `certificates are not ready` branch of the readyz check in `setupProbeEndpoints`, along with its comment saying `GetWebhookServer` has to be called lazily. The readyz check can be `mgr.GetWebhookServer().StartedChecker()` directly.

**Why is this needed**:

Since #7772, `cert.BootstrapCerts` writes the webhook certificates with a separate bootstrap manager before the main manager is created. `ManageCerts` then closes `certsReady` right away, and without internal cert management `main` closes it in the `else` branch. Both happen before `mgr.Start`, so the channel is always closed when readyz is served. The `default` branch is unreachable, and the comment no longer matches how startup works.
