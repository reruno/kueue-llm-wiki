## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

`TestParseResourceQuotas` in `cmd/kueuectl/app/create/create_clusterqueue_test.go` checks errors twice. `wantErr error` is compared with `cmpopts.EquateErrors()` (that is, `errors.Is`), and the optional `wantErrMessage string` is compared with `err.Error()`.

Replace both fields with a single `wantErr string` compared with `err.Error()`, as the other kueuectl tests do (`create_resourceflavor_test.go`, `create_localqueue_test.go`, `list_*_test.go`, `delete_workload_test.go`, `version_test.go`):

- An empty `wantErr` still means "no error expected".
- The cases that set only `wantErr` today (`errInvalidResourcesSpec` and `errInvalidResourceQuota`) need their full error messages.
- Drop the `cmpopts` import, which would no longer be used.

**Why is this needed**:

The sentinel text is already part of every message (for example `invalid resource group: flavor "beta" covers ...`), so `wantErrMessage` checks the error category too. The only extra thing `wantErr error` checks is that the sentinel is wrapped with `%w`. Nothing in kueuectl calls `errors.Is` on these sentinels outside the tests, so no caller relies on that. A single field removes the duplicate check and matches the rest of kueuectl.

Follow-up to https://github.com/kubernetes-sigs/kueue/pull/16632, raised in https://github.com/kubernetes-sigs/kueue/pull/16632#issuecomment-6528825996.
