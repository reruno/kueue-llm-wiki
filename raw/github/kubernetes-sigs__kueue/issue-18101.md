## Description

**What would you like to be added**:

Support structured log values on returned errors, as proposed by @mimowo in PR #17747.

- Add `logging.ErrorWithLogValues` with `Error()`, `Unwrap()`, and `LogValues() []any`.
- Extend `CustomLogProcessor.write` in `pkg/util/logging/logging.go` to extract these values, including through wrapped errors.
- Update `shouldSuspendChildJob` in `pkg/controller/jobframework/reconciler.go` to return the contextual error with `"ancestorJob", klog.KObj(ancestorJob)` instead of logging locally before returning it.

**Why is this needed**:

Preserve structured diagnostic fields in the final reconciliation error log without logging the same failure twice. This is a follow-up to PR https://github.com/kubernetes-sigs/kueue/pull/17747.

Requested by @tenzen-y: https://github.com/kubernetes-sigs/kueue/pull/17747#discussion_r4426981337.

**Completion requirements**:

- Tests confirm that structured values survive error wrapping and appear in the final error log.
- Tests confirm that `errors.Is` and `errors.As` still work and that ordinary errors retain existing logging behavior.
- The ancestor Workload lookup failure produces one error log with the `ancestorJob` field.
