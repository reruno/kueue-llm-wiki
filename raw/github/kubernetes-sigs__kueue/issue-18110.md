## Description


**What would you like to be cleaned**:
`reportCQPendingWorkloads` gets the ClusterQueue pending counts from `PendingBreakdown()`, which copies the active and inadmissible `LabelValsTracker`s and then merges them into a third one. 

With `CustomMetricLabels` off, only `.Total()` of each copy is read. `ClusterQueue.Pending()` and `PendingTotal()` also copy both trackers just to read the totals.


**Why is this needed**:
In `make run-tas-performance-scheduler` on main, `reportCQPendingWorkloads` takes 2.55% of Kueue's allocations, and the tracker copies in `PendingBreakdown` take 1.88%. It runs under the queue manager lock on every queue change.
