## Description

## Goal

Cut the time reviewers spend working out what a PR changes. A frontend PR shows before/after screenshots. In Kueue, the authoring agent would add generated, reproducible before/after evidence under "Useful notes for your reviewer". Close this umbrella when the tasks below are done.

Proposed conventions for all evidence skills:

- Each skill owns one marked block (`<!-- pr-evidence:<skill>:start -->` … `:end -->`) under "Useful notes for your reviewer". Re-runs replace the block in place and leave other text alone.
- About 25 visible lines per block; overflow goes in `<details>`.
- The "before" side is generated from the merge base, never typed by hand. The block header pins the base and head SHAs.
- envtest by default. kind only when the behavior needs real Pods (PodsReady), DRA, TAS node-fit, or MultiKueue.
- The agent injects the block automatically through one shared writer in `kueue-pr-issue-workflow`, and only into a PR opened by the user it runs as.

Related: #13125, #11162, #13840
