**What would you like to be added**:

Part of #18141

A skill in `cmd/experimental/skills/kueue-pr-evidence-contract-delta/` that reads the merge base and head versions of each changed file with `git show <sha>:<path>`, without a cluster or a checkout, and lists changes to:

- CRD fields, defaults, validation, and CEL messages (`config/components/crd/bases`)
- webhook error messages
- reason, label, and annotation constants, and event reasons
- metric names, labels, and help text (`pkg/metrics`)
- feature gates added, removed, or with a changed default (`pkg/features`)
- log lines whose verbosity or keys changed
- kueuectl flags, columns, and error strings

A reworded message counts as one change. The skill flags a likely `ACTION REQUIRED` when a metric, label, annotation, or log key is renamed or removed, a default changes, a gate default flips or a gate is removed, or a kueuectl flag is removed, and points to `kueue-release-notes`.

Illustrative block (log counts from the #17747 diff):

```text
**kueue-pr-evidence-contract-delta** base 1a2b3c4d5e6f -> head 9f8e7d6c5b4a
| surface | change |
| log verbosity (pkg/controller/jobframework) | V(2) -21, V(3) +1, V(4) +4, V(5) +10 |
| log.Error calls | -20 |
Likely ACTION REQUIRED: none (no metric, label, default, or gate change).
Unchanged: CRDs, webhooks, reasons, metrics, feature gates, kueuectl.
```

Non-goals: judging whether a change is acceptable, editing the release-note block.

Related: #10761

**Why is this needed**:

Changed defaults, renamed metrics, and moved log levels are easy to miss in a large diff or in generated CRD YAML, and asking about them costs review rounds. A static table lists them in the PR, so a breaking change is less likely to merge without an ACTION REQUIRED note.

Test PRs: #17747 (log verbosity), #16632 (kueuectl error messages).

**Completion requirements**:

Acceptance criteria:

- Base versions are read only from the merge base.
- Every listed surface is checked. With no changes, the block is one line naming them.
- Likely ACTION REQUIRED is flagged for the cases above.
- On #17747 the log counts match the diff; on #16632 the changed kueuectl messages are listed.
