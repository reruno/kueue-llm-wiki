## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

The golang builder image on release-0.20 is still on Go 1.27.1. `hack/images/golang/Dockerfile` on release-0.20 pins `public.ecr.aws/docker/library/golang:1.27@sha256:3680233e…` (Go 1.27.1). On main, #17823 moved the pin to `sha256:9048d5e7…` (Go 1.27.3). Dependabot updates main only, so release-0.20 needs a manual cherry-pick of #17823.

**Why is this needed**:

Until then, the v0.20.x container images build with Go 1.27.1 and miss the fixes in Go 1.27.2 and 1.27.3. I checked both digests on ECR Public. The `linux/amd64` image config of `9048d5e7…` has `GOLANG_VERSION=1.27.3`, and the one of `3680233e…` has `GOLANG_VERSION=1.27.1`.

I have the cherry-pick ready, but GitHub currently refuses to let my account open pull requests against this repository. `gh pr create` fails with `GraphQL: vladikkuzn does not have the correct permissions to execute CreatePullRequest`, and the REST API returns 404.

- Compare link: https://github.com/kubernetes-sigs/kueue/compare/release-0.20...vladikkuzn:kueue:release-0.20-golang-1.27.3?expand=1
- Branch `vladikkuzn:release-0.20-golang-1.27.3`, head `d5c38d945cffdf465087101c2c5f42bcb1acabe4`

The branch is a `git cherry-pick -x` of #17823 (c0790ce8dc245f23d17c548f7225d970afcb8200) onto release-0.20. It changes only the `FROM` digest in `hack/images/golang/Dockerfile`, from `3680233e…` to `9048d5e7751706200eb1719c7dae0436950d362f29a1da91fa05e5c63867c60f`. The FROM line conflicted because main's pre-image was a different digest, and I resolved it to #17823's digest.

A maintainer is welcome to open the PR from that branch. Otherwise I will open it as soon as GitHub allows.
