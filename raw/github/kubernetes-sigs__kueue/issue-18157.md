## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

Remove `/cmd/experimental/kueue-populator` from the `gomod` ecosystem's `directories` in `.github/dependabot.yml`.

**Why is this needed**:

kueue-populator has had no `go.mod` of its own since #10471 (the fix for #10470) moved it onto the root module. Dependabot still lists the directory for gomod updates, but there is no manifest there, so that entry does nothing. The root `/` entry already covers the populator's Go dependencies. The `docker` entry for `/cmd/experimental/kueue-populator` should stay, because the directory still has a `Dockerfile`.

I have the change ready, but GitHub currently refuses to let my account open pull requests against this repository. `gh pr create` fails with `GraphQL: vladikkuzn does not have the correct permissions to execute CreatePullRequest`, and the REST API returns 404.
