## Description

#### What happened?

The pod importer logs `End pods list` with a defer inside the namespace loop. The defer runs only when `ListPods` returns, so completion logs are emitted after all namespaces are processed and in reverse order.

#### What did you expect to happen?

Each namespace should log `End pods list` when its own Pod listing completes. The completion log should also be emitted when listing that namespace fails.

#### How can we reproduce it (as minimally and precisely as possible)?

Run the pod importer against more than one namespace with log verbosity 3 or higher. The completion logs are emitted only when `ListPods` exits, in reverse namespace order.

#### Anything else we need to know?

A fix scopes the completion-log defer to each namespace listing and adds unit coverage for normal and error paths.
