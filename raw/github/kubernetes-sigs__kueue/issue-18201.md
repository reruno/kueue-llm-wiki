## Description

**What would you like to be added**:

Emit a `FailedCreateWorkload` Warning event on the owning StatefulSet when Workload creation returns an Invalid or Forbidden API error.

Update `pkg/controller/jobs/statefulset/statefulset_reconciler.go`, which creates Workloads outside `handleJobWithNoWorkload`.

**Why is this needed**:

These failures otherwise remain visible only in controller logs. Extend the observability added by #17923 to this independent reconciliation path. Related: #17814.

**Completion requirements**:

- Report the API rejection reason on the owning StatefulSet and preserve the creation error.
- Bound event messages consistently with #17923 and avoid excessive duplicate events during repeated reconciliation.
- Add regression tests for Invalid and Forbidden creation errors, event ownership, and message truncation.
