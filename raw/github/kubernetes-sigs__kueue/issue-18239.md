**What would you like to be cleaned**:

The unit coverage profiles written by `make test` (`artifacts/cover.out` and `artifacts/cover-shard-N.out`) include files under `test/` directories. Those paths should be dropped from the profile, while product code (including `pkg/util/testing`) stays and the tests under `test/` keep running.

**Why is this needed**:

Test helpers are not product code, so counting them skews the reported unit coverage.
