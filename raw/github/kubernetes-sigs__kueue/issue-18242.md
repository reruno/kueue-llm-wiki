## Description

<!-- Please only use this template for submitting clean up requests -->

**What would you like to be cleaned**:

`ComparePodSets` / `ComparePodSetSlices` need an option to treat an empty image on named containers of a named PodSet in the stored PodSet as equal to any image. Two different non-empty images must still count as a change.

**Why is this needed**:

The fix that sets images on the Ray head PodSet sidecar containers must not make Workloads stored by older Kueue versions (with an empty sidecar image) look changed on upgrade. This option is the building block for that compatibility check and has no behavior change on its own.

Related #17601
