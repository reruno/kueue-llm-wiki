## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

A Prow job pair (an optional presubmit and a postsubmit on main) that merges the coverage profiles of `pull-kueue-test-unit-shard-0-main` and `pull-kueue-test-unit-shard-1-main` into one profile, so a single unit coverage figure shows in Prow's coverage lens and in TestGrid. The jobs should only read public artifacts, so they need no credentials.

**Why is this needed**:

Each unit shard publishes its own profile for only part of the packages, so neither number is the real total.
