## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:

Add `kueue_local_queue_workload_creation_latency_seconds` with the labels `name`, `namespace`, `job_kind`, `replica_role` and the LocalQueue custom labels. `kueue_workload_creation_latency_seconds` drops the LocalQueue custom labels and keeps `job_kind` and `replica_role`.

Like the other `local_queue_` histograms, the new metric is recorded only for LocalQueues that Kueue knows. This is a [KEP-7066 Beta criterion](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/keps/7066-custom-metric-labels/README.md#L564-L566) from #17413.

**Why is this needed**:

`kueue_workload_creation_latency_seconds` [has LocalQueue custom labels but no LocalQueue key](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/pkg/metrics/metrics.go#L738-L745). One series can belong to several LocalQueues, so the per-object cleanup in KEP-7066 [does not cover it](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/keps/7066-custom-metric-labels/README.md#L481-L483). Nothing else deletes its series either. With a LocalQueue label that has no `trackedValues`, each value seen at Workload creation adds another series.

Kueue [records the metric right after it creates the Workload](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/pkg/controller/jobframework/reconciler.go#L2296-L2302) and [does not check that the LocalQueue exists](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/pkg/controller/jobframework/utils.go#L100-L110). The new metric cannot do the same: a series for a LocalQueue that never exists would never be deleted. The other `local_queue_` histograms get this check, along with the `LocalQueueMetrics` feature gate and the `metrics.localQueueMetrics` settings, from [`ShouldExposeLocalQueueMetricsForWorkload`](https://github.com/kubernetes-sigs/kueue/blob/7476c2105b1327ae635c9f52bed5cda68ac2074f/pkg/cache/scheduler/cache.go#L1407-L1421). That helper returns false until the Workload has `status.admission`, so it cannot be used at creation.

Dashboards that group the existing metric by LocalQueue custom labels will need the new one, and the release note should say so.

Part of #17837.
