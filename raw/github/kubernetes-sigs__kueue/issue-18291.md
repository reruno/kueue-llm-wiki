**What happened**:

Step 1 of the `kueue-flake-debugger` skill collects Prow links from a flake issue with this command.

```sh
gh issue view ISSUE --repo kubernetes-sigs/kueue --comments --json comments,url
```

gh does not accept `--comments` together with `--json`. It prints "specify only one of --comments or --json" with the help text and exits 1, so the agent gets no issue data.

**What you expected to happen**:

The command returns the issue body and comments, so the agent can collect the Prow links. The flake issue template puts the link to the failed CI job in the body.

**How to reproduce it (as minimally and precisely as possible)**:

```sh
gh issue view 18072 --repo kubernetes-sigs/kueue --comments --json comments,url
echo $?
```

`gh issue view 18072 --repo kubernetes-sigs/kueue --json body,comments,url` works and returns the body with the Prow link and all comments.
