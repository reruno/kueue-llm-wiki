## Description

**What would you like to be cleaned**:

Several test assertion helpers in integration tests are missing `ginkgo.GinkgoHelper()`:

- `test/integration/singlecluster/controller/jobs/sparkapplication/sparkapplication_test_util.go`:
  - `shouldReconcileSparkApplication`
  - `shouldNotReconcileUnmanagedSparkApplication`
  - `waitForPodsReadyEnabledForSparkApplication`

- `test/integration/singlecluster/controller/jobs/kubeflow/kubeflowjob.go`:
  - `ShouldReconcileJob`
  - `ShouldNotReconcileUnmanagedJob`
  - `JobControllerWhenWaitForPodsReadyEnabled`
  - `ShouldScheduleJobsAsTheyFitInTheirClusterQueue`

Adding `ginkgo.GinkgoHelper()` ensures test failures correctly trace back to the test spec callsite rather than lines inside the helper utility, and removes the need for manual offset wrappers (`ExpectWithOffset(1)` / `EventuallyWithOffset(1)`).

**Why is this needed**:

Keeps test assertion stack traces accurate and aligns with the test helper cleanup in #16996.
