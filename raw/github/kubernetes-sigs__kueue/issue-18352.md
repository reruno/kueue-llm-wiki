## Description

**What happened**:

The release artifacts for AlphaAll=True now enables DisableMetricsAccessControl, but it shouldn't, similarly as we have DisableWaitForPodsReady=False explicitly here: https://github.com/kubernetes-sigs/kueue/blob/236120512dd1d5dffe71e3e84d0c9dea7abcb3dd/config/alpha-enabled/manager_config_patch.yaml#L14

**What you expected to happen**:

The Alpha features for DisableMetricsAccessControl and DisableWaitForPodsReady are disabled, even if AlphaAll=True.
