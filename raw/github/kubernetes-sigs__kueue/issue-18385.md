## Description

**What would you like to be cleaned**:

In `cmd/kueuectl/app/create/create_clusterqueue.go`, `parseUserSpecifiedResourceQuotas` compiles the resources regex via `regexp.MustCompile` on every invocation:

```go
regex := regexp.MustCompile(`^([a-z0-9][a-z0-9\-\.]{0,252}):((\w+[\.-]?)*\/?[\w\.-]+=[\w.]+;)*(\w+[\.-]?)*\/?[\w\.-]+=[\w.]+;?$`)
```

Because `parseUserSpecifiedResourceQuotas` is called separately for nominal quotas, borrowing limits, and lending limits, this regex is recompiled up to 3 times per command run.

Moving it to a package-level variable avoids recompiling it on every execution.

**Why is this needed**:

Avoids redundant regex compilations and follows standard Go practice of declaring reusable regular expressions at package scope.
