## Description

**What would you like to be cleaned**:

Add a per-spec manager start helper in `test/integration/framework/framework.go` that registers `ginkgo.DeferCleanup(f.StopManager, ctx)` before starting the manager. Use it in applicable per-spec integration tests, including the Job controller tests. Keep `StartManager` unchanged for suite-level callers.

Verify that cleanup runs after resource deletion while the manager is active, including when setup fails. Verify that explicit manager stop and restart within a spec remain supported.

**Why is this needed**:

If a spec omits manager cleanup, the next `StartManager` replaces the stored cancel function and the old manager can reconcile later specs' objects. A separate helper avoids changing the lifetime of managers started in `BeforeSuite`.
