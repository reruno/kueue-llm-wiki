**What would you like to be cleaned**:

During GH outage we tried to repeatedly install from GH while installing from source could have passed.

I think our tool installing script should fallback to installing from source if GH i unavailable at the moment. We may fallback after one failed attempt, or on each attempt try both approaches. Either way is fine.

Failed build: https://prow.k8s.io/view/gs/kubernetes-ci-logs/logs/periodic-kueue-test-e2e-extended-shard-2-release-0-19-1-37/2119366746526715904

**Why is this needed**:

- to avoid repeating requests to GH when it is down
- to progress the build when GH i unavailable
