## Description

**What happened**:

An elastic `SparkApplication` (Dynamic Allocation via workload slices, #17127) that is preempted is never admitted again. Its Workload finishes as `FailedToStart` and the application stays `SUSPENDED`, even once the ClusterQueue has room. On a cluster, two of three elastic applications sharing a ClusterQueue were preempted by a higher-priority one and stayed suspended:

```
invalid admission check PodSetUpdate: conflict for annotations: conflict for key=kueue.x-k8s.io/workload, value1=sparkapplication-als-2-3d1ae, value2=sparkapplication-als-2-9211c
invalid admission check PodSetUpdate: conflict for annotations: conflict for key=kueue.x-k8s.io/workload-slice-name, value1=sparkapplication-als-3-61353, value2=sparkapplication-als-3-bc2e7
```

The first admission writes the Workload name (`kueue.x-k8s.io/workload`) and the slice name (`kueue.x-k8s.io/workload-slice-name`) into `spec.driver.annotations` and `spec.executor.annotations`. An elastic application is later admitted under another Workload: a replacement slice, or the first slice of a new chain. `SparkApplication.RunWithPodSetsInfo` merges the admission with `PodSetInfo.Merge`, which reports the two names as a conflict; `podset.IsPermanent` treats it as permanent, so the job reconciler finishes the Workload as `FailedToStart` instead of starting the job.

**What you expected to happen**:

The preempted application is admitted again under its new Workload and runs.

**How to reproduce it (as minimally and precisely as possible)**:

`./repro.py` below runs it in about 8 minutes on a cluster with Kueue (SparkApplication integration, `ElasticJobsViaWorkloadSlicesForSparkApplication` on), the Kubeflow Spark Operator watching `batch-ns-uno`, the ResourceFlavor `default-flavor` and the WorkloadPriorityClasses `low` and `high`:

1. It creates the ClusterQueue and LocalQueue `readmission-repro` (4 CPUs, no cohort, `withinClusterQueue: LowerPriority`).
2. `readmission-low` (priority `low`, Dynamic Allocation 2 to 3 executors) scales up and runs under a replacement slice, while its spec still names the first slice.
3. `readmission-high` (priority `high`, static, 3 CPUs) preempts it.
4. After `readmission-high` completes, it waits up to 4 minutes for `readmission-low` to run again.

With the defect it prints `RESULT: BUG REPRODUCED: Workload <name> finished as FailedToStart: invalid admission check PodSetUpdate: conflict for annotations: ...`. It cleans up after itself; `--keep` leaves everything in place.

```python
#!/usr/bin/env python3
"""Reproduces the #17127 Dynamic Allocation support defect: an elastic SparkApplication that is
preempted stays suspended for good instead of being admitted again.

1. Creates the ClusterQueue and LocalQueue `readmission-repro` (4 CPUs, no cohort).
2. Runs readmission-low, an elastic Dynamic Allocation application of priority `low`, until it has
   scaled up to 3 executors: it is then admitted under a replacement workload slice, while its spec
   still carries the name of the first slice in kueue.x-k8s.io/workload.
3. Runs readmission-high, a static application of priority `high`, which preempts it.
4. Once readmission-high has completed, waits for readmission-low to run again.

With the defect, admitting readmission-low again fails with a permanent annotation conflict, the
Workload finishes as FailedToStart, and readmission-low stays SUSPENDED. With the fix, it runs again.

Usage: ./repro.py [--keep]    (--keep leaves the applications and queues in place)
Exit status: 1 when the defect reproduces, 0 when readmission-low runs again, 2 on a setup problem.
"""
import datetime
import json
import os
import subprocess
import sys
import time

HERE = os.path.dirname(os.path.abspath(__file__))
NS, LOW, HIGH = "batch-ns-uno", "readmission-low", "readmission-high"
OUT = os.path.join(HERE, "out-" + datetime.datetime.now().strftime("%Y%m%d-%H%M%S"))
os.makedirs(OUT)
log = open(os.path.join(OUT, "timeline.log"), "w")


def say(msg):
    line = f"{datetime.datetime.now().strftime('%H:%M:%S')} {msg}"
    print(line, flush=True)
    log.write(line + "\n")
    log.flush()


def kubectl(*args, check=True):
    return subprocess.run(["kubectl", *args], check=check, capture_output=True, text=True).stdout


def kjson(*args):
    out = kubectl(*args, "-o", "json", check=False)
    return json.loads(out) if out.strip() else {}


def app(name):
    return kjson("-n", NS, "get", "sparkapplications.sparkoperator.k8s.io", name)


def condition(obj, ctype):
    return next((c for c in obj.get("status", {}).get("conditions", []) if c["type"] == ctype), {})


def workloads(name):
    wls = [wl for wl in kjson("-n", NS, "get", "workloads").get("items", [])
           if any(o.get("name") == name for o in wl["metadata"].get("ownerReferences", []))]
    return sorted(wls, key=lambda wl: wl["metadata"]["creationTimestamp"])


def admitted(name):
    live = [wl for wl in workloads(name) if condition(wl, "Admitted").get("status") == "True"
            and condition(wl, "Finished").get("status") != "True"]
    return live[-1] if live else {}


def ready_executors(name):
    n = 0
    for p in kjson("-n", NS, "get", "pods", "-l", f"sparkoperator.k8s.io/app-name={name},spark-role=executor").get("items", []):
        if p["status"].get("phase") == "Running" and condition(p, "Ready").get("status") == "True":
            n += 1
    return n


def state(name):
    return app(name).get("status", {}).get("applicationState", {}).get("state", "")


def show():
    a = app(LOW)
    stamped = (a.get("spec", {}).get("executor", {}).get("annotations") or {}).get("kueue.x-k8s.io/workload", "-")
    wl = admitted(LOW)
    say(f"low={state(LOW) or '-':10} executors={ready_executors(LOW)} admitted slice={wl.get('metadata', {}).get('name', '-')} "
        f"spec annotation kueue.x-k8s.io/workload={stamped} | high={state(HIGH) or '-'}")


def wait_for(pred, timeout, what):
    end = time.time() + timeout
    while time.time() < end:
        if pred():
            return True
        show()
        time.sleep(5)
    say(f"timed out waiting for {what}")
    return False


def failed_to_start(name):
    for wl in workloads(name):
        fin = condition(wl, "Finished")
        if fin.get("status") == "True" and fin.get("reason") == "FailedToStart":
            return wl["metadata"]["name"], fin.get("message", "")
    return None


def cleanup():
    for name in (HIGH, LOW):
        kubectl("-n", NS, "delete", "sparkapplications.sparkoperator.k8s.io", name, "--ignore-not-found", "--wait=true", check=False)
    kubectl("delete", "-f", os.path.join(HERE, "queues.yaml"), "--ignore-not-found", "--wait=true", check=False)
    say("deleted the applications and queues")


def main():
    keep = "--keep" in sys.argv
    if app(LOW) or app(HIGH):
        sys.exit(f"{NS}/{LOW} or {NS}/{HIGH} already exists; delete them first")
    kubectl("apply", "-f", os.path.join(HERE, "queues.yaml"))
    time.sleep(3)
    kubectl("apply", "-f", os.path.join(HERE, "low.yaml"))
    say(f"applied {LOW}")

    # Step 2: the low-priority application scales up into a replacement slice
    if not wait_for(lambda: ready_executors(LOW) >= 3 and admitted(LOW).get("metadata", {}).get("name") and
                    (app(LOW).get("spec", {}).get("executor", {}).get("annotations") or {}).get("kueue.x-k8s.io/workload")
                    != admitted(LOW)["metadata"]["name"], 420, f"{LOW} to scale up into a replacement slice"):
        cleanup() if not keep else None
        sys.exit(2)
    show()
    say(f"{LOW} runs under a replacement slice; its spec still names the first one")

    # Step 3: the high-priority application preempts it
    kubectl("apply", "-f", os.path.join(HERE, "high.yaml"))
    say(f"applied {HIGH}")
    if not wait_for(lambda: state(LOW) in ("SUSPENDING", "SUSPENDED"), 300, f"{HIGH} to preempt {LOW}"):
        cleanup() if not keep else None
        sys.exit(2)
    say(f"{LOW} preempted")

    # Step 4: once the high-priority application completes, the low-priority one should run again
    wait_for(lambda: state(HIGH) in ("COMPLETED", "FAILED"), 420, f"{HIGH} to complete")
    say(f"{HIGH} is {state(HIGH)}; waiting for {LOW} to run again")
    end, result = time.time() + 240, None
    while time.time() < end:
        show()
        if failed := failed_to_start(LOW):
            result = f"BUG REPRODUCED: Workload {failed[0]} finished as FailedToStart: {failed[1]}"
            break
        if state(LOW) == "RUNNING" and ready_executors(LOW) > 0:
            result = "OK"
            break
        time.sleep(5)
    if result is None:
        result = f"BUG REPRODUCED: {LOW} is still {state(LOW)} 4 minutes after {HIGH} finished"
    say(f"RESULT: {result if result != 'OK' else f'OK: {LOW} was admitted again and runs'}")
    if not keep:
        cleanup()
    say(f"timeline: {os.path.join(OUT, 'timeline.log')}")
    sys.exit(0 if result == "OK" else 1)


if __name__ == "__main__":
    main()
```

**Anything else we need to know?**:

The other integrations merge through `podset.Merge`, which replaces stale Kueue-managed annotations for elastic admissions (`overrideableAnnotations`); merging through it in `SparkApplication.RunWithPodSetsInfo` fixes this. The `PodSetInfo.Merge` call dates from the original integration and became reachable once SparkApplications could be elastic and admitted again under new Workload names.
