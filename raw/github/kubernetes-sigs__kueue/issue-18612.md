**Anything else we need to know?**:

The Workload was reconciled once after the Namespace update, about 20ms later, and not again until cleanup. Its condition still reported the namespace mismatch. `ValidateAdmissibility` reads the Namespace through the manager's cached client, and the workload controller does not watch Namespaces, so that reconcile could see the old labels. The test sets the trigger annotation only once.

Setting the annotation inside the `Eventually` that checks the condition, with a new value on each attempt, would retry the reconcile until the cache has the new labels. #18325, where it failed, does not touch this code.
