**What would you like to be cleaned**:

all test-created namespace objects. Include the missing job cleanup
helpers and RayCluster cleanup before deleting workloads and the namespace.

**Why is this needed**:

Envtest does not automatically garbage-collect namespace objects.
Leftover resources may cause reconcile churn and increase CI memory use.
