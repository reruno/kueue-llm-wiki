## Description

**What happened**:

The LeaderWorkerSet reconciler lists the Workloads it owns through the owner reference index. A Workload that has the generated name of a group (`GetWorkloadName(<LWS UID>, <LWS name>, <group index>)`) but no owner reference to the LeaderWorkerSet is not in that list, so the reconciler tries to create it on every reconcile.

- On `main`, the create fails with `AlreadyExists`. The reconciler logs `Failed to create Workload` and requeues with backoff.
- With #18783, `AlreadyExists` is treated as created, so the reconciler skips the Workload without any log, event or condition.

In both cases the LeaderWorkerSet never owns that Workload, so the reconciler does not update it and does not delete it on scale down. The Pods of that group still get this name as their prebuilt Workload.

The name is a hash of the LeaderWorkerSet UID, so a user who can create Workloads in the namespace can predict it once the LeaderWorkerSet exists.

Raised by @mbobrovskyi in https://github.com/kubernetes-sigs/kueue/pull/18783#discussion_r4578752357.

**What you expected to happen**:

The reconciler tells a stale cache (the existing Workload is owned by the LeaderWorkerSet) apart from a Workload it does not own, and handles the second case explicitly. For example, it adopts the Workload, or it reports the conflict to the user instead of skipping it.

**How to reproduce it (as minimally and precisely as possible)**:

Not reproduced on a cluster. This comes from reading the code during review. Expected steps:

1. Create a LeaderWorkerSet with `replicas: 1` and a `kueue.x-k8s.io/queue-name` label.
2. Compute the Workload name for group index `1` from the LeaderWorkerSet UID and name, and create a Workload with that name and no owner reference.
3. Scale the LeaderWorkerSet to `replicas: 2`.
4. The reconciler does not create its own Workload for group `1`, and the Pods of group `1` reference the pre-created Workload.

The unit test case removed from #18783 covered the reconciler part: a seeded Workload with the generated name and no owner reference.
