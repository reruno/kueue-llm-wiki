## Description

**What would you like to be cleaned**:

Add a lint check for `context.Context` misuse, as a follow-up to the
`ctx-structured-logging` reviewer skill:

- A gocritic ruleguard rule that flags `_ = ctx`. No existing golangci-lint
  linter catches it: `revive:unused-parameter` and `unparam` count `_ = ctx`
  as a use.
- Enable `contextcheck`, which flags `context.Background()` when a `ctx` is in
  scope. It reports 12 hits in `pkg/` and `cmd/` today; fix or exclude them.

Checking that the context is used for logging stays with the reviewer skill.

**Why is this needed**:

The skill relies on review only. A linter catches regressions automatically.
Requested in https://github.com/kubernetes-sigs/kueue/pull/18799#discussion_r4579998178.

Drafted with AI assistance.
