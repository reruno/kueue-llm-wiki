## Description

**What would you like to be cleaned**:

Add TAS regression tests that preserve preferred node placement after failed matching retries and interleaved evaluations of different PodSets on the same snapshot.

Cover both native and WAS simulators, with caching enabled and disabled, including leader PodSets and workloads without a UID.

**Why is this needed**:

Cached matches previously lost preferred affinity scores, allowing the same workload to move to a less preferred domain. This was fixed by #18215, resolving #14438.

Retries and interleaved PodSets should not corrupt cached preferences or reuse partial results from a failed match. These tests protect that behavior beyond the score assertion tracked in #18432.
