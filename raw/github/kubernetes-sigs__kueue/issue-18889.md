## Description

**What would you like to be added**:
A way to perform planning per a set of flavors, running some via the native path, and some via the was path.

**Why is this needed**:
As of right now, some flavors may perform better or worse in terms of scheduling time depending on whether they are run via scheduler library or the native scheme.
We would like to investigate avenues of allowing to run flavors based on which Planner will perform better for their sake.

**Completion requirements**:
* We have a clear plan on how can we organize this hybrid approach.
* Prototype PR(s) created.
