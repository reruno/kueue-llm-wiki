## Description

**What would you like to be cleaned**:

- Correct the `set_release_note` docstring in `hack/releasing/set_release_note.py`: when there is no author release-note block and a generated section exists, the new block is inserted before the first generated section, even if that section has no release-note block.
- Add a test in `hack/releasing/set_release_note_test.py` with no author block and a CodeRabbit section containing a `text` block. Verify that the new release-note block appears before the generated section and that the section remains unchanged.

**Why is this needed**:

The current docstring describes only generated release-note blocks. The new `.coderabbit.yaml` instruction asks CodeRabbit to use a `text` block, so the test should cover that case.
