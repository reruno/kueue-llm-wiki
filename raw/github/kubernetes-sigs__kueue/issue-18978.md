## Description

**What would you like to be cleaned**:

`release-0.19` and v0.19.13 still require `github.com/go-jose/go-jose/v4` v4.1.4. #18721 raised it to v4.1.6 on `release-0.20`. Could the go-jose part of that change be cherry-picked to `release-0.19`, so that the next v0.19 patch release includes it?

**Why is this needed**:

go-jose v4.1.4 is affected by [GHSA-mgcc-cww5-fp2q](https://github.com/advisories/GHSA-mgcc-cww5-fp2q) (CVE-2026-116587), which v4.1.6 fixes. Image scanners report the advisory against the v0.19 manager binary.
