## Description

**What would you like to be cleaned**:

Several places outside entry points create a new context with `context.Background()` instead of using the caller's context:

- `pkg/controller/core/localqueue_controller.go` (`Create`, `Update`)
- `pkg/controller/core/clusterqueue_controller.go` (`Create`)
- `pkg/controller/core/cohort_controller.go`
- `pkg/controller/jobs/statefulset/statefulset_reconciler.go` (`handle`)
- `pkg/controller/jobs/leaderworkerset/leaderworkerset_reconciler.go` (`handle`)
- `pkg/cache/scheduler/candidate_order_cache.go` (`Warm`)

Pass the caller's context through instead. Most of these are predicate methods, which get no context from controller-runtime, so the logic may need to move into an event handler or `Reconcile`.

The `main` functions under `cmd/` are entry points and can keep `context.Background()`.

**Why is this needed**:

A new background context drops the caller's cancellation, deadlines and logger values. https://github.com/kubernetes-sigs/kueue/pull/18934 removed one such use in KueueViz.

Requested by @mimowo in https://github.com/kubernetes-sigs/kueue/pull/18934#discussion_r4614323377.
