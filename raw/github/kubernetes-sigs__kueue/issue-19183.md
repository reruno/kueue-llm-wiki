## Description

/kind cleanup

**What would you like to be cleaned**:

The `deploy` and `prometheus` Makefile targets still call `kubectl` from `PATH`:

```makefile
deploy: compile-crd-manifests yq prepare-manifests
	kubectl apply --server-side -k config/default

prometheus:
	kubectl apply --server-side -k config/prometheus
```

Other targets (`install`, `uninstall`, `install-alpha-crds`, `uninstall-alpha-crds`, `undeploy`) use the pinned `$(KUBECTL)` and depend on the `kubectl` target since https://github.com/kubernetes-sigs/kueue/pull/18880.

Switch `deploy` and `prometheus` to `$(KUBECTL)` and add the `kubectl` prerequisite.

**Why is this needed**:

Consistency, and the targets should not depend on whatever `kubectl` version is installed on the host.

Follow-up from https://github.com/kubernetes-sigs/kueue/pull/18880#discussion_r4640537263.
