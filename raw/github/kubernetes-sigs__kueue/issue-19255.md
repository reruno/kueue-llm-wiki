## Description

**What would you like to be cleaned**:

When the minimum supported Kubernetes version reaches 1.38, remove rounding from `limitRequestRatioExceeded` in `pkg/util/limitrange/limitrange.go`. Compare the original quantities exactly, remove unused rounding code and the TODO, and update tests for sub-milli and boundary values.

**Why is this needed**:

Kubernetes 1.38 LimitRanger compares exact values (kubernetes/kubernetes#141348). Rounding can admit a Workload whose Pods that version rejects. The current rounding preserves compatibility with Kubernetes 1.35–1.37.
