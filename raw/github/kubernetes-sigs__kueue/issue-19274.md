## Description

**What would you like to be added**:

Add the remaining core Kueue CRDs to `passThroughTypes` in `cmd/kueuectl/app/passthrough/passthrough.go`:
- `admissioncheck` (shortName: `ac`)
- `workloadpriorityclass` (shortName: `wpc`)
- `multikueuecluster` (shortName: `mkc`)
- `multikueueconfig` (shortName: `mkconf`)
- `provisioningrequestconfig` (shortName: `prc`)

**Why is this needed**:

Currently `kueuectl` supports pass-through commands (`get`, `describe`, `edit`, `delete`, `patch`) for Workload, ClusterQueue, LocalQueue, ResourceFlavor, Cohort, and Topology.

Running `kueuectl get admissioncheck`, `kueuectl get ac`, or `kueuectl describe wpc` currently fails with:


Users should be able to manage all Kueue CRDs directly using `kueuectl`.
