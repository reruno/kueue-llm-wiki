## Description

**What would you like to be documented or improved**:

Several annotations used in Kueue's codebase are missing from the reference table in `site/data/labels_and_annotations.yaml`:

1. `kueue.x-k8s.io/podset-partial-preemption-min-retained-count`: defined in `pkg/constants/constants.go:126`, used by batch/Job and SparkApplication partial preemption controllers/webhooks to configure the minimum count of pods to retain during preemption.
2. `kueue.x-k8s.io/raycluster-generation` and `kueue.x-k8s.io/raycluster-podset-replica-sizes`: defined in `pkg/controller/jobs/raycluster/common.go:62-66`, used in RayCluster and RayJob integrations.
3. `kueue.x-k8s.io/spark-max-executor-id`, `kueue.x-k8s.io/spark-max-executor-id-submission`, and `kueue.x-k8s.io/spark-executors-started-submission`: defined in `pkg/controller/jobs/sparkapplication/sparkapplication_controller.go:63-70`, used in SparkApplication elastic workload integration.

These should be added to `site/data/labels_and_annotations.yaml` with types, descriptions, and examples so they appear on the Kueue documentation reference page.

**Location** (URL, file path, or section if applicable):
- `site/data/labels_and_annotations.yaml`
- https://kueue.sigs.k8s.io/docs/reference/labels_and_annotations/
