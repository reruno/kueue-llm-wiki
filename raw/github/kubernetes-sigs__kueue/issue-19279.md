## Description

**What would you like to be cleaned**:

In `cmd/kueuectl/app/list/list_clusterqueue.go`:

1. Remove the redundant `if len(args) > 0` check in `Complete`:
```go
if len(args) > 0 {
    activeFlag, err := cmd.Flags().GetBoolSlice("active")
    if err != nil {
        return err
    }
    o.Active = activeFlag
}
```
`o.Active` is already bound via `addActiveFilterFlagVar(cmd, &o.Active)` when the command is constructed in `NewClusterQueueCmd`. Re-extracting the flag when positional arguments are passed is dead/redundant logic.

2. In `Validate()`, reuse `errMultipleActiveFlags` from `helpers.go` directly:
```go
func (o *ClusterQueueOptions) Validate() error {
    if len(o.Active) > 1 {
        return errMultipleActiveFlags
    }
    return nil
}
```
and remove the private `validActiveFlagOptionProvided()` helper to align with `list_localqueue.go`.

3. Add `Args: cobra.NoArgs` to `NewClusterQueueCmd` (and `NewLocalQueueCmd`) so unexpected positional arguments return an error instead of being silently ignored.

**Why is this needed**:

Aligns `list clusterqueue` with `list localqueue`, removes duplicate error strings, and ensures invalid positional arguments are properly reported to users.
