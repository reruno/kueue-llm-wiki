## Description

**What would you like to be added**:

Add shell autocompletion for enum flags and missing resource types in `kueuectl`:
1. Resource completion helpers in `cmd/kueuectl/app/completion`:
   - `CohortNameFunc` to complete cohort names (e.g. for `kueuectl create clusterqueue --cohort`).
   - `ResourceFlavorNameFunc` to complete resource flavor names.
2. Enum flag completion:
   - `--dry-run`: `none`, `server`, `client`.
   - `--active`: `true`, `false` in `kueuectl list`.
   - `--status`: `all`, `pending`, `quotareserved`, `admitted`, `finished` in `kueuectl list workload`.
   - `--queuing-strategy` (`BestEffortFIFO`, `StrictFIFO`), `--reclaim-within-cohort` (`Never`, `LowerPriority`, `Any`), and `--preemption-within-cluster-queue` (`Never`, `LowerPriority`) in `kueuectl create clusterqueue`.
3. Fix loop variable naming in `completion.go` (`wl` -> `ns`, `cq`, `lq`).

**Why is this needed**:

Currently, typing tab on these flags either produces no suggestions or defaults to local directory files. Adding completion helps avoid typos and improves CLI usability.
