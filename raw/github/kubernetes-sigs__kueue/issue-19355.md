## Description

<!-- Please only use this template for submitting enhancement requests -->

**What would you like to be added**:
The ability to configure one of 3 Planners for kueue scheduler:
1. KueueNative - nativePlanner with defaultSimulator.FindFeasibleNodes implementation,
2. KueueNativeWithShallowIntegration - nativePlanner with wasSimulator.FindFeasibleNodes implementation (requires: SchedulerLibraryIntergation FG),
3. KubeSchedulerDeepIntegration - wasPlanner (requires: SchedulerLibraryDeepIntegration FG).

**Why is this needed**:
Follow up to: #18889

**Completion requirements**:
Currently setting KueueNative annotataion value on a CQ makes it so that Kueue uses nativePlanner with defaultScheduler when DeepIntegration is disabled, and nativePlanner with wasScheduler when enabled. 
We want to give users more granular control over their setup, allowing to select either option when necessary FGs are neabled.
