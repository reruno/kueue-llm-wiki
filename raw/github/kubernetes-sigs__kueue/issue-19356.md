## Description

**What happened**:

`--listen` (KUEUEVIZ_LISTEN) adds the default port to a host with no port, but only when the value has no colon. So "127.0.0.1" becomes "127.0.0.1:8080", while "::", "::1" and "[::1]" are passed to `net.Listen` unchanged and the server fails to start:

```
"::"        -> "::"        listen tcp: address ::: too many colons in address
"::1"       -> "::1"       listen tcp: address ::1: too many colons in address
"[::1]"     -> "[::1]"     listen tcp: address [::1]: missing port in address
"127.0.0.1" -> "127.0.0.1:8080"  ok
```

**What you expected to happen**:

An IPv6 host without a port gets the default port too, e.g. "::1" becomes "[::1]:8080".

**How to reproduce it (as minimally and precisely as possible)**:

Start the KueueViz backend with `--listen ::1` (or `KUEUEVIZ_LISTEN=::`). The values above come from passing `ServerConfig{Listen: ...}.GetServerAddress()` straight to `net.Listen("tcp", ...)`.

**Anything else we need to know?**:

The logic is `normalizeListenAddress` in cmd/kueueviz/backend/config/server.go, added in #16522. I have a small fix with tests and can send it.

**Environment**:
- Kueue version: main @ e7ba2dc27 (also v0.21.0-rc.1)
