### Comment by [@ekam-walia](https://github.com/ekam-walia) — 2026-11-24T04:25:27Z

There is no signal race in `e2e-kueueviz-backend.sh` or the test harness both `make (VIZ_TEST_TESTS_STARTED)` and `docker start `(`VIZ_TEST_FRONTEND_STARTED`) synchronize on FIFOs before `cluster_create` sends `SIGINT`, and `cleanup()` kills the entire worker process group (`kill -- "-${BACKEND_TEST_PID}"`).

The flake is pure CPU contention against the hardcoded `timeout=15`: each subtest spawns bash plus ~8–10 python3 stub processes, and make verify runs this target under `make -j 8` alongside `golangci-lint`. (`test_frontend_waits_for_backend_and_preserves_failures` already had to bump its timeout to 30s for the same reason.)

This Flake can be eliminated using this approach:

1. Patch (`hack/testing/kueueviz-e2e_test.py`)
Unify all three subprocess timeouts behind a single `SUBPROCESS_TIMEOUT = 60` constant.

2. Catch `subprocess.TimeoutExpired` in `run_suite` and report `exc.stdout`, `exc.stderr`, events, and commands (using `exc.stdout/exc.stderr `directly rather than calling `communicate()` again, so it never hangs if `worker_group` still holds a pipe open before finally: kills it).
