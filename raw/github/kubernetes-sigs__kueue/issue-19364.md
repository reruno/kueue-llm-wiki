**What would you like to be cleaned**:

`TestRemoveRemoteObjectsOfLeaderWorkerSetGroups` in [`pkg/controller/admissionchecks/multikueue/workload_test.go`](https://github.com/kubernetes-sigs/kueue/blob/72c7cff03d4761a6765e23b9e360943db2f74c29/pkg/controller/admissionchecks/multikueue/workload_test.go#L3897-L3920) builds its Workload fixtures with three closures: `groupWorkload`, `admittedGroupWorkload` and `remoteGroupWorkload`.

Replace them with the `utiltestingapi.WorkloadWrapper` chains, either written in each case or cloned from a base wrapper per case (`baseWl.Clone().Name(...)`), as other tests in the repository do.

**Why is this needed**:

[Writing tests](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/writing_tests.md) asks to build fixtures with the wrappers instead of helper functions or closures.
The same pattern was fixed for `TestLocalJobHandlerUpdate` in https://github.com/kubernetes-sigs/kueue/pull/19181 after [review](https://github.com/kubernetes-sigs/kueue/pull/19181#discussion_r4666969383); this test was left out of that PR to keep its scope.
