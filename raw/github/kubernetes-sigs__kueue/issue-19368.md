## Description

**What happened**:

The generated `site/content/en/docs/reference/kueue.v1alpha1.md` displays `PreemptionLimitWindowStatus.LastUpdateTime` as `lastUpdateTime,omitempty,omitzero`. JSON tag options appear in the field name.

**What you expected to happen**:

The API reference displays `lastUpdateTime` without JSON tag options.

**How to reproduce it (as minimally and precisely as possible)**:

1. See the `LastUpdateTime` JSON tag in `apis/kueue/v1alpha1/preemptionlimit_types.go` on the PR branch.
2. Compare it with `PreemptionLimitWindowStatus` in the generated API reference in https://github.com/kubernetes-sigs/kueue/pull/19348.

**Anything else we need to know?**:

Investigate the upstream `kubernetes-sigs/reference-docs` generator used by Kueue. Fix JSON tag parsing there, add regression tests for tags with multiple options, and update Kueue's generator dependency and regenerate its references when the fix is available. Avoid hand-editing generated Markdown.
