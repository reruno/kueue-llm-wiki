## Description

**What would you like to be cleaned**:

Refactor `pkg/controller/admissionchecks/capacitybuffer/controller.go` to make admission-check state handling explicit. Consider extracting the pending-check logic from `Reconcile` into `syncPendingCheck`. Preserve the existing behavior for missing configs, admitted Ready workloads, other check states, errors, and requeues. Add or retain tests for the affected paths.

**Why is this needed**:

The current switch skips Ready, Retry, and Rejected checks, but other states fall through to buffer handling. Make the intended state invariant clear without assuming that only Pending can reach that code.
