**What would you like to be cleaned**:

Improve DeviceClass selector coverage in `Test_GetResourceRequests` in `pkg/dra/claims_test.go`.

The case "CEL selectors pre-filtered by DeviceClass selectors" uses the same expression, `device.driver == "gpu-driver"`, for the request selector and the DeviceClass selector. Removing the DeviceClass filter does not change the result, so the case cannot catch a regression that drops it.

Add a case where the request selector matches both GPU and NIC devices, the DeviceClass selector matches only the GPU, and the request asks for two devices. Expect a shortage error. Keep the existing single-device success case.

**Why is this needed**:

Without it, a regression that ignores DeviceClass selectors would pass unit tests.

Found in review of https://github.com/kubernetes-sigs/kueue/pull/19586#discussion_r4690393998.
