## Description

**What happened**:

`make generate-kueuectl-docs` writes a `--cache-dir` default that depends on the user who runs it. In some environments the 55 pages under `site/content/en/docs/reference/kubectl-kueue/commands/` change, and `make verify` fails at its `git --no-pager diff --exit-code` step.

I hit it on my local Linux machine that runs as UID 1001 with `HOME=/github/home`. That UID has no entry in `/etc/passwd`, and `id -un` prints `cannot find name for user ID 1001`. Every page changed like this:

```diff
-        <td colspan="2">--cache-dir string&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Default: &#34;$HOME/.kube/cache&#34;</td>
+        <td colspan="2">--cache-dir string&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Default: &#34;/github/home/.kube/cache&#34;</td>
```

The pages also change when `$HOME` differs from the home directory in `/etc/passwd`. Then the default becomes `$HOME` followed by the absolute path, for example `$HOME/tmp/kueuectl-docs-home/.kube/cache`.

Only the docs generator has this bug. The `kubectl-kueue` binary does not.

**What you expected to happen**:

The generated pages show `Default: "$HOME/.kube/cache"` for `--cache-dir` for any UID, `$HOME`, and `/etc/passwd`, and `make verify` passes.

**How to reproduce it (as minimally and precisely as possible)**:

On a machine where your user has an `/etc/passwd` entry, run the generator with a different `$HOME`:

```sh
make kueuectl-docs
HOME=/tmp/kueuectl-docs-home ./bin/kueuectl-docs \
	cmd/kueuectl-docs/templates \
	site/content/en/docs/reference/kubectl-kueue/commands
git diff --stat -- site/content/en/docs/reference/kubectl-kueue/commands
```

All 55 pages change.

To reproduce the UID without a passwd entry, run the generator in a container:

```sh
docker run --rm --user 12345:12345 -e HOME=/tmp -v "$PWD:/src:ro" -w /src golang:1.27 sh -c '
	go build -buildvcs=false -o /tmp/kueuectl-docs ./cmd/kueuectl-docs &&
	mkdir /tmp/out &&
	/tmp/kueuectl-docs cmd/kueuectl-docs/templates /tmp/out &&
	grep -rhoE "Default: &#34;[^&]*\.kube/cache&#34;" /tmp/out | sort | uniq -c'
```

It prints `55 Default: &#34;/tmp/.kube/cache&#34;`. The committed pages have `$HOME/.kube/cache`.
