#### What this PR does / why we need it:
This pull request adds **optional OpenTelemetry tracing** for the **Workload** controller so operators and developers can see **reconcile spans** and **high-level workload status transitions** (pending → quotaReserved → admitted → finished, etc.) in a backend such as **Jaeger**, instead of inferring behavior only from logs and metrics.
- **Configuration:** `tracing.enable` and optional `tracing.samplingRatio` on the Kueue `Configuration` CRD (controller manager section). When tracing is off, behavior stays **no-op** (no exporter overhead).
- **Export:** OTLP over **gRPC** using standard **`OTEL_EXPORTER_OTLP_*`** environment variables on the controller Deployment.
- **Correlation:** When sampling, the controller may persist **W3C trace context** and **last observed status** on **Workload** annotations so traces can continue across reconciles and record time spent in each summary status.
- **Docs and hacks:** English and Chinese reference pages under **OpenTelemetry tracing**, plus **`hack/tracing/`** (local Jaeger via Docker Compose, patch script for kind/dev clusters, optional demo manifests).
This is intentionally **experimental / demonstration** quality: it improves **visibility into status transition timing** for Workloads; design and scope can be refined in follow-ups.

#### Special notes for your reviewer:
- Some ideas and direction draw on exploration in [**agent-sandbox**](https://github.com/kubernetes-sigs/agent-sandbox); this PR is a **Kueue-specific** slice for Workload tracing only.
- **Draft / WIP:** not proposing this as the final observability model; feedback welcome on **API shape**, **annotation semantics**, **sampling defaults**, and **e2e/dev workflows**.

**Try tracing locally (kind + e2e-style run)**

1. Start Jaeger (OTLP gRPC **4317**, UI **http://localhost:16686**):

   ```bash
   docker compose -f hack/tracing/docker-compose.yaml up -d
   ```

2. Build the controller image, deploy into the test cluster, and run e2e with the OTLP patch and dev mode:

   ```bash
   export KUEUE_OTLP_PATCH=true
   export E2E_MODE=dev
   make kind-image-build test-e2e
   ```

   `KUEUE_OTLP_PATCH=true` runs `hack/tracing/patch-kueue-for-local-jaeger.sh` after deploy (enables tracing in manager config and sets `OTEL_*` on the controller; default endpoint targets **`host.docker.internal:4317`** where applicable). See **`hack/tracing/README.md`** and **`site/content/en/docs/reference/tracing.md`** for networking caveats (pod loopback vs host, kind/Docker Desktop).
