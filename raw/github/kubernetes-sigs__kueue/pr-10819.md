+## 1. Table-driven tests
+
+**Flag:** A Go test function that covers multiple scenarios inline as a single sequential block.
+
+**Ask:** Refactor to use table-driven style — `tests := []struct{ ... }{ ... }` with `for _, tc := range tests`. A monolithic test that grows one `if` block per case is a "spaghetti test" and makes it hard to add new scenarios.
```
