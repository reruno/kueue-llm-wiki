## Description

#### What type of PR is this?
/kind bug

#### What this PR does / why we need it:
When admission fails, the scheduler already removes the assumed Workload from its cache. The fix is just to also notify the ClusterQueue reconciler after that cleanup, so it can recheck the ClusterQueue and remove the finalizer once it's empty.
