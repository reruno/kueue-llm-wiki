#### What this PR does / why we need it:

This is a preparatory PR for #10311, which adds `GroupNameAnnotation` and `PrebuiltWorkloadAnnotation`.                                                                        
The existing `Group` wrapper method is renamed to `GroupNameLabel` method to improve readability and distinguish it from the upcoming `GroupNameAnnotation` wrapper method.                       
`PrebuiltWorkloadLabel` is added across all testing wrappers for the same reason.
