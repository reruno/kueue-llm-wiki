#### What this PR does / why we need it:
Eliminates the test-only branch in `admissionChecksForAdmission` that treated flavorless admissions as satisfying all admission checks. That branch was introduced as a workaround so a handful of tests that created admissions without any flavor assignments would keep passing, even though a flavorless admission is never a legal state in real use cases.
