## K8s 1.36 Bump Review (non-vendor changes only)

### Summary
The non-vendor changes are clean. No bugs introduced. The changes fall into three categories: (1) a new functional change (PreStart hook), (2) test fixes to accommodate upstream API changes, and (3) generated code / version bumps.

### PreStart Hook — the only real logic change

**Files:** `pkg/controller/jobframework/interface.go`, `reconciler.go`, `pkg/controller/jobs/job/job_controller.go`

K8s 1.36 requires the `JobSuspended` status condition to be set before allowing pod template mutations on suspended jobs. The implementation looks correct:

- **No stale-object conflict**: `PreStart` does `c.Status().Update()` which updates the in-memory object's `ResourceVersion`. Since `job.Object()` returns a pointer to the same underlying struct as `object`, the subsequent `clientutil.Patch` in `startJob` will use the updated ResourceVersion.
- **Idempotent**: Checks if the condition already exists before adding it. Safe for retries.
- **Early-return guard**: Correctly skips if the job isn't suspended.
- **Placement**: Runs before the MultiKueue skip-local-execution check — harmless but unnecessary for MultiKueue jobs that won't execute locally. Not a bug, just a minor inefficiency.
- **Only batch/v1 Job**: Only the `Job` type implements `JobWithPreStartHook`. Other job types (RayJob, MPIJob, etc.) don't get this hook, which is correct since the `JobSuspended` condition is specific to batch/v1.

### Test fixes — all appropriate

- **`base_webhook_test.go`**: Ignoring `BadValue` on `field.Error` — upstream changed how `BadValue` is populated. Tests still validate error type, field path, and message.
- **`delete_workload_test.go`**: Ignoring `ResourceVersion` on `ListMeta` — the fake client now populates this field.
- **`websocket_handler_test.go`**: Simplified `DoneChecker` mock to match a changed interface.
- **`job_controller_test.go`**: All start/unsuspend test cases correctly updated to expect the new `JobSuspended` condition. `LastTransitionTime` correctly ignored in comparisons.

### Generated / mechanical changes — all expected

- **CRDs** (charts + config): Upstream schema changes (schedulingGroup replaces workloadRef, ProcMountType/UserNamespacesSupport feature gate notes removed, ShardedListAndWatch additions).
- **OpenAPI**: New `ShardInfo` type and `shardSelector` field.
- **Informers** (`client-go/informers/`): Generated code from the new informer codegen.
- **`doc.go` files**: `+k8s:defaulter-gen=TypeMeta` — required by the new code generator.
- **`.golangci.yaml`**: Suppressing deprecation warnings for `GetEventRecorderFor` and `scheme.Builder` — pragmatic for a dep bump, but these should eventually be migrated.

### Version matrix

Dropping K8s 1.33 and adding 1.36 for E2E tests. Supported range is now **1.34, 1.35, 1.36** (N-2 skew policy). Correct.
