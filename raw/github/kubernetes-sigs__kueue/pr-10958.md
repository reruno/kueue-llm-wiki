## Pull request overview

This PR cherry-picks the Ray upgrade from 2.41.0 to 2.53.0 into the release-0.17 branch so the KubeRay e2e suite uses the newer Ray runtime intended to avoid the opencensus-related SIGABRT seen with the older version.

**Changes:**
- Bumps the default Ray version used by the build/test harness from 2.41.0 to 2.53.0.
- Updates KubeRay e2e resource settings, mainly increasing head-node CPU requests to match the newer Ray runtime needs.
- Adjusts autoscaling test defaults and assertions around scale-down timing.
