## Pull request overview

Cherry-pick of the Ray 2.53.0 update into `release-0.16`, primarily to keep KubeRay-based test coverage aligned with the newer Ray runtime and avoid the reported opencensus crash path.

**Changes:**
- Bump the default Ray test version from `2.41.0` to `2.53.0` and update the mini-image tag in the build/test Makefiles.
- Adjust KubeRay single-cluster e2e resource sizing for Ray head pods to use `1` CPU with the newer Ray image.
- Relax autoscaling test timing by increasing the in-tree autoscaler idle timeout and removing one explicit worker scale-down wait.
