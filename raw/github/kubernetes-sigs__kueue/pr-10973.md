#### What this PR does / why we need it:

Graduates the DRAExtendedResources feature gate to Beta, as part of the DRA Beta graduation tracked in #[8243.](https://github.com/kubernetes-sigs/kueue/issues/8243)

This PR addresses the KEP-2941 Beta graduation criteria for extended resources by adding event-driven DeviceClass tracking — the workload controller watches DeviceClass create/update/delete events and re-reconciles pending DRA workloads for late DeviceClass creation.

  This criterion was moved from the DynamicResourceAllocation beta section to DRAExtendedResources beta. But the DeviceClass watcher uses `NeedsDRAReconcile` which catches both RCT  workloads (`HasDRA`) and extended resource workloads. When a DeviceClass is created, it re-reconciles workloads from both paths. This is general DRA infrastructure being pulled into an extended-resources-specific graduation.
