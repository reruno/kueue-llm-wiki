Why we need it:
Splits the TAS e2e test suite into baseline and extended shards 
to reduce CI wall-clock time for PRs.

- tas-baseline: tests using only built-in Kubernetes resources (Job, Pod, StatefulSet)
- tas-extended: tests requiring custom integrations (JobSet, LeaderWorkerSet, 
  KubeRay, AppWrapper, TrainJob, MPIJob, PyTorch)

Which issue this PR fixes:
Fixes #10995

Follows the same pattern as #10472.
The old test/e2e/tas/ folder is kept unchanged in this PR .
