## Description

Fixes #10995

What type of PR is this:

/kind cleanup
/area testing

Why we need it:
Splits the singlecluster e2e test suite into baseline and extended shards
to reduce CI wall-clock time for PRs.

- singlecluster-baseline: tests using only built-in Kubernetes resources 
  (Job, Pod, StatefulSet, Deployment, metrics, visibility, etc.)
- singlecluster-extended: tests requiring custom integrations 
  (JobSet, LeaderWorkerSet, KubeRay, AppWrapper, TrainJob, JAXJob, PyTorchJob, TAS)

Which issue this PR fixes:
Fixes #10995

Follows the same pattern as #10472 and #11002.
The old test/e2e/singlecluster/ folder is kept unchanged in this PR.
