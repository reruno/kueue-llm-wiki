## Description


/kind cleanup
/area testing

Splits the singlecluster e2e test suite into baseline and extended shards
to reduce CI wall-clock time for PRs.

- singlecluster/baseline: tests using only built-in Kubernetes resources
- singlecluster/extended: tests requiring custom integrations

Follows the same pattern as #10472 and #11002.
