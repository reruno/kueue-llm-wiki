<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/kubernetes-sigs/kueue/releases">sigs.k8s.io/kueue's releases</a>.</em></p>
<blockquote>
<h2>v0.17.2</h2>
<p>Changes since <code>v0.17.1</code>:</p>
<h2>Changes by Kind</h2>
<h3>Bug or Regression</h3>
<ul>
<li>FailureRecovery: Forcefully delete pods that are Failed/Succeeded and scheduled on unreachable nodes.
This unblocks cases like a JobSet deleting a Job with foreground cascade being stuck because a pod in a terminal phase exists on one of the unhealthy nodes. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10856">#10856</a>, <a href="https://github.com/kshalot"><code>@​kshalot</code></a>)</li>
<li>Fix a race-condition bug that a deleted ClusterQueue may be kept by a finalizer, even after deletion of all workloads and LQs. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10833">#10833</a>, <a href="https://github.com/ShaanveerS"><code>@​ShaanveerS</code></a>)</li>
<li>Fixed a bug in Kueue's cache that could leave stale SubtreeQuota values in ancestor cohorts after a child Cohort
was deleted, leading to potential over-admission of workloads and incorrect metrics reporting. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10840">#10840</a>, <a href="https://github.com/mszadkow"><code>@​mszadkow</code></a>)</li>
<li>Fixed a bug where admitted Workloads could fail to patch through the v1beta1 API due to CEL validation of the <code>priorityClassSource</code> immutability rule. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10631">#10631</a>, <a href="https://github.com/kannon92"><code>@​kannon92</code></a>)</li>
<li>Observability: Fix kueue_cohort_subtree_quota and kueue_cohort_subtree_resource_reservations metrics incorrectly reporting raw milliCPU values instead of CPU units for CPU resources. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10754">#10754</a>, <a href="https://github.com/baoalvin1"><code>@​baoalvin1</code></a>)</li>
<li>Observability: downgrade the non-compatible flavor error logs to Info level (v3). (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10639">#10639</a>, <a href="https://github.com/maishivamhoo123"><code>@​maishivamhoo123</code></a>)</li>
<li>TAS: Fix a bug where admitted workloads with unhealthy nodes were not evicted when an AdmissionCheck entered Retry or when the PodsReady recovery timeout was exceeded. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10692">#10692</a>, <a href="https://github.com/pajakd"><code>@​pajakd</code></a>)</li>
<li>TAS: Fix handling of PodSet groups which could lead in some scenarios to empty topologyAssignment. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10841">#10841</a>, <a href="https://github.com/mimowo"><code>@​mimowo</code></a>)</li>
<li>TAS: Fix nil pointer panic in TAS node reconciler when unadmitted workloads exist in the cluster. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10653">#10653</a>, <a href="https://github.com/j-skiba"><code>@​j-skiba</code></a>)</li>
<li>TAS: Refine the NodeHotSwap logic to ensure that UnhealthyNodes are only updated for workloads currently assigned to a Node via a topology topology assignment. This prevents &quot;late pods&quot; from stale topologies from triggering inaccurate health reporting. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10837">#10837</a>, <a href="https://github.com/j-skiba"><code>@​j-skiba</code></a>)</li>
<li>VisibilityOnDemand: Fixed a bug in the visibility endpoint, that listing workloads from a local queue includes
workloads from other LocalQueues in different namespaces, if the other LocalQueues have the same name. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10679">#10679</a>, <a href="https://github.com/mbobrovskyi"><code>@​mbobrovskyi</code></a>)</li>
</ul>
</blockquote>
