## Description

What type of PR is this?
/kind cleanup
/area testing

What this PR does / why we need it:
This PR splits the singlecluster e2e suite into separate
baseline and extended suites.

Changes included:

Move lightweight/general tests into singlecluster/baseline
Move dependency-heavy/operator-specific tests into singlecluster/extended
Add dedicated suite setup for the extended suite
Update Makefile targets for baseline and extended execution flows
Keep TAS extended coverage isolated from baseline execution
This improves:

test organisation
maintainability
execution separation for optional/operator-heavy tests
future CI flexibility
Which issue(s) this PR fixes:
Part of https://github.com/kubernetes-sigs/kueue/issues/10995

Special notes for your reviewer:
Split the singlecluster into singlecluster/extended and singlecluster/baseline to reduce the wall clock time for CI jobs

NONE
