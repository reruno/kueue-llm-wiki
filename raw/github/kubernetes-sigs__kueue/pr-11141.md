#### What type of PR is this?

/kind feature

#### What this PR does / why we need it:

It adds a feature which automatically updates MultiKueue manager ClusterQueue quotas, based on summing up worker-side quotas.

#### Which issue(s) this PR fixes:

Fixes #9988

+	log.V(2).Info("Reconciling MultiKueue manager ClusterQueue")

+	cfg, err := r.helper.ConfigFromRef(ctx, ac.Spec.Parameters)

+		}
+		return reconcile.Result{}, err

+	if cfg.Spec.QuotaAutomation != nil && cfg.Spec.QuotaAutomation.Mode == kueue.QuotaAutomationManual {
