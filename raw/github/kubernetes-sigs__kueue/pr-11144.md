#### What this PR does / why we need it:
Some integration tests were passing `LocalQueue.Name` to `MakeAdmission` instead of `ClusterQueueReference` as expected by the function signature. This PR refactors the `MakeAdmission` function to expect a typed variable (`ClusterQueueReference`) to avoid this.
