## What this PR does / why we need it:
The local queue details page in kueueviz was not filtering workloads by queue, it returned every workload in the namespace regardless of which local queue was requested. The root cause was that `fetchLocalQueueWorkloads` accepted a `queueName` parameter but never applied it when building the response list.

The fix adds a client-side filter on `spec.queueName` in the existing loop, consistent with how kueuectl list workload localqueue handles the same case.

## Which issue(s) this PR fixes:
Fixes #6613

## Special notes for your reviewer:
Using a field selector on `spec.queueName` was considered but that field is not registered as selectable in the Workload CRD, which is the exact error the issue reports. 
Client-side filtering avoids CRD `changesand` works across all supported Kubernetes versions.

## Does this PR introduce a user-facing change?
```release-note
KueueViz: Fixed the LocalQueue details page to show only workloads from the selected queue.
```
