## Description

What type of PR is this:
/kind cleanup
/area tas
/area testing

What this PR does / why we need it:

Splits test/e2e/tas/extended/hotswap_test.go into two files:

- test/e2e/tas/baseline/hotswap_test.go: contains tests using only 
  built-in Job resources (requires TASReplaceNodeOnNodeTaints feature gate)

- test/e2e/tas/extended/hotswap_test.go: retains only tests using 
  JobSet (custom integration)

This aligns with the baseline/extended split pattern established in #11002.

Which issue(s) this PR fixes:

Part of #10995

Special notes for your reviewer:

Follow-up to #11002 which split the TAS e2e suite into baseline and extended.
The 4 Job-based hotswap tests are moved to baseline.
The 2 JobSet-based hotswap tests remain in extended.

```release-note
NONE
```
