### Comment by [@mimowo](https://github.com/mimowo) — 2026-05-18T10:18:28Z

> we could also move the `hotswap_test.go` to a separate dir (e.g. `test/e2e/tas/extended/hotswap/hotswap_test.go`) and leave procs > 1 unless we want to verify other tests too.

We are changing currently hotswap so that it is no longer using custom configuration: https://github.com/kubernetes-sigs/kueue/pull/11281. That was only needed for 0.16 when the Taints FG was alpha.

However, I think the tests still need to be reviewed for enabling parallelism on them, because:
- they don't use the NS-prefix / suffix to avoid conflicts, for example here we have hard-coded Flavor name: https://github.com/kubernetes-sigs/kueue/blob/main/test/e2e/tas/baseline/job_test.go#L61-L63
- they check specific nodes like here: https://github.com/kubernetes-sigs/kueue/blob/main/test/e2e/tas/baseline/job_test.go#L180-L193
however, the nodes might be blocked due to other jobs occupying them.

So, I would say it is a separate (possible) effort. We should probably assign higher amount of the exended resources per node, so that the jobs don't block each other, and start using NS-prefix / suffix approach. 

I will open an issue to enable parallelism for TAS tests careful of these issues so that we don't run into flakes.
