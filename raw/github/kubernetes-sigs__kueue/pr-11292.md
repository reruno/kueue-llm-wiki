## Pull request overview

Updates the elastic Job integration test to correctly verify the ordering contract for WorkloadSlice replacement: the old slice must not be marked `Finished` before the replacement slice becomes `Admitted`.

**Changes:**
- Refactors the test case to use a `watch` on `Workload` events to assert ordering between “old slice finished” and “new slice admitted”.
- Adjusts the test job parameters (name, CPU request, parallelism/completions) to better fit the scenario being validated.

  The watch loop ignores `watch.Error` events (and any other non-Modified types).
