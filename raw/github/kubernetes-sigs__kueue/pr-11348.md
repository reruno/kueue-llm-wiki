#### What this PR does / why we need it:

This pr is a follow up for PR https://github.com/kubernetes-sigs/kueue/pull/11341  , strengthening the test 

The visibility server options are configured through applyVisibilityServerOptions, especially visibilityServer.bindAddress, visibilityServer.bindPort, and TLS options.

The previous unit test only exercised the helper applyVisibilityServerSecureServingOptions. It did not verify that the full applyVisibilityServerOptions path applies those values into the final RecommendedConfig.

Tests should cover the same path used by the real visibility server startup flow, so regressions in option application are caught at the final config level.
