## Description

#### What type of PR is this?

/kind cleanup
/area testing

#### What this PR does / why we need it:
This PR optimizes the execution time of the end-to-end visibility API tests by eliminating a redundant configuration restore operation that triggers a time-consuming controller manager restart.

**Expected Savings:** ~30 seconds in the `kueue-test-e2e-sequential-baseline` workflow execution.

#### Which issue(s) this PR fixes:
Fixes #11274
