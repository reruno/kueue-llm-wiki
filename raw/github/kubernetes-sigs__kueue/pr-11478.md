<h2>Changes by Kind</h2>
<h3>Feature</h3>
<ul>
<li>Observability: Improved FairSharing strategy-evaluation logs by including DRS share values and emitting them at verbosity level V(4). (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11187">#11187</a>, <a href="https://github.com/PBundyra"><code>@​PBundyra</code></a>)</li>
</ul>
<h3>Bug or Regression</h3>
<ul>
<li>ElasticJobsViaWorkloadSlices: Fixed a bug where workload slices with identical creation timestamps could be incorrectly sorted, potentially leading to quota leaks during scale-up. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11201">#11201</a>, <a href="https://github.com/KumarADITHYA123"><code>@​KumarADITHYA123</code></a>)</li>
<li>Fixed a regression where Kueue could mark newly created Workloads as finished, potentially blocking queues. The FinishOrphanedWorkloads feature gate has been downgraded to Alpha. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11018">#11018</a>, <a href="https://github.com/mbobrovskyi"><code>@​mbobrovskyi</code></a>)</li>
<li>Fixed multi-arch image builds for importer, kueue-populator, and kueueviz backend images so runtime images
and binaries are built for the target platform, preventing wrong-architecture containers and exec format error
for non-amd64 target platforms, such as arm64, ppc64le, and s390x. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10916">#10916</a>, <a href="https://github.com/carterpewpew"><code>@​carterpewpew</code></a>)</li>
<li>Fixed vulnerability where two podsets with total requests exceeding max int64 would lead to integer overflow and break quota limits. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11140">#11140</a>, <a href="https://github.com/pajakd"><code>@​pajakd</code></a>)</li>
<li>Helm: Fixed manager probe templates so periodSeconds correctly uses the configured periodSeconds value,
rather than initialDelaySeconds. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10980">#10980</a>, <a href="https://github.com/cixuuz"><code>@​cixuuz</code></a>)</li>
<li>Helm: Fixed the FlowSchema priorityLevelConfiguration reference to use the Helm fullname template, preventing APF configuration from breaking when fullnameOverride or nameOverride is set. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10983">#10983</a>, <a href="https://github.com/cixuuz"><code>@​cixuuz</code></a>)</li>
<li>KueueViz: Fixed RBAC permissions for WorkloadPriorityClass objects by using the correct plural workloadpriorityclasses resource name. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/10984">#10984</a>, <a href="https://github.com/cixuuz"><code>@​cixuuz</code></a>)</li>
<li>KueueViz: Fixed the LocalQueue details page to show only workloads from the selected queue. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11212">#11212</a>, <a href="https://github.com/ManthanNimodiya"><code>@​ManthanNimodiya</code></a>)</li>
<li>LeaderWorkerSet &amp; StatefulSet: Fixed a race condition bug that could occasionally result in reverting, at the level of the Workload object, manual changes to the queue-name label for LeaderWorkerSet and StatefulSet. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11193">#11193</a>, <a href="https://github.com/mbobrovskyi"><code>@​mbobrovskyi</code></a>)</li>
<li>Scheduling: Fixed a bug where in-flight workloads that were concurrently marked as finished (<code>Finished=True</code>) or deactivated could be requeued by Kueue's scheduler, causing re-scheduling attempts which were interfering with the scheduling of other workloads. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11020">#11020</a>, <a href="https://github.com/mbobrovskyi"><code>@​mbobrovskyi</code></a>)</li>
<li>TAS: Fixed NodeHotSwap with TASReplaceNodeOnNodeTaints enabled to evaluate node taints using effective Workload tolerations, including tolerations from AdmissionCheck PodSetUpdates. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11228">#11228</a>, <a href="https://github.com/Ladicle"><code>@​Ladicle</code></a>)</li>
<li>TAS: Fixed a bug where multi-resource workloads, such as workloads requesting both CPU and memory,
could fail admission during second-pass scheduling for ProvisioningRequests or NodeHotSwap because one
resource's usage was double-counted against quota. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11039">#11039</a>, <a href="https://github.com/cvgenesis"><code>@​cvgenesis</code></a>)</li>
<li>TAS: Fixed cache cleanup for non-TAS Pods that reach a terminal phase without Kueue observing the expected status update, preventing stale Pod usage from remaining in the TAS cache. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11146">#11146</a>, <a href="https://github.com/amy"><code>@​amy</code></a>)</li>
<li>TAS: optimize performance of building the snapshot by pre-aggregating the node usage coming from non-TAS Pods. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11041">#11041</a>, <a href="https://github.com/jzhaojieh"><code>@​jzhaojieh</code></a>)</li>
</ul>
