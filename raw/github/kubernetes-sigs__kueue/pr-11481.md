#### What this PR does / why we need it:

Updates the repo’s development and verification toolchain from Helm v3 to Helm v4.1.4.

Helm v3 will stop receiving bug fixes after July 2026 and security fixes after November 2026, so we need to align local installs, Makefile targets, and verification scripts with Helm v4.

Changes:
- Install Helm via `helm.sh/helm/v4/cmd/helm` in `hack/tools` and `Makefile-deps.mk`
- Install `helm-unittest` with `--verify=false` (required for Helm 4 plugin installs)
- Remove the outdated `HELM_VERSION=v3.16.2` pin in `verify-helm-install.sh`
- Document Helm v4+ in the chart README template

Chart content is unchanged; Helm 4 remains compatible with existing v2 charts. Verified with `make helm-lint`, `make helm-verify`, and `make helm-unit-test`.

Fixes #11426

#### Special notes for your reviewer:

This only updates the pinned Helm CLI used for lint/template/unittest/chart packaging—not end-user cluster runtime behavior. `helm.sh/helm/v3` remains an indirect dependency of `helm-unittest` in `hack/tools/go.mod`.
