#### What this PR does / why we need it:
The "should not suspend child jobs of admitted jobs" e2e test intermittently times out waiting for the AppWrapper to transition from Running to Succeeded. MediumTimeout (45s) is insufficient when pod teardown is slow in CI. This PR switches to LongTimeout (90s) for all AppWrapperSucceeded assertions.

#### Which issue(s) this PR fixes:

-->
Fixes #11495

Also applied the same fix to `test/e2e/singlecluster/extended/appwrapper_test.go` which has an identical pattern vulnerable to the same flake.
