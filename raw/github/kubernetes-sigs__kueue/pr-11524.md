## Description

#### What type of PR is this?
/kind cleanup
/area testing

#### What this PR does / why we need it:
Updates the **AdmissionCheck controller** `Describe` block in `test/integration/singlecluster/controller/core/admissioncheck_controller_test.go`.
- Removes `ginkgo.Ordered` and `ginkgo.ContinueOnFailure` from that `Describe` block only.
- Moves manager `StartManager`/`StopManager` from `BeforeAll`/`AfterAll` into `BeforeEach`/`AfterEach` (see [Parallelize Fair Sharing Integration Test (66% speedup) #8726](https://github.com/kubernetes-sigs/kueue/pull/8726)).
Continues the split from [Eliminate ginkgo.Ordered for singlecluster integration tests #9880](https://github.com/kubernetes-sigs/kueue/issues/9880). Follows webhook work including [AdmissionCheck webhook #11464](https://github.com/kubernetes-sigs/kueue/pull/11464).

#### Which issue(s) this PR fixes:
Part of #9880

#### Special notes for your reviewer:
- One `Describe` block only; inner `When` hooks are unchanged.
- No changes to `suite_test.go` or `test/integration/framework`.
