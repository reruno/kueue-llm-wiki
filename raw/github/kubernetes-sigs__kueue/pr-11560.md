## Description

Adds DEPENDENCY_LIFECYCLE.md describing how Kueue introduces, updates, secures, and removes third-party dependencies, and references it from the dependencies-lifecycle section of SECURITY-INSIGHTS.yaml. Bumps last-updated and last-reviewed to reflect the change.

Fixes #1471

#### What type of PR is this?
/kind documentation
/area website

#### What this PR does / why we need it:
Adds a `DEPENDENCY_LIFECYCLE.md` at the repo root describing how Kueue manages third-party dependencies (scope, introduction, update cadence, Kubernetes version alignment, security updates, removal, and review), and wires it into the `dependencies.dependencies-lifecycle` section of `SECURITY-INSIGHTS.yaml`, which was previously absent.

This satisfies the corresponding entry of the [OpenSSF Security Insights spec](https://github.com/ossf/security-insights-spec) and should improve the project's score on [CLOMonitor](https://clomonitor.io/projects/cncf/kueue). Tagging `#SecuritySlam` since this completes one of the items from that initiative.

#### Which issue(s) this PR fixes:
Fixes #1471

#### Special notes for your reviewer:
- Every concrete claim in the policy is grounded in observable repo state — `.github/dependabot.yml`, `RELEASE.md`, the testgrids linked from `README.md`, `OWNERS`, and `CONTRIBUTING.md` — so each line should be straightforward to verify.
- All relative links in the doc resolve to files in this repo.
- Reviewers may want to sanity-check the `dependencies-lifecycle.comment` text in `SECURITY-INSIGHTS.yaml` since that string ends up in security tooling output.

#### Does this PR introduce a user-facing change?

```release-note
NONE
```
