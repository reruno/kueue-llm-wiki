## Description

#### What type of PR is this?
/kind cleanup
/area testing

#### What this PR does / why we need it:
Updates the `Describe` block in `test/integration/singlecluster/controller/jobs/statefulset/statefulset_controller_test.go`:
- `StatefulSet controller`
- Removes `ginkgo.Ordered` and `ginkgo.ContinueOnFailure` from that block.
- Moves manager `StartManager`/`StopManager` from `BeforeAll`/`AfterAll` into `BeforeEach`/`AfterEach` (see [Parallelize Fair Sharing Integration Test (66% speedup) #8726](https://github.com/kubernetes-sigs/kueue/pull/8726)).
Continues the split from [Eliminate ginkgo.Ordered for singlecluster integration tests #9880](https://github.com/kubernetes-sigs/kueue/issues/9880). First `controller/jobs` PR after completing `controller/core` ([#11545](https://github.com/kubernetes-sigs/kueue/pull/11545)).

#### Which issue(s) this PR fixes:
Part of #9880

#### Special notes for your reviewer:
- Single `Describe` block, two `It` specs; no inner `When` hook changes.
- Keeps `jobframework.WithEnabledFrameworks([]string{"statefulset"})` in manager setup.
- No changes to `suite_test.go` or `test/integration/framework`.
