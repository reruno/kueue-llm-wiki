## Description

What type of PR is this?

/kind cleanup
/area testing

What this PR does / why we need it:

Skip the blocking kubectl wait --for=condition=available after each external operator install. These waits serialize setup unnecessarily — BeforeSuite already gates on operator readiness before any test runs.

The waits can be re-enabled via E2E_WAIT_FOR_OPERATORS_IN_INSTALL=true.
The Kubeflow Trainer webhook wait is intentionally kept unconditional, as the runtime resources applied immediately after depend on it.

Which issue(s) this PR fixes:
Fixes #

Special notes for your reviewer:
Only install_kubeflow_trainer retains a plain kubectl wait — it gates the overlays/runtimes apply that follows it.

```release-note
NONE
```
