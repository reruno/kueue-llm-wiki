## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it:

To move the e2e tests for the native resources (k8s Job and Pod) to the "baseline" suite which does not require installing any CRDs.

This should offload the "extended" e2e test suite, baseline is much faster thanks to no CRD installation.
