#### What this PR does / why we need it:

  Manual cherry-pick of #11676 for `release-0.17`.

  The automated `/cherrypick release-0.17` failed because the original PR was authored on top of #11310 (`[TrainJob] Remove global state`), which changed the `GenericJob`
  interface signatures by adding a `client.Client` parameter to `PodsReady`, `PodSets`, `RunWithPodSetsInfo`, and `ReclaimablePods`. #11310 is a refactor and was not
  cherry-picked to `release-0.17`, so the patch from #11676 cannot apply cleanly.
