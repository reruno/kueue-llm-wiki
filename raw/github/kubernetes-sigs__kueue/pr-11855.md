## Description

#### What type of PR is this?

/kind feature

#### What this PR does / why we need it:

This PR enables WaitForPodsReady by default by applying default configuration values.

The default configuration now sets:

* timeout: 1h
* recoveryTimeout: 1h
* blockAdmission: false
* default requeuing strategy values

#### Which issue(s) this PR fixes:

Fixes #11366

#### Special notes for your reviewer:

This change updates the defaulting behavior for WaitForPodsReady and adjusts the corresponding defaulting and configuration tests.

#### Does this PR introduce a user-facing change?

```release-note
Enabled WaitForPodsReady by default and configured a default timeout and recovery timeout of 1 hour when not explicitly specified.
```
