## Description

#### What type of PR is this?
/kind documentation

#### What this PR does / why we need it:
Adds a "Scheduling stats" section to the Workload concepts page documenting the
`.status.schedulingStats` field. The section explains the `evictions` list and its
`reason`, `underlyingCause`, and `count` fields, includes a status example, and notes
that the stats are persisted across controller restarts and back the
`evicted_workloads_once_total` metric.

#### Which issue(s) this PR fixes:
Fixes #5697

#### Special notes for your reviewer:
Documentation-only change; no code or API is modified. I verified it locally with a full
`hugo --gc --minify` build (Hugo v0.162.1+extended) — builds clean, no warnings, and all
internal links in the new section resolve.

Heads-up: English isn't my first language, so I used an AI coding assistant to help me
phrase the docs clearly and idiomatically. I went through the result myself and checked
all the technical details against the source (`workload_types.go`,
`pkg/workload/workload.go`, `pkg/metrics/metrics.go`).
