## What this PR does / why we need it:

It also adds `accessProviders` to the v1beta2 `ClusterProfile` configuration used by MultiKueue. The existing `credentialsProviders` field is kept for compatibility, marked as deprecated, and still validated with the same rules. When both fields define the same provider name, the `accessProviders` entry takes precedence.

Docs, examples, generated API reference, and tests are updated to show `accessProviders` as the preferred field.

## Which issue(s) this PR fixes:

None

## Special notes for your reviewer:

The dependency bump includes a small MultiKueue source change because `cluster-inventory-api` v0.1.3 moved the provider implementation from `pkg/credentials` to `pkg/access`.

`credentialsProviders` remains accepted for compatibility, but new examples and docs use `accessProviders`. If the same provider name appears in both fields, the `accessProviders` entry is used.
