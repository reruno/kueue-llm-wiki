#### What this PR does / why we need it:
If onlyTASFlavor() return error the psAssigment has error. In this case the assignment mode should be NoFit (https://github.com/kubernetes-sigs/kueue/blob/main/pkg/scheduler/flavorassigner/flavorassigner.go#L307) but if the previous a.assignmentMode is Fit, RepresentativeMode() will persist to return Fit mode because the cache is not invalidated, which will result in a wrong scheduler results (quota reservation).

#### Which issue(s) this PR fixes:
Fixes #

#### Special notes for your reviewer:

#### Does this PR introduce a user-facing change?
```release-note
TAS: Fixed error handling for TAS topology assignments so Workloads are not considered
`Fit` when topology assignment fails. Kueue now treats such assignment errors as `NoFit`
instead of allowing the Workload to reserve quota.
```
