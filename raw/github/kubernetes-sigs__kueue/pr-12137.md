## Walkthrough

The PR adds a new Prometheus histogram metric `kueue_pod_scheduling_gate_removal_seconds` measuring the latency between workload admission and scheduling gate removal in the pod controller. To support this, the `ComposableJob.Run` interface and `Pod.Run` implementation are updated to accept a `*kueue.Workload` parameter, the reconciler call site is updated accordingly, and the metric is recorded after successful pod patches when the workload `WorkloadAdmitted` condition is True.

## Changes

|---|---|
| **New `PodSchedulingGateRemovalSeconds` metric** <br> `pkg/metrics/metrics.go`, `site/content/en/docs/reference/metrics.md` | Declares, initializes, registers, and clears the `PodSchedulingGateRemovalSeconds` histogram with `cluster_queue` and `is_group` labels, adds a `RecordPodSchedulingGateRemovalSeconds` helper function, and documents the metric in the reference guide. |
