#### Special notes for your reviewer:
This is not mergeable until all the TAS tests are passing (feature parity with the existing implementation) and until https://github.com/kubernetes-sigs/scheduler-library/pull/2 is merged.

Additionally, I want to benchmark this first (I'll update the PR later today) using our scheduler performance tests. I benchmarked the proof-of-concept I implemented earlier, the results suggested that the CPU usage does not meaningfully differ when this flag is disabled/enabled, but the memory balloons when the topology is large. This branch contains an improved implementation of the fit check, which ideally should be more performant. TBD.
