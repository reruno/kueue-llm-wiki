## Description

#### What type of PR is this?
/kind documentation
/area testing

#### What this PR does / why we need it:
The primary e2e test targets in `Makefile-test.mk` lacked the `## ` descriptions
that the `help` target scrapes, so `make help` listed none of them and contributors
had no easy way to discover how to run e2e tests. This adds help text to the
developer-facing e2e parent targets (baseline, extended, sequential, TAS,
MultiKueue, cert-manager, upgrade, and DRA suites).

The internal `-helm`, `-shard-N`, and variable-setter permutations are intentionally
left out to keep `make help` readable, mirroring how the `test-integration` family is
documented.

#### Which issue(s) this PR fixes:
Fixes #12285

#### Special notes for your reviewer:
Verified with `make help | grep -i e2e` — all 14 targets now appear.
AI assistance (Claude Code) was used to identify the affected targets and draft this change.
