/kind documentation

#### What this PR does / why we need it:

This PR addresses the follow-up comments for the Topology-Aware Scheduling task page.

It:
- reduces duplicated feature gate setup instructions by pointing users to the existing feature gate configuration documentation;
- points local contributors to the TAS kind cluster test setup instead of duplicating the cluster setup details in the task page;
- keeps a published example config command for users who are not working from a local checkout.

#### Which issue(s) this PR fixes:

Fixes #12049
