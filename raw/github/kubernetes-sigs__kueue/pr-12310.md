## Walkthrough

Two kueueviz backend handler functions are updated to propagate errors rather than silently discard them. `fetchResourceFlavorDetails` now returns a wrapped error from `getNodesForFlavor` on failure. `fetchDashboardData` aborts on errors from resource flavor, cluster queue, and local queue fetches. `fetchWorkloadsDashboardData` changes its return type to `(any, error)` and wraps workload-list and pod-list failures with `fmt.Errorf`.
