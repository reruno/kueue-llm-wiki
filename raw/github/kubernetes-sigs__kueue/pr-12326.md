## Description

#### What this PR does / why we need it:
Adds a gauge metric at the LocalQueue level to monitor AFS usage per LocalQueue:
`kueue_local_queue_admission_fair_sharing_usage`

Also, since scheduler and metric paths use the same formula, I moved the calculation to: `pkg/util/admissionfairsharing/admission_fair_sharing.go`

#### Which issue(s) this PR fixes:
Fixes #11277

#### Special notes for your reviewer:

#### Does this PR introduce a user-facing change?
```release-note
Added `kueue_local_queue_admission_fair_sharing_usage` Prometheus metric to report AFS usage per LocalQueue, calculated from the resource-weighted sum of consumed resources and pending admission penalties, and divided by the LocalQueue's fair sharing weight.
```

+		}
