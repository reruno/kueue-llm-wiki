#### What this PR does / why we need it:

Companion PR to kubernetes-sigs/kueue#12396. Marks the release-0.18 docs as an archived version and activates the version dropdown.

**`site/hugo.toml`:**
- Sets `archived_version = true` — adds the Docsy "you are viewing an older version" banner on every page
- Sets `githubbranch = "release-0.18"` (was incorrectly pointing to `main`)
- Sets `url_latest_version = "https://kueue.sigs.k8s.io"`
- Populates `[[params.versions]]` with entries for v0.19.0, v0.18, v0.17, v0.16

#### Which issue(s) this PR fixes:

Fixes #

#### Special notes for your reviewer:

Part of a set of four companion PRs enabling versioned docs. The `v0-18.kueue.sigs.k8s.io` subdomain in the dropdown requires a Netlify domain alias and DNS CNAME to kubernetes/k8s.io (separate infra step).
