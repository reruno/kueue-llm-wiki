#### What this PR does / why we need it:

Splits the large `pkg/controller/core/workload_controller_test.go` by concern, following the `scheduler_test.go` split style.

This extracts a shared `reconcileTestCase` type and `runReconcileTestCases` helper, then moves `TestReconcile` case groups into per-concern files such as DRA, requeue, eviction, and inadmissible cases.

#### Special notes for your reviewer:
