## Description

#### What type of PR is this?

/kind cleanup
/area multikueue

#### What this PR does / why we need it:

Removes the temporary workaround that manually patched a
`JobSuspended=True` condition on the local Job in the MultiKueue adapter.
(#11649)

The workaround was needed to avoid a K8s 1.36 validation regression
(kubernetes/kubernetes#139281), where modifications to scheduling directives on a
suspended Job were rejected if the `JobSuspended` condition had not yet been set by
the job controller. The regression was fixed in kubernetes/kubernetes#139287 and
cherry-picked to 1.36.2. This workaround is no longer needed.

Changes:
- Remove the `if !isJobStatusConditionTrue(...)` block from `determineStatusUpdate`
- Remove the now-unused `setJobStatusCondition` and `isJobStatusConditionTrue` helpers
- Update a stale test comment that referenced the patching behavior

#### Which issue(s) this PR fixes:

Fixes #11863

#### Special notes for your reviewer:

Regarding the test case `Test_multiKueueAdapter_SyncJob_DeferredWhenLocalSuspended`, I left the original comment content unchanged. While it still references K8s 1.36 validation rules as motivation, should this also be revised?
I'd appreciate your input on whether this comment should also be updated.
