#### What this PR does / why we need it:
 Adds placement-level gang scheduling via scheduler-library. Before admitting a workload, Kueue now runs the scheduler-library to verify all pods across all PodSets can actually be placed on cluster nodes. If any PodSet fails placement, the workload stays pending instead of wasting quota.
