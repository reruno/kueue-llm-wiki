#### What this PR does / why we need it:
The WAS e2e kind config enabled the `GangScheduling` feature gate, which upstream merged into `GenericWorkload` (kubernetes/kubernetes#139520). 

On k8s-main the control-plane components now reject it as an unrecognized feature gate and fail to start, so the kind cluster never bootstraps; `periodic-kueue-test-e2e-k8s-main-was` has failed on every run since Jun 17.
