#### What this PR does / why we need it:

cherry-pick of https://github.com/kubernetes-sigs/kueue/pull/12413

The automated cherry-pick failed because `workload_controller_test.go` has diverged significantly between main and release-0.17, so a textual cherry-pick was not practical.

This PR applies the same refactor to release-0.17's existing tests:

- extracts the shared `reconcileTestCase` type and runner from this branch's current `TestReconcile`
- splits the existing cases into the same per-concern test files/functions as main
- keeps the test cases behavior-preserving: no cases added or dropped
