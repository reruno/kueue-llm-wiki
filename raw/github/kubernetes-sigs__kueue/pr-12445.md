#### What this PR does / why we need it:

`TestScheduleForTASPreemption` and `TestScheduleForTASCohorts` duplicated the same TAS scheduling run/assert procedure.

This extracts a shared `tasScheduleTestCase` and `runTASScheduleTestCases` helper, then converts both tests to use it.

`TestScheduleForTAS` is left as-is because its run procedure differs materially, so folding it in would add complexity rather than remove duplication.
