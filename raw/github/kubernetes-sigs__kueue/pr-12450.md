## Description

This is a manual cherry-pick of #12402 to `release-0.17`, replacing the automated #12433 which failed CI.

#12402's Helm hook references the `kueue-populator.kubectlImage` template helper introduced in #10925, which is not present on `release-0.17`. The automated cherry-pick of #12402 alone therefore failed to render. This PR cherry-picks both as separate commits, with the helper dependency first:

- Deduplicate kubectl image (#10925)
- KueuePopulator: clean up created resources on helm uninstall (#12402)

The only manual resolution was in the two Helm test templates, where `release-0.17` uses different container names than `main`; the `kueue-populator.kubectlImage` helper was applied while keeping the existing container names.

```release-note
KueuePopulator Helm: `helm uninstall` removes the ClusterQueue, ResourceFlavor, Topology, ConfigMap, and RBAC created by the chart, which previously leaked after uninstall.

ACTION REQUIRED: If you installed a previous version of the kueue-populator chart, its ConfigMap and RBAC (`*-kueue-hook-*` ServiceAccount/ClusterRole/ClusterRoleBinding and the `*-kueue-resources` ConfigMap) were created as Helm hooks and are not adopted by the new release. Delete them manually before upgrading to avoid `helm upgrade`/`install` ownership conflicts.
```
