  **Parsing `CombinedOutput()` as JSON is flaky**
  
  The code at Lines 139-144 captures both stdout and stderr. Since `kueuectl` utilizes `genericiooptions.IOStreams` with a separate `ErrOut` stream, any stderr output (logs, warnings) is concatenated into the `output` buffer, causing `json.Unmarshal` to fail.
  
  Update the test to use `cmd.Output()` for JSON parsing cases to capture stdout exclusively.
