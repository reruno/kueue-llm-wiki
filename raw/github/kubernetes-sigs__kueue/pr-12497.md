<h2>Changes by Kind</h2>
<h3>Bug or Regression</h3>
<ul>
<li>DRA: Fixed a bug where pending Workloads using DRA extended resources were not requeued when their <code>DeviceClass</code> was deleted or its <code>extendedResourceName</code> changed. Kueue now re-evaluates affected Workloads so they do not remain in stale admission state. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12093">#12093</a>, <a href="https://github.com/sohankunkerkar"><code>@​sohankunkerkar</code></a>)</li>
<li>DRA: Fixed configuration validation to reject <code>deviceClassMappings[].sources</code> when the <code>KueueDRAIntegrationPartitionableDevices</code> feature gate is disabled, preventing unsupported partitionable-device configuration from being accepted. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12152">#12152</a>, <a href="https://github.com/sohankunkerkar"><code>@​sohankunkerkar</code></a>)</li>
<li>DRA: Fixed hot reconcile loops for inadmissible Workloads with deterministic DRA resolution
failures. Kueue now avoids requeueing permanent DRA spec or configuration errors while still
retrying transient failures with backoff. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12057">#12057</a>, <a href="https://github.com/thc1006"><code>@​thc1006</code></a>)</li>
<li>ElasticJobsViaWorkloadSlices: Fix the bug that regular (non-elastic) workloads with the required/preferred topology
were rejected when the feature ElasticJobsViaWorkloadSlicesWithTAS is enabled. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12044">#12044</a>, <a href="https://github.com/yaroslava-serdiuk"><code>@​yaroslava-serdiuk</code></a>)</li>
<li>Fixed LocalQueue status updates being rejected (&quot;status.flavorsReservation: Too many: ... must have at most 16 items&quot;) when the referenced ClusterQueue has more than 16 flavors, by raising the LocalQueue status flavor limits to 64 to match the ClusterQueue limits. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12087">#12087</a>, <a href="https://github.com/AsherWright"><code>@​AsherWright</code></a>)</li>
<li>Kueue-populator: Fixed <code>events.k8s.io</code> RBAC permissions for event recording. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12031">#12031</a>, <a href="https://github.com/weizhoublue"><code>@​weizhoublue</code></a>)</li>
<li>KueueViz: Fixed a bug where the dashboard briefly displayed zero counts for all metrics on page load before the WebSocket connection finished loading. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12039">#12039</a>, <a href="https://github.com/YadavAkhileshh"><code>@​YadavAkhileshh</code></a>)</li>
<li>KueueViz: Fixed a layout-bleed bug where switching directly between detail pages briefly rendered stale queue data from the previously visited resource. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12019">#12019</a>, <a href="https://github.com/YadavAkhileshh"><code>@​YadavAkhileshh</code></a>)</li>
<li>Observability: Fix ClusterQueue Borrowing Limit metric to display infinity if the limit is unset. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12105">#12105</a>, <a href="https://github.com/mszadkow"><code>@​mszadkow</code></a>)</li>
<li>Observability: Fixed a misleading <code>kueue_cluster_queue_lending_limit</code> metric value for ClusterQueues with unset <code>lendingLimit</code>. Kueue now reports <code>+Inf</code>, matching the actual unconstrained lending behavior instead of reporting 0. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12168">#12168</a>, <a href="https://github.com/weizhoublue"><code>@​weizhoublue</code></a>)</li>
<li>Observability: add a safeguard check truncating the event messages to make sure the events can be successfully recorded in the API server. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12048">#12048</a>, <a href="https://github.com/olekzabl"><code>@​olekzabl</code></a>)</li>
<li>PriorityBooster: Fix a bug that events.k8s.io Events operation permission errors. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11969">#11969</a>, <a href="https://github.com/dddwsd"><code>@​dddwsd</code></a>)</li>
<li>TAS: Fix a bug where TAS ignores excluded or transformed resources in node capacity tracking. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12034">#12034</a>, <a href="https://github.com/wafrelka"><code>@​wafrelka</code></a>)</li>
<li>TAS: Fixed error handling for TAS topology assignments so Workloads are not considered
<code>Fit</code> when topology assignment fails. Kueue now treats such assignment errors as <code>NoFit</code>
instead of allowing the Workload to reserve quota. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/12172">#12172</a>, <a href="https://github.com/yaroslava-serdiuk"><code>@​yaroslava-serdiuk</code></a>)</li>
<li>VisibilityOnDemand: Fixed forbidden list/watch errors caused by unused
MutatingAdmissionPolicy informers in the visibility server. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/11874">#11874</a>, <a href="https://github.com/kimminw00"><code>@​kimminw00</code></a>)</li>
</ul>
</blockquote>
