## Description

#### What type of PR is this?

#### What this PR does / why we need it:

Adds a new `kueue_pending_scheduling_hashes` gauge metric that reports the number of unique pending scheduling equivalence hashes per ClusterQueue.

This helps operators evaluate queue progress when `SchedulingEquivalenceHashing` is enabled. In that mode, equivalent pending workloads can be moved to inadmissible in bulk, so the number of pending hashes is the useful comparison point rather than only the number of pending workloads.

#### Which issue(s) this PR fixes:

Fixes #12463
