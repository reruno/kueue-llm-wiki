#### What this PR does / why we need it:
LeaderWorkerSet (and similar formations) allow a leader PodSet to carry no
requests for the TAS-managed resource (e.g. GPU). Before this fix, TAS
validation required every TAS-requesting PodSet to have an explicit flavor
assignment for each managed resource. A leader with zero requests would get
no flavor assignment at all and be rejected with "no TAS flavor assigned",
blocking the whole workload from admission even when nodes were idle.
