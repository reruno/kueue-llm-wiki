## Description

Fix: replace the escape-hatch ternary with the same default-value pattern already used by the maximumExecutionTimeSeconds rule, treating an absent field as the empty string on both sides:

With this change:
- Removing queueName from an admitted workload is rejected because 'q1' != ''.
- Adding a new queueName to an admitted workload that has none is rejected because '' != 'q2'.
- Legitimate mutations (e.g. resetting admission before a queue change) are unaffected because the outer QuotaReserved guard still allows changes when the workload is not admitted.
