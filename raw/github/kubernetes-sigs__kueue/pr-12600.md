### Review by [@mimowo](https://github.com/mimowo) (commented) — 2026-06-26T18:18:02Z

Lgtm overall, but I think in this case I would introduce a custom env like IMAGE_PUSH_RETRY, because I assume we may want to retry more selectovely. 

Because actually this command is sometimes used by users we ask to build and push Kueue locally, and sometimes they may point to wrong repo, and then it does not make sense to retry on 404. 

So, would it be feasible to only retry for the  known case of Context Deadline Exceeded? If so then I would limit to that case for now so that it does not do unnecessary retries for non-triable errors.
