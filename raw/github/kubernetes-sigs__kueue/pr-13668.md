#### What this PR does / why we need it:
This PR eliminates all concrete uses of `resources.MapRequests` outside of `pkg/resources` in favor of the `resources.Requests` interface. This allows `MapRequests` and `SliceRequests` implementations to be fully interchangeable under the hood without exposing their concrete types to the rest of the codebase.

#### Which issue(s) this PR fixes:

-->
Fixes #13665 

#### Special notes for your reviewer:
Test fixtures have been updated to use `map[corev1.ResourceName]int64` standard types, and interactions with `Requests` now go through interface methods like `.ForEach()`, `.Set()`, and `.GetValue()`.
