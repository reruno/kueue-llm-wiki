#### What this PR does / why we need it:
This PR updates KEP-77, proposing the design for supporting `required` and `preferred` Topology Aware Scheduling (TAS) modes during Elastic Job scaling operations. 

Previously, Elastic Jobs only supported unconstrained TAS scaling. This KEP outlines the Node-Hot-Swap algorithm for strict `required` packing, and the Fast-Path fallback strategy for `preferred` placement, unlocking topology-aware dynamic scaling for latency-sensitive workloads like AI training.
