## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it:

Two `admissionFairSharing` validation errors reported a value that is not the one at the field path they name: the `usageSamplingInterval` error carried `usageHalfLifeTime`, and a negative `resourceWeights` entry error carried the whole weights map instead of the weight at that key. Both now report the value the path points at.

The webhook half this PR used to carry, the "is not a multiple of" message naming the pod count, landed in #15736, so it is no longer here.

#### Which issue(s) this PR fixes:

None filed, details above.

#### Special notes for your reviewer:

Two lines in `pkg/config/validation.go`, each with a test that fails against the old value.

_Disclosure: I used an AI coding assistant while preparing this PR. I reviewed and tested the change myself._

#### Does this PR introduce a user-facing change?

```release-note
Configuration: Fixed the `admissionFairSharing.usageSamplingInterval` and `admissionFairSharing.resourceWeights` validation errors to report the value at the field they name.
```
