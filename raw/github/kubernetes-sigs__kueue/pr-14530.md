## Description

Cherry-pick of #14488 onto release-0.19, prepared manually since the robot hit a conflict.

The only conflict was in pkg/controller/jobs/pod/pod_controller.go, where main has WithIntegrationManager on the NewPod call and release-0.19 doesn't. I kept just the WithRoleTracker addition and left the rest of the line as it is on the branch.

Build is clean and pkg/metrics, pkg/controller/jobs/pod, pkg/controller/tas and pkg/controller/elasticjobs all pass.

```release-note
Observability: Fixed a bug where the `kueue_pod_scheduling_gate_removal_seconds` metric was missing the `replica_role` label (`leader`, `follower`, or `standalone`) carried by the other Kueue metrics.
```
