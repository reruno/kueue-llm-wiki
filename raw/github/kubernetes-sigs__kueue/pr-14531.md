## Description

Manual cherry-pick of #14348 onto `release-0.18`. The bot's automated cherry-pick (`/cherrypick release-0.18`) failed because #14348 was rebased onto current `main`, whose `go.mod` diverged from this branch.

The production change (`preemption.go`, `fair_sharing_log.go`) applied cleanly. Adaptations for `release-0.18`:

- `go.mod`: resolved to the branch's own dependency versions, then `go mod tidy` promoted `github.com/go-logr/zapr` from indirect to direct (the new test observes emitted entries through a zap core). No other dependency changed and `go.sum` is untouched.
- Test fixture adapted to this branch's API: `preemptionCtx` has no `ctx` field, and `workload.Usage.Quota` is a `resources.FlavorResourceQuantities` directly (no `workload.ResourceUsage` wrapper).

`gofmt`, `go vet`, `go build ./...`, `go test ./pkg/scheduler/preemption/...`, `go mod verify`, and `golangci-lint` all pass.
