#### What this PR does / why we need it:

Reorganizes the Workload Aware Scheduling (WAS) e2e test suites into dedicated targets and directories as proposed in the issue discussion:
- Moves WAS e2e tests out of `test/e2e/singlecluster/was` and into a dedicated `test/e2e/was/baseline` directory.
- Adds the `test-was-e2e-baseline` Makefile target for running general WAS tests with `WAS_ENABLED=true` and the `SchedulerLibraryIntegration` feature gate enabled.
- Renames existing TAS WAS targets (`test-tas-was-e2e-*` -> `test-was-e2e-tas-*`) and the Kubernetes main compatibility target (`test-e2e-k8s-main-was` -> `test-was-e2e-k8s-main-compatibility`) for naming consistency.
- Updates documentation and skill references in `cmd/experimental/skills/was-cluster/SKILL.md`.

Fixes #14591
