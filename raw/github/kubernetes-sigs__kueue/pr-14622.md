#### What this PR does / why we need it:
Reorganizes the single-cluster E2E test suites under `test/e2e/singlecluster/` according to the agreed structure in the discussion:
- Moves `test/e2e/tas/` to `test/e2e/singlecluster/tasapi/` (`baseline/` and `extended/`).
- Moves `test/e2e/singlecluster/was/` to `test/e2e/singlecluster/wasapi/` and updates the package declaration to `package wasapi`.
- Adds `test-e2e-was-api`, `test-e2e-tas-*`, and `test-e2e-was-tas-*` Makefile targets.
- Preserves legacy aliases (`test-tas-was-e2e-*`, `test-e2e-was`, and `test-e2e-k8s-main-was`) for CI/Prow backwards compatibility.
- Updates documentation in `cmd/experimental/skills/was-cluster/SKILL.md`.
