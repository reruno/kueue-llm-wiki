#### What this PR does / why we need it:

Upgrades the `github.com/ray-project/kuberay/ray-operator` dependency from
**v1.6.2** to **v1.7.0** (the latest KubeRay release).

- The e2e `KUBERAY_VERSION` and the generated `dep-crds/ray-operator` both derive
  from this module version (`hack/make/deps.mk`), so the operator and CRDs used in
  the KubeRay e2e suite move to v1.7.0 as well — no separate version bump needed.
- `go mod tidy` dropped `github.com/hashicorp/golang-lru/v2` and
  `github.com/smallnest/chanx` from the indirect set; v1.7.0 no longer pulls them in
  transitively.
- No Kueue source changes were required: the RayJob/RayCluster/RayService adapters
  build against the new API and their unit tests pass.

#### Relationship to #11264

v1.7.0 is the first KubeRay release that ships ray-project/kuberay#4841 — the
top-level `RayService.Spec.Suspend` field and its `Suspending`/`Suspended`
lifecycle. The RayService upgrade-gating POC in #11264 currently depends on that
KubeRay change and works around the missing release by hand-syncing a vendored
`rayservice_types.go` from a local KubeRay checkout. Once this bump lands, #11264
can drop that hand-synced shim and build against the official v1.7.0 API, so this
PR is a prerequisite for taking #11264 out of POC state.
