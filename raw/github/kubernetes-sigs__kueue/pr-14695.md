#### What this PR does / why we need it:

KueueViz currently permits a Helm deployment with authentication disabled while still creating a reachable ClusterIP and a cluster-wide reader binding. This allows any pod with service-network reachability to query KueueViz without authenticating.

This PR:

- defaults Helm deployments to Kubernetes TokenReview authentication and rejects Disabled or unknown authentication modes;
- binds standalone unauthenticated or unknown modes to IPv4 loopback only;
- defaults local development CORS to same-origin instead of wildcard access;
- gives the backend a dedicated ServiceAccount instead of granting cluster-wide access to the namespace default ServiceAccount;
- enables TokenReview and a matching production origin in the Kustomize deployment;
- updates the manifest generator, Helm tests, chart documentation, backend documentation, and KEP.

Per-user SubjectAccessReview authorization is intentionally not duplicated here; that is being developed separately in #13810.
