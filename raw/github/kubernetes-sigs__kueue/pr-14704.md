### Review by [@sohankunkerkar](https://github.com/sohankunkerkar) (commented) — 2026-08-24T03:55:56Z

On #13749 the reason for keeping this opt-in was that installing on 1.35 would fail, and the plan was to revisit around 1.39 when every supported version has MAP stable. A value that force-renders is the thing that reintroduces that failure.
