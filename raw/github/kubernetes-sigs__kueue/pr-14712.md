<blockquote>
<h2>v0.165.0</h2>
<p>The two main new things is the new <code>css.ChromaStyles</code> template func and the new <code>importContext</code> option demonstrated below.</p>
<pre lang="handlebars"><code>{{ $light := css.ChromaStyles (dict &quot;targetPath&quot; &quot;css/components/chroma-light.css&quot; &quot;style&quot; &quot;github&quot; &quot;mode&quot; &quot;light&quot;) }}
{{ $dark := css.ChromaStyles (dict &quot;targetPath&quot; &quot;css/components/chroma-dark.css&quot; &quot;style&quot; &quot;github&quot; &quot;mode&quot; &quot;dark&quot;) }}
{{ $opts := dict &quot;minify&quot; true &quot;importContext&quot; (slice $light $dark) }}
{{ $css := resources.Get &quot;css/main.css&quot; | css.Build $opts }}
</code></pre>
<p>The <code>importContext</code> is relevant for <code>css.Build</code>, <code>js.Build</code>, <code>css.Sass</code>, and <code>css.PostCSS</code>. and it allows you to make resources (e.g. built from <code>resources.FromString</code>) resolvable in e.g. CSS <code>@import</code> statements.</p>
