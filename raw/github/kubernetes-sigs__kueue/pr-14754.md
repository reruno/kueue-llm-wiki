#### What this PR does / why we need it:
ComputeTASNetUsage skips a topology domain when its recomputed count is lower than what the previous admission already accounted for. A defensive path was introduced by #14572 for a case that should not occur normally. There was no dedicated coverage for this, so this adds one alongside the already existant ComputeTASNetUsage test cases.
