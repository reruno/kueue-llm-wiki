## Description

Cherry pick of #13989 on release-0.18.

#13989: Reject pods as a DRA logical resource name or anywhere in a transformation

For details on the cherry pick process, see the [cherry pick requests](https://git.k8s.io/community/contributors/devel/sig-release/cherry-picks.md) page.

#### What type of PR is this?
/kind bug

```release-note
DRA & ResourceTransformation: Fixed a bug where DRA device-class mapping or a resource transformation under the reserved resource name `pods` was silently discarded or left the Workload permanently pending.

ACTION REQUIRED: Remove or rename those entries before upgrading, or the kueue-controller-manager will fail to start. Renaming a mapping name or an `outputs` key also requires updating the matching ClusterQueue `nominalQuota` entries in the same change.
```

#### Special notes for your reviewer:

`hack/cherry_pick_pull.sh` takes `pull/13989.patch`, which is the branch's twenty-seven commits rather than the merged change, and the first of them conflicts in `pkg/config/validation_test.go` because later ones edit the same table. This picks the squash commit instead, which left one conflict in that file.

The incoming side of it carried four `multi-counter:` cases that belong to `main` rather than to this change and are not on `release-0.18`. They are dropped, so what landed is this change and nothing else: the added lines match the merged commit's exactly, 308 of them, and so do the six removed.

`go build ./...`, `go vet`, and `pkg/config` and `pkg/workload` under `go test -race -shuffle=on` all pass on the branch, and `make generate` leaves the tree clean.
