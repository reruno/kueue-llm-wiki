#### What this PR does / why we need it:
cmpopts.EquateEmpty() let the comparison in TestAssignment_ComputeTASNetUsage treat a nil TASUsage and an empty one as equal. A regression that returns nil instead of the function's initialized empty map would pass. Adjusting it so the assertion will reflect a non-nil empty result that was originally intended.

#### Which issue(s) this PR fixes:

Usage: `Fixes #<issue number>`, or `Fixes (paste link of issue)`.

-->
Fixes #14757

#### Special notes for your reviewer:
This is a follow up issue for https://github.com/kubernetes-sigs/kueue/pull/14754, where @tenzen-y suggested removing cmpopts.EquateEmpty() from the cmp.Diff call in TestAssignment_ComputeTASNetUsage, so the test explicitly can distinguish a nil TASUsage from an empty one instead of treating them as equal.

I have verified this change, and the full make test unit test suite passes.
