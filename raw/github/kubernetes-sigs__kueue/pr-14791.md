#### What this PR does / why we need it:
handleDRA currently preprocesses DRA resources and queues the workload internally, but returns done=false so the reconciler continues to other AddOrUpdateWorkload calls that overwrite the DRA accounting. 
This PR makes handleDRA a pure preprocessing step that returns InfoOptions without queueing. Reconcile queues the workload once at the end with the DRA options threaded through.
