## Description

#### What type of PR is this?

#### What this PR does / why we need it:

Manual cherry pick of #14784 for release-0.18. Part 3 of #14534, which asks for the gate on release branches at alpha.

`SchedulingEquivalenceHashingIgnorePodSetName` registers at 0.18 as **Alpha, disabled by default**, so this branch keeps its current behaviour unless an operator opts in. On main it is Beta and on by default.

The hash change and both sets of tests are identical to #14784, verified by comparing the patches for `pkg/workload/workload.go`, `pkg/workload/workload_test.go`, and `pkg/scheduler/scheduler_test.go` against the merged commit.

#### Which issue(s) this PR fixes:

Part of #14534

#### Special notes for your reviewer:

Two deliberate differences from #14784.

The gate spec is rewritten, and it has to be. Kueue never sets an emulation version, so the effective version is Kubernetes' `DefaultKubeBinaryVersion`, currently 1.36. `featureSpecAtEmulationAndMinCompatVersion` picks the highest spec at or below that, so a spec written as `{0.20, Default: true, Beta}` would still be selected here and the gate would land enabled by default. It is `{0.18, Default: false, Alpha}` instead.

The dependency on `SchedulingEquivalenceHashing` goes through `validateFeatureGateDependency` in `pkg/config/validation.go`, per your comment, since that is how this branch tracks gate dependencies. Main uses the `defaultFeatureGateDependencies` map, which does not exist here. Added a `TestLoadAndValidateFeatureGates` case alongside the existing dependency cases, and confirmed it fails if the validation line is removed.

KEP-9694 does not exist on this branch, so the KEP updates from #14784 stay on main.

#### Does this PR introduce a user-facing change?

```release-note
Scheduling: Added the alpha `SchedulingEquivalenceHashingIgnorePodSetName` feature gate, disabled by default. When enabled, Workloads differing only in PodSet names share a scheduling equivalence class, so BestEffortFIFO queues stop re-evaluating each one individually. Requires `SchedulingEquivalenceHashing`.
```
