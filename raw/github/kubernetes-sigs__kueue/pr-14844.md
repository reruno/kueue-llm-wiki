#### What this PR does / why we need it:

This PR cleans up shut down for MultiKueue integration tests using the pattern in: https://github.com/kubernetes-sigs/kueue/blob/c9ff80b65a8d6de3d9ddc734ae6ced0423f3ae38/test/integration/multikueue/suite_test.go#L569-L573

Immediately tearing down `envtest` blocks the Kueue controller manager from finishing to start, which in turn blocks the API server from cleanly shutting down until it hits a 60s timeout. Stopping the Kueue controller manager first while the API server is still running allows both to clean up faster.
