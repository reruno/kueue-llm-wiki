#### What this PR does / why we need it:

Split from #13729 to keep the refill PR focused on the feature itself:

- Extracts `nominateWorkload` from the nomination loop so a single workload can go through the same nomination path and return an explicit outcome.
- Extracts `finishEntry` to share the end-of-cycle handling for admitted, evicted, and requeued entries.

These are the two scheduler paths that refill needs to reuse for workloads popped during a scheduling cycle.
