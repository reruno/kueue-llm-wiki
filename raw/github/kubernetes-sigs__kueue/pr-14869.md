#### What this PR does / why we need it:

Manually bumps `github.com/golangci/golangci-lint/v2` in `hack/tools` from v2.12.2 to v2.13.2 (PR #14861, which did this via dependabot, was closed) and fixes the lint errors the newer version reports:

- Two new `modernize`/`stringscut` findings: switch `strings.Split`/`SplitN` to `strings.Cut` in `pkg/visibility/server.go` and `test/util/e2e.go`.
- The updated `staticcheck` reports `SA1019` deprecation messages using the fully-qualified type name instead of the local selector expression (e.g. `j.Status.State` → `(github.com/.../v1.RayClusterStatus).State`). This silently broke the existing regex exclusions in `.golangci.yaml` for known/intentional deprecated-field usages (`RayCluster.Status.State`, `features.DisableWaitForPodsReady`), surfacing them as new failures. Updated the regexes to match the new format, and added a missing exclusion for `ClusterProfile.CredentialsProviders` (deprecated but kept for backward compatibility).
- Removed inline `//nolint:staticcheck` comments that are now redundant given the corrected global exclusions (`nolintlint` flagged them as unused).

No other newly-reported lint errors required follow-up; `golangci-lint run` and the custom KAL linter (`.golangci-kal.yaml`) both pass with 0 issues.
