#### What this PR does / why we need it:

Replaces the inline callback closures in `pkg/controller/core/indexer/indexer_test.go` that manually construct `Workload`, `LocalQueue`, `LimitRange`, and `Pod` objects with the existing structured test wrappers from `pkg/util/testing`, `pkg/util/testing/v1beta2`, and `pkg/util/testingjobs/pod`.

The test file previously lived in `package indexer` (an internal test) and defined its own minimal `makeWorkload`/`makeLocalQueue`/`makeLimitRange`/`makePod` helpers to avoid an import cycle, since the wrapper packages transitively import `pkg/controller/core/indexer`. This PR converts the file to an external `package indexer_test`, which breaks the cycle and lets the tests use the real wrappers directly.

A `LimitRangeWrapper.LimitTypes(...)` method was added to `pkg/util/testing/wrappers.go` since no existing wrapper supported building a `LimitRange` with an arbitrary, possibly empty, set of bare `LimitRangeItem` types.

Test coverage and assertions are unchanged; all existing subtests and cases are preserved.

This PR uses AI-assisted development (Claude Code).
