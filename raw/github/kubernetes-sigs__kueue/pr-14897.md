#### What this PR does / why we need it:
Adds regression coverage for elastic job ungating when an elastic workload scales down after admission.

- Add a `TestReconcile` fixture where the requested PodSet count is lower than the admitted count (`wl.spec.count < wl.status.admission.count`).
- Verify that ungating uses the granted admission count correctly.
- Verify the expected gated and ungated pod behavior.
