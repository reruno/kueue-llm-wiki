#### What this PR does / why we need it:

`hack/testing/retry.sh` retries `kueueviz-image-build` failures, but only for errors matching the `--continue-if` regex in `Makefile`. #14925 shows a POST request to the registry's oauth token endpoint returning a transient `502 Bad Gateway` during `image-pushing-postsubmit`, which does not match any of the existing patterns, so retry.sh aborts after attempt 1/7 instead of retrying.
