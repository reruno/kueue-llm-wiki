## Description

#### What type of PR is this?

/kind feature

#### What this PR does / why we need it?

Adds `kueue_scheduling_assignment_recomputations_total` to observe completed in-cycle assignment recomputations by `before_mode`, `after_mode`, and `reason`, alongside the existing ClusterQueue, replica-role, and configured custom ClusterQueue labels.

The initial reasons are `NoTAS` and `OverlappingPreemptionTargets`. Each completed recomputation counts once, including unchanged modes. Overlap takes precedence when both conditions hold, matching the scheduler's branch order. The final mode includes the `DeferredFit` adjustment and does not indicate admission success. Attempts returning a planner error are excluded because they have no final assignment mode; completed `NoFit` outcomes are included.

The dedicated `kueue_preemption_target_recomputations_total` metric and scheduling decisions are unchanged. Future recomputation reasons can be added separately.

Addresses #14205 for the currently implemented recomputation paths, following the scope discussion in https://github.com/kubernetes-sigs/kueue/issues/14205#issuecomment-5511167190.
