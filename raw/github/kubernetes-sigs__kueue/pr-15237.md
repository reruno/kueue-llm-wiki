## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it:

The status update guards in the ClusterQueue, Cohort and LocalQueue reconcilers compared the status value against the pointer returned by `DeepCopy()`. `equality.Semantic.DeepEqual` returns `false` when the types differ, so the guard never held and every reconcile issued a `Status().Update`, even when nothing changed.

This PR compares pointer to pointer, and adds unit tests that count `Status().Update` calls to verify the guard (0 updates when the status is unchanged, 1 when it changes).

#### Which issue(s) this PR fixes:

None

#### Does this PR introduce a user-facing change?

```release-note
ClusterQueue, Cohort & LocalQueue: Fixed a bug where the status was written to the API server on every reconcile even when nothing changed. Kueue now skips the update when the status is unchanged.
```
