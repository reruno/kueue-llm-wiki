#### What this PR does / why we need it:
`frontend-configmap.yaml` builds the KueueViz WebSocket URL from `.Values.kueueViz.backend.ingress.host` without applying the `| default "backend.kueueviz.local"` used by the other consumers of this value.

As a result, an empty host is handled inconsistently within the same `helm template`:

```text
$ helm template charts/kueue --set enableKueueViz=true \
    --set kueueViz.backend.ingress.host=""

# templates/kueueviz/backend-ingress.yaml
    - host: 'backend.kueueviz.local'        # uses the default
# templates/kueueviz/frontend-configmap.yaml
      REACT_APP_WEBSOCKET_URL: "wss://"     # no default is applied
```

`"wss://"` is still a non-empty string, so the frontend treats it as a configured WebSocket URL. This results in URLs such as `wss:///ws/workloads`, and `new URL()` throws `TypeError: Invalid URL` for every API call.
