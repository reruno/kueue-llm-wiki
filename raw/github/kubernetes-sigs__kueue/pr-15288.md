#### What this PR does / why we need it?


MultiKueue already reports how many workloads are dispatched to and admitted on
a worker cluster, but nothing reports the ones that get evicted there. Operators
can see admissions climbing without seeing that the same workloads keep bouncing
back for re-admission.

This PR adds a `multikueue_workloads_evicted_total` counter, broken down by
ClusterQueue, worker cluster and eviction reason, so re-admission churn is
visible and can be traced to a specific worker and cause. The metrics reference
and the common Grafana queries page are updated to match.

Which issue(s) this PR fixes:
Fixes part 8 of https://github.com/kubernetes-sigs/kueue/issues/11132
