#### What this PR does / why we need it?
This PR updates Kueue to Go 1.27, aligning the repository's toolchain and dependencies with `kubernetes/kubernetes:master` (which has bumped `.go-version` to `1.27.1` and `go.mod` to `1.27.0`).

Key changes:
- Bump `go` directive to `1.27.0` across `go.mod`, `hack/tools/go.mod`, `site/go.mod`, and subpackages (`cmd/kueueviz/backend/go.mod`, `cmd/experimental/webhook-conversion-repro/go.mod`).
- Update builder images in `Dockerfile` and component Dockerfiles to `golang:1.27`.
- Disable `embedlit` under `modernize` in `.golangci.yaml` (Go 1.27 enables struct literal embedded type omission, which would otherwise flag 896 existing struct literals).
- Includes the regenerated `client-go/applyconfiguration/` and `site/content/en/docs/reference/kueue-config.v1beta2.md` artifacts.

#### Useful notes for your reviewer
This PR includes the codegen alignment from #15289. If maintainers prefer to unblock CI immediately without bumping `go.mod`, #15289 can be merged first.

Compiled with Go 1.27 (`make build`), verified with `make ci-lint` (0 issues), and verified that core controller unit tests pass.
