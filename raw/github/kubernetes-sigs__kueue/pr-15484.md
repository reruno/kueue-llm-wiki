## Description

#### What type of PR is this?

#### What this PR does / why we need it?

`Check` and `Import` run `ListPods` in a goroutine and only log its error. Since `ListPods` closes the pod channel on return, the workers finish normally, the summary has no errors, and the importer exits 0 even though nothing was checked or imported. With multiple namespaces, the ones after the failing namespace are silently skipped.

This PR sends the `ListPods` result over a channel and joins it into the returned error, so the importer fails on RBAC errors, wrong namespaces, or API server errors.

#### Useful notes for your reviewer


#### Release note

```release-note
Importer: Fixed a bug where the importer reported success and exited 0 when listing Pods failed, for example due to insufficient RBAC or a wrong namespace. The importer now returns an error in that case.
```
