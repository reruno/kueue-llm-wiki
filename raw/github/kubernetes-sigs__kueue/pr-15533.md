#### What this PR does / why we need it?

Replaces the single combined `DeviceClass handler skips reserved workloads` subtest in `pkg/controller/core/workload_controller_dra_test.go` with dedicated table-driven tests: `TestDeviceClassHandler_Create`, `TestDeviceClassHandler_Update`, `TestDeviceClassHandler_Delete`, `TestDeviceClassHandler_Generic`. Each drives `deviceClassHandler` directly through its real event type and asserts requeued requests, following the pattern in `pkg/controller/unscheduledpods/tracker_test.go`.

Fixes #15507
