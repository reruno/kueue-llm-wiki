#### What this PR does / why we need it?

`firstCandidateVariant` decides which ConcurrentAdmission Variant may open its preemption gate. When a Variant has no `BlockedOnPreemptionGates` condition, it has to tell "the scheduler evaluated this Variant and it does not need preemption" apart from "the scheduler has not evaluated this Variant yet". Since #14272 it makes that call on the presence of a `WorkloadQuotaReserved` condition, and a condition with reason `PendingEvaluation` carries no such decision.

`clearWorkloadAdmission` stamps `PendingEvaluation` when the ConcurrentAdmission controller clears a Variant's admission after eviction, and `resolveGranularUnadmittedQuotaReservedCondition` stamps it on a Variant's first reconciliation. In both cases the scheduler has not evaluated the Variant, the check stops firing, and the controller opens the preemption gate of a less favorable Variant that happened to be evaluated first, which locks the preferred Variant out for `preemptionTimeout`. This PR treats `PendingEvaluation` as not evaluated.

Sibling Variants are created within the same second, so their creation timestamps are equal after RFC3339 truncation and `baseCompareFunc` falls through to comparing UIDs. The order in which siblings reach the scheduler is arbitrary, so the gate selection has to be correct for any order.

#### Useful notes for your reviewer

- The scheduler also sets `PendingEvaluation` on Variants it did evaluate. Those do not reach `firstCandidateVariant` only because `deactivateVariants` runs before `selectVariantToOpenPreemptionGate` and `IsAdmissible` then drops them on `IsActive`. Nothing records or tests that ordering.
- With `UnadmittedWorkloadsObservability` disabled — it is on by Beta default — `requeueAndUpdate` collapses every scheduler verdict to the legacy `Pending`, so the distinction this check relies on does not exist. Widening it to match `Pending` would make `firstCandidateVariant` never ungate anything, so the gate-off case needs a separate decision about the dependency between the two gates.
