<h2>Changes by Kind</h2>
<h3>Feature</h3>
<ul>
<li>MultiKueue: Added support for reusing clientConnection configuration (QPS and Burst) for worker clusters via the <code>MultiKueueReuseClientConnectionConfigForWorkers</code> Alpha feature gate. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15280">#15280</a>, <a href="https://github.com/alien1403"><code>@​alien1403</code></a>)</li>
<li>TAS: Added support for PodSet slicing alongside PodSet grouping, allowing workloads such as LeaderWorkerSet to co-locate grouped leader PodSets with sliced worker PodSets. This behavior is gated by the TASGroupedPodSetSlicing feature gate. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15252">#15252</a>, <a href="https://github.com/pajakd"><code>@​pajakd</code></a>)</li>
</ul>
<h3>Bug or Regression</h3>
<ul>
<li>CLI: Fixed a bug where <code>kueuectl create clusterqueue</code> rejected valid decimal quantities such as <code>cpu=1.5</code> or <code>memory=1.5Gi</code> in <code>--nominal-quota</code>, <code>--borrowing-limit</code> and <code>--lending-limit</code> with <code>invalid resources specification</code>. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15312">#15312</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>CLI: Fixed a bug where <code>kueuectl list workload --clusterqueue</code> never matched pending Workloads, so combining it with <code>--status pending</code> always returned no results. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15338">#15338</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>CLI: Fixed a bug where <code>kueuectl list workload</code> could print the JOB TYPE and JOB NAME columns in a random order for Workloads with multiple owner references, such as pod groups. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15393">#15393</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>CLI: Fixed a bug where <code>kueuectl list</code> with <code>-o yaml</code> or <code>-o json</code> produced invalid output when the result spanned more than one page (<code>KUEUECTL_LIST_REQUEST_LIMIT</code>, 100 by default). All pages are now merged into a single document. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15382">#15382</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>CLI: Fixed kueuectl list pods incorrectly treating any output format containing &quot;wide&quot; as -o wide, causing JSONPath and similar expressions to be silently ignored. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15159">#15159</a>, <a href="https://github.com/DevaanshPathak"><code>@​DevaanshPathak</code></a>)</li>
<li>CLI: Fixed shell completion for the <code>--clusterqueue</code> and <code>--localqueue</code> flags, which returned no suggestions once a positional argument was typed, for example in <code>kueuectl create localqueue NAME -c &lt;TAB&gt;</code>. <code>kueuectl delete workload</code> completion now also includes inactive Workloads. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15388">#15388</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>DRA: Fixed a bug where deactivating a pending Workload caused Kueue's internal resource adjustments (RuntimeClass overhead, LimitRange defaults, limits-derived requests) to be written back into the user's Workload spec. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15151">#15151</a>, <a href="https://github.com/tomsen02"><code>@​tomsen02</code></a>)</li>
<li>MultiKueue: share one rate limiter across per-worker MultiKueue REST clients. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15326">#15326</a>, <a href="https://github.com/weizhoublue"><code>@​weizhoublue</code></a>)</li>
<li>Observability: Fixed a panic that could crash the manager when <code>CustomMetricLabels</code> is enabled with a ClusterQueue-sourced label and a Pod's Kueue scheduling gate is removed. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15391">#15391</a>, <a href="https://github.com/mimowo"><code>@​mimowo</code></a>)</li>
<li>Scheduler: The scheduler now persists NoMatchingFlavor for workloads that request both covered and uncovered resources. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15314">#15314</a>, <a href="https://github.com/PannagaRao"><code>@​PannagaRao</code></a>)</li>
<li>StatefulSet: Fixed a bug where scaling a StatefulSet to zero and then back up to a different number of replicas left the Workload with the original pod count, causing it to be admitted and charged quota for the wrong number of pods. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15302">#15302</a>, <a href="https://github.com/sohankunkerkar"><code>@​sohankunkerkar</code></a>)</li>
<li>TAS NodeHotSwap: Fix a bug where workload node replacements are potentially stuck (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15397">#15397</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>TAS: Fix a bug where RecomputeAssignmentUponPreemptionTargetsOverlap doesn't work correctly when TASHandleOverlappingFlavors is enabled. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15406">#15406</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>TAS: Fixed a bug where a completed PodSet in a multi-PodSet workload kept its topology domain occupied, preventing admission of pending workloads that had sufficient quota. This behavior is gated by the ReclaimablePods feature gate. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15225">#15225</a>, <a href="https://github.com/kshalot"><code>@​kshalot</code></a>)</li>
<li>TrainJob: Fixed a bug where the TrainJob mutating webhook added a duplicate Kueue-owned runtimePatch entry on every update, causing spec.runtimePatches to accumulate stale entries. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15216">#15216</a>, <a href="https://github.com/kannon92"><code>@​kannon92</code></a>)</li>
<li>TrainJob: Fixed admission dropping runtime-defined tolerations when ResourceFlavor tolerations were applied, which could leave pods Pending on tainted nodes. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15195">#15195</a>, <a href="https://github.com/izturn"><code>@​izturn</code></a>)</li>
<li>Workloads: Fixed a bug that could crash the Kueue controller when a namespace-scoped user created a Workload without a controller owner. Kueue now ignores the unrelated Workload. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15353">#15353</a>, <a href="https://github.com/mbobrovskyi"><code>@​mbobrovskyi</code></a>)</li>
<li>Workloads: Fixed a bug where a workload requeued after a backoff period was accounted using its raw spec rather than its effective resources, dropping requests derived from limits, LimitRange defaults, and RuntimeClass overhead. Kueue now correctly accounts the adjusted resources on requeue, preventing ClusterQueue overcommitment. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/15350">#15350</a>, <a href="https://github.com/tomsen02"><code>@​tomsen02</code></a>)</li>
</ul>
</blockquote>
