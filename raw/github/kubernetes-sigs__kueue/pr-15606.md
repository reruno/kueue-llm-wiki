<h2>v0.25.0</h2>
<h2>Highlights</h2>
<p>This version of controller-runtime introduces a new experimental <code>ReadYourWritesConsistency</code> feature,
which ensures that all writes are reflected in subsequent reads from the default cache-backed client.
Stale client reads are arguably the biggest source of friction and sometimes bugs for controller
authors, providing this functionality at the library level eliminates that class of problems entirely.</p>
<p>Try it out by setting <code>Client.EnableReadYourWritesConsistency: new(true)</code> in your manager
and leave any feedback you may have on the <a href="https://redirect.github.com/kubernetes-sigs/controller-runtime/issues/3320">tracking issue</a>.</p>
