## Description

#### What type of PR is this?

/kind bug
/area integrations

#### What this PR does / why we need it?

When a Kueue-managed SparkApplication leaves `spec.executor.instances` unset, the executor PodSet is counted as 0. On stop, `RestorePodSetsInfo` wrote `instances: 0` back together with `suspend: true`, but the SparkApplication CRD requires `instances >= 1`, so the API server rejected the whole patch. The job could not be suspended and the reconciler kept retrying.

This PR restores a 0 executor count as an unset field.

None

