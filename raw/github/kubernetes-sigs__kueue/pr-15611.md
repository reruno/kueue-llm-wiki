#### What this PR does / why we need it?

`pull-kueue-test-e2e-baseline-main-1-36` failed in `[BeforeSuite]` waiting 90s for the `monitoring/prometheus-prometheus` StatefulSet. In `install_prometheus_operator` (`hack/testing/e2e-common.sh`), the operator and config-reloader images are pre-pulled with retries and `kind load`-ed before `prometheus-setup.yaml` is applied, but the Prometheus server image itself is neither: `prometheus-setup.yaml` sets no `spec.image` or `spec.version`, so prometheus-operator falls back to its own compiled-in default tag, one named nowhere in the repo. The kind node had to pull that tag live from quay.io, and quay.io flaked.

This PR pins the server image the same way `agnhost` already is: `hack/testing/prometheus/Dockerfile` carries a `FROM` line with a digest, `PROMETHEUS_IMAGE` is exported from it in `e2e-common.sh`, and `install_prometheus_operator` now pre-pulls and `kind load`s it before writing it into a temp copy of `prometheus-setup.yaml` as both `spec.image` and `spec.version`, so the operator actually uses the pinned image instead of resolving its own default.

Fixes #15552

#### Useful notes for your reviewer

- Added `/hack/testing/prometheus` to `.github/dependabot.yml` so the pinned digest gets bumped like the other `hack/testing/*` Dockerfiles.
- Both `spec.image` and `spec.version` are set on the `Prometheus` object: the operator uses `version` to decide which Prometheus CLI flags it may pass, so it has to agree with the image, not just point at it.
- This PR was written in part with the assistance of generative AI.

  I looked into a few options for this.
  
  The manifests don't carry a version to infer from: prometheus-setup.yaml sets neither spec.version nor spec.image, so there's nothing there to derive the server image from.
  
  I also tried resolving it from PrometheusCompatibilityMatrix in the operator's source at the pinned PROMETHEUS_OPERATOR_VERSION. That works, but it adds a network call to GitHub on every e2e run, plus retries and parsing over raw source.
