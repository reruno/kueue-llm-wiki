## Description

#### What type of PR is this?

/kind feature

#### What this PR does / why we need it?

Adds `ACTIVE` and `REASON` columns to `kubectl get clusterqueue -o wide` and `kubectl get localqueue -o wide`, making queue readiness and the reason for inactivity visible without inspecting YAML or describing each queue.

Both columns read the existing `Active` condition and use priority 1, so default output remains unchanged. Updates the v1beta2 API markers, generated base and Helm CRDs, and the quick-start and MultiKueue setup examples.

Closes #15566
