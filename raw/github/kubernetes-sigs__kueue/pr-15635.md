#### What this PR does / why we need it?

Since this PR, WAS simulator ignores `.spce.schedulerName` in PodSpec since we use `default-scheduler` as scheduling profile: https://github.com/kubernetes-sigs/kueue/blob/36588ad7529913c2d2696771562a65bbc8e72c4a/pkg/cache/scheduler/was/scheduling_simulator.go#L96

Fixes https://github.com/kubernetes-sigs/kueue/issues/15630

#### Useful notes for your reviewer

If Pods specify the custom scheduler name, the simulation will fail w/ the following message:

```
unable to calculate domain capacities for PodSet main, error: failed to get framework: profile not found for scheduler name "secondary-scheduler"
```
