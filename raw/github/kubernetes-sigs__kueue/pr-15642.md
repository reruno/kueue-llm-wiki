#### What this PR does / why we need it?
Adds the shard-3 testgrid link to the README production-readiness test-coverage table, reflecting the new fourth integration test shard being introduced in a companion test-infra PR. The integration test suite (39 packages across 3 shards) was causing `pull-kueue-test-integration-shard-0-main` to consistently exceed the 14-minute CI build-time threshold (second_longest ~14:37). Splitting into 4 shards reduces each shard to ~10 packages and an expected
runtime of ~11 minutes.

Related: https://github.com/kubernetes-sigs/kueue/issues/15637

#### Useful notes for your reviewer
Companion test-infra PR required to add the actual shard-3 presubmit and periodic jobs and update INTEGRATION_TOTAL_SHARDS from 3 to 4 on existing shards.
AI assisted.
