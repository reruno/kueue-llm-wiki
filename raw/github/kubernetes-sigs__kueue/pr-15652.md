#### What this PR does / why we need it?

`TrainJob.Stop` always returned `true` and always issued the restore patch, so every reconcile while a TrainJob stayed evicted or unadmitted re-sent a no-op PATCH and made the job framework emit another `Stopped` event. This PR tracks whether the call actually suspended the TrainJob, and lets `RestorePodSetsInfo` report whether it changed anything — as the `GenericJob` interface documents — so `clientutil.Patch` skips the request once Kueue's runtime patch is already cleared. The missing-runtime-patch error moves to an explicit check in `Stop`, since a `false` return now means "nothing to restore" rather than "lookup failed".
