## Description

   This is a manual cherry-pick of #15628

   Adjustments for this branch, per @mimowo 's request on #15628: the gate is backported as Alpha, disabled by default (main has Beta, enabled by default), and the version row is re-versioned to 0.19 (a future-version row would be rejected as PreAlpha at the emulated version — same pattern as #14804/#14805). With the
 gate disabled, this branch keeps the pre-#15154 Workload re-creation behavior; enabling it restores the #15154 finalization. Verified locally: build, pkg/features + pod + jobframework unit tests, and the pod integration suite on the release-0.19 tree.

   /assign mimowo
   /area integrations
   /kind feature

```release-note
Pod: added Alpha feature gate FinalizeTerminatingPodGroups (disabled by default); when enabled, an all-terminating pod group with no remaining Workload is finalized instead of re-creating a Workload (the #15154 behavior, opt-in on this branch).
 ```
