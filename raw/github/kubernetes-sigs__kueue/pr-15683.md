#### What this PR does / why we need it?

Fixes #15681

`TestSetLeaderElectionConfig` was added in #15538 as a slice of structs with a
`name` field. On the cherry-pick #15680, tenzen-y asked for two follow-up
changes to it:

- [use `testCases := map[string]struct {`, because a slice creates a
  co-dependency between test cases, and use camelCase](https://github.com/kubernetes-sigs/kueue/pull/15680#discussion_r4031948361)
- [drop the now-redundant `name string` field](https://github.com/kubernetes-sigs/kueue/pull/15680#discussion_r4031948853)

He noted the fixes belonged in a follow-up rather than in the cherry-pick, so
this PR applies them on `main`.

The table is now a `map[string]struct{...}` keyed by the case description and
iterated with `for name, tc := range testCases`, matching the other map-based
table tests in this package (for example
`TestConfigureClusterProfileCacheWithClient`,
`TestConfigureClusterProfileCache` and `TestDefaultTransformStripsManagedFields`
in the same file, and the tables in `pkg/config/validation_test.go`).

#### Useful notes for your reviewer

This is a pure style change. Both cases keep exactly the same inputs and
expectations, and every assertion in the subtest body is untouched — the diff is
5 added / 8 deleted lines in one file.
