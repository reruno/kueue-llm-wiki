#### What this PR does / why we need it?

Consolidates the standalone `TestEnsureWorkloadSlicesEvictedOriginWithReservedReplacement`
test into the existing table-driven `TestEnsureWorkloadSlices` test in
`pkg/workloadslicing/workloadslicing_test.go`, as requested during review of #15667.

The standalone test covered two scenarios for an evicted workload slice ("origin") that
still holds quota reservation while a replacement slice is pending: (1) the replacement is
not yet admitted, so the origin is kept selected, and (2) the replacement is admitted, so
the origin is finished with a `WorkloadSliceReplaced` reason and the replacement is
selected. Both scenarios are now two entries
(`EvictedOriginWithReservedReplacement_ReplacementNotAdmitted` and
`EvictedOriginWithReservedReplacement_ReplacementAdmitted`) in the table, using the same
`want.workload` comparison and `SubResourceApply` interceptor assertion mechanisms already
used by neighboring entries in the table. The standalone test function was removed.

This is a test-only change; no production code was modified, and test coverage is
preserved (verified line-by-line against the deleted test's assertions).

#### Useful notes for your reviewer

- Verified the new table entries actually exercise the "evicted-with-reserved-quota"
  early-return loop in `EnsureWorkloadSlices` (`pkg/workloadslicing/workloadslicing.go`),
  not the more common `normalizeActiveSlices` path already covered by
  `TwoWorkloads_OldWithReservedQuota_NewWithReplacementAnnotationAndQuota` (whose origin is
  not evicted).
- Validation: `go build ./...` and `go test ./pkg/workloadslicing/...` pass (including all
  23 subtests of `TestEnsureWorkloadSlices`). `make ci-lint` reports 0 issues.
  `make verify` was run; the only failing step, `verify-skills-lint`, requires Docker to
  lint markdown skill files via a container image and Docker is not available in this
  environment — this step is unrelated to the Go test change in this PR. All other
  `make verify` checks (including `fmt-verify`) passed and produced no tree diffs.
