#### What this PR does / why we need it?
`frontend-configmap.yaml` has `namespace: system` required for Helm generation via `processing-plan.yaml`, but the overlay patch `frontend_configmap_patch.yaml` was missing the matching `namespace: system` field. Kustomize requires namespace to match when applying patches, so it could not find the target, causing `kustomize build config/kueueviz` to fail.

Add `namespace: system` to `frontend_configmap_patch.yaml` to match the resource.
