#### What this PR does / why we need it?

When validating an admitted `Workload`, an invalid `resourceUsage` value could produce an error message containing the memory address of the pod count pointer instead of the actual pod count.

This changes the validation message to use the dereferenced pod count. For example:

```text
is not a multiple of 3
```

The existing unit test is also updated to verify the expected error detail.

Fixes #15735

#### Useful notes for your reviewer

* The validation logic is unchanged; only the error detail was corrected.
* Added regression coverage to verify the pod count in the validation error.
* `go test ./pkg/webhooks` passes.
* `git diff --check` and formatting checks pass.

#### Release note

```release-note
Workloads: Fixed a bug that caused an incorrect pointer value in admission errors when resourceUsage was not divisible by the assigned pod count. Kueue now reports the actual pod count.
```
