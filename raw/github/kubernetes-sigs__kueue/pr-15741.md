#### What this PR does / why we need it?

Removes Gomega usage from `pkg/controller/tas/topology_ungater_test.go`, the only unit test under `pkg/` (outside `test/integration/` and `test/e2e/`) that imported it. The Gomega calls in `TestTopologyUngaterElasticSlice` are replaced with standard-library `testing.T` assertions and `wait.PollUntilContextTimeout` (for the one polling wait), matching the conventions already used by the rest of the file and package.

This is a follow-up to #15578 as requested in #15705.
