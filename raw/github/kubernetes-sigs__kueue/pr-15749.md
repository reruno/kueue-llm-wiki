#### What this PR does / why we need it?

Decomposes `TestTopologyUngaterElasticSlice` into `TestTopologyUngater_ElasticJobs_Reconciler` and `TestPodHandler_ElasticJobs_{Create,Update,Delete,Generic}`. The reconciler test no longer calls the Pod handler, and the handler tests use `MockTypedRateLimitingInterface` instead of polling a real workqueue. The `makeSlice` helper is replaced with the wrapper and `Clone()` pattern.

Fixes #15746
