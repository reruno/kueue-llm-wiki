## Description

This is a manual cherry-pick of #15652 and #15750.

Both PRs go in together: #15750 fixes `TestStop`, which #15652 adds, so it does not apply on its own.

#15652 needed a conflict resolution: on `main`, `RestorePodSetsInfo` takes a `ctx` argument, while release-0.18 still has the old signature. This cherry-pick keeps `RestorePodSetsInfo(_ []podset.PodSetInfo)` and carries over only the behavior change — `stoppedNow` tracking, the explicit `getKueueRuntimePatch` nil check in `Stop`, and the no-op return once the replicated jobs are already cleared.

/assign tenzen-y

```release-note
TrainJob: Fixed a bug where an evicted or unadmitted TrainJob emitted a `Stopped` event and sent a redundant PATCH request on every reconcile.
```
