#### What this PR does / why we need it?

Adds a reusable `kep-review` agent skill and registers it in the skills index.

The initial review guideline keeps KEPs independent of out-of-tree Job APIs. A
KEP may start with support for one Job integration, but its title, problem
statement, semantics, and API design should describe a general Kueue capability
rather than that integration's specification.

Related: https://github.com/kubernetes-sigs/kueue/pull/13494#discussion_r4019097617
