#### What this PR does / why we need it?

`RuntimePatchWrapper` embeds `kftrainerapi.RuntimePatch`, so the promoted `DeepCopy()` returns `*kftrainerapi.RuntimePatch` and cannot be chained with the wrapper's `Obj()`. This PR adds a `Clone()` method that deep-copies the wrapped patch and returns `*RuntimePatchWrapper`, switches `TestStop` to `Clone().Obj()`, and drops the per-case copy comment as requested in the review of #15750.

Fixes #15752
