## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Concurrent Admission labels every Workload in an enabled ClusterQueue as a parent, and a Workload a user creates directly — a prebuilt one, say — is named freely: only DNS subdomain validation applies, so the name need not contain a `-`. Deriving the variant prefix sliced at the last `-` regardless, so a parent named `wl` panicked with `slice bounds out of range [:-1]`.

controller-runtime recovers the panic, so nothing crashes. The reconcile retries forever and the Workload never gets its variants.

- `getWorkloadBaseName` returns the whole name when there is no `-` to strip
- a `TestReconcile` case covers a parent Workload named without one

#### Useful notes for your reviewer

Names Kueue generates always end in `-<hash>`, so only parents that users name themselves change behaviour.

```release-note
ConcurrentAdmission: Fixed a panic that left a parent Workload without variants when its name contained no "-".
```
