## Description

#### What type of PR is this?
/kind cleanup
/area release

#### What this PR does / why we need it?
Use GitHub Actions self-repository references for same-repository actions in the release and artifact workflows.

The `$/...` syntax resolves each action from the repository and workflow revision that triggered the run. This prevents a workflow from loading newer action code from a checked-out `main` workspace during execution.

The existing checkouts are preserved because the composite actions still read repository files. References under `.automation/` are also preserved because they intentionally load actions from a separate checkout of `main`.

#### Which issue(s) this PR fixes:
Fixes #15771

#### Useful notes for your reviewer
The change is limited to action reference syntax in four workflow files.

AI assistance was used to inspect the issue, review the workflow changes, and prepare this PR. The final diff was manually reviewed.
