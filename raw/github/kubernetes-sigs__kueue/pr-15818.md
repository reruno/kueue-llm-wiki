#### What this PR does / why we need it?

Cherry-pick of #15686 to `release-0.18`.

Consolidates the standalone `TestEnsureWorkloadSlicesEvictedOriginWithReservedReplacement` test into the existing table-driven `TestEnsureWorkloadSlices` test in `pkg/workloadslicing/workloadslicing_test.go`, as requested during review of #15667.

The only deviation from the original commit is using the `SubResourcePatch` interceptor and the branch's existing `assertStatusConditionPatch` helper instead of `SubResourceApply`/`assertStatusConditionApply`, since `release-0.18` predates the `Status().Apply()` SSA migration on `main` and still uses `Status().Patch()`.
