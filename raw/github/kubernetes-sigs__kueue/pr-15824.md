#### What this PR does / why we need it?

Renames `TestBuildPodRequirementsMergesTolerations` to a generic table-driven `TestBuildPodRequirements` and extends it beyond tolerations to the rest of `buildPodRequirements`: the nodeSelector (including the non-node leaf case), required and preferred node affinity with the `TASRespectNodeAffinityPreferred` gate, the three error paths, and the Pod template. It also checks that the PodSet passed in is left unmodified.

Fixes #15777
