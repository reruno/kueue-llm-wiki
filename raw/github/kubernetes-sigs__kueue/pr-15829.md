<!--

The scheduler's `Admitted` event currently hardcodes `0s` for the wait time since quota reservation. This is misleading when a workload spends time waiting after reservation.

This change calculates the elapsed time from the `QuotaReserved` condition's `LastTransitionTime` and reports the actual duration in the event message.

#### Useful notes for your reviewer

- Added regression coverage for zero, non-zero, and missing reservation conditions.
- Preserved the existing admission-check metric behavior.
- AI assistance was used during implementation and review.
