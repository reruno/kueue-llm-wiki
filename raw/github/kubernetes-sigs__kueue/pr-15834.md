#### What this PR does / why we need it?

Adds an end-to-end test for two consecutive worker-side RayCluster autoscaling requests. The test starts with zero workers, admits a scale-up to one worker, and then admits a second scale-up to two workers. It verifies that each resize creates and admits the expected replacement WorkloadSlice before the next resize proceeds.

This reuses the dedicated MultiKueue Ray autoscaling suite and CI jobs added for https://github.com/kubernetes-sigs/kueue/pull/15725.

Related: https://github.com/kubernetes-sigs/kueue/pull/13435
