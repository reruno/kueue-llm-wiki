## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it:

Removes the stale `spec.suspend = false` side effect from the RayJob test wrapper’s `EnableInTreeAutoscaling` helper. RayJob is now the top-level Kueue-managed object for autoscaling, so suspension should remain under the normal admission flow instead of being changed by an autoscaling configuration helper.
