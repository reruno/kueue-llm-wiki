#### What this PR does / why we need it?

StatefulSet controller has a `TopologyAwareScheduling` code path that builds a Workload topology request from its Pod template

```
// pkg/controller/jobs/statefulset/statefulset_reconciler.go:395-416

if features.Enabled(features.TopologyAwareScheduling) {
    topologyRequest, err := jobframework.NewPodSetTopologyRequest(
        sts.Spec.Template.ObjectMeta.DeepCopy(),
    ).PodIndexLabel(new(appsv1.PodIndexLabel)).Build()
    // ...
    podSet.TopologyRequest = topologyRequest
}
```

but its validating admission webhook did not validate those template annotations
