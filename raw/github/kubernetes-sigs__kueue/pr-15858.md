#### What this PR does / why we need it?
Kueue has two official install paths, and both contain their own manager configuration:

- kustomize: `config/components/manager/controller_manager_config.yaml`
- Helm: `managerConfig.controllerManagerConfigYaml` in `charts/kueue/values.yaml`

The kustomize configuration includes `Cohort.kueue.x-k8s.io: 1` under `controller.groupKindConcurrency`, but the Helm configuration is missing it.

https://github.com/kubernetes-sigs/kueue/blob/15e6285b4004a202dee79c9837b4c1e29a27be14/config/components/manager/controller_manager_config.yaml#L13-L21

This PR adds the missing entry so both install paths stay consistent.
