#### What this PR does / why we need it?
Documents the validity constraints for shared PodSet groups used by topology spreading in `site/content/en/docs/concepts/topology_aware_scheduling.md`.

Specifically, states that `ValidatePodSetGroupingTopology` requires exactly two PodSets in a shared group and requires at least one PodSet with `Count == 1`.

Fixes #15790
