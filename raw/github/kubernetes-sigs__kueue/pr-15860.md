#### What this PR does / why we need it?
`ParseSpreadingAnnotation` applies the default `Required` enforcement mode when `enforcementMode` is omitted, but `NewSpreadingSpec` was returning rules with an empty enforcement mode. This could cause callers (such as `HasRequiredSpreadingLevels` or placement checks) to skip checks that apply to `Required` rules when using specs constructed via `NewSpreadingSpec`.

This PR:
1. Applies `defaultEnforcementMode` (`Required`) to rules with an empty `EnforcementMode` in `NewSpreadingSpec`.
2. Uses `slices.Clone` to avoid in-place mutation of the passed slice.
3. Extends `TestNewSpreadingSpec` to assert that omitted enforcement mode defaults to `Required` and that an explicit `Preferred` mode is preserved.

Fixes #15788
