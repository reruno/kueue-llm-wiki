#### What this PR does / why we need it?
`SpreadingRule.ExceedsShare` previously called `Quantity.ScaledValue(resource.Milli)`. Because `ScaledValue` computes `ceil(q / 10^scale)`, it rounded the configured maximum share upward. For example, a configured `maxShareAllowingPlacement: "0.4501"` scaled to `451m`, which permitted a 45.1% occupancy (`count: 451, total: 1000`) although it exceeded the 45.01% limit.

This PR:
1. Updates `SpreadingRule.ExceedsShare` to evaluate `count > maxShare * total` using exact `inf.Dec` arithmetic, preventing upward rounding while preserving support for sub-milli precision shares.
2. Removes the unused `shareScale` and `shareScaleFactor` constants.
3. Adds regression tests in `TestExceedsShare` covering sub-milli precision shares.

Fixes #15789
