#### What this PR does / why we need it?

Simplifies `pkg/scheduler/flavorassigner/podset_reducer.go`:

- Removes the `R` type parameter from `PodSetReducer` — it had only one caller shape, so `fits()` now returns `(any, bool)`.
- Removes the `refine` function field and calls `giveBack` directly, since it was the only strategy ever assigned to it.
- Moves `mustGrow` into `giveBack`, which now reports whether the final counts grew above the admitted baseline, instead of `Reduce` checking that separately after the fact.

No behavior change: the elastic multi-PodSet scale-up added in #15776 is preserved and covered by the existing reducer tests.

Fixes #15817
