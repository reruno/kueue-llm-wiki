#### What this PR does / why we need it?

`periodic-kueue-test-e2e-k8s-release-0-18-was` has failed on every run since 2026-09-18 with `Found no test suites`. #15810 pointed `run-test-e2e-k8s-main-was` at `singlecluster/wasapi`, but that suite does not exist on `release-0.18`.

This restores what the lane ran before: the `singlecluster/baseline` and `singlecluster/extended` suites with WAS enabled. `e2e-test.sh` takes a single target folder, and `singlecluster/` now also holds `tasapi`, which needs `kind-cluster-tas.yaml`, so the script runs once per suite.

Related: #15843
