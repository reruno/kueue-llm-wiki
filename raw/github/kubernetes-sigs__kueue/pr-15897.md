#### Useful notes for your reviewer

I'm currently testing if we can speed up our e2e tests by more frequent sync of the kubelet state. It seems like we some times have this steps taking >60s which might be a reason for some tests to take long.

The default is 1m which is pretty long: `--sync-frequency duration     Default: 1m0s` from https://kubernetes.io/docs/reference/command-line-tools-reference/kubelet/

I think 1m might be good for large prod clusters, but for CI tests probably 5s is better.
