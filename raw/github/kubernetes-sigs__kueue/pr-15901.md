<h2>3.14.0 / 2026-08-17</h2>
<ul>
<li>[CHANGE] API: Deprecate the <code>stats</code> query parameter of <code>/api/v1/query</code> and <code>/api/v1/query_range</code> for values other than <code>true</code> and <code>all</code>. Other values still enable basic statistics but now return a deprecation warning; they will be rejected in the next major release. <a href="https://redirect.github.com/prometheus/prometheus/issues/19124">#19124</a></li>
<li>[CHANGE] API: <code>/api/v1/status/config</code> now correctly shows <code>separator: &quot;&quot;</code> and <code>replacement: &quot;&quot;</code> in relabel configs when explicitly set to empty, instead of omitting them. <a href="https://redirect.github.com/prometheus/prometheus/issues/18653">#18653</a></li>
<li>[CHANGE] Discovery/Hetzner: Drop the <code>__meta_hetzner_datacenter</code> label for <code>hcloud</code> targets, following its removal from the Hetzner Cloud API. <a href="https://redirect.github.com/prometheus/prometheus/issues/19269">#19269</a></li>
<li>[CHANGE] PromQL: Enable duration expressions by default. The <code>promql-duration-expr</code> feature flag is now a no-op. <a href="https://redirect.github.com/prometheus/prometheus/issues/19033">#19033</a></li>
<li>[CHANGE] PromQL: Promote <code>first_over_time</code> to stable. It no longer requires the <code>promql-experimental-functions</code> feature flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/19093">#19093</a></li>
<li>[FEATURE] Discovery: Add Oracle Cloud Infrastructure compute service discovery (<code>oci_sd_configs</code>). <a href="https://redirect.github.com/prometheus/prometheus/issues/18919">#18919</a></li>
<li>[FEATURE] PromQL: Add experimental <code>start_timestamp(instant-vector)</code> function returning the start timestamp of each sample in the given vector. Requires the <code>use-start-timestamps</code> feature flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/19089">#19089</a></li>
<li>[FEATURE] PromQL: Allow <code>rate()</code> and <code>increase()</code> to use start timestamps as an alternative for rate extrapolation. Hidden behind the <code>use-start-timestamps</code> feature flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/18619">#18619</a></li>
<li>[FEATURE] TSDB: Add experimental support for encoding start timestamps in histograms and float histograms. Hidden behind the <code>histograms-st-encoding</code> feature flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/18609">#18609</a></li>
<li>[ENHANCEMENT] OTLP: Emit a warning when OTLP attribute names collide into the same Prometheus label after sanitization (e.g. <code>k8s.pod.name</code> and <code>k8s_pod_name</code> both become <code>k8s_pod_name</code>), and expose the <code>prometheus_api_otlp_translation_warnings_total</code> counter labelled by <code>category</code> to track such warnings. <a href="https://redirect.github.com/prometheus/prometheus/issues/18957">#18957</a></li>
<li>[ENHANCEMENT] Promtool: Add <code>--remote-write.path</code> flag to <code>push metrics</code> for backends that use a non-default remote-write endpoint. <a href="https://redirect.github.com/prometheus/prometheus/issues/19086">#19086</a></li>
<li>[ENHANCEMENT] Remote write: Forward histogram start timestamps in the remote write V2 protocol. <a href="https://redirect.github.com/prometheus/prometheus/issues/18903">#18903</a></li>
<li>[ENHANCEMENT] TSDB: Add <code>prometheus_tsdb_head_native_histogram_series</code> and <code>prometheus_tsdb_head_native_histogram_buckets</code> gauges tracking the number of native histogram series and buckets in the head. <a href="https://redirect.github.com/prometheus/prometheus/issues/19170">#19170</a></li>
<li>[ENHANCEMENT] UI: Add syntax highlighting, autocompletion, and linting for PromQL duration expressions (<code>step()</code>, <code>range()</code>, <code>min_of()</code>, <code>max_of()</code>) in range selectors and subqueries. <a href="https://redirect.github.com/prometheus/prometheus/issues/18625">#18625</a></li>
<li>[ENHANCEMENT] UI: Add copy button next to rule names on the Rules and Alerts pages. <a href="https://redirect.github.com/prometheus/prometheus/issues/18706">#18706</a></li>
<li>[ENHANCEMENT] UI: Improve rule group title contrast on the Rules page. <a href="https://redirect.github.com/prometheus/prometheus/issues/19181">#19181</a></li>
<li>[PERF] Speed up regex label matchers matching a set of literal values (e.g. <code>{job=~&quot;foo|bar|baz&quot;}</code>). <a href="https://redirect.github.com/prometheus/prometheus/issues/18833">#18833</a></li>
<li>[PERF] Remote read: Improve remote read throughput by removing unnecessary per-write flushing. <a href="https://redirect.github.com/prometheus/prometheus/issues/18470">#18470</a></li>

<li>[BUGFIX] TSDB: Fix <code>prometheus_tsdb_head_stale_series</code> over-counting and early eviction of series that change between float, integer histogram, and float histogram sample types. <a href="https://redirect.github.com/prometheus/prometheus/issues/19183">#19183</a></li>
