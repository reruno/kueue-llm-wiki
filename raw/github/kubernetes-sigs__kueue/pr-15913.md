#### What this PR does / why we need it?
This PR introduces the `PreemptionConfig` `v1alpha1` cluster-scoped API definition as approved in [KEP-13396: Configurable Preemptions](https://github.com/kubernetes-sigs/kueue/pull/14554).
Key changes:
- Introduces `PreemptionConfig` and `PreemptionConfigList` in `apis/kueue/v1alpha1/preemptionconfig_types.go` with full OpenAPI validation markers and doc comments.
- Defines the `PreemptionConfigNameAnnotation` (`kueue.x-k8s.io/preemption-config-name`) used on `ClusterQueue` in Alpha.
- Registers `PreemptionConfig` in the `v1alpha1` scheme (`apis/kueue/v1alpha1/groupversion_info.go`).
- Adds the CRD base under `config/components/crd/alpha/bases/` and includes it in `config/components/crd/alpha/kustomization.yaml`.
- Emits the Helm CRD template in `charts/kueue/templates/crd/` guarded by `.Values.enableAlphaAPIs`.
- Generates runtime deepcopy methods and `client-go` packages (typed clientset, informers, listers, and applyconfigurations).
Part of: #13396
KEP: https://github.com/kubernetes-sigs/kueue/pull/14554
