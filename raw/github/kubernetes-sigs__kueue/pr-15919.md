#### What this PR does / why we need it?

`PROMETHEUS_OPERATOR_VERSION ?= v0.89.0` in `hack/make/test.mk` was a hardcoded default with no Dependabot coverage, unlike the Prometheus server image pinned in `hack/testing/prometheus/Dockerfile` since #15611.

Add `hack/testing/prometheus-operator/Dockerfile` as a Dependabot-managed digest pin, and derive `PROMETHEUS_OPERATOR_VERSION` from it in `hack/make/test.mk`, the same way `RAY_VERSION` and `SKILLSAW_VERSION` are already derived from their own pinned Dockerfiles. Group both Dockerfiles under one Dependabot update in `.github/dependabot.yml`, so the two versions bump in sync instead of one lagging behind the other, mirroring the existing `vite-stack` grouping in the same file's `npm` section.

#### Useful notes for your reviewer

- `PROMETHEUS_OPERATOR_VERSION` also gates whether the Prometheus operator gets installed at all: only `run-test-e2e-baseline-%`, `run-test-e2e-certmanager-%`, and `run-test-e2e-k8s-main-was` set it, every other e2e suite leaves it unset to skip the install. This change only affects how the default is computed, not how it's passed through, so that gating is unaffected; verified with `make -n` against all three targets plus one that doesn't set it.
