#### What this PR does / why we need it?
Adds the missing T4 integration test from the hierarchical Cohort testing plan (#13237).

The test creates a mutual Cohort parent cycle and verifies that:

- the affected ClusterQueue becomes inactive with reason `CohortCycleDetected`
- workloads are not admitted while the cycle exists
- the scheduler and controller continue running without panic or hang
- removing the cycle restores the ClusterQueue to `Ready`
- previously pending and newly submitted workloads are admitted after recovery

This test was deferred until the upstream cycle-handling fix was available (#13774                                                                                    ).
