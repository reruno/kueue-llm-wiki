#### What this PR does / why we need it?

Manual cherry-pick of #15872 to `release-0.18`.

The automated cherry-pick conflicted in `test/e2e/multikueue/extended/e2e_test.go` because the release branch already contains the LeaderWorkerSet test split. The manual resolution preserves that release-branch change and moves the three KubeRay specs that exist on `release-0.18` to `kuberay_test.go`. It does not introduce the elastic RayCluster spec that is absent from this release branch.

This PR was prepared with assistance from OpenAI Codex.

Related: #15872

#### Useful notes for your reviewer

Validated with:

```
go test ./test/e2e/multikueue/extended -run '^$'
go test -v ./test/e2e/multikueue/extended -run TestAPIs -args -ginkgo.dry-run -ginkgo.label-filter=feature:kuberay -ginkgo.v
```

The dry run registers the three KubeRay specs present on `release-0.18`.
