## Description

This PR patches the cluster queue validation webhook to raise the limit on number of resource flavors allowed to be defined on the cluster queue when concurrent admission is enabled from 16 to 32.

Also leaving a cautionary note in the concurrent admission documentation regarding the performance characteristics of the current implementation, especially when the number of cluster queues is very large.

This is based on the discussion in https://github.com/kubernetes-sigs/kueue/issues/15500.
