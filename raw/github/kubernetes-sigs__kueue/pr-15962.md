#### What this PR does / why we need it?

When a `MultiKueueCluster` configuration update leaves the connection healthy, its `Active` condition remains `True`. 
However, the controller previously treated the condition as up to date because it ignored `ObservedGeneration`, leaving it stale.  
The controller must refresh `ObservedGeneration` to the latest generation to confirm that the updated spec has been evaluated successfully.
