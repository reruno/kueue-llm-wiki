## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it:

`kueuectl version` always looked up the `kueue-controller-manager` Deployment in the hardcoded `kueue-system` namespace, so `-n` / `--namespace` had no effect for custom installs.

When `--namespace` is explicitly set, the command now looks up the controller manager in that namespace. When it is unset, it keeps the default of `kueue-system`.

#### Which issue(s) this PR fixes:

Fixes #15958
