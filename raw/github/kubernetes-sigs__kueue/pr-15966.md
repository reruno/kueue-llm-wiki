#### What this PR does / why we need it?

Switch `utiltesting.NewLogger` from `testr` to `ktesting`.

#15895 is another case of a goroutine logging through a test logger after the owning test has finished. #14908/#14913 avoided the earlier case by discarding the logger at one call site, but the racing reflectors here use the scheduling-cycle logger instead.

`ktesting` handles this at the shared test logger: it finalizes the logger for each test, stops writing to its `testing.T` after the test finishes, and routes later logs to the global logger instead of dropping them.
