#### What this PR does / why we need it?

Wait for the per-snapshot WAS informer factory to stop before `Snapshot` returns.

Cancelling the build context requests shutdown, but does not wait for the informer goroutines to exit. A snapshot currently leaves those goroutines running briefly after it returns. This adds` Shutdown()` after cancellation to join them.
