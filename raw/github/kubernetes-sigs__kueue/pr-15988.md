## Description

Cherry pick of #14154 on release-0.18.

#14154: Take back only what the extended-resource charge replaces

For details on the cherry pick process, see the [cherry pick requests](https://git.k8s.io/community/contributors/devel/sig-release/cherry-picks.md) page.

Applied from the pre-#15284 form of the change, since this branch keeps the older `ResolveExtendedResourceQuota` and `totalRequestsFromPodSets` signatures and has neither the PodSet nor the DeviceClass test wrappers. Two test lines follow the branch: the pending reason is `Pending`, because `UnadmittedWorkloadsObservability` is off here, and the two gate lines in the unified-quota block's `BeforeAll` are dropped, because the upstream gate helper this branch calls directly attributes a `BeforeAll` setter to the first spec and its cleanup to the last, so a block with two specs trips its parallel-setting check. On this branch `util/resource` is imported as `resource`, and the concept page keeps its gate-off sentence with the mapping sentence added to the gate-on paragraph.
