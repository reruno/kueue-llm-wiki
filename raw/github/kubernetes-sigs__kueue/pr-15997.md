## Description

#### What type of PR is this?

/kind cleanup
/area integrations

#### What this PR does / why we need it?

`ApplyDefaultWorkloadPriorityClass` reads the default WorkloadPriorityClass before reading the Namespace. The error case from #15851 therefore fails on the first lookup, so the Namespace error path that actually denies admission was never exercised.

This PR uses a separate sentinel for each lookup, allowing a test case to control which read fails.

With the Namespace error swallowed, only the new test case fails; the existing cases continue to pass.
