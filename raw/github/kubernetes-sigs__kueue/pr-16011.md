#### What this PR does / why we need it?

`TestPodsReady` built its pods and pod groups through local closures, and the serving variant set the annotation by writing to the map directly. This replaces them with base `PodWrapper`s cloned per case, uses `PodGroupServingAnnotation()` for the serving group, and assembles the group `Pod` in the run loop so each case only lists its pods. No behavior change.

Fixes #15883
