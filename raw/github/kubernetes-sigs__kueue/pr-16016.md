#### What this PR does / why we need it?

Webhook tests built the `managedJobsNamespaceSelector` fixture inline, repeating the same `LabelSelector` literal and its conversion to a `labels.Selector` across `base_webhook_test.go`, `defaults_test.go` and `pod_webhook_test.go`. This adds `MakeManagedJobsNamespaceSelector()` next to `CustomLabelWrapper`, with `ExcludeNamespaces(...)`, `Obj()` and `Selector()`, and uses it in those tests. No behavior change.

Fixes #15911
