#### What this PR does / why we need it?

Changes `buildPodRequirements` in `pkg/cache/scheduler/tas_flavor_snapshot.go` to return an `error` instead of a string reason. Call sites use `err.Error()` only where a string reason is required. `TestBuildPodRequirements` now matches errors with `errors.Is` instead of matching error-message prefixes.

Error matching is more reliable than message matching.
