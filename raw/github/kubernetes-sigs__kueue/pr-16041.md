#### What this PR does / why we need it?

The administrator configured the following:

```
apiVersion: config.kueue.x-k8s.io/v1beta2
kind: Configuration
resources:
  excludeResourcePrefixes:
    - acme.io/
  transformations:
    - input: acme.io/vgpu-count
      strategy: Replace
      multiplyBy: acme.io/cores-per-vgpu
      outputs:
        quota.acme.io/total-vgpu-cores: "1"
```

The `excludeResourcePrefixes` value `acme.io/`  matches the prefix of `input: acme.io/vgpu-count`.

The old logic first excludes this `acme.io/` input resource, so it can no longer use that resource to generate `quota.acme.io/total-vgpu-cores` quota usage.

As a result, Workloads requesting the excluded transformation input can be admitted without accounting for  `quota.acme.io/total-vgpu-cores` .  The recorded quota.acme.io/total-vgpu-cores usage is 0, allowing tenants to bypass that ClusterQueue quota.
