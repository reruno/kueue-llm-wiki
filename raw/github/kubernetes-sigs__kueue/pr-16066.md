## Description

Cherry pick of #16055 on release-0.18. Replaces the automated #16063, which did not compile on this branch.

Manual adjustment: `RestorePodSetsInfo` has no `ctx` parameter on release-0.18, so the `V(2)` log line when skipping the submitter restore is dropped; the function returns `changed` directly, like the other integrations on this branch.

#### What type of PR is this?
/kind bug

```release-note
RayJob: Fixed a bug where a RayJob using the default submitter Job (`submissionMode: K8sJobMode` without `submitterPodTemplate`) and a head Pod template with no containers caused the Kueue webhook and reconciler to panic. Kueue now returns an error instead.
```
