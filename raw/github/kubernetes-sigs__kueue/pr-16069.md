#### What this PR does / why we need it?

Renames the shared `raycluster.ValidateCreate` helper to `ValidateRayClusterSpec` and updates its callers and unit test. The new name describes the helper's actual scope and avoids confusion with the validating webhook `ValidateCreate` methods.

This is intentionally independent from #16067 and contains no validation behavior change.
