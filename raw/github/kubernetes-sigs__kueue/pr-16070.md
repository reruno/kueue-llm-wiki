## Description

Cherry-pick of https://github.com/kubernetes-sigs/kueue/pull/13015 onto release-0.19.

On this branch the feature gate `EnforceProvisioningPodTemplateContents` is Alpha and disabled by default (version 0.19). Replace-path unit and integration tests enable it explicitly. Baseline e2e config enables it so the in-cluster replace scenario can run.

```release-note
ProvisioningRequest: Fixed a bug where a pre-existing `PodTemplate` at the deterministic name could be adopted verbatim, letting a user who can write `PodTemplate` objects decouple the capacity requested from Cluster Autoscaler from the quota-checked Workload PodSets. Kueue now replaces divergent specs with Kueue-derived contents. Gated by `EnforceProvisioningPodTemplateContents` (Alpha, disabled by default).
```
