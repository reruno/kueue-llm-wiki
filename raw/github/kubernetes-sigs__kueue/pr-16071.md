## Description

#### What type of PR is this?

/kind cleanup
/area integrations

#### What this PR does / why we need it?

Makes the RayCluster validating webhook use the existing shared `raycluster.ValidateCreate` helper that is already used for the embedded `RayClusterSpec` in RayJob and RayService.

This removes duplicate validation for autoscaling, the maximum PodSet count, and the reserved head group name. RayCluster-specific elastic-job validation remains in the RayCluster webhook as an additive check.

The helper is not renamed in this PR.

#### Useful notes for your reviewer

Shared RayClusterSpec errors are returned before the webhook runs validation paths that consume the spec. The RayCluster webhook's actionable autoscaling error message is moved into the shared helper, so RayCluster, RayJob, and RayService all explain which feature gate and annotation enable the supported configuration.

AI usage disclosure: This change was developed with assistance from OpenAI Codex. The author reviewed the implementation and test results.

Tested with:

    go test ./pkg/controller/jobs/raycluster ./pkg/controller/jobs/rayjob ./pkg/controller/jobs/rayservice -count=1
