#### What this PR does / why we need it?

Replaces the local `makeWl` helper in `TestUpdateSettlesAfsEntryPenalty` with a `baseWl` wrapper and derives each fixture with `Clone()`, as suggested in https://github.com/kubernetes-sigs/kueue/pull/15000#discussion_r4078143364.
Test-only change; the fixtures and test cases are unchanged.

Fixes Part of #16030

#### Useful notes for your reviewer

- `baseWl` is kept as a `*WorkloadWrapper` (no `.Obj()`), since `Clone()` is defined on the wrapper, not on `*kueue.Workload`.
- `makeAdmission` is kept so each fixture still gets its own `*Admission`.
- `TestUpdateSettlesAfsEntryPenaltyPerReservation` and `TestUpdateDropsUnsettleableAfsEntryPenalty` in the same file use the same `makeWl` pattern. I left them out to keep this PR scoped to the review comment, but I'm happy to include them if preferred.
