#### What this PR does / why we need it?

Cherry-picks #16071 and #16067 to `release-0.18`.

The prerequisite cleanup makes the RayCluster webhook use the shared RayClusterSpec validator. The bug fix then rejects Kueue-managed RayCluster, RayJob, and RayService resources whose head Pod template has no containers before later validation consumes the invalid spec.
