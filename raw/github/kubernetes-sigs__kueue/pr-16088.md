#### What this PR does / why we need it?

Adds KEP-10270: a built-in DQO CapacityProvider (`kueue.x-k8s.io/local-capacity`) that derives capacity per ResourceFlavor from the allocatable resources of healthy Nodes. It reuses the existing CapacityProvider and DynamicQuotaOrchestrator APIs and introduces no new API types. It replaces the closed proposal in #10745.

Part of #10270

#### Useful notes 

- Depends on the DQO fix in #16168 (unreported resources of orchestrated flavors are distributed as zero).
- Proof of concept: #16080.
- Headroom relies only on DQO's `effectiveCapacityMultiplier`; a `LocalCapacity` parameters API (per-node reserve, required resources) is listed under Alternatives for Beta.
- AI disclosure: drafted with the help of an AI coding assistant and reviewed by me.
