#### What this PR does / why we need it?

Reverts the controller-side changes from #16055.

#16067 now validates the embedded `RayClusterSpec` in the RayJob webhook and rejects Kueue-managed RayJobs whose head Pod template has no containers. With that admission validation in place, `getSubmitterTemplate` no longer needs to perform spec validation or propagate an error through the RayJob controller paths.

#### Useful notes for your reviewer

This is a direct revert of #16055. It intentionally does not retain a controller-side fallback for malformed RayJobs that already existed before the webhook validation was installed; newly created or updated Kueue-managed RayJobs are covered by #16067.
