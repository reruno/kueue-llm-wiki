#### What this PR does / why we need it?
AppWrapper is the only CRD integration without editor and viewer ClusterRoles. This PR adds `appwrapper_editor_role.yaml` and `appwrapper_viewer_role.yaml`, modeled on the SparkApplication roles,

 Also updates `rbac.md` so it lists what the batch-admin and batch-user roles actually cover.
