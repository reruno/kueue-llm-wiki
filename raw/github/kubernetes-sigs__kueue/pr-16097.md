#### What this PR does / why we need it?
Currently, we get an error when running the `/publish-release` ChatOps command:

```text
/home/runner/work/_temp/9a9990e1-1d1c-4ed3-a775-c05c867ab49c.sh: line 23: --limit: command not found
Error: Process completed with exit code 127.
```

This happens because there is an extra line break before `--limit 10`, causing GitHub Actions to interpret it as a separate command.
