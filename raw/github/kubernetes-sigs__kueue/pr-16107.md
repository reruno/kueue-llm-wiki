#### What this PR does / why we need it?

Cherry-picks #16089 to `release-0.18`.

This reverts the controller-side changes backported in #16066. #16085 now validates the embedded `RayClusterSpec` in the RayJob webhook and rejects Kueue-managed RayJobs whose head Pod template has no containers. With that admission validation in place, `getSubmitterTemplate` no longer needs to perform spec validation or propagate an error through the RayJob controller paths.

#### Useful notes for your reviewer

The only cherry-pick conflict was in `RestorePodSetsInfo`, whose release-0.18 version does not take a context or log the skipped restore. The conflict was resolved by restoring the pre-#16066 implementation while preserving the release-0.18 function shape.

This intentionally does not retain a controller-side fallback for malformed RayJobs that already existed before the webhook validation was installed; newly created or updated Kueue-managed RayJobs are covered by #16085.
