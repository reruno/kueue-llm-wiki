#### What this PR does / why we need it?

`make verify` fails intermittently in `verify-artifacts` with `no resource matches strategic merge patch "Ingress.v1.networking.k8s.io/kueueviz-ingress.system"`. `prepare-manifests` is a prerequisite of `verify-artifacts`, and Make builds sibling prerequisites in parallel, so it can run at the same time as `prepare-release-branch`, which `verify-tree-prereqs` pulls in. Both run `kustomize edit set image` in `config/components/kueueviz`. kustomize rewrites `kustomization.yaml` with `os.WriteFile`, truncating before writing, and `kustomize edit` accepts a truncated read without complaint, so the losing process writes the file back without its `resources` list and the later `kustomize build config/kueueviz` has no Ingress to patch.

Run `helm-chart-package` and `prepare-manifests` from the recipe bodies of `artifacts` and `verify-artifacts` instead of listing them as prerequisites, so they run in order after the prerequisites finish. `clean-artifacts` stays a prerequisite so that it keeps running early: in Prow `$(ARTIFACTS)` is the uploaded artifacts directory, and a later wipe would delete the skillsaw summary that `verify-skills-lint` writes near the start of the run. The standalone targets are untouched.

#### Useful notes for your reviewer

- Validated with a shim around `kustomize` that records the interval of every `kustomize edit`. `make -j8 verify-artifacts` had one pair overlapping on `config/components/kueueviz` before the change and none after, with the same 15 edits either way. A green `make verify` proves nothing here, the bad interleaving measured locally at 4 in 4337 attempts.
- `helm-chart-package` rewrites `charts/kueue/values.yaml` and reverts it, now alongside `verify-helm-verify` and `verify-helm-unit-test`, which read that file. No test in `charts/kueue/tests` asserts on the image repository or tag, and `yq` swaps the file in with a rename, falling back to a truncating copy only across filesystems (`pkg/yqlib/file_utils.go:9-50`).
- Out of scope, pre-existing and unchanged: `clean-artifacts` wipes `$(ARTIFACTS)` while `verify-skills-lint` and `verify-test-performance-multikueue-runner` write reports into it, and `generate-helm-docs` and `prepare-release-branch` both write `charts/kueue/README.md` inside `verify-helm-prereqs`. I will file both separately.
