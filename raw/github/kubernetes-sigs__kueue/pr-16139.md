## Description

#### What type of PR is this?

#### What this PR does / why we need it?
Implements candidate selector filters for `PreemptionConfig` (`apis/kueue/v1alpha1`) to support declarative preemption candidate selection as defined in [KEP-13396](https://github.com/kubernetes-sigs/kueue/tree/main/keps/13396-configurable-preemptions):
1. **Candidate Selector Filters** (`pkg/scheduler/preemption/config/filters`):
   - **Scope Constraints**: Filters candidates based on queue and cohort boundaries (`WithinLocalQueue`, `WithinClusterQueue`, `WithinParentCohort`, `WithinCohortTree`, `AnyClusterQueue`).
   - **Workload Label Selector**: Filters candidate workloads based on `metav1.LabelSelector`.
   - **ClusterQueue Label Selector**: Prunes candidate ClusterQueues based on `metav1.LabelSelector`.
   - **Priority Constraints**: Filters candidate workloads using raw (`Base`) or effective (`Boosted`) priority against preemptor priority with numeric comparisons (`LessThan`, `LessThanOrEqual`, `GreaterThan`, `GreaterThanOrEqual`).
   - **Numeric Label Constraints**: Filters workloads based on custom integer labels with absolute bounds (`minValue`, `maxValue`), relational comparisons against preemptor, and fallback values.
   - **Candidate Filter Factory**: Compiles candidate selector specifications into two-tier filters (Level 1: ClusterQueue pruning, Level 2: Workload candidate matching) with fail-fast rejection on compilation errors.
2. **Scheduler Cache Snapshot Labels** (`pkg/cache/scheduler`):
   - Propagates ClusterQueue labels into `ClusterQueueSnapshot` guarded by the `ConfigurablePreemptions` feature gate to avoid memory/cloning overhead when the feature is disabled.
3. **Testing**:
   - Comprehensive unit test suites for all filter implementations in `pkg/scheduler/preemption/config/filters/`.
   - Integration tests in `pkg/scheduler/preemption/config/evaluator_test.go` verifying end-to-end evaluation for all selector types, including standalone ClusterQueue behavior without false positives.
   - Cache snapshot tests verifying label propagation with the feature gate enabled and disabled.
Part of: #13396
#### Useful notes for your reviewer
- Candidate filtering operates at two levels: ClusterQueue level to prune entire queues without iterating over workloads, and Workload level to evaluate individual candidate workloads.
- Storing and copying ClusterQueue labels into snapshots in `pkg/cache/scheduler/` is guarded by `features.Enabled(features.ConfigurablePreemptions)`.

+func NewNumericLabelFilter(log logr.Logger, constraint kueuealpha.PreemptionConfigNumericLabelConstraint, preemptor *workload.Info) WorkloadFilter {
+	filterLog := log.WithValues("filter", "NumericLabels", "key", constraint.Key)
+	if constraint.FallbackValue != nil {
+		filterLog = filterLog.WithValues("fallback", *constraint.FallbackValue)
+	}

+		log:        filterLog,
+		constraint: constraint,
+	}

+	if constraint.Comparison != nil {
+		preemptorLog := filterLog.WithValues("preemptor", klog.KObj(preemptor.Obj))
+		if val, ok := tryGetLabelValue(preemptorLog, preemptor, constraint.Key, constraint.FallbackValue); ok {
+			f.preemptorVal = new(val)
+		} else {
+			preemptorLog.V(2).Info("Preemptor missing required numeric label without fallbackValue; the comparison will not match any candidates")
+		}
+	}

+	return f

+// NewNumericLabelFilter creates a WorkloadFilter to evaluate candidate workloads
+// based on customized integer labels and numeric comparisons against the preemptor workload.
+func NewNumericLabelFilter(log logr.Logger, constraint kueuealpha.PreemptionConfigNumericLabelConstraint, preemptor *workload.Info) WorkloadFilter {
+	filterLog := log.WithValues("filter", "NumericLabels", "key", constraint.Key)
+	if constraint.FallbackValue != nil {
+		filterLog = filterLog.WithValues("fallback", *constraint.FallbackValue)
+	}
+
+	f := &numericLabelFilter{
+		log:        filterLog,
+		constraint: constraint,
+	}
+
+	if constraint.Comparison != nil {
+		preemptorLog := filterLog.WithValues("preemptor", klog.KObj(preemptor.Obj))
+		if val, ok := tryGetLabelValue(preemptorLog, preemptor, constraint.Key, constraint.FallbackValue); ok {
+			f.preemptorVal = new(val)
+		} else {
+			preemptorLog.V(2).Info("Preemptor missing required numeric label without fallbackValue; the comparison will not match any candidates")
+		}
+	}
+
+	return f
+}
