#### What this PR does / why we need it?

When a `MultiKueue` manager `ClusterQueue` configuration update leaves its quota automation condition unchanged, the controller previously treated the condition as up to date because it ignored  `ObservedGeneration` . 

As a result,  `ObservedGeneration`  remained stale even though the updated spec had been evaluated. 

The controller must refresh  `ObservedGeneration`  to the latest generation after successful evaluation.
