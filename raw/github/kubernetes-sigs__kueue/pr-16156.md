#### What this PR does / why we need it?

A Pod group finishes when a Pod has `kueue.x-k8s.io/retriable-in-group: "false"` and no Pods are still running. In that case `Pod.Finished()` returned `success=true` even if Pods failed, because the group path never overrode the default value. The Workload was marked `Finished` with reason `Succeeded` and a message like `Pods succeeded: 0/2.`. With this PR, the group is reported as successful only when all of its Pods succeeded, which matches the documented definition of a successful Pod group.

None

#### Useful notes for your reviewer


#### Release note

```release-note
Pod Integration: Fixed a bug where a Pod group that finished because of the `kueue.x-k8s.io/retriable-in-group: "false"` annotation was marked `Finished` with reason `Succeeded` even when some of its Pods failed. Such Workloads now finish with reason `Failed` unless all Pods succeeded.
```
