## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`podset.FromAssignment` builds a PodSet's node selector from the assigned flavors. When two assigned flavors set the same node-label key to different values, the result depended on Go map iteration order, so the selector that reached the Job's Pods was not reproducible across reconciles.

This makes the merge deterministic: flavors are processed in sorted resource-name order, the first value wins, and a later conflicting value is logged at `V(2)` together with the flavor that supplied the kept value. A new `utilmaps.MergeKeepExisting` helper implements the keep-existing merge and reports conflicts to the caller.

Scope is limited to the deterministic merge. The assignment-time rejection (`FailAdmissionOnConflictingFlavorLabels`) and the admission check `podSetUpdates` handling are split into follow-up PRs, as agreed in #16170. There are no API, CRD, or feature-gate changes here.

Fixes #14409

#### Tests

- `pkg/util/maps`: unit tests for `MergeKeepExisting` (existing values win, equal values do not report a conflict, conflicts are reported, and a nil destination map is allocated).
- `pkg/podset`: `TestFromAssignment` covers a conflicting key whose winner follows sorted resource-name order, including an assignment whose flavor names sort opposite to the resource names; two flavors that agree on the value; and stable toleration order. The toleration comparison no longer needs `cmpopts.SortSlices`.
- `go test ./pkg/podset/ ./pkg/util/maps/ ./pkg/controller/jobframework/... ./pkg/controller/tas/... ./pkg/controller/admissionchecks/provisioning/... ./pkg/scheduler/...`, `go vet`, `gofmt`, and `./bin/golangci-lint run ./pkg/podset/... ./pkg/util/maps/...` pass locally.

#### Release note

```release-note
Scheduling: Fixed a bug where Kueue could set Pod node selectors nondeterministically when assigned ResourceFlavors specified conflicting values for the same node label. Kueue now keeps the value from the first flavor in sorted resource-name order.
```

  // MergeKeepExisting copies src into *dst, keeping existing values on conflict.
  // onConflict (optional) is invoked for every key whose values differ.
  func MergeKeepExisting[K comparable, V comparable, S ~map[K]V](dst *S, src S, onConflict func(k K, kept, ignored V)) {
  	if *dst == nil && src != nil {
  		*dst = make(S, len(src))
  	}
  	for k, v := range src {
  		if old, ok := (*dst)[k]; ok {
  			if old != v && onConflict != nil {
  				onConflict(k, old, v)
  			}
  			continue
  		}
  		(*dst)[k] = v
  	}
  }
