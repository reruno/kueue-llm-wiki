#### What this PR does / why we need it?
The community "Join Us" page (`site/content/en/community/_index.md`) described the WG Batch community sync as "bi-weekly" in two places, but the meeting is held **weekly** (Thursdays, 14:00 UTC, per the recurring event on the WG Batch calendar). This corrects both mentions to "weekly".

#### Useful notes for your reviewer
Docs-only change touching two strings in one file.

The cadence can be verified from the WG Batch public calendar, where the open-ended recurring event has `RRULE:FREQ=WEEKLY;BYDAY=TH`:
https://calendar.google.com/calendar/ical/8ulop9k0jfpuo0t7kp8d9ubtj4%40group.calendar.google.com/public/basic.ics
