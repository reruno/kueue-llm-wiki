## Description

#### What type of PR is this?

/kind cleanup

/area tas

#### What this PR does / why we need it?

Declares the expected node affinity of each `TestBuildPodRequirements` case as a plain `corev1.NodeAffinity` and compiles it into `wantPodRequirements` inside `t.Run`, so a constructor error fails only its own subtest. This removes the `mustNewNodeSelector` and `mustNewPreferredSchedulingTerms` helpers, which compiled the expectations with the parent test's `t` while building the table.

Fixes #15934

**Explanation**

The change removes the helper functions and moves constructor calls into each subtest, but it adds a separate `wantNodeAffinity *corev1.NodeAffinity` table field. Issue [`#15934`] requires removing the separate `wantNodeAffinity` expectation and consolidating the node-affinity data into `wantPodRequirements`. The implementation therefore does not meet the central cleanup requirement.

**Resolution**

Remove the separate `wantNodeAffinity` field. Store the expected node-affinity data within each case's `wantPodRequirements`, and build the required selector and preferred scheduling terms with `nodeaffinity.NewNodeSelector` and `nodeaffinity.NewPreferredSchedulingTerms` before comparing the complete expectation.
