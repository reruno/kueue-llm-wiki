## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`kueuectl delete workload --all` listed Workloads once. When the API server returned a continue token, later pages were left in place and the command still exited successfully.

Fixes #16185

#### Useful notes for your reviewer

`getAllWorkloads` now follows `list.Continue` the same way `kueuectl list` does. The new test returns two pages and checks that both Workloads are deleted.
