<blockquote>
<h2>v30.1.1</h2>
<ul>
<li>Fixed spurious window <code>blur</code> and <code>focusout</code> events and incorrect <code>event.relatedTarget</code> values when focusing an element after removing the previously focused element, which regressed in v30.1.0. (<a href="https://github.com/asamuzaK"><code>@​asamuzaK</code></a>)</li>
<li>Fixed focus and blur behavior across frames, and focusing the document's viewport through <code>document.documentElement.focus()</code>. (<a href="https://github.com/asamuzaK"><code>@​asamuzaK</code></a>)</li>
<li>Fixed focus targets removed or disabled by <code>blur</code> listeners becoming active, and text selections made by focus and blur listeners being overwritten. (<a href="https://github.com/asamuzaK"><code>@​asamuzaK</code></a>)</li>
<li>Fixed <code>element.focus()</code> incorrectly focusing disabled form controls and <code>&lt;input type=&quot;hidden&quot;&gt;</code> elements with <code>tabindex=&quot;&quot;</code>. (<a href="https://github.com/scttcper"><code>@​scttcper</code></a>)</li>
<li>Fixed invalid <code>style.setProperty()</code> calls changing existing <code>!important</code> priorities, serialized styles, or mutation records. (<a href="https://github.com/FedgeNo"><code>@​FedgeNo</code></a>)</li>
<li>Fixed <code>!important</code> handling when updating CSS longhands after shorthands, using variables or CSS-wide keywords, and assigning style properties directly. (<a href="https://github.com/FedgeNo"><code>@​FedgeNo</code></a>)</li>
<li>Fixed <code>&lt;noscript&gt;</code> parsing with <code>includeNodeLocations: true</code> or inside frames to honor the <code>runScripts</code> option.</li>
<li>Fixed the <code>storageQuota</code> option being ignored by frames.</li>
<li>Fixed encoding detection of HTML and XML byte input to honor XML encoding declarations and detect UTF-16 without a byte order mark.</li>
<li>Fixed exceptions caused by truncated <code>charset</code> parameters in <code>&lt;meta&gt;</code> elements, and encoding detection incorrectly using incomplete <code>&lt;meta&gt;</code> tags. (<a href="https://github.com/FedgeNo"><code>@​FedgeNo</code></a>)</li>
<li>Fixed XML serialization errors for namespaces named <code>constructor</code>, <code>toString</code>, <code>__proto__</code>, or <code>&quot;null&quot;</code>, and incorrect reuse of namespace prefixes declared on sibling elements.</li>
<li>Fixed <code>element.innerHTML</code> and <code>element.outerHTML</code> in XML documents to reject invalid characters in attribute values and avoid stack overflows on large strings.</li>
<li>Fixed selector matching for <code>:lang()</code>, <code>:nth-child(... of ...)</code> after mutations, and <code>:has()</code> with duplicate IDs or nested logical pseudo-classes. (<a href="https://github.com/asamuzaK"><code>@​asamuzaK</code></a>)</li>
</ul>
