<h2>3.15.0 / 2026-09-24</h2>
<ul>
<li>[CHANGE] PromQL: A range query whose <code>end</code> was not aligned to <code>step</code> caused subqueries inside it to evaluate past the parent's last actual step, inflating <code>peakSamples</code> in the query stats and against the <code>query.max-samples</code> limit, and wasting storage I/O reading samples that were never used in the result. Add tests to prevent regression of the fix made in <a href="https://redirect.github.com/prometheus/prometheus/issues/18081">#18081</a>. <a href="https://redirect.github.com/prometheus/prometheus/issues/18598">#18598</a></li>
<li>[CHANGE] PromQL: Do not register a start timestamp reset if the start timestamp hasn't changed between subsequent samples. <a href="https://redirect.github.com/prometheus/prometheus/issues/19454">#19454</a></li>
<li>[CHANGE] Logging: Deprecate <code>--log.level</code>; use <code>runtime.log_level</code> configuration to supply the default level. <a href="https://redirect.github.com/prometheus/prometheus/issues/19511">#19511</a></li>
<li>[FEATURE] Configuration: Allow changing the process log level through <code>runtime.log_level</code> on configuration reload. <a href="https://redirect.github.com/prometheus/prometheus/issues/19511">#19511</a></li>
<li>[FEATURE] Prometheus: Add <code>--auto-gomemlimit.refresh-interval</code> flag to periodically re-detect the container or system memory limit and update <code>GOMEMLIMIT</code> at runtime. <a href="https://redirect.github.com/prometheus/prometheus/issues/18843">#18843</a></li>
<li>[FEATURE] Scraping: Add support for scraping targets via Unix Domain Sockets. <a href="https://redirect.github.com/prometheus/prometheus/issues/12024">#12024</a>. <a href="https://redirect.github.com/prometheus/prometheus/issues/18091">#18091</a></li>
<li>[FEATURE] scrape: Implement OM2.0 scrape format. <a href="https://redirect.github.com/prometheus/prometheus/issues/18606">#18606</a></li>
<li>[ENHANCEMENT] Reduce TSDB head CPU utilization when initializing. <a href="https://redirect.github.com/prometheus/prometheus/issues/18001">#18001</a></li>
<li>[ENHANCEMENT] Docker SD: Add labels <code>__meta_docker_container_image</code> and <code>__meta_docker_container_image_id</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/19386">#19386</a></li>

<li>[ENHANCEMENT] Mixin: Support native histograms in the remote-write send-batch latency panel. <a href="https://redirect.github.com/prometheus/prometheus/issues/19522">#19522</a></li>
<li>[ENHANCEMENT] PromQL/TSDB: The <code>--enable-feature=st-storage</code> flag now automatically enables XOR2 float chunk encoding and ST-capable histogram chunk encoding, so you no longer need to pass <code>xor2-encoding</code> and <code>histograms-st-encoding</code> alongside it. <a href="https://redirect.github.com/prometheus/prometheus/issues/19518">#19518</a></li>
<li>[ENHANCEMENT] Remote write / Alertmanager: upgrade sigv4 to v0.5.0, adding <code>session_name</code> and <code>tags</code> fields for STS AssumeRole sessions. The previously undocumented <code>service_name</code> field is now also documented. <a href="https://redirect.github.com/prometheus/prometheus/issues/19569">#19569</a></li>
<li>[ENHANCEMENT] Scraping: Support zstd-compressed scrape responses, enabled via feature flag <code>zstd-scrape</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/19502">#19502</a></li>
<li>[ENHANCEMENT] TSDB: Stabilize the XOR2 float chunk encoding. <code>--enable-feature=xor2-encoding</code> is deprecated; use <code>storage.tsdb.chunk_encoding.floats: xor2</code> instead. Check that other software reading the TSDB directly (e.g. Thanos sidecar) supports XOR2 before enabling. <a href="https://redirect.github.com/prometheus/prometheus/issues/19461">#19461</a></li>
<li>[ENHANCEMENT] TSDB: add <code>prometheus_tsdb_head_appenders_created_total</code> metric. <a href="https://redirect.github.com/prometheus/prometheus/issues/19411">#19411</a></li>

<li>[ENHANCEMENT] UI: Show the effective configuration for each scrape pool on the Targets and Service Discovery pages. <a href="https://redirect.github.com/prometheus/prometheus/issues/19384">#19384</a></li>
<li>[ENHANCEMENT] scrape: Enable start time synthesis for summary <code>_count</code> and <code>_sum</code> series in scrape appender v2. <a href="https://redirect.github.com/prometheus/prometheus/issues/19323">#19323</a></li>
