#### What this PR does / why we need it?
This PR cleans up, aligns, and extends unit and integration tests for the `ConfigurablePreemptions` feature, addressing feedback across previous review threads:
1. **Test Wrapper Alignment & Consistency**:
   - Extended `pkg/util/testing/v1alpha1/wrappers.go` with `MakeCandidateSelector` (fluent builder for scopes, priority, label selectors, and numeric labels) and `RuleWithPreemptorSelector`.
   - Replaced verbose raw `kueuealpha` struct literals across `evaluator_test.go` and `preemption_configurable_test.go` with wrappers, addressing review feedback in https://github.com/kubernetes-sigs/kueue/pull/16130#discussion_r4092434466.
   - Renamed leftover test rule name `same-cluster-queue-rule` to `within-cluster-queue-rule` in `preemption_configurable_test.go`.
2. **Preemption Pipeline Integration Testing**:
   - Ported end-to-end integration tests into `preemption_configurable_test.go` verifying that `CandidateFilters` (`Priority` in Base and Boosted modes, and candidate `LabelSelector`) correctly filter candidates in the preemption pipeline now that filter compilation is merged on `main`, addressing https://github.com/kubernetes-sigs/kueue/pull/16130#discussion_r4092626958.
3. **Scope & Edge Case Test Improvements**:
   - Added explicit test verifying that `PreemptorSelector: nil` matches all preemptors, addressing https://github.com/dkaluza/kueue/pull/35#discussion_r4073331940.
   - Added scope tests with counter-example workloads across `WithinClusterQueue`, `WithinLocalQueue`, and `WithinParentCohort` in `evaluator_test.go` to prevent false positives, addressing https://github.com/kubernetes-sigs/kueue/pull/16062#discussion_r4083166139 and https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4095056272.
   - Removed a duplicate `WithinCohortTree` test across disjoint trees in `scope_filters_test.go`, addressing https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4094939692.
4. **Filter Unit Test Cleanups**:
   - In `label_filters_test.go`: invoked `buildWorkloadLabelFilter` directly instead of maintaining a local `parseSelector` helper, aligning with `cluster_queue_label_filters_test.go` and addressing https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4094202263.
   - In `numeric_label_filters_test.go`: changed candidate label from `"3.14"` to `"9.14"` in the float fallback test so float parsing would fail against preemptor `8`, proving the integer fallback value is used, addressing https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4094413434.
   - In `priority_filters_test.go`: added a `wantMatch: false` test case for negative priorities (`candidate -150` vs `preemptor -100` with `GreaterThan`) and introduced a dedicated `wantBuildErr` field to avoid conflating build errors with match outcomes, addressing https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4094559698 and https://github.com/kubernetes-sigs/kueue/pull/16139#discussion_r4094602255.
