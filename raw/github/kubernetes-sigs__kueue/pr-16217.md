#### What this PR does / why we need it?
This PR updates the KEP to detail the annotation behavior on
the Deployment integration, which causes a rollout on update.
Also, it adds two extra tests, one integration test that verifies
the annotation update on the LWS  and one unit test for
annotation propagation on the Deployment.
Lastly, it avoids propagating the Deployment annotation when it's not a Kueue managed deployment.
