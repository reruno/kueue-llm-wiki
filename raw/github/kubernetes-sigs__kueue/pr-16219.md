## Description

#### What type of PR is this?
/kind kep

#### What this PR does / why we need it?
Observability description in Configurable Preemptions bases on wrong assumptions that SchedulingStats.Eviction UnderlyingCause is not used for determining which eviction count should be updated. (It assumed that just Reason was used for finding an entry)

This is not the case [sources](https://github.com/kubernetes-sigs/kueue/blob/f6a4b52ea88a1108ad0e0e379509ec684208b435/pkg/workload/evict/evict.go#L324) - it was an error probably caused by imperfect function name.

Following the current KEP description of observability would lead to easy exhaustion of the limits in the evictions stats array.

#### Useful notes for your reviewer
As KEP was missing explicit description how conditions will be set, also adding those.
