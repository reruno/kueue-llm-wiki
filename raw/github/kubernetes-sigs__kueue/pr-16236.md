#### What this PR does / why we need it?
##### **[WHY]**
The Helm chart and the kustomize manifests are built from the same files under `config/components/`, but they pick files differently:
- Helm (`hack/processing-plan.yaml`) globs whole directories, minus `excludes`.
- kustomize only includes what `kustomization.yaml` lists under `resources:`.

So a manifest added to a directory but not to `resources:` ships with Helm installs and is silently missing from manifest installs. This has happened before:  #9911, #2995

##### **[What]**
Adds `hack/testing/kustomization/verify.sh`, which reads `hack/processing-plan.yaml` and fails when a file Helm would ship is not listed in the nearest `kustomization.yaml` `resources:`.
