#### What this PR does / why we need it?

Manual cherry-pick of #16129 to release-0.18.

The automated cherry-pick failed to compile because on release-0.18 `queues.AddOrUpdateWorkload` does not take `ctx` and does not automatically normalize resources from the client. Adapted `TestLimitRangeUpdateRetriesWorkloadPoppedWithStaleDefaults` in `pkg/controller/core/workload_controller_limitrange_test.go` to invoke `workload.AdjustResources(ctx, cl, wl)` before `queues.AddOrUpdateWorkload(log, wl)`.

Related: #16129

AI usage disclosure: Codex was used to assist in adapting the unit test signature and running local verification.
