#### What type of PR is this?

#### What this PR does / why we need it:
Adds a native regression check in `test/util` and wires `verify-rbac` into `make verify-checks` to validate RBAC manifests under `config/components/rbac/`:
1. Verifies the controller ServiceAccount (`system/controller-manager`) exists.
2. Confirms all 5 RoleBindings and ClusterRoleBindings target the controller ServiceAccount in `system`.
3. Verifies each `roleRef` resolves to an existing Role or ClusterRole with proper scope and `rbac.authorization.k8s.io` apiGroup.
4. Includes unit tests covering failure cases (missing Role/SA, scope mismatch, incorrect subject).

Runs natively via `go test` with zero external dependencies or PyPI tools.
