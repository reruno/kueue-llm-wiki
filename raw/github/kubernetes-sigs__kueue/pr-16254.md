#### What this PR does / why we need it?

Adds a shared test helper that returns sorted Pod names without a specified scheduling gate.

Updates Job integration tests to use the shared helper instead of a package-local implementation.

This cleanup is split out of kubernetes-sigs/kueue#11264, where the helper is used to verify the Pods ungated during a RayService zero-downtime upgrade.
