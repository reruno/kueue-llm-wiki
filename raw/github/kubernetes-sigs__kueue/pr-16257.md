#### What this PR does / why we need it:

Adds a `test-kueueviz-backend` Make target that runs the KueueViz backend Go tests with the race detector, and makes it a prerequisite of the existing `test-e2e-kueueviz` target.

The backend is a nested Go module, so the repository root unit-test command does not discover its tests. The existing KueueViz presubmit invokes `test-e2e-kueueviz`, but previously only built the backend before running the end-to-end checks. This change makes the existing presubmit run the backend test suite without requiring a test-infra change or an additional Prow job.

AI assistance was used to audit the current CI coverage, prepare the Make target, and validate the backend test suite. The resulting diff and validation were reviewed by the contributor.
