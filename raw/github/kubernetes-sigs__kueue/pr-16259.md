#### What this PR does / why we need it?

Extends MultiKueue worker-side Ray autoscaling support to RayService when workload slicing and `MultiKueueRayInTreeAutoscaling` are enabled.

The manager now reflects effective worker replicas from the worker RayService's active child RayCluster, creates or updates the corresponding workload slice, and repoints the worker RayService after the replacement slice is admitted.

The runtime lookup validates that the active RayCluster is controlled by the RayService and only contains worker groups declared by the service.

An extended MultiKueue RayService scale-up/scale-down E2E scenario is included.
