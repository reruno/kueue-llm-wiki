#### What this PR does / why we need it?

The StatefulSet reconciler copies the StatefulSet's `kueue.x-k8s.io/queue-name` label onto its Pods, but the Pod webhook rejects queue-name changes on ungated Pods. The StatefulSet webhook allows changing the queue-name while `ReadyReplicas == 0`, so changing it after the Pods were ungated but before any was Ready made every reconcile of that StatefulSet fail. During a rolling update the rejected label change also shared a patch with ungating a current-revision Pod, so that Pod stayed gated. This PR syncs the label only onto Pods that are still gated after ungating, as the LeaderWorkerSet reconciler already does.

None

#### Release note

```release-note
StatefulSet: Fixed a bug where changing the `kueue.x-k8s.io/queue-name` label after the Pods were ungated but before any was Ready made the StatefulSet reconciler fail on every retry, and could keep a Pod scheduling-gated during a rolling update. Kueue now only updates the queue name on Pods that are still gated.
```
