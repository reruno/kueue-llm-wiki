#### What this PR does / why we need it?

Adds unit tests for the KueueViz backend cluster queue and cohort handlers: `fetchClusterQueues`, `fetchClusterQueueDetails`, `fetchCohorts` and `fetchCohortDetails`.

The tests cover the returned fields, the per-namespace authorization filter and its cache, the `omittedPanels` reporting, and error paths. They use the controller-runtime fake client, wrapped in a small shared helper (`fake_client_test.go`) that the follow-up PRs reuse.

`handlers` coverage goes from 34.9% to 49.5%.
