#### What this PR does / why we need it?

Adds unit tests for the KueueViz backend local queue, namespace and resource flavor handlers: `fetchLocalQueues`, `fetchLocalQueueDetails`, `fetchNamespaces`, `fetchResourceFlavors`, `fetchResourceFlavorDetails` and `hasMatchingLabels`.

The tests cover namespace filtering, per-namespace authorization and the `hasClusterAccess` flag, flavor quota and node label matching, the `omittedPanels` reporting, and error paths.

With #16277, `handlers` coverage goes to 65.8%.
