#### What this PR does / why we need it?

`TotalRequestsFor` and the replaced-slice flavor check skip a PodSet that has no counterpart in the assignment or in the replaced slice. On the normal paths these lookups are expected to find one, so log the misses at V(1) instead of skipping them silently.

Follow-up to #16273, as suggested in https://github.com/kubernetes-sigs/kueue/pull/16273#discussion_r4122157406.
