## Description

Manual cherry-pick of #16241 (along with prerequisite #13570) onto `release-0.18`.

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

Backports #13570 (`f3f682d2b`) and #16241 (`187f7513f`) to `release-0.18` so that both the active heap comparator and `ClusterQueue.Snapshot()` read LocalQueue fair-sharing weights from the cached `lqWeights` map instead of making fallible `client.Get` calls via `ResolveLQWeight`.

(`/cherrypick release-0.18` on #16241 conflicted because #13570, which introduced `ClusterQueue.lqWeights` and `ComputeLocalQueueFSUsage`, had not yet been backported to `release-0.18`.)

cc @apullo777

