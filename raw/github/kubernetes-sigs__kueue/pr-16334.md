#### What this PR does / why we need it?

Cherry pick of #16270 on release-0.18. The automated cherry-pick failed to apply.

Manual adjustments: on this branch `syncQueueLabel` patches the Pods in its own pass before `finalizePods`, so the fix is a gate check in that loop instead of moving the sync after ungating. The new integration test is dropped because the shared ungate/label patch it covers only exists on main; the new unit test expects a current-revision Pod to get the label before it is ungated.

#### Useful notes for your reviewer


#### Release note

```release-note
StatefulSet: Fixed a bug where changing the `kueue.x-k8s.io/queue-name` label after the Pods were ungated but before any was Ready made the StatefulSet reconciler fail on every retry, and could keep a Pod scheduling-gated during a rolling update. Kueue now only updates the queue name on Pods that are still gated.
```
