#### What this PR does / why we need it?

Updates KEP-12100 (Partial Replica ScaleUp for ElasticJob) to match the implementation that landed after the last KEP update:

- **Baseline semantics:** `minCount` is copied forward from the replaced Workload, matched by PodSet name and capped at the new count. The scheduler uses the replaced Workload's granted count as the baseline only while that Workload is admitted (#16209, #16242, #16289, #15855). The worked example, probe lifecycle and reducer sections are updated to match.
- **Eviction:** a pending probe now survives eviction of its predecessor and can be readmitted at `minCount` (#15417). Previously the KEP said the probe was finished together with the predecessor.
- **Ray controller:** every worker group gets `minCount = count` in the initial Workload, and `minReplicas` is no longer consulted (#16209).
- **Reducer:** the giveback phase runs only when at least two PodSets ended below their target.
- **Non-goals and test plan:** the first non-goal is reworded, and the test plan lists the integration tests that now exist.

Relates to #12100
