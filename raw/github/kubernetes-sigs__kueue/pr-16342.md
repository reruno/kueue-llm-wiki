## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

The cert-manager visibility e2e test deleted the first Job's Workload by hand, because Workloads of Jobs deleted with the orphan propagation policy used to keep holding quota. #11596 fixed that, so deleting the Job is now enough to release the quota. This PR removes the workaround and its TODO.

Related: #1789
