#### What this PR does / why we need it?

The MultiKueue external-framework adapter integration test was switched from RayJob to RayCluster to work around the global RayJob reconciler state, and its "finishing the worker job" steps were commented out because `RayCluster.Finished()` always returns false. Now that the global state is gone (#11355), this PR switches the test back to RayJob and enables those steps, so job completion through the external-framework adapter is covered again.

Related: #9022
