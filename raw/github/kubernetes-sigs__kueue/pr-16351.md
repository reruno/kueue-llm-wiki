#### What this PR does / why we need it?

The WAS Job e2e test read upstream `scheduling.k8s.io/v1beta1` PodGroups as unstructured data because Kueue's `k8s.io/api` did not ship those types. Now that Kueue depends on `k8s.io/api` v0.37, this switches the helper to the typed `PodGroupList` and removes the TODO. It also updates two stale notes in the was-cluster skill: why the JobSet suite was removed, and that a 1.37 Job needs `spec.scheduling.schedulingPolicy.gang` to be gang-scheduled.
