## Description

Manual cherry-pick of #15955 onto release-0.19. The bot could not apply it.

It failed because it replays the four PR commits in order, and commit 3 added a `lendable` field to `cohort.go` that commit 4 removed again. The net diff does not touch `cohort.go` at all, so cherry-picking the squashed merge commit `992a68d1c` applies without that conflict.

One adaptation from main: `workload.Usage.Quota` is `resources.FlavorResourceQuantities` on this branch rather than the `ResourceUsage` struct main uses, so the usage literal in `TestSnapshotCarriesLendable` drops the `Assigned` wrapper. Production code is unchanged from main.

Verified on this branch: `go build ./...` clean, and `./pkg/cache/...` plus `./pkg/scheduler/...` pass. Removing the `updateCohortLendable` call fails `TestDominantResourceShare`, `TestCohortLendable`, `TestSnapshotCarriesLendable` and `TestDeleteCohortUpdatesAncestorSubtreeQuota` here, so the backported tests are doing their job on this branch and not just on main.
