#### What this PR does / why we need it?

Kueue treated `SUBMISSION_FAILED` as finished, so it marked the Workload Finished and released its quota. The Spark operator does not treat this state as terminal: with `restartPolicy` `OnFailure` or `Always` it resubmits the application, which then runs outside quota and preemption. This PR stops treating `SUBMISSION_FAILED` as finished; the operator moves the application to `FAILED` once it stops retrying.

Fixes #16363

#### Useful notes for your reviewer


#### Release note

```release-note
SparkApplication: Fixed a bug where a SparkApplication with `restartPolicy` `OnFailure` or `Always` could run outside ClusterQueue quota after the Spark operator retried a failed submission. Kueue now keeps the Workload admitted while the application is in `SUBMISSION_FAILED`.
```
