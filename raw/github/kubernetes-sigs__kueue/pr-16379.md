#### What this PR does / why we need it?

For example

```
apiVersion: config.kueue.x-k8s.io/v1beta2
kind: Configuration
integrations:
  frameworks:
    - batch/job
metrics:
  localQueueMetrics:
    enable: true
    localQueueSelector:
      matchExpressions:
        - key: team
          operator: InvalidOp     # Invalid; use In to select team=ml
          values:
            - ml
```

The invalid operator causes `localQueueSelector` parsing to fail. 

Previously, `NewLocalQueueMetricsConfig` function discarded that error and returned `nil`. Downstream code interpreted `nil` as the default configuration, no LocalQueue filtering, rather than an invalid rule.

With the `LocalQueueMetrics` feature gate enabled, metrics could therefore be emitted for all LocalQueues instead of only those labeled `team=ml`. The configuration error went unreported, potentially expanding monitoring scope and increasing metric cardinality. 

The fix propagates the parsing error to the callers, so the controller reports the invalid configuration and fails startup instead of silently collecting metrics for every LocalQueue.
