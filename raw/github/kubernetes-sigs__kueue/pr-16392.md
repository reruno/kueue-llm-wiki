#### What this PR does / why we need it?

Fixes two bugs on the KueueViz LocalQueue detail page:

1. **Missing Status cell** — The "Admitted Workloads" table header defines `Name` and `Status` columns, but each row only renders the `Name` cell. This leaves the Status column empty and the table misaligned. This adds the missing `<TableCell>` that displays the first condition type, matching the pattern used on the main Workloads page.

2. **Nil-slice JSON response** — `fetchLocalQueueWorkloads` uses `var workloads []any`, which stays nil when no workloads match the queue. Go serializes nil slices to JSON `null`. On the frontend, `if (workloadsData)` treats `null` as falsy and skips `setWorkloads(...)`, so stale workloads are never cleared from the view after removal. Changing to `make([]any, 0)` ensures the response is always `[]`.

Fixes #16391

#### Release note

```release-note
KueueViz: Fix the LocalQueue detail page missing the Status cell in the workloads table and returning null instead of an empty array for queues with no workloads.
```
