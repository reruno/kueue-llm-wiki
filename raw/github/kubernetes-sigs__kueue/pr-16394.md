## Description

/kind bug

#### What this PR does / why we need it?

`Workloads.jsx` uses `<Alert severity="info">` for the empty-state message when no workloads exist, but `Alert` is not in the MUI import. This causes a runtime crash instead of showing the friendly "No workloads found" message.

The sibling `LocalQueues.jsx` page uses the same pattern and correctly imports `Alert`. This one-liner brings `Workloads.jsx` in line.

Fixes #16393

#### Release note

```release-note
KueueViz: Fix Workloads page crash when no workloads exist by adding the missing Alert import.
```
