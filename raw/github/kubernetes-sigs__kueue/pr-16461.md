#### What this PR does / why we need it?

Cherry-pick https://github.com/kubernetes-sigs/kueue/pull/16370 and https://github.com/kubernetes-sigs/kueue/pull/16436 onto release-0.18.

Add the Alpha, disabled-by-default SkipChildJobSuspension feature gate. When enabled, Kueue leaves managed child-job suspension to the ancestor controller. This avoids suspending a running child during MultiKueue workload-slice replacement when an owner-reference lookup temporarily finds no unfinished ancestor Workload. With the gate disabled, the existing suspension behavior is preserved.

#### Useful notes for your reviewer
