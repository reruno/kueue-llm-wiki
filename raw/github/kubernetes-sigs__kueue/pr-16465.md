#### What this PR does / why we need it?

`LocalQueueMetrics` enables `LocalQueue` metrics, while `UnadmittedWorkloadsObservability` enables observability for Workloads that have not been admitted.

Using the following configuration as an illustration:

```
apiVersion: config.kueue.x-k8s.io/v1beta2
kind: Configuration
featureGates:
  LocalQueueMetrics: true
  UnadmittedWorkloadsObservability: true
metrics:
  localQueueMetrics:
    enable: true
    localQueueSelector:
      matchLabels:
        team: ml
```

A `LocalQueue` that does not match `team: ml` should not expose its LocalQueue-level count of unadmitted Workloads, even if it contains such Workloads.

Previously, that metric checked whether `LocalQueue` metrics were enabled but did not check whether the LocalQueue matched the selector. Consequently, a nonmatching LocalQueue could still expose the metric. 

The fix applies the selector to both regular reporting and resynchronization.
