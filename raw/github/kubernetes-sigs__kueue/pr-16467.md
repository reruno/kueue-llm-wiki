#### What this PR does / why we need it?

Explicitly disable `SkipChildJobSuspension` in the MultiKueue Ray autoscaling e2e configuration to measure the RayJob autoscaling spec with this feature gate disabled.

This draft is the disabled-gate comparison to #16458, using the same code baseline (36c42c8dfc10abcf90b15fa9c7cba6e28038b471). The only change from that baseline is `SkipChildJobSuspension: false` in the suite configuration.

#### Useful notes for your reviewer

Keep this PR draft for five sequential autoscaling test runs. The primary metric is the pass/fail count of `Should reflect worker-side autoscaler resizes (up, down, and up again) of a RayJob's child RayCluster back on the manager`. Overall suite outcomes are recorded separately. No diagnostic delays or product-code changes are included.

Validation: the Ray autoscaling Kustomize overlay renders successfully with `SkipChildJobSuspension: false`; `git diff --check` passes. The five CI runs are pending.

AI assistance was used to prepare this change, PR description, and test monitoring.
