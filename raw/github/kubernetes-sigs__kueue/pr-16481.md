## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

CodeRabbit's path instructions ask for table-driven tests in Ginkgo integration tests, so it suggests converting `ginkgo.It` blocks to `ginkgo.DescribeTable`, which maintainers do not want. The `**/*_test.go` instruction also asks every test file, including unit tests, to follow Ginkgo/Gomega patterns, which conflicts with the coding guidelines. This PR asks CodeRabbit for one `ginkgo.It` per scenario in Ginkgo tests and keeps map-based table-driven cases for unit tests.

Related: https://github.com/kubernetes-sigs/kueue/pull/16474#discussion_r4153174904
