#### What this PR does / why we need it?

Adds a reusable `MakeMatchExpression()` test wrapper (chained `Key`, `Operator`, `Values`, `Obj`) that can be passed to `MakeManagedJobsNamespaceSelector().MatchExpressions(...)`, and uses it in the jobframework and pod webhook tests instead of inline `metav1.LabelSelectorRequirement` literals.

Fixes #16018

#### Useful notes for your reviewer

Selector semantics in the refactored tests are unchanged. AI disclosure: this change was prepared with AI assistance (Claude Code) and reviewed by the author.

`make ci-lint` and the affected package tests pass. `make verify` could not complete locally because `verify-skills-lint` needs a Docker daemon, which was not running.
