#### What this PR does / why we need it?

Moves the `ResourceSlice` test wrapper from `pkg/util/testing` to `pkg/util/testingjobs/dra` and replaces inline `ResourceSlice` fixtures with the wrapper where it fits.

Fixes #15968

#### Useful notes for your reviewer
