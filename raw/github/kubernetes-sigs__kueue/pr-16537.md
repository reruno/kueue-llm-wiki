#### What this PR does / why we need it?
After #16000, the scheduler uses `GetPreemptionStrategyIterator` and `GetTargetsWithStrategy`, leaving `Preemptor.GetTargets` used only by tests. Migrate the remaining eight test call sites to the same entry points and remove the obsolete method, preserving the existing test inputs and assertions.

Fixes #16045

#### Useful notes for your reviewer
Follow-up to https://github.com/kubernetes-sigs/kueue/pull/16000#discussion_r4076247448.

Validation:
- `go test -race -ldflags=-linkmode=internal ./pkg/scheduler/... -count=1` passed.
- Removing the old method while keeping the original tests produced eight `GetTargets undefined` compilation errors; after migrating the tests, `go test -race -ldflags=-linkmode=internal ./pkg/scheduler/preemption/... -count=1` passed.
