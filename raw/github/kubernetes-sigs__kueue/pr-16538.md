#### What this PR does / why we need it?

Follow-up to https://github.com/kubernetes-sigs/kueue/pull/16462#discussion_r4156101888.

Moves `TestFailedSecondPassKeepsReservationWhenAlreadyPrequeued` onto `runTASScheduleTestCases` instead of maintaining a separate scheduler setup.

The helper now supports the two pieces this regression needs:
- prequeueing a second pass before the scheduling cycle
- checking the Workloads after one more scheduling cycle

The supporting AdmissionCheck and fake-clock setup is handled by the helper as well.

#### Useful notes for your reviewer

- The test passes under the existing feature-gate scenarios, so no custom FG override is needed. It now runs 18 subtests instead of 3.
- Both cycles compare the full Workloads, and the `SecondPassFailed` message is asserted so unrelated scheduling failures don't satisfy the test.
- `wantNewAssignments` now skips Workloads that already hold a reservation, not only admitted ones, since a delayed-topology Workload is reserved but not admitted. Existing cases keep the same expectations.
