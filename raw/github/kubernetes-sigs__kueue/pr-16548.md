#### What this PR does / why we need it?
Merges the three separate jobs in the `set-release-note` workflow (`authorize`, `report-authorization-failure`, `set-release-note`) into a single job. Each job spins up its own GitHub Actions runner, adding roughly 1–2 minutes of startup overhead per job. With a single job the workflow runs end-to-end on one runner without waiting for dependent jobs to be scheduled.
