#### What this PR does / why we need it?

The Prow metrics helper used a stale Grafana datasource UID and two recording rules that are no longer exposed by the Prow Prometheus backend. Update the datasource UID and collect CPU and memory usage from the current cAdvisor metrics, joining them to builds through `prow:job`. Keep request and limit metrics on the existing recording rules.
