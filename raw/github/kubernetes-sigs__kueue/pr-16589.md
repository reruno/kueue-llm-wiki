#### What this PR does / why we need it?

Backport the changes from PR 11261 to the `release-0.19` branch:

- Install `kubectl` as part of the E2E setup target.
- Reuse the exponential retry helper for kubectl downloads.
- Use the configured E2E binary directory instead of hard-coding `ROOT_DIR/bin`.

The release-specific `KUEUE_UPGRADE_FROM_VERSION` setting was retained while resolving the cherry-pick conflict in `hack/make/test.mk`.

#### Useful notes for your reviewer

This PR contains the three cherry-picked commits from PR 11261:

- `infra: install kubectl in makefile target`
- `fix: reuse exponential retry for kubectl downloads`
- `infra: use configured bin dir for e2e tools`

Validation completed with `bash -n` on the changed shell scripts, `git diff --check`, and `make -n setup-e2e-env`.
