#### What this PR does / why we need it?

**Why:** `kueuectl version` looks up the controller manager only by the name `kueue-controller-manager` and treats NotFound as "not installed". The Helm chart names the Deployment after the release, so after `helm install foo ...` the command prints only the client version.

**What:**
- `cmd/kueuectl/app/version/version.go`: look up the Deployment with a single List by `app.kubernetes.io/name=kueue,control-plane=controller-manager`, which kustomize and Helm have both set since v0.7, instead of by name. More than one match returns an error listing the names.
- Unit cases cover a renamed Helm release, a KueueViz Deployment that must not match, multiple matches, and a List error.

#### Useful notes for your reviewer

Kueue releases before v0.7 lack these labels, but `kueuectl version` itself first shipped in v0.8. A Helm `nameOverride` changes `app.kubernetes.io/name` and stays unsupported, because `control-plane` alone also matches other kubebuilder operators such as JobSet.
