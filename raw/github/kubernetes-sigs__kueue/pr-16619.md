#### What this PR does / why we need it?

revive v1.15.0 moved package-name checks from `var-naming` into a new
`package-naming` rule. Our `var-naming` argument is now ignored (revive warns
about it), so nothing has been checking package names since the bump. #10625
removed the `util/*` exclusion while this was already the case.

- Enable `package-naming` with `skip-collision-with-common-std` (needed for
  `pkg/util/{math,strings,slices}`), drop the dead `var-naming` argument.
- The rule flags two packages. Rename `pkg/scheduler/preemption/common` to
  `policy` and drop the `preemptioncommon` alias in its importers. Pure
  rename; two KEP path references updated. One parameter in
  `findCandidatesForPolicy` was also named `policy` and would shadow the
  import, so it is now `preemptionPolicy`.
- Exclude `test/util` for now. 259 importers, needs its own split (I decided this based on the #8377
  approach). Follow-up PRs will remove the exclusion.

Fixing the small finding inline and deferring the large one follows #6030 and
#14869.

Part of: #5948
