#### What this PR does / why we need it?

**Why:** `TestParseResourceQuotas` called `cmp.Diff(got, want)` under a `(-want,+got)` label, so a failing case printed the actual `ResourceGroups` as `-` and the expected ones as `+`.

**What:** In `cmd/kueuectl/app/create/create_clusterqueue_test.go`, pass want first, as the other `cmp.Diff` calls in the file do, and fix one test name ("flavors listing" → "flavors list") to match the next case and the integration test. Test-only change.
