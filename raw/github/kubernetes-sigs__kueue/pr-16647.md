#### What this PR does / why we need it?

Follow-up to tenzen-y's review comments on #16379.

- Defines a dedicated `ErrInvalidLocalQueueSelector` error in `pkg/metrics/localqueue.go`. `NewLocalQueueMetricsConfig` now wraps both this error and the underlying label-selector parsing error with `%w: %w`, so callers can identify selector failures with `errors.Is`. The final error message is unchanged (`invalid metrics.localQueueMetrics.localQueueSelector: <parse error>`), and an invalid enabled selector still fails startup.
- In `pkg/metrics/localqueue_test.go`, changes `wantErr` from `bool` to `error` and compares errors with `cmp.Diff` and `cmpopts.EquateErrors()`. The test now tells the dedicated selector error apart from unrelated errors. Existing coverage for the nil configuration, valid selectors, and disabled metrics cases is kept.

Fixes #16640
