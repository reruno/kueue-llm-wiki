## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`kueue_cluster_queue_weighted_share` and `kueue_replaced_workload_slices_total` were only cleared when a ClusterQueue's custom metric labels changed, so their series stayed after the ClusterQueue was deleted, and a cohort change left a weighted share series with the old `cohort` label behind.

This PR tracks the weighted share gauge in the ClusterQueue resource cleanup scope, which is cleared on deletion and cohort changes, and clears the replaced slices counter in `ClearClusterQueueMetrics`. The label-change-only cleanup scope becomes redundant and is removed.

None
