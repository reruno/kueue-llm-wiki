`2757-2784`: _📐 Maintainability & Code Quality_ | _🔵 Trivial_ | _⚡ Quick win_

**Synchronize the second request before releasing the blocked read.**

The handler cannot finish while it waits for `prequeueIfAbsent` to acquire the lock held by the blocked re-read. The 200 ms timeout does not prove that the handler reached the lock. If the goroutine runs only after `release()`, it can schedule a fresh pass, and the final assertion can pass without testing whether an in-flight request is lost.
