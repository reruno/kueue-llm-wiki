## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`kueuectl list workload` fails with `resource name may not be empty` when any listed Workload is not admitted and has an empty `spec.queueName`. `localQueues()` called `LocalQueues(ns).Get(ctx, "")`, and client-go rejects an empty name with an error that `IgnoreNotFound` does not filter out, so the whole command fails. This PR skips the LocalQueue lookup for such Workloads and adds an integration test.

Fixes: None

```release-note
CLI: Fixed a bug where `kueuectl list workload` failed with "resource name may not be empty" when a pending Workload had no `spec.queueName`. Such Workloads are now listed with empty LocalQueue and ClusterQueue columns.
```
