## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

When `VectorizedResourceRequests` is enabled, `NewRequestsFromMap` built an intermediate `MapRequests` and then converted it. The slice is now built directly from the input map, with the same sorted entries, exact values, empty-input behavior, and no aliasing of the caller's map.

Part of #16547

#### Useful notes for your reviewer

For six resources, direct construction allocates 2 times and the previous map-then-slice path allocates 6. `BenchmarkSchedulerTAS` (`nodes=1000`, 5 iterations, 3 runs) went from about 174,400 allocations and 69.0 MB per operation to about 135,700 allocations and 65.3 MB, with runtime unchanged.

This change was prepared with AI assistance.
