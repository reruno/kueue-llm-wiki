#### What this PR does / why we need it?

`ExactAmountString` printed a CPU amount past the Quantity limit with `Amount.String`, which is milli-CPU and had no unit. Two times `MaxInt64` cores showed up in quota messages as `18446744073709551614000`. The CPU fallback now keeps the `m` suffix. In-range CPU text and non-CPU resources are unchanged.

Part of #16547
