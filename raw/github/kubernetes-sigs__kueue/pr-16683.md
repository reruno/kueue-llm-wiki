## AI summary

The Job webhook validates Partial ScaleUp for `batch.Job` when the feature gate and workload slicing apply. For `Indexed` Jobs, `.spec.completions` must equal `.spec.parallelism`, with nil values treated as 1. `NonIndexed` Jobs skip this check. Updates that change the scale-up strategy, parallelism, or completions trigger validation.

**Balanced:** `ElasticJobsViaWorkloadSlices: For Partial ScaleUp, Kueue now requires matching completions and parallelism on Indexed batch Jobs. This behavior is gated by the ElasticJobsViaWorkloadSlicesWithPartialReplicaScaleUp feature gate.`
