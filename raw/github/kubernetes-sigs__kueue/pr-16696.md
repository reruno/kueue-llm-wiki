## Description

#### What type of PR is this?

#### What this PR does / why we need it?

The KueueViz workloads dashboard lists unrelated Pods for Workloads without a `kueue.x-k8s.io/job-uid` label, such as pod groups. The dashboard indexes Pods by their `controller-uid` label, so Pods without that label share the empty key, and Workloads without a job UID look up that same key. This PR skips Pods without a `controller-uid` label when building the index and adds a unit test.

Fixes: None
Related: #16694 (follow-up to show the Pods of pod group Workloads)
