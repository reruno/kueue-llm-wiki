## Description

Cherry pick of #16696 on release-0.19. Replaces the automated #16703, whose test did not compile on this branch.

Manual adjustments to the test: release-0.19 `fetchWorkloadsDashboardData` takes no `Identity` and returns two values, the object literals use `metav1.ObjectMeta`, and the pod counts are compared with `maps.Equal` because the KueueViz backend does not depend on `go-cmp` here.

#### What type of PR is this?
/kind bug
/area dashboard

```release-note
KueueViz: Fixed a bug where the workloads dashboard listed unrelated Pods for Workloads without a `kueue.x-k8s.io/job-uid` label, such as pod groups. Such Workloads now show an empty Pods list.
```
