#### What this PR does / why we need it?

Cherry-pick of kubernetes-sigs/kueue#16320 for `release-0.19`. Replaces the closed automatic backport kubernetes-sigs/kueue#16706.

The StatefulSet webhook must reject queue changes while its Workload holds quota, even when no Pod is Ready. Otherwise, the StatefulSet update succeeds but reconciliation repeatedly fails because the Workload's queue name is immutable while quota is reserved.

The automatic cherry-pick fails to compile because `release-0.19` does not have `findWorkload`. This backport uses the existing `findWorkloadName` helper and reads the Workload with `client.Get`. It preserves the legacy Workload name fallback and propagates lookup errors.

#### Useful notes for your reviewer

The original regression cases are unchanged. They cover quota reservation with UID-derived and legacy Workload names, plus queue changes after quota release.

The two reserved-quota cases fail against the unchanged `release-0.19` validation. With this backport, the full StatefulSet package passes:

```shell
go test -race ./pkg/controller/jobs/statefulset -count=1
```

AI disclosure: GitHub Copilot helped prepare and validate this backport.

#### Release note

```release-note
StatefulSet: Fixed a bug where changing a StatefulSet's queue while its Workload held quota could cause repeated Workload update failures when the StatefulSet had no ready replicas. Kueue now rejects the queue change until the Workload releases its quota.
```
