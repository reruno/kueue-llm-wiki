## AI summary

When Pod integration is implicitly enabled, the webhook now skips defaulting plain Pods that lack a non-empty suspended-by-parent annotation. This prevents a default LocalQueue from adding scheduling gates or a finalizer to Pods that the controller will not reconcile. The end-to-end test covers cases with and without a default LocalQueue.

Pod: Fixed a bug that could leave plain Pods stuck when Pod integration was implicitly enabled and a default LocalQueue existed. Kueue no longer adds scheduling gates or a finalizer to these Pods.
