#### What this PR does / why we need it?
MultiKueue: delete stale remote workload when a workload slice is replaced

When a finished local workload slice was replaced by a newer slice, the old remote workload was left on the worker cluster, causing two live slices with the same slice name to coexist on the worker. This introduces a targeted removeRemoteWorkload helper that deletes only the remote workload (not the remote job, which the replacement slice still owns) and calls it during replaced-slice reconciliation, with retry when worker clusters are temporarily unavailable.
