#### What this PR does / why we need it?

`test-kueueviz-backend` runs `go test` directly in `cmd/kueueviz/backend`, which has its own `go.mod`. So `go test` downloads the backend modules from proxy.golang.org with no retry, and a single HTTP/2 `INTERNAL_ERROR` stream reset failed `pull-kueue-test-e2e-kueueviz-main` before any test ran. The image build already retries on this exact error (`Makefile:73`), but this target runs on the host and was added later, in #16257.

This PR runs `go mod download` under `$(NETWORK_INSTALL_RETRY)` before `go test`, the same way `ginkgo-top` and `gomod-download` do. Only the download is retried, so a test failure still fails immediately, and a download that keeps failing still fails after 7 attempts.
