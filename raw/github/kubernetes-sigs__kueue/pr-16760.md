#### Useful notes for your reviewer

Conflicts were limited to flavorassigner.go and its tests.

- #16661 is not included. release-0.19 predates tas.GroupKeyForPodSet, and its TAS snapshot still uses positional group keys, so backporting that part alone would leave the grouping inconsistent
- The numeric group-name case can panic the 0.19 scheduler, but the job webhook rejects numeric group names, so the reproduced path requires a directly created Workload
- The new TAS cases need CPU allocatable because release-0.19 checks TAS fit during flavor scanning

The regression tests fail on the original release-0.19 code and pass with this cherry-pick.
