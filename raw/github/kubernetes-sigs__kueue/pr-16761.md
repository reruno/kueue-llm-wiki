## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

Cherry pick of #16627 on release-0.19. Replaces the automated #16697, whose integration test failed on this branch.

Manual adjustment: the StrictFIFO preemption gate test now enables `UnadmittedWorkloadsObservability`. The gate is Alpha and disabled by default on release-0.19, so without it the workload controller kept the legacy `Pending` reason instead of `PreemptionGated`.

#### Useful notes for your reviewer


#### Release note

```release-note
Scheduling: Fixed a bug where Workloads blocked by a closed preemption gate could retain a stale `QuotaReserved` condition and `status.resourceRequests`. Such Workloads now report the `PreemptionGated` reason on the `QuotaReserved` condition instead of `AdmissionGated`.
```
