#### What this PR does / why we need it?
In Topology Ungater, before assigning domains to pods based on ranks, we get all (non-terminated) pods for a workload. This list of pods might include some pod from a previous admission that is stuck terminating on a failed node. The stuck pod might have the same rank as one of the new pods, which breaks the `readRanksIfAvailable` and causes the fallback to  greedy assignment. 

Its easy to identify such a pod because it is ungated and assigned to a domain outside of the current Topology Assignment.  In this PR we just ignore such pods in Topology Ungater, which fixes the assignment of pods to domains.
