## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

With `podSetMergePolicy` set, PodSets with matching templates were merged even when they were admitted to different ResourceFlavors. The merged PodTemplate only took the node selectors and tolerations of the first PodSet's flavors, so the ProvisioningRequest asked for all the capacity on that flavor's nodes and none on the others. This PR merges PodSets only when their flavor assignments are equal.

None

#### Release note

```release-note
ProvisioningRequest: Fixed a bug where `podSetMergePolicy` merged PodSets admitted to different ResourceFlavors, so the ProvisioningRequest requested all their capacity on the first PodSet's flavor. Kueue now merges only PodSets assigned to the same flavors.
```
