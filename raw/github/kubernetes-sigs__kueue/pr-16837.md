#### What this PR does / why we need it?
hack/releasing/requirements.txt pinned PyYAML 6.0.3 with only a small subset of platform hashes. Running make release-utils-test failed with a hash mismatch on any platform or Python version not covered by those hashes (e.g. macOS with Python 3.14, Linux aarch64 with Python 3.13).                     
                                                                                                                                                            
Replace the partial list with all 68 hashes published on PyPI for PyYAML 6.0.3, covering every platform (macOS, Linux, Windows), architecture (x86_64, arm64, aarch64, s390x), Python version (cp38–cp314, including free-threaded cp314t), and the source tarball.
