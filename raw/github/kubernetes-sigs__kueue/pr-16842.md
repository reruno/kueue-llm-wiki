#### What this PR does / why we need it?

Fixes `SetNodeCondition` so that when the requested node condition is missing, the helper appends the new condition and then updates the local pointer to reference the appended entry before setting fields on it.

This prevents a nil pointer panic when tests call `SetNodeCondition` for a condition type that is not already present on the Node.

Adds regression coverage for:
- adding a missing node condition
- updating an existing node condition

Also adds a behavioral test utility verify target so these tests run in CI.
