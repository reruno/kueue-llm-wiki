#### What this PR does / why we need it?

The KueueViz workloads dashboard matches Pods to a Workload by the Workload's `kueue.x-k8s.io/job-uid` label and the Pod's `controller-uid` label, which only batch Job Pods carry, so pod group Workloads show no Pods. This PR also indexes Pods by their pod group name, read from the `kueue.x-k8s.io/pod-group-name` annotation or label, and looks up a Workload by its name when no Pod matches its job UID. The fallback also covers StatefulSet and LeaderWorkerSet Workloads, which have a job UID but whose Pods are pod groups.

Fixes #16694
