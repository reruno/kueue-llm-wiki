#### What this PR does / why we need it

Adds integration test coverage for the RayCluster ElasticWorkloadSlices partial scale-up flow when a fully admitted scale-up is followed by a scale-down.

The test now verifies that after scaling from 12 workers down to 8:

- the Workload requested PodSet count is updated to 8
- the admitted PodSet assignment remains at 12 until the running pods actually shrink
- quota usage still reflects the admitted 1 head + 12 workers

This covers KEP step 4 from the existing TODO and leaves the remaining TODO scoped to the multi-PodSet order-based scenarios.
