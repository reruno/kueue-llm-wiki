#### What this PR does / why we need it?

Cherry-pick https://github.com/kubernetes-sigs/kueue/pull/16780 onto `release-0.19`.

Introduce `workloadslicing.Manager` and initialize it once in `JobReconciler`. Move `EnsureWorkloadSlices` into `pkg/workloadslicing/manager.go` as a method, and adapt its caller and existing tests. This provides the shared workload slicing dependencies for subsequent changes.

This change was developed with assistance from OpenAI Codex.
