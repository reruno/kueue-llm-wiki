#### What this PR does / why we need it?

Cherry pick of #16743 on release-0.19.

`kueue_replaced_workload_slices_total` is defined and documented in the metrics reference, but it was never added to `Register()`, so it never appeared on the `/metrics` endpoint. This PR registers it.

Related: #16623

#### Useful notes for your reviewer

The only conflict was in the import block of `pkg/metrics/metrics_test.go`; resolved by keeping only the `ctrlmetrics` import needed by the new test.

AI assistance was used to prepare this PR.
