#### What this PR does / why we need it?

In KubeRay, if `replicas` is less than `minReplicas`, KubeRay still creates `minReplicas` Pods for the worker group. Therefore, the workload’s PodSet count will be lower than the actual number of worker Pods when replicas is less than `minReplicas`, and thus some worker Pods will remain scheduling-gated until replicas is increased to `minReplicas`.

In our production environment, during an allocation timeout in Ray 2.55.1, the Ray Autoscaler sets `replicas=1` and populates `workersToDelete` while `minReplicas=maxReplicas=2`, without restoring replicas to minReplicas in that timeout path. KubeRay still maintains two worker Pods because of the minimum replica bound.

* With `replicas=2` and `minReplicas=2`, KubeRay creates two worker Pods.
* One Pod times out because it cannot obtain sufficient resources within `RAY_AUTOSCALER_RECONCILE_ALLOCATE_STATUS_TIMEOUT_S` seconds.
* Autoscaler V2 terminates the timed-out Pod and updates `replicas` from 2 to 1.
* Kueue updates the worker PodSet count to 1.
* In some Ray versions, the autoscaler does not restore `replicas` to 2.
* As a result, one worker Pod remains scheduling-gated indefinitely.

However, a bug in Ray 2.55.1 prevents the autoscaler from increasing replicas from 1 to 2 because it sees that two worker Pods already exist. As a result, one Pod remains Pending indefinitely with a scheduling gate even if sufficient cluster resources become available later.

In the tested Ray 2.46.0 (autoscaler v1) and 2.58.0 (autoscaler v2) runs, the autoscaler restored `replicas` to `minReplicas=2` after the timeout, and both workers could run once capacity was released. Therefore, this issue does not occur in either of the two versions mentioned above.

Although the trigger is a Ray Autoscaler bug, fixing the count calculation in Kueue provides a version-independent safeguard. The fix applies to all Ray versions supported by this integration: Kueue derives worker counts from the RayCluster replica bounds rather than relying on a particular autoscaler version to restore `replicas` to `minReplicas`.
