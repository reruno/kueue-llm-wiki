## Description

/kind bug

Manual backport of #15576 to `release-0.20`, requested in https://github.com/kubernetes-sigs/kueue/pull/15576#issuecomment-6047514333. Replaces the closed automated backport #16879.

Refresh pending-workload metrics when LocalQueues are created, resumed, moved internally, stopped, or deleted. Store custom LocalQueue labels before the create handler reports metrics.

Uses the final merged diff (`8d7462c56d01db475a56b94acb65dd2068db7fa7`), including the migrated `test/util/behavioral` imports. The automated backport failed to compile because it imported the removed `test/util` package.

Validation:
- Regression tests reproduce stale/missing metrics before the production fix.
- Full `pkg/cache/queue` and `pkg/controller/core` unit tests pass with `-race`.
- All three LocalQueue lifecycle integration scenarios pass with `-race` on Kubernetes 1.37.0 envtest (delete, Hold, HoldAndDrain); all three fail before the fix.
- `gofmt` and `git diff --check` pass.

```release-note
Observability: Fix stale pending-workload metrics when LocalQueues are created, resumed, stopped, or deleted, including Workloads observed before their LocalQueue.
```
