## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

Cherry-pick of kubernetes-sigs/kueue#16371 for `release-0.20`.

When one PodSet shrinks below its admitted predecessor's grant and another grows, the scheduler can leave the replacement Workload pending even though a partial allocation fits the quota. This backport caps the predecessor-derived `MinCount` at the replacement PodSet's requested count.

#### Useful notes for your reviewer

The RayCluster regression test uses the `behavioral` helpers already present on this release branch. The scheduler regression case is unchanged from the original PR.

Validation passed: 32 partial scale-up scheduler subtests, the RayCluster regression integration test, `make ci-lint`, and `make verify`. Verification used the Go 1.27.0 toolchain required by this branch.

AI disclosure: GitHub Copilot helped prepare and validate this backport.

#### Release note

```release-note
ElasticJobsViaWorkloadSlices: Fixed a bug where a replacement Workload could remain pending when one PodSet shrank below its predecessor's grant while another grew.
```
