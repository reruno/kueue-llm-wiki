  I'm not sure if I understand correctly.
  
  How I understand it - we have 2 flows:
  1. Partial admission - the job can be reduced during admission in order to admit it to the cluster. MinCount is used there as a minimal required number of pods to allow the admission. 
  Users can use `kueue.x-k8s.io/job-min-parallelism` to specify it.
  2.
