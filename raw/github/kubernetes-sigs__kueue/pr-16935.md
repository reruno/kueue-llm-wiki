#### What this PR does / why we need it?

Manual release scripts can finish successfully while their release issue checklist remains unchecked. Mark the corresponding steps after successful prepare (release and main), promotion, CI, milestone, and local release-note updates. Keep PR-merge waiting items unchecked.

Extract the existing checklist marking into a self-contained `mark_step_done.py <step>` CLI that reads the issue body from stdin and writes it to stdout. Import the same implementation in the env-based ChatOps logger. Prepare captures the helper source in a shell variable before switching branches and runs it with `python3 -c`, so older release branches do not need the new file.

All five manual scripts check for `python3` alongside `gh` before pushing or updating release issues.

Dry runs, cancelled or failed submissions, and missing PRs leave the checklist unchanged. Issues without the new step markers remain compatible.

Fixes #16920

#### Useful notes for your reviewer

ChatOps `/sync-release-notes` already marks its step through the successful `report-result` action; the local call covers manual runs.
