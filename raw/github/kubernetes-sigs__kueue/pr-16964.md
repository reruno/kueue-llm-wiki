#### What this PR does / why we need it?

Simplifies the `ginkgo.By` steps in the LocalQueue pending metrics integration tests
(`test/integration/singlecluster/controller/core/localqueue_pending_metrics_test.go`).

Each loop iteration now has two steps instead of three:
1. the LocalQueue lifecycle action (delete, Hold or HoldAndDrain);
2. a single metrics check that groups the related assertions.

Both steps use `ginkgo.By` callback bodies, so each description stays next to its code.
The same structure is applied to the deletion, Hold, and HoldAndDrain tests.

This improves readability and keeps the lifecycle scenarios consistent. All metric
assertions are preserved, each scenario remains its own `ginkgo.It`, and there are no
behavioral changes.

Fixes #16877

#### Useful notes for your reviewer

Test-only change. Most of the diff is indentation, because the code moved into `ginkgo.By`
callbacks.
