## Description

#### What type of PR is this?

/kind feature

#### What this PR does / why we need it?

`hack/migrate-to-v1beta2.sh` is slow on large clusters, and on busy ones it rarely finishes:

- It runs one kubectl process per object. Process start, discovery and auth cost about 1 s each (EKS and GKE).
- Reruns patch every object again, including ones already annotated.
- The first failure stops that kind or namespace. An object deleted mid-run (NotFound), or one the validating webhook
  rejects on any update, stops every rerun at the same place.

This PR changes the script to:

- **Skip migrated objects.** It reads the annotation in the same LIST call; `--reannotate` patches them anyway.
- **Patch in batches.** Up to `--batch-size` names (default 100) go to one `kubectl annotate`/`patch` call. Calls stay
  sequential, and kubectl's client-side rate limiter paces the requests, so API server load doesn't rise.
- **Keep going on per-object errors.** Each chunk counts objects as migrated, gone (deleted since the list; not a
  failure) or failed. Batched webhook denials don't name the object, so the failed names are derived and printed.
- **Check the CRD storage version first.** If a kind's CRD doesn't store the target version, the script skips that kind
  with an error, since annotating would mark unmigrated objects as migrated.

Related: #9094
Fixes: https://github.com/kubernetes-sigs/kueue/issues/16983

#### Useful notes for your reviewer

- Existing flags, the per-namespace listing, the dry-run modes and `--downgrade` are unchanged.
- New permission: `get` on `customresourcedefinitions` (in `--help`). Without it, every kind is skipped with an error.
- Server-side dry run on a dev cluster with ~5k Kueue objects: 8m53s. All LocalQueues skipped; 2,494 ClusterQueues,
  663 skipped, 1,829 patched in ~20 kubectl calls; the 2 webhook-denied ones reported by name. Today's script stops
  ClusterQueues at the first of them.
- AI disclosure: written with AI assistance (Claude); I reviewed it and ran the tests above.

#### Release note

```release-note
migrate-to-v1beta2.sh: skip objects already annotated with the target storage version (`--reannotate` to patch them
anyway), patch in batches (`--batch-size`, default 100), keep going past per-object errors, and check each CRD's
storage version first. The script now needs `get` on customresourcedefinitions.
```
