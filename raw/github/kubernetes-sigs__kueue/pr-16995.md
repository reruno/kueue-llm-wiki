#### What this PR does / why we need it?

MultiKueue worker workload slices can initially lack owner references. Extend the existing prebuilt slice replacement reconciliation test to verify that the worker job adopts the ownerless successor while the predecessor is finished. Preserve the predecessor's existing controller reference.

Keep the existing workload count, PodSet preservation, and replacement completion assertions.

#### Useful notes for your reviewer

This is a standalone test change based on main. It covers the existing reconciliation behavior independently of https://github.com/kubernetes-sigs/kueue/pull/16778.
