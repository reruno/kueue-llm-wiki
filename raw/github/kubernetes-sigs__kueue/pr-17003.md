Bumps [stbenjam/skillsaw](https://github.com/stbenjam/skillsaw) from 0.20.0 to 0.21.0.
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/stbenjam/skillsaw/releases">stbenjam/skillsaw's releases</a>.</em></p>
<blockquote>
<h2>v0.21.0</h2>
<h2>What's New</h2>
<ul>
<li><strong>Cursor plugins and marketplaces:</strong> Native discovery and validation for Cursor plugin manifests, marketplaces, and their components, with source containment checks.</li>
<li><strong>Pi packages and projects:</strong> Discover Pi package resources, <code>.pi/</code> project resources, flat Markdown skills, prompt templates, and local package references, and validate Pi skills against Pi's native metadata contract (<code>pi-skill-valid</code>).</li>
<li><strong>OpenClaw plugins:</strong> Native plugin discovery plus opt-in authoring rules for manifests, packages, and resources.</li>
<li><strong>Codex:</strong> Follow portable OpenAI overlay precedence, including portable installs and late exclusions.</li>
<li><strong>Muse Code:</strong> Recognize newly documented hook events.</li>
<li><strong>Claude marketplaces:</strong> Tell standalone marketplace catalogs apart from plugin declarations.</li>
</ul>
<h3>Fixes and improvements</h3>
<ul>
<li>Restore skill coverage that native Pi and OpenClaw discovery had dropped.</li>
<li>Fix release-audit findings across discovery, autofix, and the CLI, including in the Pi, Cursor, and OpenClaw paths.</li>
<li><code>hooks-dangerous</code> no longer flags local scripts run with Bun (e.g. <code>bun run scripts/format.ts</code>).</li>
<li>Unknown or removed rule IDs in configuration now produce advisory <code>unknown-rule</code> warnings instead of failing CI.</li>
<li>New site changelog and a simpler getting-started guide; onboarding now recommends the skills CLI.</li>
</ul>
<h3>Upgrading from 0.20.0</h3>
<ul>
<li>Keep <code>version: &quot;0.20.0&quot;</code> in <code>.skillsaw.yaml</code> to defer new automatically enabled rules; set it to <code>&quot;0.21.0&quot;</code> when ready. <code>openclaw-manifest-valid</code>, <code>openclaw-package-valid</code>, <code>openclaw-resources</code>, and <code>pi-resource-paths</code> require explicit opt-in.</li>
<li><strong>Removed:</strong> the <code>skillsaw docs</code> command and the <code>content-critical-position</code>, <code>content-actionability-score</code>, and <code>skill-frontmatter</code> rules (use <code>agentskill-valid</code>). Remove them from your configuration.</li>
<li>Pi-owned skills are now checked by <code>pi-skill-valid</code> (WARNING) instead of <code>agentskill-valid</code> (ERROR). Set <code>severity: error</code> to keep them blocking.</li>
<li>The <code>repo_type</code> field in JSON and SARIF output may change: the new Cursor, Pi, and OpenClaw types rank above earlier ones. Match on the <code>repo_types</code> list instead.</li>
<li>New dependencies: <code>wcmatch</code>, <code>pathspec</code>, and <code>json5</code>.</li>
</ul>
<p>See the <a href="https://skillsaw.org/upgrading-0.21/">upgrade guide</a> for details.</p>

</blockquote>
