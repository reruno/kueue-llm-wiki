<blockquote>
<h2>kustomize/v5.8.2</h2>
<h2>Introduction</h2>
<p>In this release, we implemented refactoring to update dependencies and add new features.</p>
<p>This release adds the <code>kustomize edit add configuration</code> and <code>kustomize edit remove component</code> commands. <a href="https://redirect.github.com/kubernetes-sigs/kustomize/issues/6037">#6037</a> <a href="https://redirect.github.com/kubernetes-sigs/kustomize/issues/6083">#6083</a>
The built-in OpenAPI schema is now loaded from a pre-compiled bundle embedded in the binary. <a href="https://redirect.github.com/kubernetes-sigs/kustomize/issues/6190">#6190</a>
The schema itself is still based on Kubernetes v1.21.2, so the output of <code>kustomize build</code> is not expected to change. If you notice any difference, please file an issue.</p>
