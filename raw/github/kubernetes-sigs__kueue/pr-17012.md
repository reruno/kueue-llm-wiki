#### What this PR does / why we need it?

Fixes #17011 

In `apis/kueue/v1beta2/clusterqueue_types.go`, `ConcurrentAdmissionPolicy.Migration.Mode` is documented as defaulting to `TryPreferredFlavors`:

```go
// - `TryPreferredFlavors` (default): a Workload will try to migrate to the preferred flavor after it's admitted and running.
// - `RetainFirstAdmission`: a Workload, once admitted to a flavor, will stick to a flavor and will not be migrated.
```

Both the webhook (`pkg/webhooks/clusterqueue_webhook.go:251`) and controller (`pkg/controller/concurrentadmission/controller.go:853`) already treat an empty `Mode` as `TryPreferredFlavors`. However, the Go field had `// +required` and lacked `// +kubebuilder:default=TryPreferredFlavors`. This caused the generated CRD to require `mode`, rejecting manifests where `concurrentAdmissionPolicy.migration` was configured without explicitly setting `mode`.

This PR:
1. Changes `// +required` to `// +optional` and adds `// +kubebuilder:default=TryPreferredFlavors` on `ConcurrentAdmissionPolicy.Migration.Mode`.
2. Regenerates CRD manifests in `config/components/crd/bases` and Helm chart templates.
