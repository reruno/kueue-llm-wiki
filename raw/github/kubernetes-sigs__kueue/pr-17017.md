#### What this PR does / why we need it?

Cherry-pick of #16923 onto `release-0.19`, requested in https://github.com/kubernetes-sigs/kueue/pull/16923#issuecomment-6078163715 after the automated cherry-pick failed.

Backports lazy unit-package discovery, bounded verify concurrency, generation prerequisites that allow independent checks to overlap site generation, shared Helm documentation rendering, aligned CLI documentation CGO settings, and per-module lint timing.

#### Useful notes for your reviewer

- Resolved conflicts in `hack/make/test.mk` and `hack/make/verify.mk` while preserving this branch's existing targets and release settings.
- This branch has no `test/performance/multikueue` source. The corresponding README and dedicated targets are omitted; the shared package-selection logic and regression tests are retained.
- Validation on 2026-10-09: both shell regression tests, Bash syntax checks, and `git diff --check` passed. Offline Go package discovery selected 201 packages; real 1/2/3-shard runs matched the unsharded selection without omissions or duplicates.
- Full `make verify`, Go compilation, and release-branch performance measurements were not run locally. No release-branch speedup is claimed.
- No migration is required. Revert this cherry-pick to roll back.
