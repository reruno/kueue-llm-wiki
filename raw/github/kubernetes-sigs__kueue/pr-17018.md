#### What this PR does / why we need it?

Cherry-pick of #16923 onto `release-0.20`, requested in https://github.com/kubernetes-sigs/kueue/pull/16923#issuecomment-6078163715 after the automated cherry-pick failed.

Moves MultiKueue performance-tool unit tests into unit CI and backports lazy unit-package discovery, bounded verify concurrency, generation prerequisites that allow independent checks to overlap site generation, shared Helm documentation rendering, aligned CLI documentation CGO settings, and per-module lint timing.

#### Useful notes for your reviewer

- Resolved the `verify-checks` conflict by preserving this branch's existing checks, removing the separate performance-runner check, and adding package-selection and generation-order regressions. Release settings are unchanged.
- Validation on 2026-10-09: both shell regression tests, Bash syntax checks, and `git diff --check` passed. Offline Go package discovery selected 218 packages, including all four MultiKueue performance-tool packages; real 1/2/3-shard runs matched the unsharded selection without omissions or duplicates. Focused performance-tool selection also passed.
- Full `make verify`, Go compilation, and release-branch performance measurements were not run locally. No release-branch speedup is claimed.
- No migration is required. Revert this cherry-pick to roll back.

Disclosure: AI assisted with conflict resolution, validation, review, and this PR description.
