#### What this PR does / why we need it?
Adds `@` prefix to the `if` statement in the `verify` Makefile target to suppress make's command echo. Without it, Prow CI logs printed the raw `if git ls-files ...` (see https://prow.k8s.io/view/gs/kubernetes-ci-logs/pr-logs/pull/kubernetes-sigs_kueue/17014/pull-kueue-verify-main/2108522358519107584#1:build-log.txt%3A1247) command line before executing it, which was highlighted as a potential error in the build output – even when the check passed. This caused unnecessary confusion when reading CI logs.

#### Useful notes for your reviewer
The `@` prefix is a standard make convention to silence command echoing. No behavior change – only the printed command line is suppressed; error messages (`echo "ERROR: ..."`) are still emitted as before.
