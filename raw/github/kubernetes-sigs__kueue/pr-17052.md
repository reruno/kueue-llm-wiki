#### What this PR does / why we need it?

For non-adjacent TAS PodSet groups, the job reconciler could apply admission info to the wrong PodSets. With JobSet, this can swap labels, node selectors, and topology annotations between ReplicatedJobs, leaving Pods `SchedulingGated` even after admission.

This PR matches assignments by PodSet name and builds the infos in spec order.

<!--

Fixes #16266

#### Useful notes for your reviewer

- The new JobSet tests cover PodSet info ordering and the missing-assignment error path. I also reproduced the stuck `SchedulingGated` Pod on kind, without preemption.
- Missing assignments now follow the existing invalid-PodSet-info handling, finishing the Workload with `FailedToStart`.
- Some test fixtures (Pod group unit tests and Job integration tests) now use matching PodSet and assignment names. Their expectations are unchanged.
