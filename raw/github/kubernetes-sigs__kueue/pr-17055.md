#### What this PR does / why we need it?

Fixes #17054 

When creating a LocalQueue using `kueuectl create localqueue` with `--dry-run=client`, `Validate(ctx)` attempts to retrieve the specified ClusterQueue from the live cluster:

```go
if !o.IgnoreUnknownCq {
	_, err := o.Client.ClusterQueues().Get(ctx, o.UserSpecifiedClusterQueue, metav1.GetOptions{})
	if err != nil {
		return err
	}
}
```

This breaks offline execution (such as GitOps manifest templating in CI without a running cluster) or cases where the target ClusterQueue has not yet been applied to the cluster, returning:

```text
Error: clusterqueues.kueue.x-k8s.io "my-cq" not found
```

In `Run(ctx)`, client dry-run is skipped (`if o.DryRunStrategy != dryrun.Client`). This PR updates `Validate(ctx)` to also skip the remote check when `o.DryRunStrategy == dryrun.Client`.

This PR:
1. Adds `o.DryRunStrategy != dryrun.Client` guard to ClusterQueue lookup in `Validate(ctx)`.
2. Adds unit tests covering `Validate(ctx)` with dry-run client, dry-run none, missing fields, and `--ignore-unknown-cq`.
3. Adds integration test coverage for `create localqueue --dry-run=client` with an unknown cluster queue.
