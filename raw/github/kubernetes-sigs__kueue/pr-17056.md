## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`kueuectl create resourceflavor --tolerations key=:NoSchedule` currently creates an `Exists` toleration, which also matches nonempty taint values such as `key=value:NoSchedule`. The same problem affects `key=` without an effect.

Preserve explicit empty values as `Equal` tolerations. Bare keys and keyless tolerations keep their existing `Exists` behavior. Add regression coverage through the public command and API persistence tests.

#### Useful notes for your reviewer

AI assistance was used for the code, tests, validation, and this description.

Validated CLI unit tests with race detection and three runs, the complete kueuectl envtest suite with race detection, and `make ci-lint`. A public CLI dry-run also verifies taint matching for empty values and the existing wildcard forms.

The complete `make verify` passed using `DOCKER` and `CONTAINER_ENGINE` overrides for an isolated nerdctl/BuildKit runtime.

#### Release note

```release-note
CLI: Fixed kueuectl create resourceflavor so explicit empty values in --tolerations (for example key=:NoSchedule) match only empty taint values instead of any value.
```
