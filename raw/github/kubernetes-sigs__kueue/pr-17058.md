#### What this PR does / why we need it?

The RayJob TAS ranks-ordering e2e test verifies placement of Ray worker pods.

In K8sJobMode, RayJob also creates a submitter pod. The submitter pod is needed
for this mode, but it is not part of the RayCluster worker rank ordering that
the test asserts.

The test was adding a required topology annotation to the submitter pod template.
That made the submitter participate in admission-time TAS placement as an extra
hard constraint, so the test could fail before reaching the worker placement
checks.

This PR removes the required topology annotation from the submitter pod template.
The submitter pod is still present, so the test still exercises RayJob
K8sJobMode.
