#### What this PR does / why we need it?

Fixes #17061 

In `test/integration/singlecluster/controller/admissionchecks/provisioning/provisioning_test.go`, the test `"Should ignore the change if Workload is Admitted and the ProvisioningRequest's condition is set to BookingExpired"` used a hardcoded `time.Sleep(100 * time.Millisecond)` to wait for the controller to see the workload as admitted.

On loaded or resource-constrained CI runners, 100ms may expire before controller reconciliation finishes, causing the admission check to be marked as rejected and flaking the test.

This PR:
1. Replaces the hardcoded `time.Sleep(100 * time.Millisecond)` with `behavioral.ExpectAdmissionCheckState(ctx, k8sClient, wlKey, ac.Name, kueue.CheckStateReady)`.
2. Synchronizes on the controller's admission check condition update using `gomega.Eventually` before updating the workload's admission status.
