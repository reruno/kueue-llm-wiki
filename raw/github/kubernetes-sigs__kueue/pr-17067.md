#### What this PR does / why we need it?

Fixes #17066 

In `test/util/behavioral/queues.go`, several assertion helpers (`UnholdClusterQueue`, `UnholdLocalQueue`, `ExpectClusterQueuesToBeActive`, `ExpectLocalQueuesToBeActive`) were missing `ginkgo.GinkgoHelper()`.

When an assertion fails inside these functions, Ginkgo v2 reports the failure location inside the helper function instead of pointing to the calling test spec.

This PR adds `ginkgo.GinkgoHelper()` to these functions, ensuring test failure stack traces correctly pinpoint the call site in test specs.

#### Useful notes for your reviewer

All modified helpers are located in `test/util/behavioral/queues.go`.
