#### What this PR does / why we need it?


Extracts `FlavorScanState` and its receiver methods from `pkg/workload/workload.go` into a dedicated file `pkg/workload/flavor_scan_state.go`, and relocates its unit test `TestAssignmentClusterQueueState` to `pkg/workload/flavor_scan_state_test.go`.
This is a pure 1:1 refactoring:
- Moves `FlavorScanState` struct and its methods (`Clone`, `MatchesSchedulingShape`, `PendingFlavors`, `TriedFlavorsForPodSetResource`, `TriedFlavorsForGroup`, `RestoreAfterRecompute`, `RecordPodSet`) to `pkg/workload/flavor_scan_state.go`.
- Relocates `TestAssignmentClusterQueueState` to `pkg/workload/flavor_scan_state_test.go`.
- Removes the now-unused `utilmaps` import from `pkg/workload/workload.go`.
- No functional or behavioral changes.
