#### What this PR does / why we need it?

https://github.com/kubernetes-sigs/kueue/pull/16766#discussion_r4229684924

Extracts `FlavorScanState` and its methods into a dedicated file `pkg/workload/flavor_scan_state.go` (and `pkg/workload/flavor_scan_state_test.go`), and tightens its API boundary:

- Moves `FlavorScanState` and its receiver methods from `pkg/workload/workload.go` to `pkg/workload/flavor_scan_state.go`.
- Moves `flavorScanStateOutdated` from `pkg/scheduler/scheduler.go` onto `FlavorScanState.IsOutdated` and relocates `TestFlavorScanStateOutdated` from `pkg/scheduler/scheduler_test.go` to `pkg/workload/flavor_scan_state_test.go`.
- Adds `NewFlavorScanState` to encapsulate the internal `TriedFlavors` slice allocation used by `pkg/scheduler/flavorassigner`.
- Unexports `triedFlavorsForPodSetResource`, which is only called internally within `pkg/workload/flavor_scan_state.go`.
