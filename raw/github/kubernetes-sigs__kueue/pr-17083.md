#### What this PR does / why we need it?

Adds a minimal baseline E2E test suite for TAS to validate the basic deep WAS integration with `SchedulerLibraryIntegration` and `SchedulerLibraryDeepIntegration` enabled, without preemptions or hierarchical topologies:
1. Rejection when ClusterQueue quota is exceeded
2. Rejection when pod does not fit on any individual node
3. Admission and completion when quota and node capacity both fit
4. Admission and pod execution when quota and node capacity fit
5. Queuing when nodes are busy, admitting once nodes are freed
