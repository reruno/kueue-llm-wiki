## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Small cleanup of the configurable preemption `PreemptionEvaluator`:
- Removes the unused `clock` field and constructor parameter.
- Passes the preemptor to the evaluator constructors and stores it as a field. `FindCandidates`, `orderedCandidates` and `candidatesFor` no longer take it as an argument.

Each evaluator is already built once per scheduling attempt of a single workload, so binding the preemptor at construction matches how the evaluator is used. It also avoids passing the same argument through every internal call.

Part of #13396
