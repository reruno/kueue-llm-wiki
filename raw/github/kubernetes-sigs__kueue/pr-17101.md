## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`/set-release-note` put every line after the command into the release note, including other commands in the same comment such as `/remove-kind cleanup` and `/kind bug`.

The note is now the text after the last `/set-release-note` line, up to the next command line. Other commands in the same comment are still handled by Prow as before. The workflow now runs when the comment contains `/set-release-note`, so the command also works after another command such as `/kind bug`.

Fixes #17085

#### Useful notes for your reviewer

- A command line is `/` + word, optionally followed by arguments, matched case-insensitively like Prow, for example `/kind bug` or `/Set-release-note`.
- Known limit: a note line that starts with `/word` ends the note. I kept the rule simple instead of listing Prow commands; happy to change it if you prefer a fixed list.
- Tests cover the example in the issue, a multiline note followed by `/lgtm` and `/approve`, a repeated command, the command after another command, a capitalized command, and a comment with only commands. These are the cases mbobrovskyi tested in https://github.com/mbobrovskyi/kueue/pull/500.
- Ran the release-utils suite the same way `make verify` does: 31 tests pass. Doctests in `set_release_note.py` pass.

  A note line that starts with `/word` ends the note, and everything from that line on is dropped without a warning. For example, `API change:\n/v1beta2 is now the default` gives just `API change:`. The bot still replies `✅ The release note was updated.`, so the author may not notice the cut.
  
  You offered a fixed list of Prow commands. I think that's the better trade-off: if the list misses a command, the command shows up in the release-note block, where it's easy to see and fix, instead of note text being silently lost. Something like:
  
  ```python
  # Prow commands enabled for this repository, see
  # https://prow.k8s.io/command-help?repo=kubernetes-sigs%2Fkueue
  PROW_COMMANDS = frozenset({
      "approve", "assign", "unassign", "cc", "uncc",
      "hold", "unhold", "lgtm", "kind", "area", "priority", "triage",
      "lifecycle", "close", "reopen", "retitle", "milestone",
      "test", "retest", "ok-to-test", "cherry-pick", "cherrypick",
      "release-note-none", "stage", ...
  })
  COMMAND_LINE_RE = re.compile(r"^/(?P<name>[a-z][a-z0-9-]*)(?:[ \t]+\S.*)?$", re.IGNORECASE)
  
  
  def _is_prow_command_line(line: str) -> bool:
      """Report whether the line is a Prow command, such as "/kind bug"."""
      match = COMMAND_LINE_RE.match(line.rstrip())
      if match is None:
          return False
      name = match.group("name").lower()
      # The label plugin accepts "/remove-<label>" for any label prefix.
      return name in PROW_COMMANDS or name.startswith("remove-")
  ```
