#### What this PR does / why we need it?

The Status column on the Workloads page and in the LocalQueue detail workloads table showed the type of the first condition, which is usually `QuotaReserved` regardless of the workload's state.

This adds `getWorkloadStatus` in `src/utils/workloadStatus.js`. It follows `workload.Status` in `pkg/workload`, which `kueuectl list workload` uses: Finished, then Admitted, then QuotaReserved, otherwise Pending. Both tables use it.

Fixes #17102

#### Useful notes for your reviewer

- Only the Status cell changes. The fix for #16276 touches the Preempted cells on the next lines of `Workloads.jsx`, so whichever PR merges second may need a small rebase.
- Added vitest cases for no status, pending, quota reserved, admitted, finished, and evicted back to pending.
- Ran `npm test` (104 tests pass) and `npm run build` in `cmd/kueueviz/frontend`.
- This PR was written in part with the assistance of generative AI.
