/kind bug

#### What this PR does / why we need it?

`fetchWorkloadDetails` returned an error when the Workload's LocalQueue was not found, so the details page failed for any Workload whose LocalQueue had been deleted.

A NotFound LocalQueue is now treated as a missing queue: the ClusterQueue name comes from `status.admission` if the Workload is admitted, otherwise it is "Unknown", as for a Workload without a queue name. Other errors from the lookup are still returned.

Fixes #17103

#### Useful notes for your reviewer

- Updated the unit test that expected an error for a missing LocalQueue, and added cases for the admission fallback and for a non-NotFound error.
