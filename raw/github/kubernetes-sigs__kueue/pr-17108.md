## Description

#### What type of PR is this?

/kind cleanup
/area tas

#### What this PR does / why we need it?

Replaces three inline "NoSchedule or NoExecute" taint effect checks with the existing `utiltaints.IsSchedulingTaint` helper:

- flavor assignment: `checkFlavorForPodSets`
- TAS node controller: `hasSchedulingTaints` and `classifyTaints`

After this change, the set of taint effects that Kueue evaluates is defined in one place.

Fixes #17106

#### Useful notes for your reviewer

- No behavior change. The helper's condition is identical to the removed inline checks.
- this PR was prepared with AI assistance.
