#### What this PR does / why we need it?

This adds a bounded context when shutting down the kueueviz backend HTTP server.

Previously, the backend called `srv.Shutdown(context.Background())`, so graceful shutdown had no upper bound if an active HTTP request did not complete. The new shutdown context uses a 30 second timeout so process termination is more deterministic.

<!--

Fixes #17134

#### Useful notes for your reviewer

This does not add separate WebSocket connection tracking. Upgraded WebSocket connections are typically not waited on by `net/http.Server.Shutdown`, so this change focuses on bounding ordinary HTTP server shutdown.
