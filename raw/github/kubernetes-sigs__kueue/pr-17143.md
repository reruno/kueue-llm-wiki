#### What this PR does / why we need it?

kueueviz only enables authentication when `KUEUEVIZ_AUTH_MODE` is exactly `TokenReview`.

Before this change, an unknown or misspelled value would let the backend start without installing the authentication and authorization middleware. This PR validates the auth mode during server config loading and fails startup for unsupported values.

Fixes #17142

#### Useful notes for your reviewer

Supported values are now limited to `Disabled` and `TokenReview`.

Tests cover the default mode, both supported values, and an unsupported value. The default-mode test also isolates `KUEUEVIZ_AUTH_MODE` from the caller environment.

This PR was created with AI assistance.

#### Release note

```release-note
kueueviz: Invalid KUEUEVIZ_AUTH_MODE values now cause backend startup to fail instead of silently disabling authentication.
```
