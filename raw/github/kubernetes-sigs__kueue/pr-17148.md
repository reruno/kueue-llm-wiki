## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`pull-kueue-verify-main` has been failing on every PR since the kubekins image moved to Go 1.27.2. Go 1.27.2 writes export data v5, and golangci-lint v2.13.2 (x/tools v0.49.0) only reads up to v4, so every package fails with `typecheck`.

This bumps golangci-lint and the KAL custom build to v2.14.0 (x/tools v0.50.0), and fixes the 6 new findings it reports.

#### Special notes for your reviewer

Verified locally with Go 1.27.2: `make ci-lint`, `make lint-api` and `make gomod-verify` pass.
