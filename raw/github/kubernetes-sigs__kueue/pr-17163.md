## Description

#### What type of PR is this?

/kind cleanup
/area testing

#### What this PR does / why we need it?

Remove the redundant outer `ginkgo.GinkgoHelper()` call from `AssertMsgForMk`.

The outer function has already returned when the diagnostic closure runs, so its helper annotation does not affect failure attribution. The annotation inside the closure is kept.

Fixes #17138

#### Useful notes for your reviewer

This follows the [review suggestion](https://github.com/kubernetes-sigs/kueue/pull/17136#discussion_r4259634179) to make this cleanup on main.

Local before-and-after checks confirmed that diagnostic messages and assertion failure locations remain unchanged.

Checks passed:
