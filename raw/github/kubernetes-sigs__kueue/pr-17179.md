#### What this PR does / why we need it?

Cherry pick of https://github.com/kubernetes-sigs/kueue/pull/16739 onto `release-0.19`.

Return empty arrays instead of `null` for successful resource-list queries with no results. This lets the Local Queues, Cluster Queues, Cohorts, and Resource Flavors pages display an empty state instead of loading indefinitely.

```release-note
KueueViz: Fixed indefinite loading on the Local Queues, Cluster Queues, Cohorts, and Resource Flavors pages when no resources are found.
```
