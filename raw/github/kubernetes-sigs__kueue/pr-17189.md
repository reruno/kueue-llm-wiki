#### What this PR does / why we need it?

Cherry pick of #16849 on release-0.19.

Manual adjustments: release-0.19 has no KueueViz RBAC checks, so `buildWorkloadPodsIndex` keeps its `Client` argument and two return values, and the new test calls `fetchWorkloadsDashboardData` without an `Identity`.
