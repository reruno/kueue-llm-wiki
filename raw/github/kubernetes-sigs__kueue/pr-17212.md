#### What this PR does / why we need it?

Manual cherry-pick of #16278 to `release-0.19`. The automated cherry-pick #17185 did not compile on this branch.

`release-0.19` has no per-request authorization in the KueueViz backend, so the tests are adapted:

- `New` takes two arguments, and `fetchLocalQueues` and `fetchNamespaces` take no namespace or identity.
- The authorizer, `hasClusterAccess` and `omittedPanels` cases are dropped, since that code does not exist here.
- Struct literals use `ObjectMeta`, since promoted fields are not allowed with this branch's Go version.

The remaining cases cover the same fetch functions, list errors, namespace dedup and sorting, flavor quota and node label matching, and `details.nodeLabels`.

#### Useful notes for your reviewer

- Test only change, no production code touched.
- Ran `go test ./...`, `go vet ./handlers` and `golangci-lint` with the branch's `.golangci.yaml` in `cmd/kueueviz/backend`.
