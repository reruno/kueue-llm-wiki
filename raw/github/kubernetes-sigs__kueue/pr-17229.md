#### What this PR does / why we need it?
**WHY**
There is no working way to run the MultiKueue e2e suites with Helm. `make test-multikueue-e2e-helm` fails:
```
make: *** No rule to make target `test-multikueue-e2e', needed by `test-multikueue-e2e-helm'.  Stop.
```
#11627 split the MultiKueue e2e suite into baseline and extended, and 
#11886 removed `test-multikueue-e2e`.`test-multikueue-e2e-helm` still depends on the removed target.

**What**
- Add `test-multikueue-e2e-baseline-helm`.
- Add `test-multikueue-e2e-extended-helm`.
- Add `test-multikueue-e2e-sequential-helm`.
- Remove the broken `test-multikueue-e2e-helm`.

**How**
Each new target sets `E2E_USE_HELM=true` and depends on the matching suite target.
`run-test-multikueue-e2e-baseline-%`, `run-test-multikueue-e2e-extended-%` and `run-test-e2e-multikueue-sequential-%` already forward `E2E_USE_HELM` to `e2e-multikueue-test.sh`, so only `hack/make/test.mk` changes.
