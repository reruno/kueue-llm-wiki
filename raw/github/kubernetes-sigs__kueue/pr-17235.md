## Description

#### What type of PR is this?

/kind bug
/area dashboard

#### What this PR does / why we need it?

Some KueueViz pages built a link from a name that can be missing. The dashboard linked "N/A" to `/cluster-queue/undefined` for workloads that are not admitted, the workload detail page linked "Unknown" to `/cluster-queue/Unknown`, and ClusterQueues without a Cohort got an empty link to `/cohort/`.

These places now render plain text when the name is missing, and a link otherwise.

Fixes #17232

#### Useful notes for your reviewer

- `LocalQueues.jsx` and `LocalQueueDetail.jsx` also link to `spec.clusterQueue`, but that field is required on a LocalQueue, so I left them as they are.
- Added `MissingNameLinks.test.jsx` with render tests for the workload detail ClusterQueue link and the ClusterQueue detail Cohort link. Two of the four cases fail without the fix.
- Ran `npm test` (108 tests pass) and `npm run build` in `cmd/kueueviz/frontend`.
- This PR was written in part with the assistance of generative AI.

#### Release note

```release-note
KueueViz: Fixed links to missing ClusterQueues and Cohorts, such as "N/A" on the dashboard linking to `/cluster-queue/undefined`.
```

  A small visual suggestion here:
