## AI summary

`newVirtualPod` no longer adds a `SchedulingGroup` by default. `CandidateVirtualPodsForPodSet` adds it to candidate pods, while virtual pods for workloads with node placements do not receive the PodGroup link. The test expectation was updated.

### Suggested release note

WorkloadAwareScheduler: Candidate virtual pods retain their PodGroup link for gang scheduling. Virtual pods with node placements do not receive this link.
