#### What this PR does / why we need it?

The ResourceFlavor detail page reads `details.nodeLabels` and `details.nodeTaints`, but the backend sent only `tolerations` and the taints under `taints`. Both sections always showed "None".

`fetchResourceFlavorDetails` now sends `nodeLabels`, `nodeTaints` and `tolerations`, the keys the page reads.

Fixes #17270

#### Useful notes for your reviewer

- The `taints` key is dropped. Nothing in the frontend reads it.
