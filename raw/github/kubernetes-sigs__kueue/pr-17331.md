#### What this PR does / why we need it?
Bumps `sigs.k8s.io/cluster-inventory-api` from v0.1.3 to v0.2.0 and migrates Kueue to `ClusterProfile` `multicluster.x-k8s.io/v1alpha2`.                  
                                                                                                                                                            
In v0.2.0, `access.Config.BuildConfigFromCP` accepts only `*v1alpha2.ClusterProfile`, and `v1alpha1` is deprecated.
