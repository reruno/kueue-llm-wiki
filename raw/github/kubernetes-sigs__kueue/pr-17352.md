#### What this PR does / why we need it?

`verify-skills-lint` prints the full skillsaw report in every `make verify` log, even when it passes. The Prow log viewer highlights its `Errors: 0` line in red, the same kind of noise #17283 removed for `e2e-common_test.sh`.

This PR bumps skillsaw to 0.22.0 and runs it with the new `-q` flag. A clean run prints nothing, and a run with errors or warnings prints only the findings and the summary. The full report is still written to `skillsaw-summary.html` in the artifacts directory. `make skills-lint` shares the recipe, so it is quiet too.
