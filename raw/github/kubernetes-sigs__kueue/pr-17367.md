#### What this PR does / why we need it?

Cherry-pick of #16884 onto `release-0.19`, requested in https://github.com/kubernetes-sigs/kueue/pull/16884#issuecomment-6213544210.

Respect KubeRay worker group `minReplicas` and `maxReplicas` when deriving PodSet counts, including multi-host replicas. When an autoscaler allocation timeout reduces `replicas` below `minReplicas`, KubeRay still creates the minimum number of workers; accounting for that minimum prevents the extra workers from remaining scheduling-gated.

#### Useful notes for your reviewer

Resolved conflicts against release-0.19: retained its existing imports and SerializePodSetCounts API; omitted partial replica scale-up fixture updates and WorkerGroupPodCounts assertions because that feature, integration test file, and helper do not exist on this branch. The replica-bound calculation, BuildPodSets cases, UpdatePodSets regression case, and input immutability check are preserved.
