#### What this PR does / why we need it?

Replace hardcoded PodSet indexes and counts in the SparkApplication integration with three named constants:

- `driverPodSetIndex = 0`
- `executorPodSetIndex = 1`
- `sparkPodSetCount = 2`

The constants are used consistently in `PodSets`, `RunWithPodSetsInfo`, and `RestorePodSetsInfo`.

This makes the driver-first ordering explicit and avoids repeated magic numbers. There are no functional changes.

Fixes #17363
