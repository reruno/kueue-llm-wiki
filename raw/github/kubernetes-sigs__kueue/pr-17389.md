#### What this PR does / why we need it?

The AdmissionCheck controller has no unit tests yet. This PR adds `TestAdmissionCheckReconcile`, which covers `Reconcile`:

- adds the finalizer when it is missing
- keeps the finalizer when it is already present
- keeps the finalizer while a ClusterQueue still uses a deleting AdmissionCheck
- removes the finalizer (so the AdmissionCheck is deleted) when no ClusterQueue uses it
- ignores an AdmissionCheck that does not exist

It also adds a `Finalizers` method to the AdmissionCheck test wrapper, matching the other wrappers.
