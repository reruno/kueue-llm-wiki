## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Adds a shared `SetLocalQueueStopPolicy` testing helper in `test/util/behavioral/queues.go` that sets a LocalQueue's `spec.stopPolicy` to any value. It reads the latest LocalQueue and retries the update using the existing Ginkgo/Gomega `Eventually` pattern.

`UnholdLocalQueue` is now a thin wrapper over the helper (`kueue.None`), so there is a single implementation of the retry logic.

The `Hold` and `HoldAndDrain` cases in `localqueue_pending_metrics_test.go` now call the helper instead of duplicating the get/patch/retry block. Both remain separate `ginkgo.It` cases, the pending-metric assertions are unchanged, and the now-unused `ptr` and `client` imports are removed.

Fixes #16876
