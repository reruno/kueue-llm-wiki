## Description

manual cherry-pick of #17346 onto release-0.19, since the bot hit a conflict in `pkg/controller/core/cohort_controller.go`.

the only conflict was the Cohort `Update` handler: release-0.19 has no quota status check there, so the handler updates the cache and queue manager when the spec changes (`specUpdated`) instead of `specOrQuotaUpdated` on main. everything else applied as is.

tested on this branch: `go test ./pkg/controller/core/`, plus the integration suites `test/integration/singlecluster/controller/failover` and `test/integration/singlecluster/controller/core`, all passing.

/assign mimowo

```release-note
Cohorts are now kept in the scheduler cache on every replica, so a replica that takes over leadership can admit from Cohort quota right away.
```

/kind bug
