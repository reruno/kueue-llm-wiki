## AI summary

The Workload webhook rejects new preferred topology requests when `SchedulerLibraryDeepIntegration` is enabled. The error identifies `spec.podSets[].topologyRequest.preferred` and names the feature gate. Unchanged preferred topology remains valid on updates, and the validation does not apply when the gate is disabled.

### Suggested release note

**Workloads:** Fixed a bug where Workloads could request unsupported preferred topology when `SchedulerLibraryDeepIntegration` was enabled. Kueue now rejects these requests during webhook validation while allowing unchanged requests on updates.
