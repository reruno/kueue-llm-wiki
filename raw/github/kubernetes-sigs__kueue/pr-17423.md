## Description

#### What type of PR is this?

/kind bug
/area multikueue

#### What this PR does / why we need it?

`multikueue_workloads_dispatched_total`, `multikueue_workloads_admitted_total` and `multikueue_workloads_evicted_total` were missing from `ClearClusterQueueMetrics`, so their series stayed after the ClusterQueue was deleted.

This PR clears them in `ClearClusterQueueMetrics` and adds a unit test that covers several worker clusters and replica roles and checks that another ClusterQueue's series are kept.

Part of #17415
