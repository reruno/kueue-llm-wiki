#### What this PR does / why we need it?
Only the queue reads `Info.SchedulingHash`. The scheduler cache, the unadmitted-condition resolver, and the DRA checks also build Infos. They paid for the hash on every Workload event. They now pass `WithSkipSchedulingHash()`.
