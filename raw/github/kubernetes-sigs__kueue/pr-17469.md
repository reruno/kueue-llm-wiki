## Description

This is an automated cherry-pick of #17157

/assign mimowo

```release-note
MultiKueue: Fixed a regression where `MultiKueueOrchestratedPreemption`, enabled by default since v0.20, added two status writes for every Workload replicated to a worker cluster, reducing MultiKueue admission throughput. `status.preemptionGates` no longer lists a `Closed` state for gates that have not been opened; such gates remain closed.
```

/kind bug
/kind regression
