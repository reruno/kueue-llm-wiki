#### What this PR does / why we need it?
kubernetes/test-infra#38044 moves Kueue's `milestone_applier` mapping out of the shared `config/prow/plugins.yaml` into a Kueue-owned supplemental plugin config, `config/prow/plugins/kubernetes-sigs/kueue/kueue_pluginconfig.yaml`. That file has its own `OWNERS` (Kueue approvers and the release team), so milestone bumps no longer need top-level test-infra approval.

This PR points `hack/releasing/milestone_pull.sh` at the new file. The file has the same `milestone_applier` → `kubernetes-sigs/kueue` → `main` layout, so the existing read/edit logic and its tests are unchanged. Only comments that described `plugins.yaml` are updated.
