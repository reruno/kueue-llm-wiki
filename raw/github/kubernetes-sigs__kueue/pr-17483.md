## Description

#### What type of PR is this?

/kind bug
/area multikueue

#### What this PR does / why we need it?

When a MultiKueueCluster was deleted, `ClearMultiKueueClusterMetrics` dropped only `multikueue_cluster_status`, so `multikueue_workloads_dispatched_total`, `multikueue_workloads_admitted_total` and `multikueue_workloads_evicted_total` kept reporting the removed worker cluster.

This PR clears them in `ClearMultiKueueClusterMetrics` and extends its unit test to check that another worker cluster's series are kept.

Related: #17423
