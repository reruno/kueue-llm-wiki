#### What this PR does / why we need it?

Bumps `sigs.k8s.io/lws` from v0.11.1 to v1.0.0, the first stable LeaderWorkerSet release, and re-vendors it.
The e2e operator install and the integration-test CRDs follow the `go.mod` version, so they also move to v1.0.0.

#### Useful notes for your reviewer

- The diff contains only `go.mod`, `go.sum` and `vendor/`. No other modules change version.
- The v1.0.0 API changes are additive and opt-in, so no Kueue code changes are needed:
  - new `spec.podTerminationPolicy` (`Sequential` default, or `Parallel`)
  - new `leaderWorkerTemplate.maxGroupRestarts` and `leaderWorkerTemplate.restartBackoff`
  - new `Degraded` condition, and annotations plus a pod finalizer used only when `maxGroupRestarts` is set
  - the CRD now defaults `spec.rolloutStrategy` to `{type: RollingUpdate}`
- Tested locally:
  - `go build ./...`
  - unit tests in `pkg/controller/jobs/leaderworkerset`, `pkg/controller/jobs/statefulset` and `pkg/controller/tas`
  - integration tests in `test/integration/singlecluster/controller/jobs/leaderworkerset` (5/5) and `test/integration/singlecluster/webhook/jobs` (80/80)
  - `make ci-lint` (0 issues)
  - `make verify`
- AI disclosure: Claude Code helped prepare this change. I reviewed and tested it.
