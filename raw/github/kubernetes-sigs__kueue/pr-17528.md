## Description

#### What type of PR is this?

#### What this PR does / why we need it?
The `kueue-alpha` entry in `hack/genref/config.yaml` was commented out because
`apis/kueue/v1alpha1` had no types. It now defines `CapacityProvider`,
`DynamicQuotaOrchestrator` and `PreemptionConfig`, but they are missing from the
API reference.

This enables the entry and adds the generated `kueue.v1alpha1.md`, served at
`/docs/reference/kueue.v1alpha1/` as suggested in the issue. The entry is named
`kueue` (not `kueue-alpha`) so the page name matches that URL and the
`kueue.v1beta2.md` convention.

Fixes #17498

#### Useful notes for your reviewer
- Generated with genref v0.28.0 (the version pinned in `hack/tools`). Re-running it with
  the unchanged config reproduces the existing reference pages byte for byte.
- All 65 in-page anchors in the new page resolve.
- Sidebar order: the reference pages have no `weight`, so the new page sorts by title
  and lands just before "Kueue v1beta2 API" rather than after it. Happy to add a weight
  if you prefer a specific position.
- Open PRs that change `apis/kueue/v1alpha1` (e.g. #17523, #16684) will need to
  regenerate this page after this merges; `make verify` will flag it.
