/kind bug

#### What this PR does / why we need it?

`useWebSocket` kept the data of the previous URL until the new socket sent its first message, so a page that switched to another object showed the old one in the meantime.

The hook now resets `data` and `error` when the URL changes, and ignores events from the previous socket after cleanup.

Fixes #17531
