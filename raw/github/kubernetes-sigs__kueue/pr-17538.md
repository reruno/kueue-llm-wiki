#### What this PR does / why we need it?

"Pod Sets Count" on the workload detail page and in the Workloads page tooltip showed the pod count of the first pod set only.

It now shows the number of pod sets. A new "Pod Count" line shows the pods summed over all pod sets, as the dashboard already does. The sum lives in `podCount` in `utils/workloadStatus.js`.

Fixes #17534

#### Useful notes for your reviewer

- Added `podCount` tests for no, one and several pod sets.
- Ran `npm test` (117 tests pass) and `npm run build` in `cmd/kueueviz/frontend`.
