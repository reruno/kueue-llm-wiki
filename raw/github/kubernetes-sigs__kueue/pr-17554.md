#### What this PR does / why we need it?

This PR replaces message-based error assertions in `pkg/cache/scheduler/was/scheduler_simulator_test.go` with sentinel errors and `cmpopts.EquateErrors()`.

- Added sentinel errors in the WAS scheduler simulator: `errFindFeasibleNodesNotAllowed`, `errScheduleWorkloadNotAllowed`.
- Feature-gate guards in `FindFeasibleNode()` and `ScheduleWorkload()` now return these sentinels directly.
- Updated the affected assertions in `TestFindFeasibleNodesWithDeepIntegration`, `TestScheduleWorkloadWithoutDeepIntegration`.

#### Useful notes for your reviewer

- This PR doesn’t follow the issue’s plan to coordinate upstream `scheduler-library` changes because after some consideration with @mbobrovskyi: Making changes to `scheduler-library` would take a long time and force the community to make changes if they’re also checking errors by message. Wrapping `scheduler-library` errors with custom errors in Kueue would still rely on error-message matching.
