#### What this PR does / why we need it?

`TrainJob.PodSets()` dry-run creates a throwaway Workload to default the PodSets, and names it after the TrainJob. A dry-run create still fails with `AlreadyExists` when a Workload with that name exists in the namespace (for example a pod group or a prebuilt Workload with the same name), so every TrainJob reconcile failed and the TrainJob never got its Workload.

This PR uses `generateName` for the throwaway Workload, and adds an integration test that fails with `workloads.kueue.x-k8s.io "trainjob-test" already exists` without the fix.

None
