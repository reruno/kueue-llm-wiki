#### What this PR does / why we need it?
Fixes #17521

Currently, Kueue's deployment webhook prevents updating `kueue.x-k8s.io/queue-name` if `ReadyReplicas > 0`. Because Deployments are handled through the plain Pod integration where each replica pod gets its own workload, changing the deployment queue label updates `spec.template`, triggering a rolling update. New pods queue under the new queue while active pods under the old ReplicaSet keep running until replaced.

This change relaxes the check to allow updating the queue name while `ReadyReplicas > 0`, while still preventing removing the queue name entirely (`newQueueName == ""`).

#### Useful notes for your reviewer
Updated unit tests in `pkg/controller/jobs/deployment` and integration tests in `test/integration/singlecluster/webhook/jobs` to verify that queue updates succeed on active Deployments and that clearing the queue label remains forbidden.
