#### What this PR does / why we need it?

`.github/dependabot.yml` sets no `schedule.day`, so all weekly ecosystems open their PRs together, on Fridays at about 09:33 UTC. A run opens 9 to 14 PRs, and each one starts about 54 presubmits. Over the last 3 months, 7 of 9 incidents with Pod scheduling timeouts fell in that window, and no run with fewer than 10 PRs had timeouts.

This PR sets `schedule.day` so each weekly ecosystem runs on its own day. Go modules, the largest at up to 9 PRs a run, get Tuesday, which had the lowest presubmit load over the last 3 months. Docker runs on Monday, and npm and pip on Wednesday. Thursday stays free for patch releases and the cherry-pick waves after them, and Friday stays free so a failed PR doesn't wait over the weekend.

#### Useful notes for your reviewer

- The weekday differences in load were small, and run size is what predicts timeouts. Runs of 7 to 10 PRs had at most 2 timeouts on any weekday, and every large incident came from a run of 12 or more PRs.
- The daily `github-actions` updates are unchanged, since `.github/` changes skip the presubmits. Cherry-pick waves are not covered here, see #16958.
- This PR was written in part with the assistance of generative AI.
