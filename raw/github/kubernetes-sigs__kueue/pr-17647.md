#### What this PR does / why we need it?

Manual cherry-pick of #16612 to release-0.19, since the automated cherry-pick conflicted on `test/integration/multikueue/suite_test.go`. The production code applies cleanly; the tests are adapted to release-0.19: the MultiKueue integration suite sets up the LeaderWorkerSet reconciler and webhook like the other integrations on this branch, and the unit test uses the release-0.19 `GetMultiKueueAdapters`, `newClustersReconciler` and `reconcile.Request` forms.

Fixes: None

#### Useful notes for your reviewer


#### Release note

```release-note
MultiKueue & LeaderWorkerSet: Fixed a bug where finishing, preempting, or scaling down one group of a LeaderWorkerSet deleted the LeaderWorkerSet on the worker cluster, stopping and recreating the other groups still running there. Kueue now deletes the remote LeaderWorkerSet only after its last group is removed from the worker.
```
