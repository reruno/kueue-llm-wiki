<h3>Feature</h3>

<li>KueueViz: The workloads dashboard now shows the Pods of pod group Workloads, including StatefulSet and LeaderWorkerSet Workloads. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17186">#17186</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>

<h3>Bug or Regression</h3>
<ul>
<li>CLI: Fixed a bug that caused kueuectl create clusterqueue to reject quota specifications with hyphenated resource names. Kueue now accepts these resource names. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16987">#16987</a>, <a href="https://github.com/Dasmat13"><code>@​Dasmat13</code></a>)</li>
<li>CLI: Fixed a bug where <code>kueuectl list workload</code> failed with &quot;resource name may not be empty&quot; when a pending Workload had no <code>spec.queueName</code>. Such Workloads are now listed with empty LocalQueue and ClusterQueue columns. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16986">#16986</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>CLI: Fixed a bug where <code>kueuectl version</code> printed only the client version, without the controller manager image, when Kueue was installed with Helm under a release name other than <code>kueue</code>. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16953">#16953</a>, <a href="https://github.com/Eason09053360"><code>@​Eason09053360</code></a>)</li>
<li>CLI: Fixed a bug where kueuectl list workload --for could list workloads more than once when a paginated job-UID search ended with an empty page. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17084">#17084</a>, <a href="https://github.com/Huangpinhan"><code>@​Huangpinhan</code></a>)</li>
<li>CLI: Skip remote ClusterQueue lookup in create localqueue when using --dry-run=client. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17109">#17109</a>, <a href="https://github.com/Dasmat13"><code>@​Dasmat13</code></a>)</li>
<li>Configuration: Fixed the <code>admissionFairSharing.usageSamplingInterval</code> and <code>admissionFairSharing.resourceWeights</code> validation errors to report the value at the field they name. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16943">#16943</a>, <a href="https://github.com/thc1006"><code>@​thc1006</code></a>)</li>
<li>DRA: Fixed a bug where a Workload updated while the scheduler was processing it could be requeued with quota charges computed for its previous spec, causing over- or under-admission. Kueue now hands such a Workload back to the workload controller to recompute its charges. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17208">#17208</a>, <a href="https://github.com/Anjali-Chauhan1"><code>@​Anjali-Chauhan1</code></a>)</li>
<li>ElasticJobsViaWorkloadSlices: Fixed a bug where an admission retry could cause a zero-count PodSet to lose a suitable flavor and block later scale-up. Kueue now selects a suitable flavor across retries. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17107">#17107</a>, <a href="https://github.com/prash2512"><code>@​prash2512</code></a>)</li>
<li>FairSharing: Fixed the preemption bug where workloads within nominal quota were preempted if the ClusterQueue borrowed on an uncontested flavor or within an internal sub-cohort. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17031">#17031</a>, <a href="https://github.com/akshat-lakhera"><code>@​akshat-lakhera</code></a>)</li>
<li>JobSet: Fixed a bug where an evicted Workload could keep its quota reserved, and was not requeued, if a JobSet restart had recreated child Jobs that had already succeeded. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17215">#17215</a>, <a href="https://github.com/MaysaMacedo"><code>@​MaysaMacedo</code></a>)</li>
<li>KueueViz: Fix the workload Status column showing the first condition type instead of the workload status. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17191">#17191</a>, <a href="https://github.com/onkar717"><code>@​onkar717</code></a>)</li>
<li>KueueViz: Fixed a bug where the backend HTTP server could hang indefinitely during graceful shutdown if active HTTP requests did not complete. The server now enforces a 30-second shutdown timeout. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17198">#17198</a>, <a href="https://github.com/fat-catTW"><code>@​fat-catTW</code></a>)</li>
<li>KueueViz: Fixed indefinite loading on the Local Queues, Cluster Queues, Cohorts, and Resource Flavors pages when no resources are found. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17175">#17175</a>, <a href="https://github.com/weizhoublue"><code>@​weizhoublue</code></a>)</li>
<li>KueueViz: The namespaces websocket now only provides LocalQueue-backed live updates to users with cluster-wide watch access to LocalQueues. Users without that permission still receive the initial namespace snapshot filtered by their list permissions. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17180">#17180</a>, <a href="https://github.com/fat-catTW"><code>@​fat-catTW</code></a>)</li>
<li>Observability: Fixed a bug where <code>kueue_cluster_queue_weighted_share</code> and <code>kueue_replaced_workload_slices_total</code> kept reporting a deleted ClusterQueue, and <code>kueue_cluster_queue_weighted_share</code> kept a stale series with the old <code>cohort</code> label after a ClusterQueue moved to another Cohort. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17239">#17239</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>Observability: Fixed a bug where custom-label updates to a ClusterQueue or LocalQueue could leave stale metric gauge series in Prometheus. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17219">#17219</a>, <a href="https://github.com/akshat-lakhera"><code>@​akshat-lakhera</code></a>)</li>
<li>Observability: Fixed a bug where deleting a ClusterQueue could remove the <code>kueue_cohort_subtree_quota</code> and <code>kueue_cohort_subtree_resource_reservations</code> series of its Cohort while other ClusterQueues or child Cohorts remained in it. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16941">#16941</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>Pod, AppWrapper &amp; Kubeflow Jobs: Fixed a bug where changing the <code>kueue.x-k8s.io/queue-name</code> label of a suspended job to an invalid LocalQueue name was accepted, so the Workload could not move to the new queue and the job reconciler failed on every retry. Kueue now rejects the update. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16972">#16972</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>Pod: Avoid counting a terminating Pod's deletion grace period twice when deciding whether its PodGroup still holds quota. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17077">#17077</a>, <a href="https://github.com/gola"><code>@​gola</code></a>)</li>
<li>Pod: Fixed a bug where, with <code>SkipReassignmentForPodOwnedWorkloads</code> enabled, a Workload owned by a single Pod that was preempted or evicted due to node failures while its Pod was still scheduling-gated (for example while an AdmissionCheck was pending) stayed parked with <code>Requeued=False</code> forever and its Pod was never deleted. Such Workloads are now requeued, and Workloads already left in that state by an earlier version are requeued on upgrade. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17173">#17173</a>, <a href="https://github.com/nsega"><code>@​nsega</code></a>)</li>
<li>Pods: Fixed a bug where a Pod could bypass ClusterQueue quota by setting the kueue.x-k8s.io/role-hash annotation to another role's value and running an oversized Pod under that role's reservation. Kueue now verifies, before removing the scheduling gate, that each Pod of a group fits the effective spec (LimitRange and RuntimeClass adjustments applied) of the PodSet its role hash names; a Pod that does not fit is kept gated and a Warning event is emitted. The gated Pod does not fail the Workload or disturb running peers, but the group cannot become PodsReady until the Pod is replaced by one that fits; with waitForPodsReady, the Workload is evicted and requeued (up to the requeue limit).
The check is controlled by the Alpha PodIntegrationVerifyRoleRequests feature gate, disabled by default on this release. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17123">#17123</a>, <a href="https://github.com/vladikkuzn"><code>@​vladikkuzn</code></a>)</li>
<li>RayService: Fixed webhook validation errors referencing <code>spec.rayClusterSpec</code> instead of the actual API field <code>spec.rayClusterConfig</code>. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17097">#17097</a>, <a href="https://github.com/cryo-zd"><code>@​cryo-zd</code></a>)</li>
<li>Scheduling: Fixed a bug that could prevent ClusterQueues in the same tree from requeueing workloads when quota became available after a Cohort cycle was resolved. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17079">#17079</a>, <a href="https://github.com/henry3260"><code>@​henry3260</code></a>)</li>
<li>Scheduling: Fixed a bug where a Workload that needed to borrow quota could not preempt Workloads in its own ClusterQueue, even when withinClusterQueue allowed preemption. Kueue now preempts those Workloads. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17010">#17010</a>, <a href="https://github.com/zhengchenyu"><code>@​zhengchenyu</code></a>)</li>
<li>SparkApplication: Fixed a bug where a SparkApplication without <code>spec.executor.instances</code> could not be suspended when its Workload was evicted or deactivated, because Kueue wrote back an invalid <code>instances: 0</code>. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16968">#16968</a>, <a href="https://github.com/tenzen-y"><code>@​tenzen-y</code></a>)</li>
<li>TAS: Fixed a bug where a workload with non-adjacent PodSet group members (for example, a JobSet) could start with another PodSet's labels and node selectors, leaving some Pods scheduling-gated. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17089">#17089</a>, <a href="https://github.com/apullo777"><code>@​apullo777</code></a>)</li>
<li>TAS: Fixed a bug where topology preemption could exclude workloads on overlapping TAS flavors, even when removing them could make the incoming workload fit. With <code>TASHandleOverlappingFlavors</code> enabled, Kueue now considers those workloads as candidates. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16919">#16919</a>, <a href="https://github.com/Nilsachy"><code>@​Nilsachy</code></a>)</li>
<li>TAS: Fixed a bug with <code>FlavorFungibilityPreserveScanProgress</code> enabled where workloads using <code>TryNextFlavor</code> could repeatedly retry a topology-blocked <code>ResourceFlavor</code> or skip viable borrowing flavors across scheduling cycles when all flavors required borrowing or when a later flavor had nominal quota. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17070">#17070</a>, <a href="https://github.com/j-skiba"><code>@​j-skiba</code></a>)</li>
<li>TAS: Improved required-topology placement failure messages to identify the required level and explain that all Pods must fit in a single topology domain. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17172">#17172</a>, <a href="https://github.com/HasonoCell"><code>@​HasonoCell</code></a>)</li>
<li>Workload: Fixed the validation message shown when changing <code>spec.maximumExecutionTimeSeconds</code> on an admitted Workload to say &quot;immutable while the workload is admitted&quot; instead of &quot;while workload quota reserved&quot;. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/16946">#16946</a>, <a href="https://github.com/thc1006"><code>@​thc1006</code></a>)</li>
<li>Workload: Reject negative Pod overhead when WorkloadValidateResourcesAreNonNegative is enabled. (<a href="https://redirect.github.com/kubernetes-sigs/kueue/issues/17201">#17201</a>, <a href="https://github.com/nareshpatel1015"><code>@​nareshpatel1015</code></a>)</li>
</ul>
