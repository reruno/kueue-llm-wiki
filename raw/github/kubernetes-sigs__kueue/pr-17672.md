#### What this PR does / why we need it?

Manual cherry-pick of #17640 to release-0.19, since the automated cherry-pick conflicted on `pkg/controller/jobs/mpijob/mpijob_webhook_test.go`. The production code applies cleanly; the conflict was only with `TestValidateUpdate` cases that are not on release-0.19, so they are left out.

#### Useful notes for your reviewer


#### Release note

```release-note
TAS: Fixed a bug where an MPIJob with `runLauncherAsWorker` that set `kueue.x-k8s.io/pod-index-offset` alongside `kueue.x-k8s.io/podset-group-name` was admitted but never started, while holding quota. Kueue now accepts `"1"`, which matches the offset implied by the PodSet group, and rejects other values; remove the annotation from existing MPIJobs that use another value.
```
