#### What this PR does / why we need it?

`FindLatestAdmittedWorkloadForSlice` and `FinishReplacedWorkloadSlices` duplicate the same namespace-scoped lookup using the workload slice name index. Extract a private `listMatchingWorkloadSlices` helper that lists the chain and filters it with a caller-provided `keep` predicate using `slicesutil.Pick`.

The admission lookup supplies its admission, finished, eviction, and concurrent-admission variant conditions. Replacement cleanup excludes finished slices before collecting replacement relationships and finishing predecessors. Ordering, replacement semantics, and error handling remain unchanged.

Related discussion: https://github.com/kubernetes-sigs/kueue/pull/17643#discussion_r4356923916
