#### What this PR does / why we need it?

Simplifies the PodGroup cleanup in `wasPlanner.addPodGroups`, as requested by https://github.com/kubernetes-sigs/kueue/pull/17605#discussion_r4350263656.

- The PodGroups and CompositePodGroups that were added to the simulator are now tracked in slices.
- The `revert` closure removes tracked PodGroups and CompositePodGroups.
- The closure is now also used after an add failure, replacing the three rollback `for` loops in the add paths.
