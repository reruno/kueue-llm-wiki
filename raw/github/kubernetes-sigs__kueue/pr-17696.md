<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/gohugoio/hugo/releases">github.com/gohugoio/hugo's releases</a>.</em></p>
<blockquote>
<h2>v0.168.0</h2>
<h2>Notable new features</h2>
<ul>
<li>New <a href="https://gohugo.io/configuration/imaging/#firstframeonly"><code>imaging.firstFrameOnly</code></a> option (and a matching processing flag) to only decode/encode the first frame of animated images. Hugo now also only decodes the first frame when the target format doesn't support animation, and fails early with an informative error if processing all frames would exceed the WASM memory limit.</li>
<li>New <a href="https://gohugo.io/methods/resource/framecount/"><code>FrameCount</code></a> method on images, e.g. to check if an image is animated.</li>
<li><a href="https://gohugo.io/methods/site/language/"><code>site.Language</code></a> now has <code>Translate</code> and <code>Format*</code> methods, so you can e.g. range over <code>site.Languages</code> and translate into each language.</li>
<li>New <code>charset</code> option for <a href="https://gohugo.io/functions/js/build/"><code>js.Build</code></a> and <a href="https://gohugo.io/functions/css/build/"><code>css.Build</code></a>.</li>
<li>Basic support for the OSC 7501 program status (working/done/idle/error) in terminals that support it, alongside the existing OSC 9;4 progress.</li>
</ul>
<h2>Security fixes</h2>
<p>This release is built with Go 1.27.2, which includes <a href="https://seclists.org/oss-sec/2026/q4/101">15 security fixes</a>. The most relevant for Hugo are:</p>
<ul>
<li>Two <code>html/template</code> escaping fixes, which also apply to Hugo's fork of the package: <a href="https://redirect.github.com/golang/go/issues/81821">CVE-2026-94448</a> (context tracking not reset on consecutive expressions in JS template literals) and <a href="https://redirect.github.com/golang/go/issues/81823">CVE-2026-97030</a> (<code>yield</code> not recognized as a regexp preceder keyword). Both could lead to incorrect escaping of inline JavaScript.</li>
<li>Several <code>net/http</code> fixes (HTTP/2 server crash and memory exhaustion, connection desynchronization, unbounded <code>Range</code> header parsing), relevant for <code>hugo server</code> and remote resources. The corresponding HTTP/2 fixes are also included via the upgrade of <code>golang.org/x/net</code> to v0.61.0.</li>
<li><a href="https://redirect.github.com/golang/go/issues/81739">CVE-2026-56857</a>: <code>os.Root.Mkdir(All)</code> could follow junctions out of the root on Windows.</li>
</ul>
<p>Also:</p>
<ul>
<li><code>github.com/tdewolff/minify</code> is upgraded to v2.24.19, which fixes <a href="https://github.com/tdewolff/minify/releases/tag/v2.24.18">GHSA-3ppm-p7r9-c5w3</a>: <code>&lt;/script&gt;</code> (and <code>&lt;!--</code>) inside inline scripts was not properly escaped (case-insensitively) when minifying JS in HTML.</li>
<li>Hugo now ignores <code>module.replacements</code> defined in themes; only the project can define replacements.</li>
</ul>
