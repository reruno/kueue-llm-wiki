#### What this PR does / why we need it?

Cherry-pick #17690 to release-0.19.

Extract `listMatchingWorkloadSlices` with a caller-provided `keep` predicate and reuse it in `FindLatestAdmittedWorkloadForSlice`. The existing filtering and latest-slice selection behavior remain unchanged.

#### Useful notes for your reviewer

Conflicts were resolved for release-0.19:

- Preserve the existing `excludeVariants bool` API; this branch does not have the options API from main.
- Omit the replacement-cleanup call-site change because `FinishReplacedWorkloadSlices` does not exist on this branch. The helper therefore has one caller on release-0.19.

Validation: `go test ./pkg/workloadslicing/...` and `git diff --cached --check` passed.
