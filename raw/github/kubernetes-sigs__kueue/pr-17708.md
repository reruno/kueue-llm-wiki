## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Fixes #17707

Adds `cohort` (alias: `co`) and `topology` (alias: `topo`) to `kueuectl`'s pass-through commands (`get`, `describe`, `edit`, `patch`, `delete`).

Both `Cohort` and `Topology` are core CRDs under the `kueue.x-k8s.io` group, but running `kueuectl get cohort` or `kueuectl describe topology` previously resulted in an `unknown command` error.

Also includes integration tests and updated reference documentation.

#### Useful notes for your reviewer

- Added Cohort and Topology cases in `test/integration/singlecluster/kueuectl/passthrough_test.go` covering pass-through commands with their aliases (`co`, `topo`) against kubectl.
- Auto-generated documentation was regenerated with `make generate-kueuectl-docs`.
