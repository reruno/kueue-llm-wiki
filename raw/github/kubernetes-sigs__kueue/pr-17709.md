## Description

## Summary

Manual backport of #17523 to `release-0.20`, addressing the automated cherry-pick conflict reported after the original PR merged.

## Changes

- Reject stale `CapacitySynchronized=True` conditions when `ObservedGeneration` differs from the provider's current `metadata.generation`.
- Report `ProviderNotReady` with generation-specific diagnostics.
- Preserve previously applied effective quotas when capacity discovery is not ready.
- Backport regression tests for stale, current, missing-generation, failed-synchronization, and mixed-provider scenarios.
- Update API comments, CRD descriptions, and KEP documentation.

## Release-specific adaptations

Resolved the `discovery.go` conflict against the release branch's existing implementation without introducing unrelated main-branch capacity-limit changes.

Restored two test helpers required by the backported regression tests but absent from `release-0.20`.
