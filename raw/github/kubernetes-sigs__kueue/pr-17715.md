#### What this PR does / why we need it:
Expands docs and adds an integration test demonstrating how to configure shared license quotas across multiple compute flavors using dedicated ResourceGroups in a ClusterQueue.

Fixes #17684

This covers:
- An integration test showing a ClusterQueue with two ResourceGroups (`cpu` on on-demand/spot, and `example.com/license` on a headless flavor). It verifies that workloads on different compute flavors share the license pool, that jobs without license requests can still be admitted when licenses are full, and that pending jobs get admitted once a license is released.
- A new use-case section in the `share_quotas_across_flavors` doc with full YAML examples (ResourceFlavors, ClusterQueue, and sample Job).
- Clarification on pod schedulability when using extended resources in Kubernetes.
