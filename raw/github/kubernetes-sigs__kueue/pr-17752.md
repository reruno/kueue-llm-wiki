#### What this PR does / why we need it?

This PR replaces message-based error assertions in `pkg/cache/scheduler/was/virtual_podgroups_test.go` and `pkg/cache/scheduler/was/virtual_pods_test.go` with sentinel errors. It follows #17554, which did the same but for `scheduler_simulator.go` only.

- Added three sentinel errors in `virtual_podgroups.go`: `errWorkloadIsNil`, `errSliceSizeNotDivisor`, `errNonPositiveSliceSize`.
- Added three sentinel errors in `virtual_pods.go`: `errWorkloadOrPodSetIsNil`, `errMergeResourceFlavor`, `errMergePodSetUpdate`.
- Updated `TestBuildVirtualPodGroups`, `TestCandidateVirtualPodsForPodSet_Validation`, `TestCandidateVirtualPodsForPodSet_NodeSelector` to compare errors via `cmpopts.EquateErrors()`.
