## AI summary

When a fast-admission Pod group has active Pods with different role hashes, Kueue now deactivates the Workload if too few Pods match its declared PodSets. If enough Pods match, Kueue deletes the unmatched Pods and keeps the Workload active.

### Suggested release note

Pod: Fixed a bug where mismatched role hashes in a fast-admission Pod group could leave Pods gated or cause Workload churn. Kueue now deactivates the Workload when too few Pods match its declared PodSets and removes unmatched Pods when enough Pods match.
