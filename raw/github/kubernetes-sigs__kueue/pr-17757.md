## AI summary

When active Pods in a fast-admission Pod group have different role hashes, Kueue deactivates the Workload if too few Pods match its declared count. If enough Pods match, Kueue removes the extra mismatched Pod. This prevents repeated Workload recreation.

### Suggested release note

PodGroup: Fixed a bug that caused repeated Workload recreation when active Pods in a fast-admission group had different role hashes. Kueue now deactivates the Workload when too few Pods match its declared count.
