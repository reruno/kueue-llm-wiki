#### What this PR does / why we need it?

- Merges the ClusterQueue and LocalQueue `stopPolicy` set/unset test helpers into a one set of generic helpers.
- Previously, both helpers did the same work, with the only difference in the queue type. Now there are three (`SetQueueStopPolicy`, `SetQueueStopPolicyWithTimeout`, `UnsetQueueStopPolicy`) helpers that accept both queue types.
- All affected integration and E2E tests were updated to use the new helpers.

### Comment by [@unaimeds](https://github.com/unaimeds) — 2026-10-28T12:03:05Z

After some consideration with @mbobrovskyi, we decided that implementing generic helpers doesn't pay off vs what we have right now.

The helpers end up same size (+28/-32), but four simple typed functions become generics plus a type switch, `**kueue.StopPolicy`, and an unreachable panic.
The constraint and the switch also have to be kept in sync by hand. The call sites don't read any better: `SetClusterQueueStopPolicy(cq, …)` is already clear.

The only real issue is the difference of intervals (`ShortInterval` in `setClusterQueueStopPolicy` vs `Interval` in `setLocalQueueStopPolicy`) which I'll address in a separate PR.
