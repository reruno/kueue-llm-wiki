#### What this PR does / why we need it?

- Merges the ClusterQueue and LocalQueue `stopPolicy` set/unset test helpers into a one set of generic helpers.
- Previously, both helpers did the same work, with the only difference in the queue type. Now there are three (`SetQueueStopPolicy`, `SetQueueStopPolicyWithTimeout`, `UnsetQueueStopPolicy`) helpers that accept both queue types.
- All affected integration and E2E tests were updated to use the new helpers.
