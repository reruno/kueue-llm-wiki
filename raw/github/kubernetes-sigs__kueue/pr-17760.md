#### What this PR does / why we need it?

No presubmit runs `kueue-priority-booster-verify`, so the booster Helm chart is never rendered in CI. This PR makes `kueue-priority-booster-test` run the booster `helm-verify` target before the unit tests, so the existing `pull-kueue-priority-booster-test-unit-main` job catches chart rendering errors without a test-infra change. `go vet` is skipped here because golangci-lint in `pull-kueue-verify-main` already covers it. This follows the approach of #16257.

Related: #11335
