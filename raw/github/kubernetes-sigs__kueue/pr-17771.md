#### What this PR does / why we need it?

The pull-kueue-verify-release-0-20 job failed on PR #17765. During make verify, the gomod-verify target runs go mod tidy, which downloads module zips from proxy.golang.org. While fetching sigs.k8s.io/scheduler-plugins@v0.35.4-devel.zip, the connection was reset (stream error: stream ID 5; INTERNAL_ERROR; received from peer). Go doesn’t retry that, so one dropped download failed the whole step.

NETWORK_INSTALL_RETRY is the helper already defined in hack/make/deps.mk. It runs the command up to 7 times with exponential backoff (2s, 4s, 8s, and so on). If the proxy drops a connection again, go mod tidy is retried instead of failing the job. Modules that already downloaded stay in the cache, so a retry only re-fetches what failed.

Fixes #17768
