#### What this PR does / why we need it?

`buildCohortTree` started from Cohorts without a listed parent, so Cohorts whose parents form a cycle, and their children, were not shown in the tree view. Each cycle is now shown once: one of its Cohorts is detached from its parent and listed as a root.

Fixes #17776

#### Useful notes for your reviewer

- `buildCohortTree` is now exported for the new `Cohorts.test.js`, which covers nesting, a missing parent and a cycle.
- Ran `npm test` and `npm run build` in `cmd/kueueviz/frontend`.

  **Issue: Children that sort alphabetically before a cycle get detached as separate roots**
  
  Because `Cohorts.jsx` sorts `cohortList` alphabetically before calling `buildCohortTree`, the first unvisited Cohort in this loop is not guaranteed to be part of the cycle itself—it can be a normal child Cohort whose parent is in the cycle.
  
  **Example:**
  - `cycle-a` and `cycle-b` form a cycle (`cycle-a` <-> `cycle-b`).
  - `alpha-child` and `zeta-child` both have `parentName: "cycle-a"`.
  
  Since `alpha-child` sorts before `cycle-a`, this loop visits `alpha-child` first, detaches it from `cycle-a`, and renders `alpha-child` as a standalone top-level root (while `zeta-child` stays nested under `cycle-a`).
