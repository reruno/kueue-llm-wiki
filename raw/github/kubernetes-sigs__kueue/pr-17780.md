#### What this PR does / why we need it?

The "Local Queues Using This Cluster Queue" table showed only the LocalQueue name, so LocalQueues with the same name in different namespaces could not be told apart. The table now shows `namespace/name`.

Fixes #17777

#### Useful notes for your reviewer

- Added a render test with two `user-queue` LocalQueues in different namespaces to `MissingNameLinks.test.jsx`.
- Ran `npm test` and `npm run build` in `cmd/kueueviz/frontend`.
