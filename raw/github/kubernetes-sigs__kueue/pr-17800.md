#### What this PR does / why we need it?

In KueueViz's All Namespaces view, adding or deleting resources can change the positions of namespace groups while a user has View YAML open for a Workload or LocalQueue.

The page reuses view state based on group position and resource name rather than identifying each resource by both namespace and name. If a same-named resource in another namespace takes that position, it inherits the open dialog state, and the dialog loads its YAML. The resource being viewed therefore changes without the user selecting another resource. Each resource's view state should remain independent and should not transfer to another resource when list positions change.
