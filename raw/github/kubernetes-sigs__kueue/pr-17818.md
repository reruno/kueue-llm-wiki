#### What type of PR is this?

#### What this PR does / why we need it?

Fixes #17763

In `test/integration/singlecluster/kueuectl/passthrough_test.go`, cluster-scoped objects (`ClusterQueue`, `ResourceFlavor`, `Cohort`, and `Topology`) share fixed names across test runs and aliases. Previously, cleanup only happened via the CLI delete command at the end of each test case. An assertion failure during get or patch left objects behind, causing subsequent alias checks or reruns to fail with `AlreadyExists`.

This registers deferred cleanup using `behavioral.ExpectObjectToBeDeleted(ctx, k8sClient, obj, true)` right after object creation in `DescribeTable`, ensuring objects get cleaned up even on failure while tolerating `NotFound` once the CLI delete command succeeds.

#### Useful notes for your reviewer

- Scoped to cluster-scoped resources (`ClusterQueue`, `ResourceFlavor`, `Cohort`, `Topology`).
- Reuses the existing `behavioral.ExpectObjectToBeDeleted` suite helper.

  `ExpectObjectToBeDeleted` can't take `obj` directly since `client.Object` doesn't satisfy `ObjAsPtr[T]`, but the switch can be dropped by inlining the non-generic equivalent, the same pattern the "Delete the object" step already uses:
  
  ```suggestion

  				gomega.Expect(client.IgnoreNotFound(k8sClient.Delete(ctx, obj))).To(gomega.Succeed())

  					g.Expect(k8sClient.Get(ctx, key, obj)).Should(utiltesting.BeNotFoundError())
  				}, behavioral.Timeout, behavioral.Interval).Should(gomega.Succeed())
  			})
  ```
  
  This also avoids silently skipping cleanup for any type added to the table later, since the current switch has no `default`.
