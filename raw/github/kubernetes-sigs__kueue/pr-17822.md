#### What this PR does / why we need it?

Single-cluster e2e jobs compile the suite inside `ginkgo run`, which only starts after Kueue is deployed, while most of the job's CPU sits idle during cluster bring-up.
This PR starts `ginkgo build` in the background when `e2e-test.sh` starts and runs the compiled `.test` binary once Kueue is ready.
The new `compile_e2e` and `wait_for_compile` timing lines show how long the compile took and how long the run still waited for it.

Time from the start of `e2e-test.sh` to the first spec, and the whole Prow job (median):

| Job | To first spec, before | To first spec, after | Job, before | Job, after |
|---|---|---|---|---|
| `pull-kueue-test-e2e-baseline-main-1-35` | 157s | 115s (-42s) | 646s | 605s (-41s) |
| `pull-kueue-test-e2e-extended-shard-0-main-1-35` | 190s | 146s (-44s) | 690s | 645s (-45s) |

Before: median of 36 successful runs per job from 26 PRs, 2026-10-26 to 2026-10-27.
After: one run of each job on this PR. The background compile took 88s and 129s, and `wait_for_compile` was 0s in both.
