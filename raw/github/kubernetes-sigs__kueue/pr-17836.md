## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

Removes temporary address-taken variables.

#### Useful notes for your reviewer

Go 1.26 lets the [`new`](https://pkg.go.dev/builtin#new) builtin take a value to point to, so a variable declared only to have its address taken right after is no longer needed.

We can use [`ptr.To`](https://pkg.go.dev/k8s.io/utils/ptr#To), but I prefer the `new`.
