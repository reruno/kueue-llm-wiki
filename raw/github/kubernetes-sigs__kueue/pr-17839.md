```release-note
Observability: Updated logging for scheduler, flavor-assignment, and preemption. Scheduler per-Workload messages stay at verbosity level 2 by default and move to level 3 when the `LogLevelForSchedulerMainLoop` feature gate is enabled. The "Workload skipped from admission" message moved from level 0 to level 2, or 3 with the gate.

ACTION REQUIRED: If your dashboards, alerts or log queries depend on Kueue log messages, keys or verbosity levels,
review them before upgrading. For the complete list of logging changes, see https://github.com/kubernetes-sigs/kueue/pull/17746. If you enable the `LogLevelForSchedulerMainLoop` feature gate, set the log level to 3 or higher to keep the scheduler's per-Workload messages.
```
