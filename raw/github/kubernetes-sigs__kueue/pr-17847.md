## Description

#### What type of PR is this?
/kind cleanup

#### What this PR does / why we need it:
Removes `behavioral.SetLocalQueueStopPolicyWithTimeout`. In sequential baseline tests, the long timeout was used to wait for the apiserver to accept webhook requests with the restored `caBundle` rather than testing the queue stop policy.

- Exports `e2e.WaitForWebhookDataPath` to probe the webhook data path directly via dry-run `ResourceFlavor` creation.
- In `default_config_test.go`, adds an explicit step waiting for webhooks to accept requests before calling `SetLocalQueueStopPolicy`.
- In `ha_test.go`, switches to standard `SetLocalQueueStopPolicy` as `WaitForKueueAvailability` already probes the webhook data path.
- Removes `SetLocalQueueStopPolicyWithTimeout` and simplifies `setLocalQueueStopPolicy`.

This prepares #17758.

#### Which issue(s) this PR fixes:
Fixes #17819
