## Description

Manual cherry-pick of #13307. The automated one failed because `fair_strategy.go` does not exist on release-0.19, so the change is applied to the same functions in `preemption.go`. `requestedFlavorResources` reads `workloadUsage.Quota`, matching the release branch.

/assign mimowo

```release-note
FairSharing: Fixed a bug where a workload could be blocked from reclaiming its parent Cohort's nominal quota when that Cohort's DominantResourceShare was inflated by borrowing on an unrelated flavor. The nominal-quota preemption claim is now evaluated at the level where the preemptor's and target's subtrees meet, so descendants of a Cohort get preferential access to the Cohort's own nominal quota, and a ClusterQueue within its own nominal quota no longer preempts across a borrowing parent Cohort.
```

AI disclosure: the port was prepared with Claude Code and reviewed by me.

/kind bug
