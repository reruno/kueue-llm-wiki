#### What this PR does / why we need it?

Config API documentation generation loads `defaults.go` along with the API types. Importing `resourcelock` solely for `LeasesResourceLock` pulls in `client-go/kubernetes` and its generated clients, substantially increasing genref's dependency-loading work.

Use a local constant with the same `"leases"` value and keep the client-go import in the existing defaulting test, where it checks that Kueue's default remains aligned with client-go during dependency upgrades. Defaulting behavior and generated API documentation are unchanged.
