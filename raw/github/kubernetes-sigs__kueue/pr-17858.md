#### What this PR does / why we need it?

Adds `equality.WithIgnoreEmptyContainerImage(podSet, names...)`, a `ComparePodSets` option that tolerates an empty image on named containers of a named PodSet in the stored (second) PodSet. Two non-empty images that differ still count as a change. The tolerance is one-directional. It applies only through `ComparePodSets`/`ComparePodSetSlices`, and only to `Containers`, not `InitContainers`. Repeated calls are merged.

This PR enables #17859, which sets images on the Ray head PodSet sidecar containers. #17859 uses this option so that Workloads stored by older Kueue versions, with an empty sidecar image, are not seen as changed on upgrade. On its own the option has no caller and does not change behavior.

Follow-up to #17601 / #17786.
