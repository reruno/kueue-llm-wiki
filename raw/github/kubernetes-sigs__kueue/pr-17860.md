#### What this PR does / why we need it?

Adds provisioning admission-check integration specs for the Ray head PodSet sidecar image fix in #17859:

- `Should create the ProvisioningRequest for a RayCluster with in-tree autoscaling`
- `Should create the ProvisioningRequest for a RayJob in SidecarMode`
- `Should replace a legacy reserved Workload with an empty submitter image for a suspended RayJob`: checks that a legacy Workload which holds quota but is not admitted is deleted and recreated with the image set.

`suite_test.go` installs the Ray operator CRDs. It also adds an opt-in `runRayControllers` manager option, which sets up the RayCluster and RayJob reconcilers, webhooks and indexes.

Follow-up to #17601 / #17786.

Fixes #18244
