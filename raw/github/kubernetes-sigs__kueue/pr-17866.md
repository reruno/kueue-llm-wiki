#### What this PR does / why we need it?

Local `make verify` runs every generator and check, including four-platform CLI compilation, even when a change only affects documentation or unrelated Go code.

Add explicit `verify-go`, `verify-api`, `verify-cli`, `verify-manifests`, `verify-helm`, `verify-docs`, and `verify-scripts` targets so developers can run the relevant parts during local iteration. Split manifest and CLI artifact recipes while keeping the complete `make verify` and release artifact behavior intact.

Document how to choose scopes and run generators before readers, and update the verification skill accordingly. CLI impact includes shared and platform-specific production dependencies, module dependencies, the license, and the build script; checking only `cmd/` is insufficient. These targets do not inspect Git changes or automatically select work. Scoped targets omit the full pipeline's final Git-clean assertion and do not replace application tests. Build-system and generator-tooling changes, uncertain scope, and explicit requests for full validation still use `make verify`.

Related: #17014. That PR separates CLI compilation into a required CI job; this PR provides explicit scopes for local verification. Both touch CLI recipe extraction and will need reconciliation when merged.

#### Useful notes for your reviewer

Validation against `upstream/main` at `b605d39a1b`:

- Full `make verify`: passed in 92.77 seconds after the selector removal, including generation, lint, Helm checks, ShellCheck, all four CLI platforms, and the final generated-file Git-clean check.

- `make verify-cli CLI_PLATFORMS=darwin/arm64 ARTIFACTS=/private/tmp/kueue-scoped-cli-artifacts`: passed.
- `make verify-manifests`: passed in 32.55 seconds; confirmed its log contains no CLI compilation.
- `git diff --check`: passed.

The standalone CLI and manifest targets were exercised before the documentation/selector removal follow-up; their recipes are unchanged by that follow-up. Timings are local measurements, not CI performance guarantees. Application unit, integration, and cluster E2E suites were not run.
