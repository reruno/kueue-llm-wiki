#### What this PR does / why we need it?
The usage line of `kueuectl delete workload` did not match the arguments the command accepts:
  - It showed a single `NAME`, although the command accepts several names.
  - It suggested that `NAME` and `--all` can be combined, although the command rejects that combination.
  - It did not mention `--all-namespaces` (which only works together with `--all`) or `--namespace`.
