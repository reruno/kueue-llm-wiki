## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`kueuectl list workload` resolves LocalQueues, pending workload summaries, and owner API discovery data for every result page. Repeated references across pages cause redundant API requests.

This change reuses those values, including NotFound results, for one command invocation.

Fixes #17873

#### Useful notes for your reviewer

The cache is scoped to `listAndPrint`, so it does not persist across commands.

The tests cover two-page output and verify that successful and NotFound auxiliary reads are each issued once per key.
