## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

`KUEUECTL_LIST_REQUEST_LIMIT` accepted `0` and negative integers, passing them to the Kubernetes List API.

This change rejects non-positive values before making the request and adds coverage for `0` and `-1`.

Fixes #<issue-number>

#### Useful notes for your reviewer

Validation is in the shared `listRequestLimit` helper, so it applies to all supported `kueuectl list` commands.

Codex was used to help preparing this PR.
