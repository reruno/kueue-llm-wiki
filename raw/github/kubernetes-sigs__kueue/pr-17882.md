#### What this PR does / why we need it?

`setup-e2e-env` builds helm from source (`go install`) in every e2e job, but only the `*-helm` targets, the Spark operator install (`test-e2e-sequential-extended`, `-shard-1`) and the DRA example driver install (`test-e2e-dra-*`, `test-e2e-multikueue-dra`) run helm.
This PR removes `helm` from `setup-e2e-env` and adds it to those targets, so the other e2e jobs skip the build.

Time cost of the 28 e2e presubmits that do not run helm and ran in both PRs, measured from the `make-timing` lines in their build logs:

| | Before (#17419) | After (this PR) |
|---|---|---|
| helm build per job | 35–64 s (avg 43 s) | not built |
| helm build, sum of 28 jobs | 1200 s (20 min) | 0 s |
| avg time from `make` start to e2e suite start | 242 s | 188 s |
| avg job duration | 623 s | 563 s |

The 5 jobs that run helm (DRA ×4, `sequential-extended-shard-1`) still build it; their avg job duration changed from 662 s to 639 s, which shows the run-to-run noise.
