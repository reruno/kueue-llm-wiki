#### What this PR does / why we need it?

`test-integration` builds the `kubectl-kueue` binary on every shard, but only the `singlecluster/kueuectl` suite runs it, and that suite is in shard 0.
Shards 1 to 3 each spend about 70s on a build they never use; shard 2 is the slowest shard, so this also shortens the wait for the whole integration set.
On sharded runs, where `INTEGRATION_TARGET` is an explicit package list, this PR builds `kueuectl` only for the shard that includes the kueuectl suite. Unsharded runs still always build it.
It also drops the dependency from `test-e2e-k8s-main-was`, which runs only `singlecluster/wasapi` and never calls `kubectl-kueue`.

Whole Prow job duration (median):

| Job | kueuectl build, before | Job, before | Job, after |
|---|---|---|---|
| `pull-kueue-test-integration-shard-0-main` | 69s | 594s | 607s (still builds; within the 578s to 618s before range) |
| `pull-kueue-test-integration-shard-1-main` | 71s | 604s | 532s (-72s) |
| `pull-kueue-test-integration-shard-2-main` | 70s | 762s | 707s (-55s) |
| `pull-kueue-test-integration-shard-3-main` | 71s | 599s | 528s (-71s) |

Before: median of 8 successful runs per shard from 7 PRs, 2026-10-28; the build time is the `make-timing` line after `go build ... cmd/kueuectl/main.go`.
After: one run of each job on this PR.
