#### What this PR does / why we need it?

Manually adapted backport of the shared Pod tracker component from #17809 to `release-0.19`, as preparation for the TAS residual occupancy fixes tracked in #16354.

Requested in https://github.com/kubernetes-sigs/kueue/pull/17809#issuecomment-6467071141.

#### Useful notes for your reviewer

Original merge commit: `96e7452dd30a5adbbd4069ae2367cb0f4eb5d179`.

The automated cherry-pick failed because `release-0.19` does not contain the WAS Pod tracker, virtual Pod replacement, or Workload preemption implementation that the original PR refactors.

This backport adds only `podtracker/pod_tracker.go` and `podtracker/pod_tracker_test.go`. Both files are byte-for-byte identical to the original merge commit. The remaining WAS hunks update implementation and test paths that do not exist on this branch, so they are omitted. The existing 0.19 WAS implementation is unchanged.

The tracker has no production callers on `release-0.19` yet. This is a preparatory component backport, rather than the complete original patch or a fix for TAS residual occupancy by itself. Consumer integration and the occupancy fixes belong in subsequent PRs.

Local validation on 2026-10-28, using Go 1.26.6 and the vendored dependencies offline:

- `go test -race -coverprofile=podtracker.cover ./pkg/cache/scheduler/podtracker`: passed, with 98.3% statement coverage. Rechecked with `-count=1`.
- `CGO_ENABLED=0 go test -tags=exclude_scheduler_library ./pkg/cache/scheduler/podtracker`: passed, confirming that the component builds and tests without scheduler-library integration.
- `gofmt -l pkg/cache/scheduler/podtracker` and `git diff --check`: passed.
- `make verify` and `make ci-lint`: both stopped at Makefile line 112 because GNU sed is unavailable locally. Repository-wide verification and golangci-lint have not been completed.
- Integration/E2E tests and dependency vulnerability scanning were not run. This backport changes no runtime integration, APIs, or dependencies.

No migration is required. To roll back, revert this backport commit.
