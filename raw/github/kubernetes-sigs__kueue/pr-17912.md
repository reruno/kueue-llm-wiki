#### What this PR does / why we need it

Manual backport of #17382 to `release-0.19`.

The automated cherry-pick failed because of differences in the surrounding code on the release branch.

This change replaces hardcoded SparkApplication PodSet indexes and counts with three named constants:

- `driverPodSetIndex = 0`
- `executorPodSetIndex = 1`
- `podSetsCount = 2`

The constants are used consistently in `PodSets()`, `RunWithPodSetsInfo()`, and `RestorePodSetsInfo()`.

All release-0.19-specific logic is preserved. No functional or API changes.
