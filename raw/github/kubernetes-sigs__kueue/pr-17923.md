## AI summary

When Workload creation fails with an error other than `AlreadyExists`, Kueue now emits a Warning event with the `FailedCreateWorkload` reason on the owning Job. The event message includes the creation error and is truncated to the event message size limit. Truncation does not split a UTF-8 character. Kueue still returns the original error. Regression tests cover transient and forbidden creation errors, plus message truncation.
