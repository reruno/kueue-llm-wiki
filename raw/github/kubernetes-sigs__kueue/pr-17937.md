## Description

What type of PR is this?

What this PR does / why we need it:
Introduces the `DisableStatefulSetWorkloadNameFallback` feature gate as Beta (enabled by default) targeting GA in v0.22.

When enabled, `findWorkload()` skips the fallback search for legacy workload names without owner UID (`GetWorkloadName("", sts.Name)`). Clusters upgrading with existing legacy workloads can disable this feature gate to maintain fallback adoption until workloads can be migrated.

Which issue(s) this PR fixes:
Part of #17936
