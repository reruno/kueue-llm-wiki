#### What this PR does / why we need it?

This PR updates the `setLocalQueueStopPolicy` test helper to use `ShortInterval` (10ms), like `setClusterQueueStopPolicy` does.
This should make tests run faster in case of retries.

<!--
Use `Fixes #123` for an issue addressed by this PR; it will be closed when the PR merges.
Use `Related:` or `Part of:` to reference an issue without closing it.
-->
Related: #17758, #17602, https://github.com/kubernetes-sigs/kueue/pull/17758#issuecomment-6468471927

#### Useful notes for your reviewer

`setClusterQueueStopPolicy` was updated to use `ShortInterval` in a recent PR. So the only difference between `setLocalQueueStopPolicy` and `setClusterQueueStopPolicy` at the moment is the interval used. This PR removes that difference.
