#### What this PR does / why we need it?

The taint check used `append(podSpec.Tolerations, flavor.Spec.Tolerations...)`.   
When the Workload's tolerations slice has spare capacity, this writes into the Workload object's backing array, and that object is shared with the informer cache.   
This PR uses `slices.Concat` instead. Nothing reads that memory today, so there is no user-visible change.
