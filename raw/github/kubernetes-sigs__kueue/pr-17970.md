#### What this PR does / why we need it?

Adds integration coverage for the `kueueworkload` and `kueueworkloads` aliases of kueuectl's own `delete workload` command (`cmd/kueuectl/app/delete/delete_workload.go`). Until now only the `kwl` alias was exercised, in the `SlowSpec` Workload scenario of `passthrough_test.go`.

Two independent `ginkgo.It` scenarios are added to `test/integration/singlecluster/kueuectl/delete_test.go`, next to the existing standalone-delete scenario:

- `kueuectl delete kueueworkload <name> --namespace <ns> --yes`
- `kueuectl delete kueueworkloads <name> --namespace <ns> --yes`

Each scenario creates a standalone Workload, runs the alias in-process through `app.NewKueuectlCmd` (the same harness the other `delete_test.go` scenarios use), and expects no error. It then asserts that the Workload is gone with `behavioral.ExpectObjectToBeDeleted(ctx, k8sClient, wl, false)`. Because `deleteNow` is `false`, the test does not delete the Workload itself, so the assertion only passes if the command removed it. Test resources are cleaned up by the suite's `AfterEach` (`behavioral.DeleteNamespace`), as for the other scenarios in the file.

Fixes #17897
