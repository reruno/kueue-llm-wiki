<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/go-jose/go-jose/releases">github.com/go-jose/go-jose/v4's releases</a>.</em></p>
<blockquote>
<h2>v4.1.6</h2>
<h2>Fixed Security Issues</h2>
<p>This release contains a fix for <a href="https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q">https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q</a></p>
<h2>Breaking Changes</h2>
<p>The fix for <a href="https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q">https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q</a> involves capping the size of the RSA modulus of keys accepted by JWK parsing. This limit is 4096 bits. If you need this to be higher, set <code>MaxRSAModulusBits</code> before performing any JWK parsing.</p>
<h2>Changed</h2>
<ul>
<li>Reject mismatched JWE CEK lengths by <a href="https://github.com/akshithg"><code>@​akshithg</code></a> in <a href="https://redirect.github.com/go-jose/go-jose/pull/266">go-jose/go-jose#266</a></li>
<li>Add a tests containerfile and threat model by <a href="https://github.com/mcpherrinm"><code>@​mcpherrinm</code></a> in <a href="https://redirect.github.com/go-jose/go-jose/pull/300">go-jose/go-jose#300</a></li>
<li>Fix error message for future issued tokens by <a href="https://github.com/inahga"><code>@​inahga</code></a> in <a href="https://redirect.github.com/go-jose/go-jose/pull/303">go-jose/go-jose#303</a></li>
</ul>
<p><strong>Full Changelog</strong>: <a href="https://github.com/go-jose/go-jose/compare/v4.1.5...v4.1.6">https://github.com/go-jose/go-jose/compare/v4.1.5...v4.1.6</a></p>
<h2>v4.1.5</h2>
<h1>Fixed security issues</h1>
<ul>
<li>cipher/cbc_hmac: don't panic on empty ciphertext (<a href="https://redirect.github.com/go-jose/go-jose/issues/292">#292</a>)</li>
<li>cipher/cbc_hmac: don't panic on invalid key (<a href="https://redirect.github.com/go-jose/go-jose/issues/291">#291</a>)</li>
<li>json: limit stack depth (<a href="https://redirect.github.com/go-jose/go-jose/issues/290">#290</a>)</li>
<li>jwt: reject out-of-range NumericDate values (<a href="https://redirect.github.com/go-jose/go-jose/issues/278">#278</a>)</li>
<li>Check alg against pubkey curve during verify. (<a href="https://redirect.github.com/go-jose/go-jose/issues/293">#293</a>)</li>
<li>Reject malformed Ed25519 JWKs (<a href="https://redirect.github.com/go-jose/go-jose/issues/250">#250</a>)</li>
<li>jws: choose verification key per-signature (<a href="https://redirect.github.com/go-jose/go-jose/issues/243">#243</a>)</li>
</ul>
<h1>Breaking Changes</h1>
<p>In <a href="https://redirect.github.com/go-jose/go-jose/issues/226">#226</a>, we un-exported jose.RandReader. This was used to be able to stub out the randomness function in tests, but is ignored as of Go 1.26 in some APIs, so no longer serves a useful function.</p>
<h1>Changed</h1>
<ul>
<li>Verify OpaqueSigner's Public() return is public (<a href="https://redirect.github.com/go-jose/go-jose/issues/260">#260</a>)</li>
<li>jws: skip signature on ErrJWKSKidNotFound (<a href="https://redirect.github.com/go-jose/go-jose/issues/248">#248</a>)</li>
<li>Handle JWE JSON without protected header (<a href="https://redirect.github.com/go-jose/go-jose/issues/240">#240</a>)</li>
<li>jws: don't strip internal whitespace before parsing JSON (<a href="https://redirect.github.com/go-jose/go-jose/issues/239">#239</a>)</li>
<li>jws: fewer calls to OpaqueSigner.Public() (<a href="https://redirect.github.com/go-jose/go-jose/issues/224">#224</a>)</li>
<li>Return a specific error when parsing empty string (<a href="https://redirect.github.com/go-jose/go-jose/issues/216">#216</a>)</li>
<li>Reject typed nil at Verify time (<a href="https://redirect.github.com/go-jose/go-jose/issues/285">#285</a>)</li>
</ul>
