## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

Fixes #17983

GitHub only applies labels from `.github/ISSUE_TEMPLATE/` automatically when issues are created through the web UI. Because CodeRabbit creates issues via `gh issue create`, template labels (such as `kind/*`) are not added unless passed explicitly.

This PR:
1. Updates `cmd/experimental/skills/kueue-pr-issue-workflow/SKILL.md` to clarify that template labels are only applied automatically in the web form, and `gh issue create` or API calls must pass each label with `--label`.
2. Adds an instruction in `.coderabbit.yaml` (`tone_instructions`) to pass every template label with `gh issue create --label`.
