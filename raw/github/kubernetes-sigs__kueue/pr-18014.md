## Description

#### What type of PR is this?

/kind bug
/area dashboard

#### What this PR does / why we need it?

The ResourceFlavor page built taint and toleration labels from every field, but the API omits empty optional fields. A taint without a value showed `key=undefined (NoSchedule)`, an `Exists` toleration without a key showed `undefined (Exists): undefined`, and a node taint without a value showed `key= (NoSchedule)`.

This adds `formatTaint` and `formatToleration` in `utils/taints.js` and uses them for flavor taints, flavor tolerations and node taints. The format follows `kubectl describe`: `key=value:Effect`, `key:Effect`, `op=Exists`, `for 300s`.

Fixes #18013

#### Useful notes for your reviewer

Tests cover both helpers and a page render with the empty fields. The render test fails on the old code.

/cc danylott akram
