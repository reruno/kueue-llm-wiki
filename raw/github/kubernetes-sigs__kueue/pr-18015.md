#### What this PR does / why we need it?

Manual cherry-pick of #16516 to release-0.19, since the automated cherry-pick #17953 did not build. The production code is the same, plus the `k8s.io/apimachinery/pkg/util/sets` import that `workload.go` does not have on release-0.19. The unit test uses the release-0.19 `GetMultiKueueAdapters`, `newClustersReconciler` and `reconcile.Request` forms, and leaves out the `TestWlReconcileResetsLocalStatus` context from #17420, which is not on release-0.19.

Related: #16516

#### Useful notes for your reviewer


#### Release note

```release-note
MultiKueue: Fixed a bug where the Workload and Job on a worker cluster removed from a MultiKueueConfig kept running after their Workload was evicted and dispatched to another cluster, so the same job could run twice. This fix does not cover a kueue-controller-manager restart before the cleanup completes.
```
