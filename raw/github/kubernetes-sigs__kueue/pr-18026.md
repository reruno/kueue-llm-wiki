#### What this PR does / why we need it?

Manual cherry-pick of kubernetes-sigs/kueue#17801 to `release-0.19`, as requested in https://github.com/kubernetes-sigs/kueue/pull/17801#issuecomment-6518699215.

This defaults the Pod index offset to `0` for grouped PyTorchJob and JobSet components started through AppWrapper when TAS is enabled. Explicit offsets remain unchanged. The fix preserves index-based topology placement instead of falling back to greedy placement.

The automated cherry-pick failed on the integration test imports. This backport retains the required imports and uses explicit `metav1.ObjectMeta` in the two new `Workload` literals for compatibility with the branch's Go 1.26 language version. No other changes were added to the original fix.

#### Useful notes for your reviewer

Source commit: `fb92741a125e056307ed36f5994721238e4eb2fc`.

Validation passed:

```shell
go test -race ./pkg/controller/jobs/appwrapper -count=1
make test-integration INTEGRATION_TARGET=./test/integration/singlecluster/controller/jobs/appwrapper INTEGRATION_NPROCS=1 INTEGRATION_KUEUECTL_DEP= GINKGO_ARGS=--focus=should.place.grouped ARTIFACTS=/tmp/kueue-backport-17801/integration
make ci-lint ARTIFACTS=/tmp/kueue-backport-17801/lint
make verify ARTIFACTS=/tmp/kueue-backport-17801/verify
```

Both added TAS integration specs passed with race detection. The first integration invocation had an incorrectly quoted focus filter. After that was corrected, integration compilation and lint exposed the Go 1.26 incompatibility described above. All checks passed after the compatibility adjustment.

The integration run reported the branch's existing Ginkgo CLI/library patch-version mismatch (`2.32.1`/`2.32.0`). It did not prevent the tests from passing. No real-cluster E2E tests were run.

This backport was prepared with GitHub Copilot assistance.

#### Release note

```release-note
TAS: Fixed a bug that could prevent grouped PyTorchJob and JobSet pods submitted through AppWrapper from receiving index-based topology placement when no pod index offset was set. Kueue now applies the default offset.
```
