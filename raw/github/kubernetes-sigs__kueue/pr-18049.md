#### What this PR does / why we need it?

This is a partial backport of kubernetes-sigs/kueue#17906 to `release-0.19`, limited to the ClusterQueue display fix.

An admitted Workload can retain its original ClusterQueue after its LocalQueue is deleted and recreated with a different ClusterQueue. Workload details previously preferred the current LocalQueue and could show the wrong ClusterQueue.

This PR prefers `status.admission.clusterQueue` when available and skips the LocalQueue lookup. Workloads without a nonempty admission ClusterQueue retain the existing LocalQueue fallback.

#### Useful notes for your reviewer

The authorization changes from the original PR are not included. `release-0.19` only supports authentication and lacks the per-resource authorization layer used by that fix. This PR does not introduce authorization changes.

Regression tests cover admission precedence, skipped LocalQueue lookups, empty admission values, and missing queue names. The existing missing LocalQueue and error cases remain covered.
