#### What this PR does / why we need it?

DRA e2e jobs cloned dra-example-driver and built its image from source on every run. That took about 2 minutes of the ~11 minute `pull-kueue-test-e2e-dra-counter-main` job, and MultiKueue DRA builds it once per cluster.
This PR pulls the released image and Helm chart from `registry.k8s.io` instead. The version still comes from `hack/tools/go.mod`, so dependabot keeps tracking it.
In a local `make test-e2e-dra-counter` run, all 8 specs passed and installing the driver took 6s.

There is no fallback to building from source:
- Since v0.2.0, upstream has pushed each image to `registry.k8s.io` before publishing the GitHub release, and dependabot bumps arrive days later. If an image were missing, only that dependabot PR would fail until the image is published.
- A fallback would rarely run and could break without anyone noticing, for example the `CGO_ENABLED=0` Makefile patch.
- Trade-off: testing an unreleased driver version would need the build step back.
