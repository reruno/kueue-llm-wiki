#### What this PR does / why we need it?
Follow up of #17881

`KUEUECTL_LIST_REQUEST_LIMIT` controls pagination for `kueuectl list`, but it was not described in the command help or website reference.

Document the environment variable and its default value in `kueuectl list --help`, then regenerate the CLI reference.

Related: #17881
