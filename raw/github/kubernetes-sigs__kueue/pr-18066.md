#### What this PR does / why we need it?

`make helm` ran `go install helm.sh/helm/v4/cmd/helm`, which compiles helm from source on every fresh CI pod. In `pull-kueue-test-e2e-dra-counter-main` this took 65s, and every job that uses helm (DRA and Helm e2e, Helm lint/unit tests, artifacts) pays the same cost.
This PR downloads the official release archive from `get.helm.sh`, verifies its sha256 checksum, and skips the download when `bin/helm` already reports `HELM_VERSION`. `HELM_VERSION` still comes from `hack/tools/go.mod`, so dependabot keeps tracking it.
Locally, a fresh `make helm` took 2.6s; `make helm-lint`, `make helm-unit-test` and `make helm-verify` pass. The download and checksum also work in Alpine (busybox `sha256sum`) and Debian containers.
