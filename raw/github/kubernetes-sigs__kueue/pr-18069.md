## Description

#### What type of PR is this?

/kind cleanup
/area testing

#### What this PR does / why we need it?

Increase the default single-cluster Ginkgo process count from four to six within the existing seven-CPU integration CI allocation. Each process has its own envtest API server; suites still execute sequentially.

Keep `INTEGRATION_NPROCS` configurable through the environment and command line, and document the serial override. MultiKueue retains its separate default of three processes. Test scenarios, assertions, race detection, package sharding, timeouts, and CPU allocations are unchanged. The accompanying https://github.com/kubernetes/test-infra/pull/38234 raises memory requests and limits by 2Gi for the corresponding main and patch-release CI jobs.

Related: #17943

#### Useful notes for your reviewer

This worker-count change is independent of the test parallelization in #17947. `INTEGRATION_NPROCS` remains configurable; the final default is six, and MultiKueue retains its separate default.
