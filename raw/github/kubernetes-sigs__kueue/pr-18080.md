#### What this PR does / why we need it?
Refactors workload identifiers from `client.ObjectKey` (`types.NamespacedName`) to `workload.Reference` across the WAS preemption path, scheduling simulator, and pod tracker.

Fixes #17996

#### Useful notes for your reviewer
- `PreemptWorkload` across `Simulator` and `Checker` implementations now takes `workload.Reference`.
- `podsByWorkload` and pod lookup helpers in `pkg/cache/scheduler/podtracker` are updated to key by `workload.Reference`.
- Simulator options, preemption candidates, and victims use `workload.Reference`.
