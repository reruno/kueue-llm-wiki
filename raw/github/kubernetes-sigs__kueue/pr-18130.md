## Description

What type of PR is this?
/kind cleanup

What this PR does / why we need it?
Fixes #17983

GitHub silently drops labels when an issue is created by an author or bot without triage permissions (such as CodeRabbit).

This PR updates `kueue-pr-issue-workflow/SKILL.md` to instruct callers to pass template labels via CLI/API and include the corresponding `/kind <name>` or `/area <name>` command on its own line outside HTML comments in the issue body so Prow applies them.
