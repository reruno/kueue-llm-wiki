## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`TestParseResourceQuotas` in `cmd/kueuectl/app/create/create_clusterqueue_test.go` checked each error twice: `wantErr error` was compared with `cmpopts.EquateErrors()` (i.e. `errors.Is`), and the optional `wantErrMessage string` was compared with `err.Error()`.

This PR replaces both fields with a single `wantErr string`, compared with `err.Error()`, as the other kueuectl tests do (`create_resourceflavor_test.go`, `create_localqueue_test.go`, `list_*_test.go`, ...):

- An empty `wantErr` still means "no error expected".
- The cases that set only a sentinel error (`errInvalidResourcesSpec`, `errInvalidResourceQuota`) now assert the full message.
- The unused `cmpopts` import is dropped.

The sentinel text is already part of every error message, so nothing is lost. Nothing in kueuectl calls `errors.Is` on these sentinels outside the tests.

Fixes #18094

Follow-up to #16632.

#### Useful notes for your reviewer

Test-only change. No production code is modified. The assertion for success cases is now slightly stricter: an unexpected error is reported as a diff against `""` instead of being skipped.
