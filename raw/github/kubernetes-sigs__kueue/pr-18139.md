## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

Migrating from the old chart's YAML default with `controllerManagerConfigYaml: null` and `--reuse-values` succeeds once, but Helm saves the null and subsequent upgrades reject it during schema validation.

Treat null values for `mode`, `controllerManagerConfigYaml`, and `structuredOverrides` as absent in both the Kueue and Populator charts. Update their schemas, configuration selection, rendering tests, and migration documentation. Explicitly empty YAML retains its existing meaning, and incorrect non-null types and unknown keys remain rejected.

Clarify how `--reuse-values`, `--reset-then-reuse-values`, and `--reset-values` handle inherited defaults and saved settings, including how to remove overrides during upgrades.

Fixes #17717

#### Useful notes for your reviewer

This PR covers null handling in the charts and the related upgrade guidance. Upgrade-test infrastructure is tracked separately in #17716.

AI disclosure: Codex assisted with the implementation and PR description.

Helm: Fix subsequent upgrades after migrating manager configuration with null inputs.
