#### What this PR does / why we need it?

The RayService integration had its own `rayServiceReconciler` (struct, `NewReconciler`, `Reconcile`, `SetupWithManager`) that duplicated `jobframework`'s `genericReconciler` line for line: same `For(...).Owns(&kueue.Workload{})`, same role-tracker `LogConstructor`, plus one extra watch on owned `RayCluster`s.

This PR replaces it with `jobframework.NewGenericReconcilerFactory(newJob, <RayCluster owner watch>)`, matching how RayJob already builds its reconciler. `NewReconciler` keeps the same function signature (`jobframework.ReconcilerFactory`), so all call sites, including the integration test suites, are unchanged.

No behavior change.

#### Useful notes for your reviewer

Compare the removed `SetupWithManager` with `genericReconciler.SetupWithManager` in `pkg/controller/jobframework/reconciler.go`; they are identical apart from the setup hook loop.
