#### What this PR does / why we need it?

The `objAsPtr` type constraint of the shared Ray MultiKueue adapter (`pkg/controller/jobs/ray`) embeds both `metav1.Object` and `client.Object`. `client.Object` already embeds `metav1.Object`, so the first entry is redundant. This PR removes it, together with the now-unused `metav1` import.

The constraint's method set is unchanged, so no behavior change.

#### Useful notes for your reviewer

`kubeflowjob.objAsPtr` has the same redundancy; it is left untouched to keep this PR scoped to Ray.
