## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it:

This is a manual cherry-pick of #17865 to release-0.19.

Conflicts came from API differences on release-0.19 (no `integrationManager` on the webhooks), so the webhooks call `jobframework.ApplyDefaultLocalQueueWithManagedJobsNamespaceSelector` as before, wrapped in the new `CanApplyDefaultLocalQueue` check. The integration test also needed the `controllerconstants` import.

#### Which issue(s) this PR fixes:

Fixes #17863

#### Does this PR introduce a user-facing change?

```release-note
Deployment, StatefulSet, and LeaderWorkerSet: Fixed a bug where updates to running objects without a queue-name label were rejected after a default LocalQueue was created. Kueue now applies the default only when the queue-name label can be set.
```
