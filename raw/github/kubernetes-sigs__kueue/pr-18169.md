#### What this PR does / why we need it?
Adds integration tests for LeaderWorkerSet pod template updates in the webhook.

For a LeaderWorkerSet managed by Kueue, the webhook only rejects pod template changes to fields in the pod shape (`utilpod.SpecShape`), such as container requests, ports, tolerations and node selectors. Other container fields can change. Only unit tests and e2e tests (image change only) covered this before, and nothing covered `command`, `args` or `env`.

The new tests in `test/integration/singlecluster/webhook/jobs/leaderworkerset_webhook_test.go` check that:
- changing `command`, `args`, `env` or `image` in the leader and worker container is accepted, with one step per field;
- changing container requests is still rejected with `Forbidden`.
