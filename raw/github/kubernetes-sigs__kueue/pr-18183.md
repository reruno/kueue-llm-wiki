#### What this PR does / why we need it?

The importer deferred each namespace's `End pods list` log until `ListPods` returned. This made the logs appear after all namespaces were processed and in reverse order.

Scope the defer to each namespace listing so the end log is recorded before the next namespace starts. This also preserves the end log when listing fails.

Add unit tests for normal ordering and list errors.

Fix: #18182
