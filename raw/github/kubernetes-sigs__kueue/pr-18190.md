#### What this PR does / why we need it?

Cherry pick of #18133 on release-0.19.

#18133: DRA: share pool eligibility checks and skip invalid ResourceSlice pools

The automated cherry-pick failed with conflicts in test files only. `claims.go`, `counters.go` and the new `pools.go` are the same as on `main`.

Conflict resolution:
- release-0.19 still has the ResourceSlice test builder in `pkg/util/testing` (#16524 moved it to `testingjobs/dra` on `main` and was not backported). The tests use `utiltesting.MakeResourceSlice`, and the new `CounterSet` helper is added there instead of to `testingjobs/dra/wrappers.go`.
- Dropped one `claims_test.go` case, "excludes invalid pools with a counter source". It needs the `mappings` field in the test table, which release-0.19 doesn't have. `pools_test.go` covers the counter source path directly.
- release-0.19 is on Go 1.26, so `pools_test.go` sets the Workload name through `ObjectMeta`.
