## AI summary

Added the `DeclareWorkloadFailureOnUnretriablePodGroups` feature gate. When enabled, an unretriable PodGroup that does not have all Pods succeed produces a Workload with reason `Failed`. When disabled, the previous success outcome remains.

### Suggested release note

**Pod:** When a PodGroup finishes because a Pod is unretriable and not all Pods succeeded, Kueue marks the Workload as `Failed`. This behavior is gated by `DeclareWorkloadFailureOnUnretriablePodGroups`.
