#### What this PR does / why we need it?

Backports the residual TAS Pod accounting fix from #16339 to `release-0.19` as an opt-in Alpha feature.

With `TASResidualPodAccounting` enabled, TAS continues accounting for bound Pods after their Workloads release quota. Scheduling waits for existing eviction/deactivation cleanup instead of preempting unrelated Workloads when releasing those Pods would make the assignment feasible. The backport preserves staged and consecutive victim release, partial admission, flavor-scan behavior and elastic predecessor accounting.

The feature is Alpha and **disabled by default** on this release branch, and requires `TopologyAwareScheduling`. Leaving it disabled preserves reservation-only accounting.

Related: #16337. Backport of #16339.

Release-specific adaptation (no native planner on this branch):

- The existing release-0.19 scheduler and partial-admission reducer are preserved; the residual-release probe is integrated into the scheduler's assignment path instead of the newer planner.
- The existing `NonTasUsageReconciler` is extended for bound TAS Pod lifecycle events instead of introducing a second controller.
- Release-0.19's node-filter-only scheduler-library integration is retained; dynamic Pod simulation and DRA APIs that do not exist on this release branch are not backported.
- The feature dependency uses the existing release-0.19 validation helper; behavioral tests enable the gate explicitly and default-off coverage is retained.
- The unrelated failed-node replacement changes from #15263 are not bundled.

The backport carries the full change set: residual Pod usage accounting in the cache and snapshot, the extended `NonTasUsageReconciler` TAS branch and event predicates, workload controller hooks, the flavorassigner topology split with the `WaitingForResidualTASPods` marker, the scheduler residual-release probe in the assignment path, the feature gate with dependency validation, documentation and feature-gate reference updates, and the unit and integration test suite adapted to this release branch.
