#### What this PR does / why we need it?

Combines two changes on upstream main at `77e324c000deba3f35890d3871196f4bde3a961b` as exactly two commits for combined CI validation:

- Add the alpha, disabled-by-default `MultiKueueClusterNames` feature gate and `kueue.x-k8s.io/multikueue-cluster-names` annotation, intersecting requested worker clusters with those authorized by the Workload's MultiKueueConfig.
- Skip remote Workload reads when reconciling a replaced elastic workload slice that is not being deleted. Deletion still cleans up remote objects.

Related: https://github.com/kubernetes-sigs/kueue/pull/18232
Related: https://github.com/kubernetes-sigs/kueue/pull/18211
