#### What this PR does / why we need it?

`SetupRayClusterWebhook` and `SetupRayServiceWebhook` call `jobframework.ProcessOptions(opts...)`, which already applies every option, and then loop over `opts` again to apply each one a second time. This PR removes the extra loop, matching `SetupRayJobWebhook` and the other integrations' webhooks.

All `jobframework.With*` options only assign fields, so applying them twice had the same result as applying them once. There is no behavior change.
