## AI summary

The WAS simulator now maps each pod result to one of three placements. A successful pod gets a node placement. A pod with error status gets an error-only placement. Other failed pods get a reasons-only placement.

The WAS planner stops before the preemption fallback when any pod failure has an error. It returns those failures directly. Failures with only reasons still resolve to preemption, unless the Workload has unhealthy nodes.
