## Description

/kind bug

#### What this PR does / why we need it?

StatefulSet and LeaderWorkerSet pods are created without a pod group name, so the pod create event queues a single-pod reconcile request. The StatefulSet or LeaderWorkerSet reconciler sets the group name shortly after, and that update event queues the group request. When the pod controller reached the stale single-pod request, `Load` returned a retryable error, so controller-runtime requeued it with backoff until the pod was deleted. This PR makes the error unretryable so the stale request is dropped.

#### Useful notes for your reviewer

#### Release note

```release-note
Pod: Fixed a bug where a stale single-pod reconcile request for a Pod that joined a pod group after creation, such as a StatefulSet or LeaderWorkerSet Pod, was retried with backoff until the Pod was deleted, repeatedly logging `got a single pod reconcile request for a pod group`.
```
