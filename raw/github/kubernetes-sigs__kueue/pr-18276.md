#### What this PR does / why we need it?

Cherry-pick of #18232 onto release-0.19.

MultiKueue skips remote Workload reads when reconciling a replaced elastic workload slice that is not being deleted. This reduces reconciliation overhead that can delay dispatching new Workloads after a manager restart or worker reconnect. Deleting a replaced slice still cleans up remote objects.

#### Release note

```release-note
MultiKueue: The manager no longer reads remote Workloads from worker clusters when it reconciles an elastic workload slice that was replaced by a newer slice. Many such slices could delay dispatching new Workloads after a manager restart or a worker reconnect.
```
