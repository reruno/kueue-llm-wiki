  For community transparency, let me quickly clarify this file structure.
  
  We decided to leave the approval of JobFramework interface files (interface.go and multikueue.go) to the repository's top-level approver.
  
  Because those require more stability than internal logic, since this is exposed to external repositories, and we assume that those interfaces are leveraged as externalFrameworks controllers in ecosystem repositories more and more.
