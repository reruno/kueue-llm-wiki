#### What this PR does / why we need it?

Combines three changes on upstream main at `7a49b15b8` for combined CI validation. Not meant to be merged.

- `35a5cb61a`: the annotation commit, picked from `d35e9498b` in #18280 (originally `31bd887b194fab9bee6dac33601e32c08384a49b`). It adds the alpha, disabled-by-default `MultiKueueClusterNames` feature gate and the `kueue.x-k8s.io/multikueue-cluster-names` annotation.
- `3648e2a1a`: the commits of #18277 at `8d0489371`, squashed into one commit with the same final diff. MultiKueue sets the `RemoteObjectsRemoved` condition once the remote objects of a finished Workload are removed from every worker, and then skips the worker reads for that Workload.
- `56cba702c`: the commits of #18236 at `c4c8a1023`, squashed into one commit with the same final diff. The manager opens its watches on worker clusters with a 2 hour timeout instead of the API server's 30–60 minute default.

Related: #18277, #18236, #18280, #14539
