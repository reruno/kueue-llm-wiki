#### What this PR does / why we need it?

Step 1 of the `kueue-flake-debugger` skill collects Prow links with `gh issue view ISSUE --repo kubernetes-sigs/kueue --comments --json comments,url`. gh rejects `--comments` together with `--json`, prints "specify only one of --comments or --json" with the help text, and exits 1, so the agent gets no issue data.

This PR drops `--comments` and asks for `--json body,comments,url`. The body is needed too, since `FLAKE.md` puts the link to the failed CI job there.

Fixes #18291
