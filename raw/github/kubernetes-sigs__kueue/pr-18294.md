</ul>
<h2>Fixes</h2>
<ul>
<li>The injected stylesheet is prepended to <code>&lt;head&gt;</code> again, so CSS variable overrides
work without <code>!important</code> (regression in 11.1.0). Thanks <a href="https://github.com/Aakashpai"><code>@​Aakashpai</code></a>, <a href="https://redirect.github.com/fkhadra/react-toastify/issues/1295">#1295</a>.
Closes <a href="https://redirect.github.com/fkhadra/react-toastify/issues/1287">#1287</a>.</li>
</ul>
<h2>Internal</h2>
<ul>
<li>Build migrated from tsup to tsdown. Publish layout unchanged.</li>
<li>tsconfig: dropped deprecated <code>baseUrl</code>, scoped to library sources.</li>
<li>CI: latest Node LTS, pnpm 12.</li>
<li>Playground: type fixes, <code>none</code> transition option.</li>
</ul>
<p>Thanks to <a href="https://github.com/Aakashpai"><code>@​Aakashpai</code></a> and reporters of the fixed issues.</p>
