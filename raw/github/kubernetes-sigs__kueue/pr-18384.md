#### What this PR does / why we need it?

Removes `ginkgo.Ordered` from 14 single-cluster integration test files (Job, JobSet, Pod, failover, resource transformations, scheduler).

- Setup from `BeforeAll`/`AfterAll` moves into `BeforeEach`/`AfterEach`, so each spec starts and stops its own manager.
- The manager is stopped with `ginkgo.DeferCleanup(fwk.StopManager, ctx)`. It runs after all `AfterEach` cleanup, so objects with finalizers are deleted while the manager is still running.
- The shared `unmanaged-ns` namespace in the Job and JobSet tests is replaced by a generated namespace per spec.
- The `staticNameTB` wrapper in the Pod tests is removed, since `features.SetFeatureGatesDuringTest` does not use the test name.

  Without `Ordered`, this container's specs no longer see a fixed config. `backoffBaseSeconds`, `backoffLimitCount` and `waitForPodsReadyRecoveryTimeout` are closure vars that `JustBeforeEach` reads, but most nested `BeforeEach` blocks set only some of them. So the manager config for a spec now depends on which spec ran last in the same ginkgo process (`test-integration-run` uses `-procs=5`).
  
  From the code (I have not seen it fail):
