## Description

#### What type of PR is this?

/kind cleanup
/area testing

#### What this PR does / why we need it?

Most `hack/testing/retry.sh` callers repeat `--attempts 7 --delay 2 --exponential`. This PR makes those settings the defaults and removes them from callers, including the Dockerfiles and `cmd/experimental` Makefiles that the issue does not list.
`--exponential` is replaced by `--no-exponential`, because webhook endpoint polling (`--attempts 150 --delay 2`) must keep a constant delay. No caller relied on the old defaults, and callers with their own attempts and delay keep them.
The new `hack/testing/retry_test.sh` covers the defaults and overrides and runs in `make verify`. `e2e-common_test.sh` now also checks that polling keeps a constant delay.

Fixes #18383

#### Useful notes for your reviewer

| Behavior | Level | Command / result |
|---|---|---|
| New defaults (7 attempts, 2s, backoff), overrides, `--no-exponential`, fractional delay | shell unit | `make verify-retry-test`: pass. With integer doubling, the fractional case stops after 1 attempt and fails. |
| Webhook endpoint polling keeps a constant 2s delay | shell unit | `bash hack/testing/e2e-common_test.sh` (the `verify-e2e-common-test` recipe): pass. Without `--no-exponential`, it fails with delays `2 4`. |

Both targets run in `make verify` (`verify-checks`).
