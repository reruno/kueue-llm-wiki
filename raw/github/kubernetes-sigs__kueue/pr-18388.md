#### What this PR does / why we need it?

The tool installer writes logs to `.cache/tool-installation` in the repository, but neither `.gitignore` nor `.dockerignore` covers that path. The logs show up as untracked files, `git add -A` commits them, and they enter the Docker build context through `COPY . .`.
This PR ignores `.cache` in both files. A new test in `install_test.py`, which runs in `make verify`, checks that the default log path stays ignored by git.

Related: #18137
