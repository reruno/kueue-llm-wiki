#### What type of PR is this?

#### What this PR does / why we need it?

`site/data/labels_and_annotations.yaml` is the source for the rendered labels and annotations reference table. Three keys that the controllers read or write were not listed, so they were invisible to users searching the reference:

- `kueue.x-k8s.io/concurrent-admission-parent`: the label the ConcurrentAdmission controller puts on a parent Workload. Variants do not carry it.
- `kueue.x-k8s.io/elastic-job-scale-up-strategy`: the annotation that selects `atomic` or `partial` scale-up for an elastic Job, and the conditions the webhook enforces when `ElasticJobsViaWorkloadSlicesWithPartialReplicaScaleUp` is enabled.
- `kueue.x-k8s.io/multikueue-worker-workload-pod`: the label Kueue adds to Pods it creates for a Workload that carries `kueue.x-k8s.io/multikueue-origin` on a worker cluster.

Each entry follows the existing format with type, example, `used_on`, and a description. The YAML parses and each key appears exactly once.

Fixes #18312

#### Useful notes for your reviewer

The descriptions are taken from the constants and from the pages that already document the features (`concepts/concurrent_admission.md`, `concepts/elastic_workload.md`).
