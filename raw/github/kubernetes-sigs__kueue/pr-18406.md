#### What this PR does / why we need it?

`(*WorkloadReconciler).markDRAInadmissible` returned `(bool, ctrl.Result, error)`, but every return path used `true` and `ctrl.Result{}`. Its four callers either passed these constants through as `done`/`result` or discarded them with `_`.

This PR changes it to return only `error`. The callers now set `done=true` and `ctrl.Result{}` directly. This follows the same pattern as #18335.

No behavior change.
