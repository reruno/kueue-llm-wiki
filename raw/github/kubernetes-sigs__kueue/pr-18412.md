## Description

#### What type of PR is this?

/kind cleanup
/area integrations

#### What this PR does / why we need it?

The StatefulSet reconciler looked up the Workload before checking whether another framework, such as LeaderWorkerSet, manages the StatefulSet, and then discarded the result.
Pod events of LeaderWorkerSet-owned StatefulSets still reach this reconciler, so each of them paid for a lookup it did not need, and a failed lookup returned an error and retried.
This PR checks the framework first, so these StatefulSets return without the lookup.
