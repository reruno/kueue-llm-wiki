#### What this PR does / why we need it?

Clarifies how Kueue evaluates candidate `ResourceFlavors` against Pod `.nodeSelector` and `.affinity.nodeAffinity.requiredDuringSchedulingIgnoredDuringExecution`.

Specifically:
- Clarifies that candidate `ResourceFlavors` evaluate only against the label keys declared in the flavor's `.spec.nodeLabels` (non-contradiction matching), rather than requiring all keys declared on the Pod.
- Adds an evaluation comparison table contrasting Kueue flavor evaluation with Kubernetes `Node` evaluation.
- Adds a warning and best practices for avoiding unintended admissions when using disparate label keys across mutually exclusive sibling flavors in the same `resourceGroup` (using shared keys with distinct values or configuring `ResourceFlavor` `nodeTaints` and `tolerations`).

Fixes #15136

This documentation addition directly incorporates the matrix table and recommendations discussed in #15136.
