#### What this PR does / why we need it?
Self-nominate @vladikkuzn as a reviewer for the areas below. As discussed with @mimowo and @mbobrovskyi.

### Integrations
Self-nominate @vladikkuzn as a reviewer for the Pod, Deployment, StatefulSet and LeaderWorkerSet integrations (`pkg/controller/jobs/{pod,deployment,statefulset,leaderworkerset}`), using new `*-integration-reviewers` aliases next to the approver aliases added in #18191.

- #13960: fix(pod): refuse adopting and finalizing foreign Workloads by pod group name (authored)
- #13382: fix(pod): verify role requests before ungating a pod group (authored)
- #2813: [jobframework] Deployment integration (authored)
- #3001: StatefulSet integration (authored)
- #3515: LeaderWorkerSet integration (authored)
- #8670: Add MultiKueue support for LeaderWorkerSet (reviewed)

### Infra
Self-nominate @vladikkuzn as a reviewer for `hack/` and the root `Makefile`, using a new `infra-reviewers` alias next to `infra-approvers`.

- #1920: [makefile] Support for sed on Darwin (authored)
- #8731: Parallel `make verify` (authored)
- #8988: Re-enable running make verify in parallel #8906 (authored)
- #17039: Render unit coverage in Prow's coverage view (authored)
- #18140: Update FUZZTIME TODO to reference Go 1.28 (authored)
- #9362: Automate adding kind/* labels to cherry-pick PRs (authored)

### Experimental tools
Self-nominate @vladikkuzn as a reviewer for `cmd/experimental/kueue-priority-booster` via `kueue-priority-booster-reviewers`, and add @vladikkuzn to `agent-reviewers`. The `agent-reviewers` alias also covers root `AGENTS.md` (existing root filter) and `cmd/experimental/skills`.

- #9959: Kueue priority booster (authored)
- #17037: Require release-note, test rows, and gate checks before opening a PR. (authored)
- #18178: Skills: add kueue-pr-evidence-state-diff and the shared PR evidence helpers (authored)
- #18334: Add kueue-pr-evidence-red-green skill for fail-before, pass-after test evidence (authored)

#18178 and #18334 are still open.

`vladikkuzn` is inserted first in `agent-reviewers`, so this edit does not sit on the `- pbundyra` line removed by open #18268. Open #13556 adds `scheduler-approvers` after the `agent-reviewers` block.

Each area is a separate commit, so this can be split into three upstream PRs.
