#### Useful notes for your reviewer

One conflict, in `test/integration/singlecluster/tas/tas_test.go`: on `release-0.20` the shared `BeforeEach` also enables the `TASResidualPodAccounting` feature gate, which is alpha (off by default) on this branch but beta (on by default) on `main`. I kept that line ahead of the new `DeferCleanup(fwk.StopManager, ctx)`, so the manager stops before the gate is restored.

Otherwise all 12 files apply with the same line changes as `main`.
