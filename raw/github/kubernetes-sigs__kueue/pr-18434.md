#### What this PR does / why we need it?

The LeaderWorkerSet reconciler falls back to a literal `1` when `spec.leaderWorkerTemplate.size` is unset, in `podSets()` and when setting the pod group total count annotation, while the webhook uses `defaultLeaderWorkerSetSize`. This PR uses the constant in both places so the PodSet count, the pod group total count and the webhook all read the same default. No behavior change.
