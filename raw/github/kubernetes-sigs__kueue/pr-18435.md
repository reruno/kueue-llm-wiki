#### Useful notes for your reviewer

Three files from the original PR are left out because they don't exist on `release-0.19`:

- `test/integration/singlecluster/controller/dra/dra_prioritized_list_test.go`
- `test/integration/singlecluster/tas/tas_topology_spreading_test.go`
- `test/integration/singlecluster/tas/tas_workload_slice_refill_test.go`

`tas_test.go` had one conflict: on this branch the top-level `Describe` also has a `BeforeEach` that enables `TASResidualPodAccounting`. I kept it ahead of the `BeforeEach` that starts the manager, so the gate is set before the manager starts. The other 8 files apply with the same line changes as `main`.
