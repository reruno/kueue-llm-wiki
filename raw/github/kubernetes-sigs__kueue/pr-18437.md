#### What this PR does / why we need it?

Documents the built-in MultiKueue capacity provider for Dynamic Quota Orchestration (Alpha) introduced in #18382 ([KEP-17401](https://github.com/kubernetes-sigs/kueue/tree/main/keps/17401-dqo-multikueue-provider)):
- Updates `site/content/en/docs/concepts/dynamic_quota_orchestration.md` to reference the built-in node and MultiKueue capacity providers.
- Adds the "Derive capacity from MultiKueue worker clusters" section in `site/content/en/docs/tasks/manage/setup_dynamic_quota_orchestration.md` with complete YAML manifests, quota aggregation semantics, disconnection/failure conditions, and cleanup instructions.
- Adds the "Migrate from MultiKueue manager quota automation" step-by-step migration guide for upgrading from the deprecated KEP-9988 Alpha1 quota automation.

## AI summary

This PR updates the Dynamic Quota Orchestration documentation for the MultiKueue capacity provider, which is Alpha.

- `site/content/en/docs/concepts/dynamic_quota_orchestration.md` (+4/-2): States that Kueue includes a controller that derives capacity from Nodes and a controller that sums quotas from MultiKueue worker clusters. Links to setup instructions. Keeps the option to run a custom controller or write status manually for testing. Removes the statement that Kueue does not yet include a provider controller.
- `site/content/en/docs/tasks/manage/setup_dynamic_quota_orchestration.md` (+142/-2): Adds `MultiKueueCapacityProviderConfig` to the alpha API installation steps. Adds setup for manager ClusterQueue capacity derived from connected worker ClusterQueues. Covers matching manager and worker LocalQueues, quota aggregation, connection and error behavior, and required worker-cluster permissions. Adds migration steps from `MultiKueueManagerQuotaAutomation` to Dynamic Quota Orchestration, including the resulting quota, metric, and condition behavior.
