#### What this PR does / why we need it?

Follow-up cleanups for the elastic SparkApplication support from #17127, from the review comments by @ivnovakov:

- Add `TestPodSetsExecutorCount` cases for the `SUCCEEDING`, `FAILING` and `FAILED` states, so `driverStarted` is covered after the driver finishes ([comment](https://github.com/kubernetes-sigs/kueue/pull/17127#discussion_r4468984043)).
- Use `behavioral.ExpectClusterQueueResourceUsage` in the elastic SparkApplication integration tests and remove the local `expectPodsUsage` helper ([comment](https://github.com/kubernetes-sigs/kueue/pull/17127#discussion_r4468984052)).
- Remove the unreachable-node example from the `UNKNOWN` state comment, as Kubernetes no longer sets the `Unknown` Pod phase ([comment](https://github.com/kubernetes-sigs/kueue/pull/17127#discussion_r4468984061)).

Fixes #18415
