#### What this PR does / why we need it?

Follow-up to the elastic SparkApplication KEP-77 update in #18068, from the review comments by @sohankunkerkar:

- State in the Phase 4 Alpha limitations that only unconstrained topology is supported for an elastic SparkApplication, and that the SparkApplication webhook does not reject required or preferred topology ([comment](https://github.com/kubernetes-sigs/kueue/pull/18068#discussion_r4482192567)).
- State in the Phase 4 Alpha limitations that elastic SparkApplications with MultiKueue are out of scope, and add a SparkApplication Beta criterion to evaluate and deliver MultiKueue support, including scaling from the manager cluster to the worker cluster ([comment](https://github.com/kubernetes-sigs/kueue/pull/18068#discussion_r4482198917)).

Fixes #18395
