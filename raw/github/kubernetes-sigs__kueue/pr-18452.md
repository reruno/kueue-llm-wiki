#### What this PR does / why we need it?

Removes two pieces of dead code in the LeaderWorkerSet reconciler. No behavior change.

- `getStatefulSets` wrapped the `List` error in `client.IgnoreNotFound`, but `List` returns an empty list instead of `NotFound`, so the `return nil, nil` branch was unreachable. It now handles the error like `getPods`.
- `newPodSet` only checked `podIndexLabel` for nil and then passed a hardcoded `WorkerIndexLabelKey` to the topology request builder. It now passes `podIndexLabel` through; a nil value leaves the builder unset as before.
