## Description

What type of PR is this?

What this PR does / why we need it:
Fixes error silencing when resolving effective resources for workloads (#9030), scoped down to an MVP follow-up to closed #15828.

Instead of swallowing lookup errors:
- Record `AdjustmentErr` in `workload.Info`.
- Return `AdjustmentErr` in `ValidateAdmissibility` for unadmitted workloads, so the workload controller marks missing RuntimeClasses as `Misconfigured` (or retries reconciliation on internal errors).
- Move workloads out of the inadmissible queue in ClusterQueue once the adjustment error clears (e.g. after the RuntimeClass is created).

Which issue(s) this PR fixes:
Fixes #9030

Suggested release note:
```release-note
Workloads: Fixed a bug where workloads could be scheduled with unresolved RuntimeClass overhead. Kueue now keeps workloads with missing RuntimeClasses misconfigured until the RuntimeClass is created.
```
