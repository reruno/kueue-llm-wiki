## AI summary

The CustomMetricLabels KEP records a Beta decision. Kueue does not track custom Workload label value combinations for Beta. The Beta criteria change the earlier "Re-evaluate" item into a "Decide on" item that states this decision.

The KEP documents the following behavior:
- Pending workload metrics delete a series when its count goes to zero.
- Admitted active workload metrics keep zero-valued series, but the number of values has a limit.
- Config validation requires `trackedValues` for Workload labels. A value that is not in the list maps to `kueue.x-k8s.io/_UNTRACKED_VALUE_`.
- Each Workload label accepts at most 12 `trackedValues`. With the untracked value, it emits at most 13 distinct values. A configuration allows at most 2 Workload labels.

The implementation history adds a 2026-11-06 entry for this decision.

The change touches one file, `keps/7066-custom-metric-labels/README.md`, with 6 lines added and 1 removed. It changes documentation only.
