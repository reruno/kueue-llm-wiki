#### What this PR does / why we need it?

This is a manual cherry-pick of #17823 onto release-0.20.

release-0.20's builder image, `hack/images/golang/Dockerfile`, is still pinned to the digest set by #15900 (`3680233e…`, Go 1.27.1), so the v0.20.x container images build with Go 1.27.1. On main, #17823 moved the pin to `9048d5e7…` (Go 1.27.3). Dependabot updates main only, so the release branch needs a manual pick.

I verified both digests on ECR Public. The `linux/amd64` image config of `public.ecr.aws/docker/library/golang@sha256:9048d5e7751706200eb1719c7dae0436950d362f29a1da91fa05e5c63867c60f` has `GOLANG_VERSION=1.27.3`; the one for `3680233e…` has `GOLANG_VERSION=1.27.1`.

#### Useful notes for your reviewer

The commit was made with `git cherry-pick -x` of c0790ce8dc245f23d17c548f7225d970afcb8200. The FROM line conflicted because main's pre-image differed (`f20d83a`), and I resolved it to #17823's digest. Nothing else changes.
