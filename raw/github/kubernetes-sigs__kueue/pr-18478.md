#### What this PR does / why we need it?

Extends `infra-approvers` to infra files the role does not cover yet:
- `.github/actions/`: added in #13411 after the role was created in #11370. These composite actions are only called from `.github/workflows/`, which `infra-approvers` already owns.
- `cloudbuild.yaml` and `cloudbuild-periodic.yaml`: the existing `^\.cloudbuild.yaml$` filter never matched, because the file has no leading dot.
