#### What this PR does / why we need it?

Follow-up of #18382. Moves the `coveredResources` check and the normalized capacity building out of the MultiKueue CapacityProvider `Reconcile` into a `normalizedCapacity` helper, so `Reconcile` no longer indexes `ResourceGroups[0]` and `OrchestratedFlavors[0]` directly. Also logs the per-reconcile message at `V(3)` instead of `V(2)`.

Resolves https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4492112728 and https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4492286375.

Part of #18424
