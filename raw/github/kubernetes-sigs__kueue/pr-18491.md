## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

Adds `cooldown: default-days: 14` to every Dependabot ecosystem (pip, gomod, github-actions, docker, npm). Dependabot then proposes a release only once it is two weeks old, so a release that is pulled, or followed by a fix within two weeks, never opens a pull request. Today the default is 3 days.

Cooldown applies to version updates only; a security update still opens at once (the Dependabot options reference states this for the `cooldown` option). The grouped updates and the `k8s.io/*` ignore rules are unchanged.

What it saves: the image digests in `hack/images` moved three times in ten days (#17650, #17725, #18168 for distroless; #17651, #17823 for golang), each one a presubmit run and a review. With a two-week wait, consecutive digests collapse into one pull request.

#### Which issue(s) this PR fixes:

None.

#### Special notes for your reviewer:

Only `.github/dependabot.yml` changes. The file parses, and each of the five `updates` entries carries the new key.
