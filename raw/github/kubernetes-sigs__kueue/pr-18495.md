#### What this PR does / why we need it?

Fixes #18417

SparkApplications created on older releases with the elastic annotation do not have `ElasticJobSchedulingGate` in the executor template. When updating or unsuspending such a job, `ValidateUpdate` called `validateCreate`, which unconditionally checked for the scheduling gate, rejecting valid updates with:
`spec.executor.template.spec.schedulingGates: Invalid value: null: an elastic job must have the ElasticJobSchedulingGate`

This change updates `validateElasticJob` to check scheduling gates against the previous object state on update:
- If the old job had the gate, dropping it is rejected.
- If the old job was created without the gate, updates and unsuspension are permitted.

#### Useful notes for your reviewer

Added unit test in `sparkapplication_webhook_test.go` covering updating an elastic job created without the scheduling gate.

#### Release note

```release-note
SparkApplication: allow updating and unsuspending elastic jobs created before the executor scheduling gate was required.
```
