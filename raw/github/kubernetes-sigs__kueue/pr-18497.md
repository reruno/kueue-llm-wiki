## AI summary

When a replacement non-TAS Pod has lower resource requests, Kueue now detects the decrease even if a previously requested resource is omitted. This lets TAS requeue the workload on the Pod’s former node.

### Suggested release note

TAS: Fixed a bug where replacing a non-TAS Pod with lower resource requests could leave its former node unmarked for requeue. Kueue now detects decreases, including requests omitted from the replacement Pod.
