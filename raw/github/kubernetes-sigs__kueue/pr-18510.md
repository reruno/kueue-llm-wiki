<li>[CHANGE] API: The experimental search endpoints now clamp <code>batch_size</code> to 1000. <a href="https://redirect.github.com/prometheus/prometheus/issues/19731">#19731</a></li>

<li>[CHANGE] Remote write: Stop exposing the deprecated <code>prometheus_remote_storage_metadata_total</code>, <code>prometheus_remote_storage_metadata_failed_total</code>, <code>prometheus_remote_storage_metadata_retried_total</code>, and <code>prometheus_remote_storage_metadata_bytes_total</code> metrics for Remote Write 2.0 queues. <a href="https://redirect.github.com/prometheus/prometheus/issues/20080">#20080</a></li>

<li>[CHANGE] TSDB: Reject exemplars whose label names are not unique, instead of storing them and serving a duplicate JSON key from <code>/api/v1/query_exemplars</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/19896">#19896</a></li>
<li>[FEATURE] API: Allow overriding PromQL Start Timestamp processing on a per-query basis using the <code>X-Prometheus-Use-Start-Timestamps</code> HTTP header. <a href="https://redirect.github.com/prometheus/prometheus/issues/19066">#19066</a></li>
<li>[FEATURE] Agent: Support metadata-wal-records in Prometheus Agent mode. <a href="https://redirect.github.com/prometheus/prometheus/issues/19684">#19684</a></li>
<li>[FEATURE] PromQL: Add experimental <code>integral()</code> function for computing integral-over-time of range vectors behind the <code>--enable-feature=promql-experimental-functions</code> flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/14440">#14440</a></li>
<li>[FEATURE] PromQL: Add experimental query cost estimation, actual cost reporting, and configurable execution limits, enabled with <code>--enable-feature=query-cost</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/20028">#20028</a></li>
<li>[FEATURE] PromQL: Smoothed and Anchored vector selectors are now stable and always-on. <a href="https://redirect.github.com/prometheus/prometheus/issues/19697">#19697</a></li>
<li>[FEATURE] PromQL: Use start timestamps to detect counter resets when float timeseries are queried using extended range selector modifiers (<code>anchored</code>, <code>smoothed</code>). This feature is hidden behind <code>use-start-timestamps</code> feature flag. <a href="https://redirect.github.com/prometheus/prometheus/issues/18966">#18966</a></li>
<li>[FEATURE] Promtool: print test filename during promtool tests <a href="https://redirect.github.com/prometheus/prometheus/issues/18271">#18271</a></li>
<li>[FEATURE] PromQL: Allow unquoted Unicode letters and dots behind a feature flag <a href="https://redirect.github.com/prometheus/prometheus/issues/20162">#20162</a></li>
<li>[ENHANCEMENT] Search API: Warn when participating remote-read storage does not support search. <a href="https://redirect.github.com/prometheus/prometheus/issues/19992">#19992</a></li>
<li>[ENHANCEMENT] Remote Read: Add native histogram prometheus_remote_read_handler_gate_wait_duration_seconds to measure concurrency-gate wait duration, including requests canceled while waiting. <a href="https://redirect.github.com/prometheus/prometheus/issues/18355">#18355</a></li>
<li>[ENHANCEMENT] Remote Write: Add experimental flag <code>convert_nhcb_to_classic</code> to convert NHCB to classic histograms for external systems that dont support NHCBs. <a href="https://redirect.github.com/prometheus/prometheus/issues/17205">#17205</a></li>
<li>[ENHANCEMENT] promtool: Add <code>--allow-incompatible-block-duration</code> so users can specify any max-block-duration instead of being restricted to the default Prometheus block durations. <a href="https://redirect.github.com/prometheus/prometheus/issues/19363">#19363</a></li>
<li>[PERF] Remote write: Cache repeated OTLP histogram metric names. <a href="https://redirect.github.com/prometheus/prometheus/issues/19717">#19717</a></li>
<li>[PERF] OpenMetrics 2.0 parser: Reuse classic histogram and summary expansion buffers across scrapes. <a href="https://redirect.github.com/prometheus/prometheus/issues/19907">#19907</a></li>
<li>[PERF] PromQL: Decode only histogram sum/count (not buckets) for timestamp(), start_timestamp() and absent(). <a href="https://redirect.github.com/prometheus/prometheus/issues/19738">#19738</a></li>
<li>[PERF] PromQL: Only select the fixed window for subqueries with an <code>@</code> modifier. <a href="https://redirect.github.com/prometheus/prometheus/issues/19863">#19863</a></li>
<li>[PERF] Remote write / TSDB: Deduplicate per-series metadata structs in memory with <code>unique.Handle</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/20040">#20040</a></li>
<li>[PERF] Scrape: Avoid some copies of scrape response bodies. <a href="https://redirect.github.com/prometheus/prometheus/issues/19394">#19394</a></li>
<li>[PERF] TSDB: Improve XOR2 compression and append performance by selecting value windows based on encoding cost. <a href="https://redirect.github.com/prometheus/prometheus/issues/19962">#19962</a></li>
<li>[PERF] TSDB: Reduce memory used writing and reading checkpoint metadata records. <a href="https://redirect.github.com/prometheus/prometheus/issues/19712">#19712</a></li>
<li>[PERF] Scrape: Convert classic histograms to NHCB directly in the OpenMetrics 2.0 parser without wrapping in <code>NHCBParser</code>. <a href="https://redirect.github.com/prometheus/prometheus/issues/19880">#19880</a></li>
<li>[PERF] Scrape: Reduce OpenMetrics 2.0 parser allocations and CPU overhead by lazily constructing composite series and exemplar labels. <a href="https://redirect.github.com/prometheus/prometheus/issues/19895">#19895</a></li>
<li>[BUGFIX] Remote read: Abort failed streaming responses without writing duplicate headers or appending plain-text errors to the protobuf stream <a href="https://redirect.github.com/prometheus/prometheus/issues/19749">#19749</a></li>
<li>[BUGFIX] TSDB: Fix loss of out-of-order samples when a WAL checkpoint drops a series record that the out-of-order write-behind log still needs <a href="https://redirect.github.com/prometheus/prometheus/issues/19737">#19737</a></li>
<li>[BUGFIX] TSDB: Fix queries that seek within a head chunk returning samples committed after the query started <a href="https://redirect.github.com/prometheus/prometheus/issues/19854">#19854</a></li>
<li>[BUGFIX] TSDB: Preserve mapped chunks when WAL replay merges multiple references for the same series, preventing missing out-of-order samples and duplicate in-order chunks after restart <a href="https://redirect.github.com/prometheus/prometheus/issues/19805">#19805</a></li>

<li>[BUGFIX] Logging: Preserve rule and TSDB block values in JSON logs. <a href="https://redirect.github.com/prometheus/prometheus/issues/19572">#19572</a></li>
