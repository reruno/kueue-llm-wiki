#### What this PR does / why we need it?

Follow-up to the Topology Spreading KEP-13746 update in #16578, from the review comments by @ivnovakov:

- State that spreading counts only Workloads admitted to the same ClusterQueue and flavor, in the KEP (accounting key, spreading group, selector) and in the TAS docs. This is a design choice; add a Beta criterion to re-evaluate it ([comment](https://github.com/kubernetes-sigs/kueue/pull/16578#discussion_r4381235868)).
- State that a workload blocked only by spreading reports `WaitingForQuota`, or `WaitingForPreemptedWorkloads` when preemption can satisfy the rules, not `TopologyPlacementFailed`, and update the related Beta criterion ([comment](https://github.com/kubernetes-sigs/kueue/pull/16578#discussion_r4381235879)).
- Set `topologyRequest.required` to the partition level in the "Example with two rules" Workload, so it passes validation ([comment](https://github.com/kubernetes-sigs/kueue/pull/16578#pullrequestreview-5657399051)).

Fixes #17764
