#### What this PR does / why we need it?

Follow-up of #18382 addressing the test review comments:
- Exports `behavioral.ExpectClusterActive` (using `MediumTimeout` and `AssertMsg`) and reuses it in `test/e2e/multikueue/baseline/capacity_provider_test.go` instead of a test-local helper ([`r4493357687`](https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4493357687)).
- Uses `behavioral.ExpectObjectToBeDeleted` directly in `test/e2e/multikueue/baseline/capacity_provider_test.go` since `MediumTimeout` is already the default ([`r4493549675`](https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4493549675)).
- Moves reusable `CapacityProvider`, `DynamicQuotaOrchestrator`, `ClusterQueue` effective quota, and `MultiKueueConfig` helpers into `test/util/behavioral/` (`dqo.go`, `queues.go`, `multikueue.go`) and shares them across both the MultiKueue integration and E2E tests ([`r4493409221`](https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4493409221)).
- Uses `behavioral.SetResourceNominalQuota` via `behavioral.UpdateClusterQueueResourceNominalQuota` ([`r4493421266`](https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4493421266)).
- Replaces `defer func()` cleanup with `ginkgo.DeferCleanup` in `test/integration/singlecluster/webhook/core/multikueuecapacityproviderconfig_test.go` ([`r4493578913`](https://github.com/kubernetes-sigs/kueue/pull/18382#discussion_r4493578913)).
