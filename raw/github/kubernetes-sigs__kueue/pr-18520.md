#### What this PR does / why we need it?

Breaks `ReconcileGenericJob` in JobFramework down into helpers, following the workload controller breakdown in #17811. `ReconcileGenericJob` goes from 315 to ~115 lines and now reads as a list of steps.

| Helper | What moved |
|---|---|
| `reconcileNamespaceSelector` | Getting the namespace and checking `managedJobsNamespaceSelector` |
| `findTopLevelAncestor` | Resolving the top-level Kueue-managed ancestor, including the `JobNestingTooDeep` event |
| `shouldIgnoreJobWithoutQueueName` | Ignoring jobs without a queue name, for both `manageJobsWithoutQueueName` settings |
| `reconcileChildJob` | Suspending a child job when its ancestor's workload is missing or not admitted |
| `reconcileCustomWorkloadConditions` | Patching conditions from `JobWithCustomWorkloadConditions` |
| `syncCustomWorkloadActivation` | Syncing `spec.active` from `JobWithCustomWorkloadActivation` |
| `reconcileFinishedWorkload` | Finalizing the job and dropping the finalizer once the workload is finished |
| `reconcileDeletedWorkload` | Stopping the job and dropping the finalizer once the workload is being deleted |
| `reconcileOnHold` | Releasing the quota reservation of a job on hold |
| `reconcileFinishedJob` | Marking the workload finished when the job finishes |
| `reconcileReclaimablePods` | Updating `status.reclaimablePods` |
| `reconcilePodsReady` | The WaitForPodsReady check around `reconcilePodsReadyCondition` |
| `reconcileEvicted` | Stopping an evicted job, clearing admission and applying `afterDeactivatedByKueue` retention |
| `reconcileSuspendedJob` | Starting an admitted suspended job, or syncing admission check events and the queue name |
| `reconcileNotAdmittedJob` | Suspending a running job whose workload is not admitted |

Helpers that can stop reconciliation return `(done bool, result ctrl.Result, err error)`, like in #17811, so each call site is `if done { return result, err }`. `reconcileChildJob` and `reconcileSuspendedJob` always end reconciliation, so their condition stays at the call site and they return `(ctrl.Result, error)`.
