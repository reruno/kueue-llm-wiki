#### Useful notes for your reviewer

`test/integration/singlecluster/scheduler/scheduler_dynamicquota_test.go` from the original PR is left out because it doesn't exist on `release-0.19`.

Five files had conflicts because `release-0.19` doesn't have some of the code these tests use on `main`. In each one I applied the same `BeforeAll` -> `BeforeEach` + `DeferCleanup(fwk.StopManager, ctx)` change and kept the branch's existing code:

- `job_controller_test.go`, `jobset_controller_test.go`: kept the branch's `WaitForPodsReady{}` manager config (`main` also sets `UnscheduledTimeout`). The per-workload `WorkloadLevelWaitForPodsReady` specs and their imports aren't on this branch, so I didn't add them. The comment on the shared `BeforeEach` no longer mentions those specs.
- `pod_controller_test.go`: the scheduling shape ordering `Describe` doesn't enable `PodGroupSchedulingShapeOrdering` on this branch, so I didn't add it. `staticNameTB` is removed as in the original PR.
- `resource_transformations_test.go`: kept the branch's `managerAndSchedulerSetup(transformations, "nvidia.com/vgpu-")` signature.
- `elastic_flavor_test.go`: already used `BeforeEach` here; replaced the existing `DeferCleanup` closure with the same one-liner as on `main`.

The other 7 files apply with the same line changes as `main`.
