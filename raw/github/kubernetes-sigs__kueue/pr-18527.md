#### What this PR does / why we need it?

Cherry-picks #18307 onto `release-0.20`, completing the automatic cherry-pick that failed after the original PR merged.

Adds `make image-presubmit` to build all six presubmit images sequentially with one temporary BuildKit builder, sharing Go compilation caches and cleaning up the builder on success or failure.

Uses the final merged commit `88a1b5041a9dbcb0ed275a56afc12d065958afeb`. The only conflict resolution preserves the release branch's existing `verify-checks` prerequisites and adds `verify-image-build-test`; it does not import main-only checks. Existing image versions, build parameters, and download retries are preserved.

#### Useful notes for your reviewer

The image recipes, Dockerfile changes, regression tests, and documentation match #18307, which records the original upstream image-build and presubmit validation. The four Docker-free regression tests exercise the real Make recipes, including shared builder lifetime, six image tags, platform coverage, serial execution under parallel Make, and creation/build/cleanup failures. They are selected by `make verify` on this release branch.

Local validation on 2026-11-09:

- `make verify-image-build-test`: passed, all four tests.
- `make verify-generation-order`: passed.
- `git diff --check upstream/release-0.20 HEAD`: passed.
- `BIN_DIR=/Users/shown/workspace/golang/kueue/bin mise exec go@1.27.0 -- make verify`: attempted; failed because the local Docker daemon socket was unavailable for `verify-skills-lint`. Full verification is not claimed as passed.

Actual container image builds and real-cluster tests were not run locally because the Docker daemon is unavailable. There are no controller, API, feature-gate, or dependency changes. No migration is required; reverting this backport restores the previous build flow.
