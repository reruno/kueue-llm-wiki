<ul>
<li><strong>IMPORTANT</strong>: suspended TrainJobs that use the MPI plugin (e.g. DeepSpeed, MLX) and were created before the upgrade
fail to resume after upgrading to v2.4, because the new <code>PRTE_MCA_*</code> env vars cannot be applied to the existing immutable JobSet.
Wait for MPI-based TrainJobs to complete before upgrading, or recreate the affected TrainJobs after the upgrade.</li>
</ul>
