#### What this PR does / why we need it?  
  
 Removes `ginkgo.Ordered` from `test/integration/singlecluster/controller/dra/dra_test.go`, so its specs can be spread across Ginkgo processes. This completes the DRA package after #18311.

- Each spec starts its own manager in `BeforeEach` and stops it with `ginkgo.DeferCleanup(fwk.StopManager, ctx)`. The restarts in `BeforeAll`/`AfterAll` are removed.
- Contexts with a custom `DeviceClassMappings` config or feature gates now set them per spec. Their `DeviceClass` is deleted in the same `DeferCleanup`, after the manager stops.
