#### What this PR does / why we need it?

#16350 added `obligationMask` and used it for `domainState.sliceCount`. Other leader fields still used separate `...WithLeader` names, and some code had one version for "with leader" and another for "without leader".

This PR uses `obligationMask` for these fields too. Now a function can take the mask as a parameter, so we don't need two copies of the same code. The behavior should stay the same.

#### Useful notes for your reviewer

This is a refactor. The behavior should not change.
The biggest change is `consumeDomain`. When no leaders are left, it works the same as the old "no leaders" code, for both pods and slices.
