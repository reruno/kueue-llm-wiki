#### What this PR does / why we need it?

`make generate-code` failed in `pull-kueue-test-integration-shard-3-main` when proxy.golang.org dropped the `golang.org/x/tools@v0.52.0` download with `stream error: stream ID 5; INTERNAL_ERROR; received from peer`. `hack/tools/code-generator/generate.sh` already retries `go mod download k8s.io/code-generator`, and that call passed. The failed download came next, from the `go install` of the generators that `kube_codegen.sh` runs through the script's `go` wrapper. The wrapper sends that install to `go -C hack/tools install`, with no retry.

This PR runs the wrapper's `install` branch through `hack/testing/retry.sh --stream`, as `hack/tools-installer/source.sh` does for tool installs. The new `verify-generate-code` target runs `hack/testing/generate-code_test.sh`. The test runs the real `generate.sh` with a fake `go` whose first `install` fails with the error from CI.
