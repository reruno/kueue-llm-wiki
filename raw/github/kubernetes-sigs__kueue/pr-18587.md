#### Useful notes for your reviewer  
  
These files from the original PR are left out because they don't exist on `release-0.19`:
- `test/integration/singlecluster/controller/dra/dra_prioritized_list_test.go`
- `test/integration/singlecluster/controller/jobs/raycluster/raycluster_controller_partial_scaleup_test.go`
- `test/integration/singlecluster/tas/tas_topology_spreading_test.go`
- `test/integration/singlecluster/tas/tas_workload_slice_refill_test.go`

Six files had conflicts because `release-0.19` doesn't have some of the code these tests use on `main`. In each one I replaced `DeferCleanup(fwk.StopManager, ctx)` + `StartManager(...)` with `StartManagerForSpec(...)` and kept the branch's existing code:
- `job_controller_test.go`, `jobset_controller_test.go`: kept the branch's `WaitForPodsReady{}` manager config (`main` also sets `UnscheduledTimeout`).
- `pod_controller_test.go`: the max-not-ready-count specs and the scheduling observations `Describe` aren't on this branch, so I didn't add them. The scheduling shape ordering `Describe` doesn't enable `PodGroupSchedulingShapeOrdering` on this branch, so I didn't add it.
- `raycluster_controller_test.go`: the elastic jobs `Describe` still starts the manager in `BeforeAll` on this branch, so it's unchanged. The Concurrent Admission spec isn't on this branch, so I didn't add it. In the PodsReady timeout `BeforeEach`, the branch registered `DeferCleanup(fwk.StopManager, ctx)` after the restart; I switched the restart to `StartManagerForSpec` and dropped that trailing `DeferCleanup`. The cleanup order is the same.
- `resource_transformations_test.go`: kept the branch's `managerAndSchedulerSetup(transformations, "nvidia.com/vgpu-")` signature.
- `tas_test.go`: kept the branch's separate `BeforeEach` that enables `TASResidualPodAccounting`.

The other 17 files apply with the same line changes as `main`.
