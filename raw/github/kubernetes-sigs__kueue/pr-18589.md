#### What this PR does / why we need it?

Add a GitHub Actions workflow that fires on `issues.opened` and `issues.edited`,
reads the leading emoji from the issue title, and applies the matching template
labels if they are missing. The Actions token has triage permission, so labels
are applied reliably regardless of who or what created the issue (web form, gh
CLI, API, bot).

Also expand the label bullet in `kueue-pr-issue-workflow/SKILL.md` to make it
explicit that `gh issue create --label` silently fails without triage permission,
and that `/kind` Prow commands in the body are the only reliable mechanism. Add a
short reminder to `.coderabbit.yaml` `tone_instructions` for the same reason.
