#### What this PR does / why we need it?

With  ElasticJobsViaWorkloadSlicesWithTAS  enabled, Kueue supports only unconstrained topology for elastic Workloads.
Create-time validation missed the submitter Pod for elastic RayJobs using  K8sJobMode . A RayJob with required or preferred topology on its submitter Pod could be created, but the scheduler would reject the unsupported request on the  submitter  PodSet. The entire Workload would remain pending and the RayJob suspended, with no error at creation time.

The fix adds webhook validation to reject these requests at creation time.
