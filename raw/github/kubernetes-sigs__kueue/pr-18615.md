#### What this PR does / why we need it?

Kubernetes 1.36.0 and 1.36.1 reject spec updates on a suspended Job that has no
`JobSuspended=True` condition (kubernetes/kubernetes#139281, fixed in 1.36.2). To
work around it, the MultiKueue batch/Job adapter patches `JobSuspended=True` on the
local Job while the remote Job runs and the local Job is still suspended (#11649).

As agreed in #11863, the workaround stays enabled while Kueue supports Kubernetes 1.36.
This PR adds the Alpha feature gate `MultiKueueJobSuspendedWorkaroundDisabled`
(default `false`). When enabled, the adapter skips the patch, so clusters on
Kubernetes 1.36.2 or newer can turn the workaround off.

This supersedes #12414: I took it over from @k-ngs with their agreement, rebased it
on current main and kept their commits.

Part of: #11863
