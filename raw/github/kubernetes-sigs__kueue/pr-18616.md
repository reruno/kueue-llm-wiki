#### What this PR does / why we need it?

The workload controller reads the Namespace from the manager's cache and doesn't watch Namespaces. The test triggers one reconcile right after updating the Namespace labels, and that reconcile can still see the old labels. This PR waits until `managerClient` returns the new labels before triggering the reconcile.
