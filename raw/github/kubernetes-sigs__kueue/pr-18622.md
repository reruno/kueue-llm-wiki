#### What this PR does / why we need it?
Manual cherry-pick of #18590 onto `release-0.19`. The automated cherry-pick failed with conflicts in `dra_test.go` and `dra_pd_test.go`.

This branch does not have the MultiKueue DRA specs from the original change, so `dra_pd_test.go` is unchanged. The DeviceClass tracking specs now delete `gpu.example.com` from `AfterEach` instead of a Go `defer`, which Ginkgo does not run on timeout or interrupt. Deletions that are part of a spec stay in the spec. Manager start and stop stay on `BeforeAll` and `AfterAll`.

#### Useful notes for your reviewer
Cherry-pick of #18590. The DRA integration tests for that change were run on main with `INTEGRATION_TARGET=./test/integration/singlecluster/controller/dra GINKGO_ARGS="--randomize-all --repeat=3" make test-integration`. On this branch I compiled `./test/integration/singlecluster/controller/dra`.
