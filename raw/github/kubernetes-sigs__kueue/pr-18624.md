#### What this PR does / why we need it?

Root-module images download dependencies that their vendored builds never use, and the KueueViz backend cannot reuse matching Go packages compiled from vendor when their absolute source paths differ. Remove the manager, populator, and priority-booster module downloads and enable `-trimpath` consistently in all five Go Dockerfiles so matching dependencies can share the existing compilation cache.

Set manager presubmit compilation to `GOMAXPROCS=2` and `go build -p=2`, which was consistently faster than automatic settings in six alternating runs. These budgets apply only to the manager presubmit and can be overridden independently or set empty; standalone and release builds keep their existing parallelism defaults.

All six images, four manager architectures, tags, load behavior, sequential aggregation, and builder cleanup are preserved. The independent backend module retains its retried downloads. Temporary benchmark loops, build-argument switches, resource observers, and verbose compilation output have been removed; `image-presubmit` runs once.

Part of #18302.
