#### What this PR does / why we need it?

Kueue accepts elastic `SparkApplication` jobs with required or preferred topology, but elastic TAS scheduling currently does not support these constraints. After creation, the jobs remain suspended and their `Workload` objects remain pending, even when sufficient resources are available.

For `Job`, `RayCluster`, `RayJob`, and `RayService`, Kueue already rejects these requests at creation time.

Kueue should also reject `SparkApplication` creation in this scenario instead of leaving users waiting indefinitely.

## AI summary

This PR rejects creation of elastic `SparkApplication` jobs that set required or preferred topology annotations on the driver or executor. The check applies when `ElasticJobsViaWorkloadSlicesWithTAS` is enabled and the workload-slicing annotation is set. Elastic TAS scheduling does not support these topology constraints. Before this change, such jobs passed creation. They could then stay suspended with pending `Workload` objects.

Changes:
- `pkg/controller/jobs/sparkapplication/sparkapplication_webhook.go`: `ValidateCreate` now calls `jobframework.ValidateElasticJobTopologyRequest` on the driver and executor pod templates. The check runs only when the TAS gate is enabled and the workload-slicing annotation is set. It runs only on create, so updates are not affected. A pod-set derivation error is returned directly.
- `pkg/controller/jobs/sparkapplication/sparkapplication_webhook_test.go`: Unit tests cover forbidden driver and executor topology cases, allowed unconstrained topology, the TAS gate disabled, and non-elastic jobs. An update test confirms that an existing suspended elastic job can be unsuspended.
- `test/integration/singlecluster/webhook/jobs/sparkapplication_webhook_test.go`: Integration tests cover the four driver and executor required or preferred topology cases. Each case expects a Forbidden error that names the annotation path and states that topology is not supported with elastic jobs.

Verification: The diff was inspected, with 3 files and 165 lines added. Test results were not available. No unit or integration test run was confirmed for this head.

### Suggested release note

```text
SparkApplication: Fixed a bug where elastic SparkApplications with required or preferred topology annotations on the driver or executor could stall in a suspended state with pending Workloads. Kueue now rejects creation of these SparkApplications.
```

This behavior is gated by the `ElasticJobsViaWorkloadSlicesWithTAS` feature gate.
