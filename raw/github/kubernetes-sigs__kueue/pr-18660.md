#### What this PR does / why we need it?

Removes `ginkgo.Ordered` from 19 single-cluster integration test files (AppWrapper, JAXJob, MPIJob, PaddleJob, PyTorchJob, TFJob, XGBoostJob, TrainJob, RayCluster, RayJob, RayService, SparkApplication, and the exclude-resources, DRA fair sharing and quota check strategy scheduler tests).

- Setup from `BeforeAll`/`AfterAll` moves into `BeforeEach`/`AfterEach`, so each spec starts and stops its own manager.
- Each spec starts its manager with `fwk.StartManagerForSpec`.
- Cluster-scoped objects that were created once per container (ResourceFlavors, the AppWrapper PriorityClass, the DRA DeviceClass) are now created and deleted in every spec.
- The shared `unmanaged-ns` namespace is replaced by a generated namespace per spec. With a fixed name, the second spec on the same Ginkgo process fails with `AlreadyExists`, because envtest never finishes deleting a namespace.
