#### What this PR does / why we need it?

Cherry pick of #18633 onto `release-0.19`, following the [backport request](https://github.com/kubernetes-sigs/kueue/pull/18633#issuecomment-6814696967) and resolving the [automatic cherry-pick conflict](https://github.com/kubernetes-sigs/kueue/pull/18633#issuecomment-6814706219).

Prepare only the tools used by KueueViz, reuse backend race-test compilation when building the test server, and retain stage timings and reliable process cleanup/exit-status handling.

Conflict resolution: `release-0.19` has no `e2e-kueueviz-rbac-bypass.sh` and already uses a single browser-test cluster. Keep that script absent, omit the source PR's new RBAC invocations, and adapt its regression harness to this branch's backend/local browser workflows. Existing backend race tests, frontend unit tests, Cypress scenarios and artifacts remain selected. No product code, dependencies or deployment settings change.

#### Useful notes for your reviewer

AI assistance was used to resolve conflicts and review the backport. The [source PR](https://github.com/kubernetes-sigs/kueue/pull/18633) passed all 53 normal Prow checks, including its full verification and repeated E2E comparisons. Its performance measurements apply to main; no release-0.19 speedup is claimed from those measurements.

At the contributor's request, validation runs in upstream CI only. No local tests, builds or Docker runs were performed; local `make verify` was not run for that reason. Release-branch verification and E2E results are pending.

| Behavior | Level | Command and result | Not run and why |
| --- | --- | --- | --- |
| Preserve the branch's single-cluster workflow, Cypress invocation, failure cleanup and backend exit statuses | unit | Three adapted methods in `python3 hack/testing/kueueviz-e2e_test.py`, selected by `verify-e2e-common-test`; upstream verification pending | No local execution, as requested |
| Preserve quoted Go flags and match the preceding backend race tests | unit | Parameterized Make recipe cases in the same harness; upstream verification pending | No local execution, as requested |
| Required tools and race-cache reuse preserve all existing KueueViz tests | e2e | `make kind-image-build test-e2e-kueueviz`, selected by `pull-kueue-test-e2e-kueueviz-release-0-19`; upstream result pending | No local execution, as requested |

No migration is required. Reverting this backport restores the previous CI preparation and build commands.
