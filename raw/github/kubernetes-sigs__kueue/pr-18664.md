#### Useful notes for your reviewer

`dra_test.go` had conflicts because `release-0.19` doesn't have some of the code `main` has around these tests. In each one I applied the same change as `main` (`BeforeAll` -> `BeforeEach` with `StartManagerForSpec(...)`) and kept the branch's existing code:
- DeviceClass tracking context: kept the branch's `deviceClass = nil` reset in `BeforeEach`. On this branch `AfterEach` already deletes `deviceClass`, so I didn't add the per-spec `defer` deletes from `main` to the three DeviceClass-deletion specs.

The other hunks apply with the same line changes as `main`.

`INTEGRATION_TARGET=./test/integration/singlecluster/controller/dra GINKGO_ARGS="--randomize-all --repeat=2" make test-integration`: 66/66 passed in all 3 runs.
