## AI summary

This PR updates the v0.19 release documentation and changelog to v0.19.13. It makes no code changes.

- `CHANGELOG/CHANGELOG-0.19.md`: adds the v0.19.13 entry. It lists upgrade guidance and bug fixes across CLI, Cohort, TAS, MultiKueue, metrics, and other areas.
- `site/content/en/v0.19/docs/_index.md` and `site/content/zh-CN/v0.19/docs/_index.md`: change the version values from v0.19.12 to v0.19.13.
- `site/content/en/v0.19/docs/concepts/workload_priority_class.md`: documents that, for suspended jobs reconciled by the job framework, a pending queue-name change is applied with a Workload priority update when the Workload has not reserved quota. Custom queue-name handlers must opt in. Serving Pod groups keep their existing queue.
- `site/content/en/v0.19/docs/tasks/manage/observability/configure_custom_metric_labels.md`: documents when custom-label value changes keep old metric series. Series remain only when every custom label for that source kind sets `trackedValues`. Otherwise, Kueue removes the old series and metrics restart from zero under the new value.
