#### What this PR does / why we need it?

Fixes #18687

Currently, CodeRabbit assigns the requester by default whenever asked to open a new issue.

This updates:
1. `.coderabbit.yaml`: instructs CodeRabbit under `tone_instructions` not to assign anyone to newly opened issues unless requested.
2. `cmd/experimental/skills/kueue-pr-issue-workflow/SKILL.md`: adds an instruction under `## Opening issues` not to assign anyone to newly opened issues unless requested.
