#### What this PR does / why we need it?
Adds the `infra-reviewers` alias as reviewers wherever `infra-approvers` own files. Previously, only `hack/` and the `Makefile` requested `infra-reviewers`.

The new paths are:

- `.github/actions/` and `.github/workflows/`
- `Dockerfile` / `.dockerignore`
- `.github/dependabot.yml`
- `cloudbuild.yaml` / `cloudbuild-periodic.yaml`
- `.krew.yaml`
- `site/hugo.toml`
