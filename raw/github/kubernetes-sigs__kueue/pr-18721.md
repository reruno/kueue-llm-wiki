#### What this PR does / why we need it?

Bumps three indirect dependencies on `release-0.20` to pick up CVE fixes:

| Module | From | To | Fixes |
|---|---|---|---|
| `golang.org/x/net` | v0.58.0 | v0.62.0 | CVE-2026-78663, CVE-2026-78659, CVE-2026-78660, CVE-2026-78669, CVE-2026-97032 (HTTP/2), CVE-2026-78661, CVE-2026-97045 (`html`) |
| `github.com/go-jose/go-jose/v4` | v4.1.4 | v4.1.6 | CVE-2026-116587 |
| `go.etcd.io/etcd/client/pkg/v3` | v3.7.0 | v3.7.1 | CVE-2026-73500 |

The x/net bump also raises the other `golang.org/x` modules (crypto, mod, sys, term, text, tools, sync) to the versions on `main` (x/sync is one minor version behind).

#### Useful notes for your reviewer

- Generated with `go get golang.org/x/net@v0.62.0 github.com/go-jose/go-jose/v4@v4.1.6 go.etcd.io/etcd/client/pkg/v3@v3.7.1 && go mod tidy && go mod vendor`. Only `go.mod`, `go.sum` and `vendor/` change.
- The builder image on this branch is already Go 1.27.3 (#18476), so the stdlib copy of the HTTP/2 fixes is in place too.

Tested locally with Go 1.27.3:
- `go build ./...`, `go vet`, `go mod verify`: pass
- `make test`: 12,924 tests, 0 failures
