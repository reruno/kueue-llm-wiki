#### What this PR does / why we need it?
kueue-populator has had no go.mod of its own since https://github.com/kubernetes-sigs/kueue/pull/10471 (the fix for https://github.com/kubernetes-sigs/kueue/issues/10470) moved it onto the root module. Dependabot still lists the directory for gomod updates, but there is no manifest there, so that entry does nothing. The root / entry already covers the populator's Go dependencies. The docker entry for /cmd/experimental/kueue-populator should stay, because the directory still has a Dockerfile.
