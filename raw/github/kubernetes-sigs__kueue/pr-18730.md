#### What this PR does / why we need it?

The Kueue runtime patch manager name and the helper that finds the Kueue runtime patch in a TrainJob were defined twice: once in the TrainJob integration and once in the TrainJob test wrappers.

This PR moves both into a new `pkg/util/trainjob` package. The TrainJob controller, webhook, MultiKueue adapter, test wrappers and tests now use this single definition. The helper can't live in the TrainJob integration package, because that package's unit tests import the test wrappers, which would create an import cycle.

This PR moves the Kueue runtime-patch manager name and the runtime-patch lookup helper into the shared `pkg/util/trainjob` package. The change covers 12 files (+149/-70).

- Adds `KueueRuntimePatchManager` and `KueueRuntimePatch` to `pkg/util/trainjob/trainjob.go`, with unit tests in `trainjob_test.go`.
- Removes the local `runtimePatchManagerName` constant and `getKueueRuntimePatch` helper from the TrainJob controller. The controller uses the shared helper.
- Updates the TrainJob webhook, MultiKueue adapter, and their tests to use the shared constant and helper.
- Removes `KueueRuntimePatchManager` and `KueueRuntimePatch` from `pkg/util/testingjobs/trainjob/wrappers.go`. Test code now uses the shared helpers.
- Updates the e2e and integration tests to use the shared helpers.

The change is a refactor. Runtime-patch behavior is unchanged. The patch contents and append conditions stay the same.
