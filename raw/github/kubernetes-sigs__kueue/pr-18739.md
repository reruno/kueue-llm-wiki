<h3>New features</h3>

<li>Diagnose Codex instruction selection and cumulative byte limits (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/675">#675</a>)</li>
<li>Pi: opt-in settings schema rule and <code>pi.changelogPath</code> checks (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/673">#673</a>)</li>
<li>Validate new Antigravity plugin and MCP fields from agy 1.3.6 (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/668">#668</a>)</li>
<li>Validate optional Codex onboarding skill references (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/645">#645</a>)</li>
<li>Validate the Claude Code hook <code>onFailure</code> field (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/663">#663</a>)</li>
<li>Flag uninstallable Claude marketplace names and entry hook forms (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/672">#672</a>)</li>
<li>Recognize Codex <code>PreModelRequest</code> and <code>PostModelRequest</code> hook events (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/665">#665</a>)</li>
<li>Treat Muse <code>StopFailure</code> and <code>PostToolBatch</code> as documented hook events (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/666">#666</a>)</li>
<li>Sync <code>grok-hooks-valid</code> with Grok Build 1.0.77 (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/671">#671</a>), <code>pi-mcp-valid</code> with Pi 1.5.0 (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/670">#670</a>), and OpenClaw theme icons and OS aliases with v2026.11.1 (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/667">#667</a>)</li>
<li>VS Code diagnostics pilot and publisher onboarding example (<a href="https://redirect.github.com/stbenjam/skillsaw/issues/658">#658</a>)</li>
</ul>
