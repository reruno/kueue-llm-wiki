<h2>v4.54.3</h2>
<ul>
<li>Fixed preservation of YAML aliases across documents within the same input stream, without leaking anchors between files (<a href="https://redirect.github.com/mikefarah/yq/issues/2956">#2956</a>) Thanks <a href="https://github.com/ingydotnet"><code>@​ingydotnet</code></a></li>

</ul>

<ul>

<li>Fixed YAML structure being changed when assigning head comments (<a href="https://redirect.github.com/mikefarah/yq/issues/2847">#2847</a>) Thanks <a href="https://github.com/rootsec1"><code>@​rootsec1</code></a></li>

<li>Fixed preservation of comments on TOML inline table values (<a href="https://redirect.github.com/mikefarah/yq/issues/2879">#2879</a>) Thanks <a href="https://github.com/iamhuman-cheolheelee"><code>@​iamhuman-cheolheelee</code></a></li>
<li>Fixed INI keys containing colons (<a href="https://redirect.github.com/mikefarah/yq/issues/2886">#2886</a>)</li>
