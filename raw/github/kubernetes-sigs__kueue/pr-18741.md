<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/itchyny/gojq/releases">github.com/itchyny/gojq's releases</a>.</em></p>
<blockquote>
<h2>Release v0.12.20</h2>
<ul>
<li>implement <code>gojq.ToInt</code> and <code>gojq.ToFloat64</code> for converting number values</li>
<li>fix destructuring alternative operator (<code>?//</code>) to reset variables of
later alternatives, and to propagate <code>break</code> and <code>halt</code> errors</li>
<li>fix update-assignment operator against object with overlapping paths</li>
<li>fix <code>delpaths</code> function to delete ancestor paths before descendant paths</li>
<li>fix <code>getpath</code> function against string input</li>
<li>fix indexing and slicing a number literal written after a unary operator</li>
<li>fix slice indices of floating point numbers for jq compatibility</li>
<li>fix date and time functions against fractional, non-finite, and out of range numbers</li>
<li>fix <code>strptime</code> function to accept the zero time instant</li>
<li>fix <code>match</code>, <code>test</code>, and <code>capture</code> functions to support array arguments</li>
<li>fix <code>match</code> function to report an empty match after a non-empty one</li>
<li>fix <code>split/1</code> function against empty input string</li>
<li>fix math functions against large number literals like <code>1e1000</code></li>
<li>fix <code>jn/2</code> and <code>yn/2</code> functions to avoid long recurrence on large orders</li>
<li>fix <code>abs</code> function against non-numbers for jq compatibility</li>
<li>fix <code>isnan</code> function to return false for non-numbers for jq compatibility</li>
<li>fix <code>halt_error</code> function not to print a newline after non-string values</li>
<li>fix <code>--argjson</code> and <code>--jsonargs</code> options to reject empty and multiple JSON values</li>
<li>fix <code>--stream</code> option error message against unterminated input</li>
<li>fix JSON parse error message after a large value in non-seekable input like stdin</li>
<li>fix offset of YAML parse error on multi-byte characters</li>
<li>fix panic on continuing iteration after an invalid path error</li>
<li>fix data race on input iterator when running code concurrently</li>
<li>fix <code>add</code> function to handle a nil map and slice as the first value</li>
<li>support destructuring alternative operator (<code>?//</code>) in <code>reduce</code> and <code>foreach</code> syntax</li>
<li>allow optional operator followed by alternative operator without spaces (<code>.a?//1</code>)</li>
<li>improve performance of function calls by avoiding copies of scope values,
and path tracking in <code>path</code>, <code>paths</code>, <code>|=</code>, and <code>del</code> by reducing allocations</li>
</ul>
</blockquote>
