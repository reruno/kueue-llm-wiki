#### What this PR does / why we need it?

Fixes three places in the TAS concept page that disagree with the code:

- `TASFailedNodeReplacementFailFast` has been enabled by default since v0.14, but the paragraph about it said Kueue retries by default and that the gate must be enabled to stop retrying. The alert right above that paragraph already says the gate is enabled by default.
- The Feature Gate Interaction Matrix labeled the `FNFF=false` row as "Default Hot Swap". It is now "Hot Swap", and the `FNFF=true` row is marked "(default)".
- The matrix listed the Pod-termination trigger for any value of `TASReplaceNodeOnPodTermination`. With that gate disabled, a node is treated as failed after 30 seconds of `NotReady`, regardless of Pod state, as the paragraph below the table already says. The Trigger cells now mention this case.

The wording of the existing sentences is kept; only the incorrect parts are changed.

## AI summary

This PR changes one file: `site/content/en/docs/concepts/topology_aware_scheduling.md` (11 lines added, 5 removed). It is a documentation-only change.

- **Fast Hot Swap text:** The paragraph now starts with the disabled-gate case. If `TASFailedNodeReplacementFailFast` is disabled, Kueue retries replacement until it succeeds or the workload is evicted. The text states that the gate is enabled by default. When the gate is enabled, Kueue attempts replacement once and evicts and requeues the workload on failure. A new paragraph says that when `TASNodeReplacementDeferFailFastWhenUsefulInflightEvictions` is enabled, Kueue does not evict the workload if evictions already in progress are expected to free a suitable placement.
- **Feature-gate interaction text:** The introduction now states that `TASReplaceNodeOnPodTermination` and `TASFailedNodeReplacementFailFast` depend on `TASFailedNodeReplacement`. When `TASFailedNodeReplacement` is `false`, both dependent gates must also be `false`. Otherwise, Kueue fails to start. The previous sentence said the other gates have no effect.
- **Feature-gate matrix:** The table now has five rows instead of three. Each row lists all three gate values explicitly.
  - `FNR=false`, `RNO=false`, `FNFF=false`: hot swap is disabled.
  - `FNR=true`, `RNO=true`, `FNFF=false`: labeled "Hot Swap". The trigger is `NotReady` and pods terminating or terminated.
  - `FNR=true`, `RNO=false`, `FNFF=false`: labeled "Hot Swap". The trigger is `NotReady` for 30 seconds.
  - `FNR=true`, `RNO=true`, `FNFF=true`: labeled "Fast Hot Swap (default)". The behavior cell adds the exception for in-progress evictions.
  - `FNR=true`, `RNO=false`, `FNFF=true`: labeled "Fast Hot Swap". The trigger is `NotReady` for 30 seconds. The behavior cell adds the same in-progress eviction exception.
