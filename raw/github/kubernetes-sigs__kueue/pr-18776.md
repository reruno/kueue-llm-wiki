<blockquote>
<h2>v1.47.0/v0.69.0/v0.23.0/v0.1.0</h2>
<p>This release contains the first stable release of the OpenTelemetry Go Logs API and SDK.
Our project stability guarantees now apply to the following modules:</p>
<ul>
<li><code>go.opentelemetry.io/otel/log</code></li>
<li><code>go.opentelemetry.io/otel/sdk/log</code></li>
</ul>
<p>See our <a href="https://github.com/open-telemetry/opentelemetry-go/blob/main/VERSIONING.md">versioning policy</a> for more information about these stability guarantees.</p>
<h3>Added</h3>
<ul>
<li>Add <code>String</code> method for <code>KeyValue</code> type in <code>go.opentelemetry.io/otel/attribute</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8205">#8205</a>)</li>
<li>Add <code>String</code> method for <code>Set</code> type in <code>go.opentelemetry.io/otel/attribute</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8347">#8347</a>)</li>
<li>Add <code>WithMaxExportBatchSize</code> to <code>go.opentelemetry.io/otel/sdk/metric</code> to configure the maximum export batch size for <code>PeriodicReader</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8960">#8960</a>)</li>
<li>Add <code>WithAttributeValueDepthLimit</code>, <code>DefaultAttributeValueDepthLimit</code>, and <code>SpanLimits.AttributeValueDepthLimit</code> in <code>go.opentelemetry.io/otel/sdk/trace</code> to configure the maximum depth of span, event, link, and instrumentation scope attribute values. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8938">#8938</a>)</li>
<li>Add <code>WithAttributeValueDepthLimit</code> in <code>go.opentelemetry.io/otel/sdk/log</code> to configure the maximum depth of log record and instrumentation scope attribute values. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8938">#8938</a>)</li>
<li>Add <code>WithMaxResponseSize</code> to <code>go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp</code>,
<code>go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp</code>, and
<code>go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8941">#8941</a>)</li>
<li>Add experimental <code>ProbabilitySampler</code> in <code>go.opentelemetry.io/otel/sdk/trace/x</code> that conforms to the <a href="https://opentelemetry.io/docs/specs/otel/trace/sdk/#probabilitysampler">OpenTelemetry specification's threshold-based sampling algorithm</a>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8123">#8123</a>)</li>
<li>Add experimental <code>*Binder</code> extension interfaces in <code>go.opentelemetry.io/otel/metric/x</code> for instruments that support binding attributes ahead of time. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8760">#8760</a>)</li>
<li>Add the experimental <code>Finisher</code> synchronous metric instrument extension interface to <code>go.opentelemetry.io/otel/metric/x</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8906">#8906</a>)</li>
</ul>
<h3>Changed</h3>
<ul>
<li>Use the <a href="https://opentelemetry.io/docs/specs/otel/common/#attribute-collection-representation-for-non-otlp">OpenTelemetry Attribute Collection representation for non-OTLP protocols</a> for metric data diffs in <code>go.opentelemetry.io/otel/sdk/metric/metricdata/metricdatatest</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8993">#8993</a>)</li>
<li>Apply a maximum depth of 64 by default to span, event, link, log record, and instrumentation scope attribute values in <code>go.opentelemetry.io/otel/sdk/trace</code> and <code>go.opentelemetry.io/otel/sdk/log</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8938">#8938</a>)</li>
<li>Reduce allocations when applying attribute value length limits in <code>go.opentelemetry.io/otel/sdk/trace</code> and <code>go.opentelemetry.io/otel/sdk/log</code> by rebuilding composite values only when truncation is needed. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8912">#8912</a>)</li>
<li>Decode <code>traceparent</code> using a hex lookup table in <code>go.opentelemetry.io/otel/propagation</code>, which rejects the specification-disallowed upper-case characters without a separate scan of the header. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8739">#8739</a>)</li>
<li>Decode all characters at constant indices in <code>TraceIDFromHex</code> and <code>SpanIDFromHex</code> in <code>go.opentelemetry.io/otel/trace</code> to eliminate bounds checks. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8740">#8740</a>)</li>
</ul>
<h3>Fixed</h3>
<ul>
<li>Count valid U+FFFD replacement characters toward attribute value length limits in <code>go.opentelemetry.io/otel/trace</code>, <code>go.opentelemetry.io/otel/sdk/trace</code>, and <code>go.opentelemetry.io/otel/sdk/log</code>.</li>
<li>Truncate string attribute values to empty strings when the configured length limit is zero, including malformed UTF-8, in <code>go.opentelemetry.io/otel/trace</code>, <code>go.opentelemetry.io/otel/sdk/trace</code>, and <code>go.opentelemetry.io/otel/sdk/log</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/9054">#9054</a>)</li>
<li>Fix a data race in <code>NewPeriodicReader</code> where <code>r.inst</code> was assigned after the background goroutine was launched in <code>go.opentelemetry.io/otel/sdk/metric</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/9028">#9028</a>)</li>
<li>Prevent precision loss for large <code>int64</code> values in <code>Sum</code>, <code>Histogram</code>, and <code>ExponentialHistogram</code> aggregations in <code>go.opentelemetry.io/otel/sdk/metric</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8981">#8981</a>)</li>
<li>Ensure <code>grpc.DialOption</code> values passed via <code>WithDialOption</code> take precedence over conflicting internally-computed defaults in
<code>go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploggrpc</code>,
<code>go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetricgrpc</code>, and
<code>go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8805">#8805</a>, <a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8834">#8834</a>, <a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8836">#8836</a>)</li>
<li>Treat overflowing <code>OTEL_METRIC_EXPORT_INTERVAL</code> and <code>OTEL_METRIC_EXPORT_TIMEOUT</code> values as invalid in <code>go.opentelemetry.io/otel/sdk/metric</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8800">#8800</a>)</li>
<li>Prevent a panic in <code>NewFixedSizeReservoir</code> and <code>FixedSizeReservoirProvider</code> when given a negative size in <code>go.opentelemetry.io/otel/sdk/metric/exemplar</code>; negative sizes are now clamped to zero, consistent with a size of zero. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8832">#8832</a>)</li>
<li>Preserve exponential histogram <code>ZeroThreshold</code> during OTLP metric export in <code>go.opentelemetry.io/otel/exporters/otlp/otlpmetric</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8801">#8801</a>)</li>
<li>Ensure metric helpers in <code>go.opentelemetry.io/otel/semconv/v1.32.0</code>, <code>go.opentelemetry.io/otel/semconv/v1.33.0</code>, and <code>go.opentelemetry.io/otel/semconv/v1.34.0</code> record measurements only once when no attributes are provided. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8849">#8849</a>)</li>
<li>Treat empty <code>OTEL_TRACES_SAMPLER</code> and <code>OTEL_TRACES_SAMPLER_ARG</code> values as unset in <code>go.opentelemetry.io/otel/sdk/trace</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8873">#8873</a>)</li>
<li>Normalize global <code>OTEL_EXPORTER_OTLP_ENDPOINT</code> path joining in <code>go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp</code> so trailing-slash base URLs do not produce double-slash log export paths. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8864">#8864</a>)</li>
<li>Prevent a deadlock when formatting an error passed to <code>RecordError</code> calls back into the span in <code>go.opentelemetry.io/otel/sdk/trace</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8815">#8815</a>)</li>
<li>Prevent <code>SimpleSpanProcessor.Shutdown</code> from panicking when constructed with a nil exporter in <code>go.opentelemetry.io/otel/sdk/trace</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8844">#8844</a>)</li>
<li>Propagate invalid exponential histogram scale errors to Prometheus exporter self-observability metrics in <code>go.opentelemetry.io/otel/exporters/prometheus</code>. (<a href="https://redirect.github.com/open-telemetry/opentelemetry-go/issues/8839">#8839</a>)</li>
</ul>
