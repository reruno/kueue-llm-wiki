#### What this PR does / why we need it?

Bumps `github.com/ray-project/kuberay/ray-operator` from `v1.7.0` to `v1.8.0-rc.0`.

KubeRay v1.8 adds `spec.idleSuspend` and `spec.idleTerminationOptions` to RayCluster (kuberay-project/kuberay#5210). Kueue needs the new API to support idle termination, see #18774.

- Only `go.mod`, `go.sum` and `vendor/` change. `volcano.sh/apis` moves from `v1.14.0` to `v1.15.2` as an indirect dependency.
- The e2e `KUBERAY_VERSION` and `dep-crds/ray-operator` derive from this module version (`hack/make/deps.mk`), so the operator image and the CRDs used by the tests move to `v1.8.0-rc.0` as well.
- No Kueue source changes are needed.
- I will follow up with `v1.8.0` once it is released, as was done for v1.6.0 (#9886, then #10034).

Part of: #18774
