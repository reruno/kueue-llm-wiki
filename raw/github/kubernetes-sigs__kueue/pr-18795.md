#### What this PR does / why we need it?

Backports the DRA quota charge preservation fix to release-0.19. When DRA charges are refreshed while a workload is inflight, requeueing now preserves the refreshed charges instead of restoring stale requests.

Related: #17388

#### Useful notes for your reviewer

The test conflict was resolved using the release-0.19 queue APIs while retaining the refreshed charge coverage. Validation performed: `git diff --check`; `go test ./pkg/cache/queue/` passed.

AI assistance was used to prepare this backport and resolve the release-branch compatibility differences; the contributor reviewed the resulting change.

#### Release note
```release-note
DRA: Fixed a bug where a Workload whose quota charges were recomputed while the scheduler was processing it, for example after a DeviceClass listed in deviceClassMappings was created or a LimitRange default changed, could be requeued with its old charges and reserve quota with them.
```
