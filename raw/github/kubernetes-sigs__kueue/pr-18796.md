#### What this PR does / why we need it?

`periodic-kueue-push-images` fails to build the `ray-project-mini` image:

```
ERROR: Could not find a version that satisfies the requirement ray==2.60.0 (from versions: none)
```

The cause is the Dependabot bump of the ray-mini base image from `python:3.13-slim` to `python:3.15-slim` (#18738), not the KubeRay upgrade. Ray publishes only wheels, with no sdist. Ray 2.60.0 has wheels for `cp310`–`cp314`, so pip finds nothing to install on Python 3.15. The same failure was fixed before by pinning Python 3.13 in #12589.

This PR:
- Restores `hack/testing/ray-mini/Dockerfile` to the previous `python:3.13-slim` digest.
- Moves `/hack/testing/ray-mini` into its own Dependabot `docker` entry that ignores major and minor `python` updates (patch and digest updates still flow). It uses a separate entry because `hack/testing/linkchecker` also uses the `python` image and should keep its bumps.

The `rayproject/ray` bump to 2.60.0 (#18737) is fine and stays.

Fixes #18784
