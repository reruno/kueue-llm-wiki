## Description

#### What type of PR is this?
/kind bug

#### What this PR does / why we need it?
Validates `deviceClassMappings[].deviceClassNames` and `excludeDeviceClassNames` as DeviceClass names (DNS subdomain, up to 253 characters) instead of label keys, so valid names longer than 63 characters no longer stop Kueue from starting. Both lists use one helper, `validateDeviceClassName`.

Fixes #18780

#### Useful notes for your reviewer
The second commit covers `excludeDeviceClassNames`, which landed in #18632.

#### Release note
```release-note
DRA: `deviceClassMappings[].deviceClassNames` and `excludeDeviceClassNames` now accept any valid DeviceClass name, including names longer than 63 characters. ACTION REQUIRED: names that are not DNS subdomains (for example with uppercase letters, underscores or a `prefix/name` form) now fail validation at startup. They could never match a DeviceClass, so remove or fix them before upgrading.
```
