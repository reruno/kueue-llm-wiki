#### What this PR does / why we need it?

Adds the `ctx-structured-logging` reviewer skill and lists it in `cmd/experimental/skills/reviewer/README.md`. The entry was dropped from the index earlier, and this PR restores equivalent guidance with documented exceptions.

The skill flags a `context.Context` that is silenced (`_ = ctx`, `var _ = ctx`) instead of being used. It asks the reviewer whether the context should be:
- used for structured logging via `ctrl.LoggerFrom(ctx)`, or
- passed to the context-aware calls the function makes.

It does not treat every unused context as a defect. It lists the cases to skip:
- interface or callback implementations whose signature requires a context;
- stubs and fakes;
- a discard that a comment justifies;
- functions with nothing to log and no context-aware calls.

Fixes #13467
