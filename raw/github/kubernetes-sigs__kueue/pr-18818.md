<h3>Breaking Changes</h3>
<ul>
<li>feat!: Add webhook namespace-selector for multi-tenant deployments (<a href="https://redirect.github.com/kubeflow/spark-operator/pull/3217">#3217</a> by <a href="https://github.com/RobuRishabh"><code>@​RobuRishabh</code></a>)
<ul>

</li>
</ul>
