## Description

#### What type of PR is this?

#### What this PR does / why we need it?

`TopologyAwareScheduling` is enabled by default. The case `legacy overlap skip with RecomputePreemptionTargetsUponOverlap disabled` in `TestScheduleRecomputePreemptionTargets` sets it to `false`, but it passes without the override, so this PR removes it.

The two other `pkg/scheduler` cases that set it to `false` keep it: they cover the TAS-disabled path on purpose (#8209, #14228).

Part of #18804
