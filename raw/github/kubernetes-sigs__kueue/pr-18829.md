## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`TopologyAwareScheduling` is enabled by default. Five cases in the LeaderWorkerSet `TestReconciler` set it to `false`, but they pass without the override, so this PR removes it. None of them is about TAS: three cover `maxSurge`, one the owner reference of a redundant prebuilt Workload, and one `WorkloadLevelWaitForPodsReady`.

The other ten cases keep the override, because they fail without it.

Part of #18804
