## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`TopologyAwareScheduling` is enabled by default. Twelve cases in the StatefulSet `TestReconciler` set it to `false`, but they pass without the override, so this PR removes it. None of them creates a Workload, which is where TAS changes the expected result.

The other eight cases keep the override, because they fail without it. The remaining lines of the diff are `gofmt` realignment.

Part of #18804
