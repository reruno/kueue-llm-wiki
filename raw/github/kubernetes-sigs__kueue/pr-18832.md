## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`TopologyAwareScheduling` is enabled by default. Twelve overrides in the Pod integration unit tests set it to `false`, but the tests pass without them, so this PR removes them:

- `TestDefault`: eleven cases. The webhook does not gate the Pod in any of them, which is where TAS changes the expected result. Seven have an owner that Kueue already manages, and Kueue does not manage the other four.
- `TestReconcilePodQueueAndPriority`: one override for all cases. The test builds the Workload from the Pod under the same gate value, so the comparison does not depend on it.

The other twenty overrides in the package stay, because their tests fail without them.

Part of #18804
