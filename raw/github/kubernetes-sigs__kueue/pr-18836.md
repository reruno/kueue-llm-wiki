## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

`TopologyAwareScheduling` is enabled by default. Sixty-four cases in the Job `TestReconciler` set it to `false`, but they pass without the override, so this PR removes it. None of them creates a Workload or rewrites its PodSets, which is where TAS changes the expected result.

The other 22 overrides in the file stay, because their tests fail without them: 13 in `TestReconciler` and 9 in `TestPodSets`. `TestReconciler` runs each case twice, with `WorkloadRequestUseMergePatch` enabled and disabled, so these 22 are the 35 failing subtests counted in the issue.

Four lines of the diff are `gofmt` realignment.

Part of #18804
