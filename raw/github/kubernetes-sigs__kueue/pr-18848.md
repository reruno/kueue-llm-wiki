#### What this PR does / why we need it?

Follow-up to #18829, as suggested in https://github.com/kubernetes-sigs/kueue/pull/18829#issuecomment-6913148674.

Nine cases in the LeaderWorkerSet `TestReconciler` set `TopologyAwareScheduling` to `false` only to avoid the pod index label that TAS adds to the worker PodSet. This PR removes the override and expects the label, so these cases run with the default feature gates.

"should create prebuilt workload without topology request if TAS is disabled" keeps the override.

Part of #18804
