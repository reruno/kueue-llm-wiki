This PR updates the KEP for partial preemption (`keps/975-partial-preemption/README.md`). It changes one file, with 9 lines added and 7 removed.

The KEP now states that Alpha supports partial preemption for both classical preemption and Fair Sharing. The change:

- Removes the statements that deferred Fair Sharing support to Beta.
- Updates the Alpha algorithm description to cover both preemption modes.
- Updates the feature-gate interaction table. The Fair Sharing row now reads "Supported in Alpha."
- Adds Fair Sharing partial-preemption behavior to the unit-test plan.
- Adds the Fair Sharing scope to the Alpha graduation criteria.
- Adds an implementation-history entry that moves Fair Sharing support from Beta to Alpha.

This PR changes documentation only. It does not change Go code.

