#### What this PR does / why we need it?

Follow-up to #18836, as suggested in https://github.com/kubernetes-sigs/kueue/pull/18836#issuecomment-6913657222.

Nineteen cases in the Job unit tests set `TopologyAwareScheduling` to `false` only to avoid the pod index label that TAS adds to the PodSet: thirteen in `TestReconciler` and six in `TestPodSets`. This PR removes the override and expects the label, so these cases run with the default feature gates.

The three "... if TAS is disabled" cases in `TestPodSets` keep the override.

Part of #18804
