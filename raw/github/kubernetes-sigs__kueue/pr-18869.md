Follow-up to #18850, as agreed in https://github.com/kubernetes-sigs/kueue/pull/18850#discussion_r4584753215.

## AI summary

This PR removes the explicit `features.TopologyAwareScheduling: true` feature gate override from three StatefulSet webhook test cases in `pkg/controller/jobs/statefulset/statefulset_webhook_test.go`:

- `TestValidateCreate`: the case for unconstrained topology set to false alongside required topology. The case still enables `TASRejectFalseUnconstrainedTopology`.
- `TestValidateUpdate`: the case that adds conflicting TAS annotations.
- `TestValidateUpdate`: the case that corrects invalid TAS annotations.

The change is test-only. It removes 3 lines and adds none. The override is redundant because `TopologyAwareScheduling` is enabled by default. Runtime behavior is unchanged.
