#### Useful notes for your reviewer

The cherry-pick had two conflicts on `release-0.19`:
- `raycluster_controller_partial_scaleup_test.go`: this file does not exist on the branch, because the ElasticJob scale-up integration tests were not backported. I dropped it, so the `expectPodsUsage` part of #18063 is not included.
- `test/util/behavioral/queues.go`: the helper does not exist on the branch either. I added `ClusterQueueResourceUsage`, `ExpectClusterQueueResourceUsage` and `ExpectClusterQueueResourceUsageWithTimeout` as they are in `main`, plus the `time` import they need.

`scheduler_test.go` applied cleanly. Expected values and timeouts are unchanged.

`INTEGRATION_TARGET=./test/integration/singlecluster/scheduler/... GINKGO_ARGS="--focus='Workload slicing with multiple podSets'" make test-integration`: 2/2 specs passed.
