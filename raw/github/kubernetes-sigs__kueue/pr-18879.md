- Validation: provisioning unit tests, go vet, and the provisioning integration suite (27/27, on previous base `fd8af4700`) passed. - AI disclosure: prepared with AI assistance (Claude Code orchestrating GPT-6.1 Terra workers); validation listed above was run locally.

```release-note
ProvisioningRequest: Fix a bug where a Workload stayed Pending on a ProvisioningRequest admission check when a PodSet had a container without an image, such as the KubeRay autoscaler or the RayJob SidecarMode submitter. The ProvisioningRequest PodTemplate now fills missing images with the placeholder image `kueue.x-k8s.io/placeholder-image:placeholder`, and already stuck Workloads recover without being recreated.
```
