## AI summary

This PR adds test coverage for cached affinity in the TAS (Topology Aware Scheduling) snapshot logic. It changes two test files and no production code.

- `pkg/cache/scheduler/tas_flavor_snapshot_test.go`: Expands `TestMatchingLeavesCacheIsInvisible`. The test now covers preferred-affinity settings, interleaved PodSets, missing workload UIDs, virtual hostname levels, and injected node-matching failures. It creates simulators through a factory and checks topology levels, placements, failure reasons, and matching call counts.
- `pkg/cache/scheduler/tas_flavor_snapshot_was_test.go`: Adds `TestWASMatchingLeavesCacheIsInvisible`. It runs the same matching test through a WAS simulator factory, with scheduler-library integration enabled.

Linked issue `#18882` asks for parity between WAS and the Native Planner for preemptions without targets. This PR does not change preemption handling. Reviewers questioned the `Fixes #18882` reference, and a related open PR (`#18456`) overlaps with the shared test-case struct.
