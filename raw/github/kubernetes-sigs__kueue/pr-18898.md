#### What type of PR is this?

#### What this PR does / why we need it?

Same cleanup as #18890.

`TopologyAwareScheduling` is enabled by default, so setting it to `true` changes nothing. This PR removes that override from the 29 Job cases that have it: 20 in `job_webhook_test.go` and 9 in `job_controller_test.go`.

The cases that set it to `false` stay, because they cover TAS disabled.

Part of #18804
