## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Same cleanup as #18890.

`TopologyAwareScheduling` is enabled by default, so setting it to `true` changes nothing. This PR removes that override from the 37 places that have it in the `pkg/scheduler` and `pkg/cache` unit tests.

`TestSnapshotWithOverlappingTASUsage` sets no other feature gate, so its `featureGates` field is removed too.

The cases that set it to `false` stay, because they cover TAS disabled.

Part of #18804

- Removes `TopologyAwareScheduling: true` overrides from unit tests in `pkg/scheduler` and `pkg/cache`. The gate is enabled by default, so these overrides had no effect.
