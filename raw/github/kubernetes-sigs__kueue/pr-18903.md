## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

Same cleanup as #18890.

`TopologyAwareScheduling` is enabled by default, so setting it to `true` changes nothing. This PR removes that override from the 17 places that have it in the `jobframework`, `workload`, `webhooks`, `podset`, core controller and TAS controller unit tests.

The cases that set it to `false` stay, because they cover TAS disabled.

Part of #18804
