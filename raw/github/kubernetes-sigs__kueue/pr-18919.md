## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

First part of removing the standalone kustomize binary, split out of #18880. `kubectl kustomize` has no `edit` command, so this replaces the `kustomize edit` calls with yq, which the repo already pins:

- `kustomize edit set image` (Makefile, appwrapper manifests, e2e scripts) now uses the new `hack/kustomization-set-image.sh`.
- `kustomize edit add patch` in the cert-manager e2e setup now uses a small yq helper.
- `cmd/importer/README.md` now says to set the importer image in `kustomization.yaml` by hand, and uses the `main` tag instead of the stale `main-latest`.

`kustomize build` is not changed here. #18880 switches it to `kubectl kustomize`.

Part of #11075

#### Useful notes for your reviewer

- The script does the same as `kustomize edit set image NAME=NEW_NAME[:NEW_TAG][@DIGEST]`: it replaces the entry, so a tag or digest that is not given is removed, or adds it and keeps the list sorted. It rejects a few invalid forms that kustomize accepts, like `:v1`, because it would otherwise write them differently.
- yq drops blank lines when it writes a file, so this removes the blank lines from the four `kustomization.yaml` files the script edits. Otherwise `make verify` would show them as changed after `prepare-release-branch`.
- `deploy`, `prepare-manifests`, `prepare-release-branch` and `appwrapper-manifests` now list `yq` instead of `kustomize`, because they only used it to edit files. `deploy` still gets `kustomize` through `compile-crd-manifests` until #18880 lands.

| Behavior | Command and result |
|---|---|
| Script matches `kustomize edit set image` | `make kustomization-set-image-test`: the expected files are kustomize v5.8.3 output |
| Files stay unchanged | Setting each file's current images leaves all four files byte-identical, so `make verify` stays clean |
| Release manifests do not change | `_prepare_manifests_recipe` and `_artifacts_recipe`: the 12 files are identical to `main` |
| Verify | `make kustomize-build-verify` and `hack/testing/verify-generation-order_test.sh` pass |

## AI summary

This change replaces `kustomize edit` calls with a `yq`-based helper in build, deployment, and e2e tooling. It does not change Kueue runtime behavior. `kustomize build` is unchanged.

- Adds `hack/kustomization-set-image.sh`. The script takes a directory and `NAME=NEW_NAME[:NEW_TAG][@DIGEST]`. It rejects invalid input with a usage or image-format error. It requires a nonempty new name and at least one of tag or digest. It uses `YQ` when set, otherwise `bin/yq`. It updates `DIR/kustomization.yaml`. A matching image entry is replaced as a whole, so an omitted tag or digest is removed. A missing entry is added, and the list is sorted by name. It writes through a temporary file in the system temporary directory, then copies the result into place.
- Adds `KUSTOMIZATION_SET_IMAGE` in `hack/make/deps.mk`. It wraps the script with the configured `YQ` binary. The `appwrapper-manifests` target uses it and now depends on `yq` instead of `kustomize`.
- Updates `Makefile` image-setting steps for the manager, KueueViz, populator, and priority-booster manifests to use the script. The `deploy`, `prepare-manifests`, and `prepare-release-branch` targets now depend on `yq`. `deploy` still obtains `kustomize` through `compile-crd-manifests`.
- Adds `kustomization_add_patch()` to `hack/testing/e2e-common.sh`. It appends a patch only when no entry with the same path and target kind exists. An empty kind adds a path-only entry. The cert-manager e2e setup uses this helper instead of `kustomize edit add patch`. `set_managers_image` and `restore_managers_image` call the script.
- Updates `cmd/experimental/kueue-populator/run-e2e.sh` to set the populator image with the script.
- Removes blank lines or repeated settings from four `kustomization.yaml` files. The listed resources are unchanged.
- Adds `verify-kustomization-set-image-test` to `verify-checks`. Adds `hack/testing/kustomization-set-image_test.sh`. Adds a `kustomization_add_patch` test to `hack/testing/e2e-common_test.sh`.
- Open review question: `cmd/importer/README.md` still tells users to run `kustomize edit set image`. This change does not update it.
