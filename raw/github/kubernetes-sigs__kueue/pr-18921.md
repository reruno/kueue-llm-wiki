## AI summary

This PR adds validation for DRA `deviceClassMappings` in the Kueue configuration. It changes three files.

- `pkg/config/validation.go`:
  - Rejects a mapping that has two sources with the same `driver`/`name`. Counter and capacity sources share one key set within a mapping.
  - Collects counter names from all counter sources in a mapping, not only the first one.
  - When one DeviceClass maps to different resources, rejects the reuse if either mapping has no counter names, or if their counter-name sets overlap. Otherwise, merges the names.
- `pkg/config/validation_test.go`: adds `TestValidate` cases for duplicate counter and capacity sources within one mapping. Adds cases for a counter name reused by a later source or mapping for the same DeviceClass, including a case where an intervening mapping adds a different counter.
- `keps/2941-DRA/README.md`: documents that a mapping can contain multiple counter sources. States that duplicate `(driver, name)` pairs are rejected. Allows a DeviceClass to appear in multiple mappings when their counter names are distinct. Documents that each counter or capacity source must match enough devices at runtime. This PR does not change runtime code.

Configurations with duplicate sources, or with counter names reused across mappings for the same DeviceClass, now fail validation at startup. Kueue v0.19 and v0.20 accepted some of these configurations.

## Suggested release note

```release-note
DRA: Fixed a bug that caused a `deviceClassMappings` entry with duplicate counter or capacity sources (same `driver` and `name`) to charge quota twice when the entry was used. Now Kueue rejects these entries during configuration validation at startup. Kueue also checks all counter sources when mappings share a DeviceClass.

ACTION REQUIRED: Before you upgrade, remove duplicate `driver`/`name` sources from any `deviceClassMappings` entry. Also remove counter names that are reused for the same DeviceClass in another mapping. Kueue fails validation at startup for these configurations.
```
