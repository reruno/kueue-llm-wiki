#### What this PR does / why we need it?

Cherry-pick of #17374 to `release-0.20`, as [requested](https://github.com/kubernetes-sigs/kueue/pull/17374#issuecomment-6929689051). Releases unused topology reservations after elastic Jobs shrink so waiting Jobs can use the freed capacity.

#### Useful notes for your reviewer

Resolved an import conflict by preserving this branch's existing alias. The fix and regression coverage match #17374.

Passed locally:
- `go test -race -count=1 ./pkg/controller/tas ./pkg/controller/core ./pkg/cache/queue`
- All six Job integration cases in `Job controller with TAS and ElasticJobsViaWorkloadSlices`, plus the TAS unhealthy-node recovery regression, with race detection and envtest Kubernetes 1.37.0.
- `make verify`

AI assistance was used to prepare this cherry-pick.

#### Release note

```release-note
TAS × ElasticJobsViaWorkloadSlices: Fixed a bug where an elastic Job kept unused topology capacity reserved after scaling down, preventing waiting Workloads from using it. Kueue now releases that capacity once the removed Pods terminate.
```
