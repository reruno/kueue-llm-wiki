#### What this PR does / why we need it?

Enable `contextcheck` in the shared golangci-lint configuration so lost context propagation is checked automatically.

Handle the 12 baseline findings in the root module:
- Pass the incoming context at three scheduler-cache test call sites instead of obtaining a separate `t.Context()`.
- Add justified line-level exemptions for the two MultiKueue lines where the controller-lifetime logger and the remote watchers must outlive the reconciliation. The resync in the same function now uses the reconciliation context.
- Add justified line-level exemptions for the three Workload event handlers' cache and queue updates: event contexts end before delayed resource lookups. The enqueue calls in the same handlers now receive the event context, since `TypedEnqueueRequestForObject` ignores it.

Handle three additional findings in the independent kueueviz backend module: use `context.WithoutCancel(ctx)` for informer-handler cleanup and as the parent of the existing timeout-bound shutdown context. This preserves context values while allowing cleanup after cancellation.

The ruleguard rule, DSL dependencies, vendored files, and custom rule test tooling have been split out for a separate discussion, as requested in review. This PR contains only contextcheck configuration and its call-site fixes/exemptions.
