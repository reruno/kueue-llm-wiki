#### What this PR does / why we need it?

**Do not merge. This draft PR only runs CI.**

Dependabot's bump of spark-operator from v2.5.2 to v2.6.0 (#18818) failed every job because Kueue no longer compiles:

```
vendor/github.com/kubeflow/spark-operator/v2/api/v1beta2/zz_generated.openapi.go:221:6: undefined: v1.PodStatusResult
vendor/github.com/kubeflow/spark-operator/v2/api/v1beta2/zz_generated.openapi.go:298:6: undefined: v1.WorkloadReference
```

spark-operator v2.6.0 is built against `k8s.io/api` v0.35, and its generated OpenAPI file references two `core/v1` types that `k8s.io/api` v0.37 removed. Kueue uses v0.37.

kubeflow/spark-operator#3281 bumps spark-operator to `k8s.io` v0.37. This PR points `github.com/kubeflow/spark-operator/v2` at that PR's head commit (`yindia/spark-operator@9c371a1`) with a `replace` directive. The goal is to confirm that the upstream change fixes the Kueue build and CI before we ask upstream to merge and release it.

The `require` line is v2.6.0, so the e2e lanes install the released v2.6.0 operator. The Go code compiles against the fork's types.

Related: #18824
Related: #18107
