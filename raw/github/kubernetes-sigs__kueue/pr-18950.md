## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

Manual cherry-pick of #17056 for `release-0.19`, replacing #18944.

Preserves explicitly empty toleration values as `Equal`, while keeping the existing wildcard forms as `Exists`.

#### Useful notes for your reviewer

The new command test uses explicit `TypeMeta` and `ObjectMeta` literals for Go 1.26 compatibility. The parser fix and integration regression are unchanged from the merged PR.

Validation with Go 1.26.10: create package race unit tests, kueuectl race integration tests with envtest Kubernetes 1.36.0, `make fmt-verify`, and package-scoped golangci-lint 2.14.0 pass. The command regression fails against the original parser and passes with the fix.

/assign mbobrovskyi

#### Release note

```release-note
CLI: Fixed a bug where `kueuectl create resourceflavor --tolerations key=:NoSchedule` created an `Exists` toleration that also matched taints with nonempty values. It now creates an `Equal` toleration with an empty value. To tolerate any value, omit the `=` (for example `key:NoSchedule`).
```
