#### What this PR does / why we need it?

Unexports two helpers in `pkg/controller/jobs/raycluster` that are only used within that package:

- `ParsePodSetReplicaSizes` becomes `parsePodSetReplicaSizes`. Its only callers are `common.go` and `common_test.go`.
- `BuildPodSetAnnotationsPathByNameMap` becomes `buildPodSetAnnotationsPathByNameMap`. Its only callers are `common.go` and `raycluster_webhook.go`. This also matches the unexported helper with the same name in the JobSet webhook.

A repo-wide search across `pkg/`, `test/`, and `cmd/` found no callers outside the package. This is a rename only; logic is unchanged.

Follow-up to PR 18946.
