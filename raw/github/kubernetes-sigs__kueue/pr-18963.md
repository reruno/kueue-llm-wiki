#### What this PR does / why we need it?

The KueueViz frontend had only a few JS-level unit tests, so most component
changes could only be verified through the slower Cypress e2e suite.

This PR adds DOM-level unit tests (Vitest + Testing Library) for all
frontend components and the `useWebSocket` hook. They cover loading, error
and empty states, user interactions and edge cases.

- Adds tests for `App`, `AuthContext`, `ClusterQueueDetail`, `ClusterQueues`,
  `Cohorts`, `FlavorTable`, `LocalQueueDetail`, `LocalQueues`, `Login`,
  `Navbar`, `ResourceFlavors`, `ViewYamlButton`, `YamlViewer` and `useWebSocket`.
- Extends the existing tests for `Dashboard`, `Workloads`, `WorkloadDetail`,
  `ResourceFlavorDetail`, `CohortDetail`, `ErrorMessage` and `UsageBar`.
- Adds shared helpers in `src/testing/helpers.jsx`.
- Adds `npm run test:coverage` and `make test-coverage`, backed by
  `@vitest/coverage-v8`, and documents how to write tests in `CONTRIBUTING.md`.

Frontend coverage goes from 50.8% to 98.9% of statements, and from 136 to
372 tests. No component code is changed.

Fixes #12633

#### Useful notes for your reviewer

- `ErrorMessage.test.js` and `UsageBar.test.js` are renamed to `.test.jsx`,
  because Vite only parses JSX in `.jsx` files. The `buildCohortTree` tests
  moved from `Cohorts.test.js` into `Cohorts.test.jsx`.
- Coverage thresholds are not enforced. That can be a follow-up.
- `package-lock.json` also bumps a few `@babel/*` packages as a side effect
  of adding the coverage package.
