#### What this PR does / why we need it?

Fixes #18962

With `SchedulerLibraryDeepIntegration` enabled, a lower-priority Workload
waiting for an AdmissionCheck can reserve quota without creating Pods. WAS
cannot represent that Workload as a Pod-level victim, so a higher-priority
Workload could remain pending even when its Pods fit on current nodes.

This change falls back to Kueue quota-only target selection after WAS confirms
node feasibility but returns no Pod-level victims.
