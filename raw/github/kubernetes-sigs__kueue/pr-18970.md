#### Useful notes for your reviewer

The cherry-pick had conflicts on `release-0.19`:
- `rayclusterwebhook/elastic_partial_scaleup_test.go`, `rayjob_controller_partial_scaleup_test.go`, `rayservice_controller_partial_scaleup_test.go` and `sparkapplication_elastic_test.go`: these files do not exist on the branch, because the ElasticJob partial scale-up integration tests were not backported. I dropped them.
- The `waitForPodsReady` containers in the job tests: `main` sets `UnscheduledTimeout`, which does not exist on the branch. I kept the branch's empty `WaitForPodsReady{}` and applied the move to `BeforeEach` with `fwk.StartManagerForSpec`.
- `mpijob_controller_test.go`: I did not add the `unscheduledTimeout` spec, because it needs the `WaitForPodsReadyUnscheduledTimeout` feature gate, which is only in `main`.

The other files applied cleanly. The `RayCluster with elastic jobs via workload-slices support` container in `raycluster_controller_test.go` stays `Ordered`, because #18660 does not change it.

Integration tests: 15/15 suites, 213/213 specs passed.
