#### What this PR does / why we need it?
This updates KEP-2941 to graduate `KueueDRAIntegrationPrioritizedList` to Beta in v0.21. Beta keeps the Alpha scope: Kueue charges a `firstAvailable` request only when its alternatives ask for the same `count` on one logical resource. Alternatives that differ in `count` or logical resource, and alternatives with a `counter` or `capacity` source, stay rejected. Supporting any of them needs its own Alpha gate.
