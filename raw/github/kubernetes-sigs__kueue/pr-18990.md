## Description

#### What type of PR is this?

#### What this PR does / why we need it?
Validates `deviceClassMappings[].deviceClassNames` and `excludeDeviceClassNames` as DeviceClass names (DNS subdomain, up to 253 characters) instead of label keys, so valid names longer than 63 characters no longer stop Kueue from starting. Both lists use one helper, `validateDeviceClassName`.

Fixes #18780

#### Useful notes for your reviewer
The second commit covers `excludeDeviceClassNames`, which landed in #18632.

#### Release note
```release-note
DRA: `deviceClassMappings[].deviceClassNames` and `excludeDeviceClassNames` now accept any valid DeviceClass name, including names longer than 63 characters. ACTION REQUIRED: names that are not DNS subdomains (for example with uppercase letters, underscores or a `prefix/name` form) now fail validation at startup. They could never match a DeviceClass, so remove or fix them before upgrading.
```

## AI summary

This change updates validation for DeviceClass names in the Kueue configuration. Both `deviceClassMappings[].deviceClassNames` and `resources.excludeDeviceClassNames` now use one shared helper, `validateDeviceClassName`. The helper checks each name with the Kubernetes DNS subdomain validator (`IsDNS1123Subdomain`). It accepts names up to 253 characters, including names longer than 63 characters. It rejects names that are not DNS subdomains, such as names with uppercase letters, underscores, or a slash-prefixed label-key form.

The change also:

- Updates `validateDeviceClassName` to remove the label-key check and the separate 253-character check.
- Updates the API field documentation in `apis/config/v1beta2/configuration_types.go` and `site/content/en/docs/reference/kueue-config.v1beta2.md`.
- Updates `pkg/config/validation_test.go` with cases for names longer than 63 characters, a valid 253-character name, and invalid characters or formats.

The feature-gate check, the 16-name limit, the duplicate check, and the check against mapped DeviceClasses are unchanged.

Diff size: 4 files, 179 lines added, 38 lines removed.

Test results: not available. The PR does not report test runs, and this summary did not run them.

## Suggested release note

```text
ConfigAPI: Fixed a bug where valid DeviceClass names longer than 63 characters in `deviceClassMappings[].deviceClassNames` or `excludeDeviceClassNames` were rejected at startup. Now Kueue accepts any valid DeviceClass DNS subdomain of up to 253 characters.

ACTION REQUIRED: If your configuration lists a DeviceClass name that is not a valid DNS subdomain, such as one with uppercase letters, underscores, or a `/` prefix, remove or correct that name before upgrading. Kueue now rejects these names at startup.
```
