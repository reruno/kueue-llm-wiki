## AI summary

This PR upgrades Hugo from 0.169.0 to 0.170.0 and adds Dart Sass 1.108.2 as a build dependency. Hugo 0.170.0 removed LibSass, so `toCSS` now needs the Dart Sass `sass` binary on `PATH`.

- **Dart Sass installer:** Adds `site/scripts/install-dart-sass.sh`. It installs Dart Sass 1.108.2 into a destination directory.
  - If the destination already has an executable `sass` that reports 1.108.2, the script exits without changes.
  - It supports Linux x86_64/ARM64 and macOS x86_64/ARM64. Other platforms fail.
  - It downloads the archive with `curl --retry 3`, verifies its SHA-256 checksum, and extracts it.
  - If the destination exists without an executable `sass`, the script refuses to replace it.
- **Make targets:** `hack/make/deps.mk` defines `DART_SASS_DIR` as `$(BIN_DIR)/dart-sass` and adds a `dart-sass` target. That target runs the installer through `NETWORK_INSTALL_RETRY`.
- **Local site server:** `site-server` now depends on `dart-sass`. It prepends `DART_SASS_DIR` to `PATH` when it runs `hugo server`.
- **Netlify:** `netlify.toml` sets `HUGO_VERSION` to `0.170.0`. The production, deploy-preview, and branch-deploy build commands each run the installer into `${HOME}/.local/dart-sass` and add that directory to `PATH` before Hugo runs. The production command keeps its npm install, Hugo garbage collection, minification, and search build steps.
- **Tool dependencies:** `hack/tools/go.mod` updates `github.com/gohugoio/hugo` to `v0.170.0` and `hugo-goldmark-extensions/passthrough` to `v0.6.0`. It removes `bep/golibsass`, `oasdiff/yaml`, and `oasdiff/yaml3`. `go.sum` also changes.
- **Documentation:** The website contribution guidelines document the Dart Sass requirement. The Kueue documentation-writing skill adds the `make dart-sass` step to its validation instructions.

No exported or public declarations change.
