#### What this PR does / why we need it?
Dependabot never proposed a Docsy update for the website. `site/go.mod` requires Docsy as `// indirect`, because the site imports it as a Hugo module and no Go package imports it. For Go modules, Dependabot updates only direct dependencies by default, so Docsy stayed at v0.11.0 (the last bump was manual).

This PR moves `/site` into its own `gomod` entry with `allow: dependency-type: "all"`, so Dependabot also proposes updates for the Docsy module. The schedule and labels match the shared `gomod` entry; `/`, `/hack/tools`, and `/cmd/kueueviz/backend` keep the default (direct dependencies only) to avoid a flood of indirect-dependency PRs.
