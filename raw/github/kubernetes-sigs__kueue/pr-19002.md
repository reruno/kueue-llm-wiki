## Description

Cherry pick of #18977 on release-0.19.

#18977: Pick a ResourceFlavor that fits the Pod in the Pod importer

For details on the cherry pick process, see the [cherry pick requests](https://git.k8s.io/community/contributors/devel/sig-release/cherry-picks.md) page.

The cherry-pick robot could not apply the change. With `git cherry-pick`, only `cmd/importer/cache/cache.go`, `cache_test.go` and `pkg/scheduler/flavorassigner/flavorassigner.go` conflict; the other files apply cleanly. The behavior is the same as on main. The conflicts and one compile difference are resolved as follows:
- `cmd/importer/cache/cache.go`: release-0.19's importer cache does not use the `resourcegroups` package, so `flavorsByResourceFrom` keeps the branch's `[]kueue.ResourceGroup` input. It now returns every flavor of the group, in order, instead of only the first.
- `cmd/importer/cache/cache_test.go`: takes main's version, which tests through `Load` and `FlavorsByResourceForClusterQueue`.
- `pkg/scheduler/flavorassigner/flavorassigner.go`: renames `flavorSelector` to `FlavorSelector` and keeps the branch's `corev1.Node{ObjectMeta: metav1.ObjectMeta{Labels: ...}}`.
- `cmd/importer/pod/check.go` applied without a conflict but did not compile: `corev1.Node` in this branch's `k8s.io/api` has no promoted `Labels` field. It now uses the same `ObjectMeta` form and imports `metav1`.

#### What type of PR is this?
/kind bug

#### Useful notes for your reviewer

`go build ./...`, `go vet` and `go test` pass for `cmd/importer/...` and `pkg/scheduler/flavorassigner`. `go test ./test/integration/singlecluster/importer/...` passes with envtest 1.37. With release-0.19's original `cache.go` and `check.go`, the 5 new `TestImportNamespace` cases fail. With this PR, they pass.

AI tools (Claude Code) assisted with this backport; the conflicts were resolved and the tests run as described above.

```release-note
Importer: Fixed a bug where the Pod importer always used the first ResourceFlavor of a resource group, so a Pod could be imported with a flavor whose node labels or taints it does not match. The importer now uses the first flavor that fits the Pod's node selector, required node affinity and tolerations, and rejects the Pod when none does.
```
