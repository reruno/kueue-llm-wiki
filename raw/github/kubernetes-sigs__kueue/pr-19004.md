#### What this PR does / why we need it?

Offline Helm rendering can omit MutatingAdmissionPolicy resources even when `enableMutatingAdmissionPolicy` is enabled, because target-cluster API discovery is unavailable. The chart now also renders the policy and its binding when the target Kubernetes version is at least 1.36. API discovery remains supported, and the existing flag still controls both paths.

This takes over https://github.com/kubernetes-sigs/kueue/pull/14704 by Amir Ibrahim (@amirialy). His two original signed-off commits retain their authorship and author dates; the updated GitOps examples are a separate commit.

Fixes #14592

## AI summary

This PR changes the Helm chart so it renders the `MutatingAdmissionPolicy` and its `MutatingAdmissionPolicyBinding` when the target Kubernetes version is 1.36 or later. Before this change, rendering required the target cluster to advertise the API. The `enableMutatingAdmissionPolicy` value still controls both resources.

- `charts/kueue/templates/map/manifests.yaml` and `hack/processing-plan.yaml`: both resources render when `enableMutatingAdmissionPolicy` is true and either the API version is advertised or `.Capabilities.KubeVersion.Version` satisfies `>=1.36-0`. The generator input and generated template match. The Deployment condition in `processing-plan.yaml` changes only by trailing whitespace.
- `charts/kueue/values.yaml`: the `enableMutatingAdmissionPolicy` description now says the feature requires Kubernetes 1.36+ or the `admissionregistration.k8s.io/v1` MutatingAdmissionPolicy API. The value and default are unchanged.
- `charts/kueue/tests/mutatingadmissionpolicy_test.yaml`: adds Helm unit tests for Kubernetes 1.35 without the API, with the API, and with the feature disabled. It also adds tests for Kubernetes 1.36 with the feature enabled and disabled.
- `charts/kueue/README.md` and `charts/kueue/README.md.gotmpl`: add an "Offline manifest generation" section. It covers setting an explicit target Kubernetes version for Helm or Kustomize, enabling `enableMutatingAdmissionPolicy`, using a chart release that contains the fix, and prefetching the chart for offline Kustomize builds.
