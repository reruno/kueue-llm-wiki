## AI summary

This PR changes release-note tooling in `hack/releasing/`. It does not change Kueue runtime behavior.

- `hack/releasing/set_release_note.py`: Updates the `set_release_note` docstring. When no author release-note block exists and a generated section exists, the new block goes before the first generated section. This applies even if that section has no release-note block. The docstring also states that an author block after a generated release-note block is rejected.
- `hack/releasing/set_release_note_test.py`: Adds a `CODERABBIT_TEXT_SECTION` fixture, which is a generated section with a `text` block. Adds two test cases. Both assert that the new release-note block is inserted before this section. One case has a summary before the section. The other case has the section as the only body content.

No public or exported declarations change.
