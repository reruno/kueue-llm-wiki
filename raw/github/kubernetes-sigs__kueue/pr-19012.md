#### What this PR does / why we need it?

Combines two changes on upstream main at `71c236e4d` for combined CI validation. Not meant to be merged. It replaces #18935 (closed); #18407 is now part of upstream main.

- `0db45a6c2`: the cluster-targeting annotation commit from #18288 (originally `31bd887b194fab9bee6dac33601e32c08384a49b`): the alpha, disabled-by-default `MultiKueueClusterNames` feature gate and the `kueue.x-k8s.io/multikueue-cluster-names` annotation. A conflict in `test/integration/multikueue/jobs_test.go` was resolved by keeping both new specs.
- `ed3bcb70c`: #18949 at `a03d9caf7`, squashed. The MultiKueue AdmissionCheck event handler uses `handler.EnqueueRequestsFromMapFunc`, so the Workloads of initial-list AdmissionCheck events are queued at low priority after a manager restart.
