#### What this PR does / why we need it?

Brings the dependency bumps of #18721 to `release-0.19`, to pick up CVE fixes:

| Module | From | To | Fixes |
|---|---|---|---|
| `golang.org/x/net` | v0.58.0 | v0.62.0 | CVE-2026-78663, CVE-2026-78659, CVE-2026-78660, CVE-2026-78669, CVE-2026-97032 (HTTP/2), CVE-2026-78661, CVE-2026-97045 (`html`) |
| `github.com/go-jose/go-jose/v4` | v4.1.4 | v4.1.6 | CVE-2026-116587, plus CVE-2026-116585 and CVE-2026-116586 (fixed in v4.1.5) |
| `go.etcd.io/etcd/client/pkg/v3` | v3.6.8 | v3.6.14 | CVE-2026-73500 |

The x/net bump also raises the other `golang.org/x` modules (crypto, mod, sync, sys, term, text, tools) to the versions on `release-0.20`. For `golang.org/x/crypto` that is v0.55.0 to v0.58.0, which includes the fixes for CVE-2026-78662 and CVE-2026-56855 (`ssh`).

A plain cherry-pick of #18721 does not apply, because `release-0.19` starts from older versions of several of these modules, so the change is regenerated on this branch. The one difference from #18721 is etcd: `release-0.19` is on the etcd 3.6 line, so `client/pkg` goes to v3.6.14, the 3.6 release with the fix, instead of v3.7.1.

This PR started as the go-jose bump only and was widened to the full set of #18721 as asked in review.

Fixes #18978

#### Useful notes for your reviewer

- Generated with `go get golang.org/x/net@v0.62.0 github.com/go-jose/go-jose/v4@v4.1.6 go.etcd.io/etcd/client/pkg/v3@v3.6.14 && go mod tidy && go mod vendor` (Go 1.26.10). Only `go.mod`, `go.sum` and `vendor/` change.
- The `go` directive stays at 1.26.0. All of the new `golang.org/x` versions declare `go 1.26.0`.
- The vendored `golang.org/x/*` and go-jose trees are identical to the ones on `release-0.20` (same git tree hashes).
- `hack/tools/go.mod` is not changed. It is not part of the manager binary and #18721 did not change it either.

Tested locally with Go 1.26.10:
- `go build ./...`, `go vet ./...` and `go mod verify`: pass
- `go mod tidy` and `go mod vendor` leave the tree unchanged
- `go test -race` on the packages that `make test` selects (204 packages, 111 of them with tests): pass
