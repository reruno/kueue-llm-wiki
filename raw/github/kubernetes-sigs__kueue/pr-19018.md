## Description

This is a manual cherry-pick of #19001 to release-0.19.

The automated cherry-pick conflicted in pkg/cache/queue/metrics.go because release-0.19 does not have custom metric labels on workloads for LocalQueues. The conflict was resolved by updating the fallback branch when the ClusterQueue is missing to report pending workloads as inadmissible, and adapting the test for release-0.19 custom LocalQueue labels.

/assign sohankunkerkar

```release-note
Observability: Fixed a bug that caused LocalQueue pending workload metrics to report zero when the associated ClusterQueue did not exist or was deleted. Now Kueue reports these pending workloads as inadmissible and refreshes the metrics when a ClusterQueue is deleted.
```

/kind bug
