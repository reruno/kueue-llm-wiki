#### What this PR does / why we need it?

Adds `hack/releasing/provenance.py`, which builds the SLSA v1 build provenance predicate for a staging build. It also checks a verified attestation against a release tag and its commit. A ref or commit mismatch is reported as not ready, so a caller can keep waiting while a moved tag is rebuilt. The module has no callers yet, so release behavior does not change.

Part of #1466 (KEP-1466; design in #17754).
