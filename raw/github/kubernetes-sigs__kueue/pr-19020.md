## Description

#### What this PR does / why we need it?

When `DIGEST_DIR` is set, the image targets pass `--metadata-file` to buildx for the kueue, kueueviz, kueue-populator, and kueue-priority-booster images. The Helm chart push writes each chart digest to `DIGEST_DIR`. A relative `DIGEST_DIR` is made absolute. Without `DIGEST_DIR` the build commands are unchanged, so release builds do not change.

Part of #1466 (KEP-1466; design in #17754).

#### Useful notes for your reviewer

| behavior | level | command and result | not run and why |
|---|---|---|---|
| `--metadata-file` is passed only when `DIGEST_DIR` is set; a relative `DIGEST_DIR` is made absolute; the default goal is unchanged | unit | `make verify-image-build-test` (`hack/testing/image-build_test.py`): passed | none |
| Chart digest is parsed from the `helm push` output; a missing digest fails | unit | `make verify-image-build-test` (`hack/testing/helm-chart-package_test.py`): passed | none |

Note: `make -n` output without `DIGEST_DIR` is identical to `main`.
