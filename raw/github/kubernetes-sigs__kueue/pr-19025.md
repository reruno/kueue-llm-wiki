#### What this PR does / why we need it?

Bumps the Docsy theme of the website from v0.11.0 to v0.18.1 and adapts the site to each release:

- Imports the theme from `github.com/docsy/docsy/theme`, the module path after the Docsy theme folder move (v0.16) and the move to the `docsy` GitHub organization (v0.18).
- Drops the explicit module mounts and uses the theme's own mounts. Since v0.16, Docsy gets Bootstrap and Font Awesome from npm, so this adds the npm workspace that `hugo mod npm pack` generates (`site/packages/hugoautogen`).
- Removes the `head-css.html` override, which only existed for the deprecated language direction API, so Docsy compiles its styles with Dart Sass (installed by `site/scripts/install-dart-sass.sh`).
- Rebases the `sidebar-tree.html` override on the current template and keeps the Pagefind search button.
- Keeps the current look of the navbar override: the logo margin, the navbar icon width under Font Awesome 7, and the position of the light/dark theme menu.
- Restores the sidebar language menu on narrow viewports (`sidebar_lang_menu`), adds zh-CN strings for the new TOC title, switches to the renamed anchor class, and moves the favicons to the `static/` root, where Docsy now discovers them.
- Makes `make site-server` install the site's npm dependencies and documents the Node.js requirement.

Related: #18994

#### Useful notes for your reviewer

No behavior change outside the website.

- The theme was upgraded one release at a time (v0.12.0, v0.13.0, v0.14.3, v0.15.0, v0.16.0, v0.17.0, v0.18.0, v0.18.1). After each step, the production build was compared with the previous one: generated HTML and CSS diffs, and headless Chrome screenshots of the home, docs (light and dark), community, zh-CN, and mobile pages. The theme menu, Pagefind search, and code copy buttons were checked as well.
- Intended visual changes from Docsy: bolder top-level TOC entries, a TOC title ("On this page"), and slightly wider Font Awesome 7 icons outside the navbar.
- The Android icons in `static/favicons/` are no longer linked, because Docsy only discovers `favicon*` and `apple-touch-icon*` files.
- Please check the Netlify deploy preview: deploy previews rely on Netlify installing the npm dependencies automatically.
- Follow-ups, not in this PR: `site/layouts/partials/head.html` still loads jQuery 3.5.1 and the Bootstrap 4.6.2 bundle, and `autoprefixer`/`postcss-cli` are no longer used.
