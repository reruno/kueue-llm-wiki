## Description

#### What type of PR is this?

/kind bug

#### What this PR does / why we need it?

When one LocalQueue update changed a custom metric label value and set `spec.stopPolicy`, the controller cleared the LocalQueue gauges but skipped the resync, so `kueue_local_queue_admitted_active_workloads` went missing and dropped to -1 once the Workloads finished. An update that made the LocalQueue match `localQueueSelector` while stopping or resuming it also left the gauges missing, because the scheduler cache kept the old LocalQueue labels.

This PR always resyncs after clearing and refreshes the cached LocalQueue on every update. It continues #17457, keeping the original commit, and addresses the review comments there.

Fixes #17356


## AI summary

This PR fixes missing LocalQueue workload gauges after one update changes a custom-label value and sets `spec.stopPolicy`.

**Behavior changes in `LocalQueueReconciler.Update` (`pkg/controller/core/localqueue_controller.go`):**

- The reconciler updates the scheduler cache's LocalQueue copy on every update. Previously, it updated the cache only in some branches.
- The queue manager calls remain conditional on stop-policy transitions.
- The gauge resync no longer skips queues that are transitioning to a stopped policy.
- A comment about clearing gauges during updates is removed.

**Tests:**

- `pkg/controller/core/localqueue_controller_test.go`: `TestLocalQueueCustomLabelUpdateMetricRefresh` configures LocalQueue metrics in the scheduler cache and queue manager. It seeds the fake client with the original LocalQueue, so the test models an update that arrives after the caches are built. It adds an admitted Workload and checks that the admitted and reserving active-workload gauges use the `beta` label. The table cases cover stopped and non-stopped queues.
- `test/integration/singlecluster/controller/core/custom_labels_test.go`: adds an integration test. A label change from `alpha` to `beta` and a stop policy change to `Hold` happen in one update. The test checks that both gauges move to the `beta` series and that the `alpha` series is removed. It also checks that both `beta` gauges reach zero after the Workload finishes.
- `test/integration/singlecluster/controller/core/localqueue_controller_test.go`: adds integration tests for a LocalQueue whose labels start matching the metrics selector in the same update as a stop policy change. The tests cover a change to `Hold` and a change from `Hold` to `None`. Both expect the admitted and reserving gauges to report 1.
- `test/util/behavioral/metrics.go`: `ExpectLQReservingActiveWorkloadsMetric` accepts optional custom label values after the existing labels.

**Diff size:** 5 files changed, 227 lines added, 50 lines removed.
