## AI summary

This PR aligns logging in the `Cohort`, `LocalQueue`, and `WorkloadPriorityClass` controllers with the Kueue logging policy. The change affects logs only. It does not change Events, conditions, or API writes.

- **Log levels:** Routine per-object logs move from level 2 to level 3. Some event logs also change level.
- **Removed logs:** Duplicate logs and `V(2).Error` logs are removed.
- **Renamed keys:** `oldValue` becomes `previousValue`. `newPriority` becomes `priority`.
- **Error handling:** Errors are wrapped with operation-specific context. In `WorkloadPriorityClass` reconciliation, parallel workload update errors are collected and joined with `errors.Join`, so all causes are kept. `NotFound` update errors are still ignored.
- **Tests:** `TestWorkloadPriorityClassReconcile` adds a case where updates to two workloads fail with distinct errors. The test checks each expected error with `errors.Is`.
- **Scope:** 4 files changed, 127 lines added, 68 lines removed.

Dashboards, alerts, and log queries that use the old messages, keys, or levels may need updates. Set log verbosity to 3 or higher to keep per-object reconcile and event logs.
