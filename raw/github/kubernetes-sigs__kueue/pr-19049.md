#### What this PR does / why we need it?

`FlavorFungibility` is Beta and enabled by default since v0.5, but some tests still turn it on explicitly. The calls don't change the result, and they make it hard to tell which tests depend on the gate.

This PR removes those calls:
- 6 `featureGates` entries and 2 `SetFeatureGateDuringTest(..., true)` calls in `TestAssignFlavors`, `TestAssignFlavors_RecordsTriedFlavors` and `TestRecomputeRecordsTriedFlavors` (`pkg/scheduler/flavorassigner`),
- 4 `featureGates` entries in `TestSchedule` (`pkg/scheduler`),
- 1 `SetFeatureGateDuringTest(..., true)` call in `TestPartialAdmissionWithResidualTASPods` (`pkg/scheduler`),
- 1 `SetFeatureGateDuringTest(..., true)` call in the TAS integration suite (`tas_test.go`).

Kept on purpose:
- the table-driven gate in `TestPartialAdmissionWithResidualTASPods`, which is set from a `bool` field, including the case that turns the gate off,
- the `FlavorFungibilityPreserveScanProgress` entries, because that is a separate gate.

## AI summary

This PR removes explicit `features.FlavorFungibility` gate enablement from tests. The gate is already enabled by default, so these settings are redundant. The change affects tests only. It removes 14 lines across 4 files and adds none.

- `pkg/scheduler/flavorassigner/flavorassigner_test.go`: removes 8 lines. These are six table-case `featureGates` entries for zero-count flavor scanning and two `SetFeatureGateDuringTest(..., true)` calls for the flavor-scan bookmark and recomputation tests.
- `pkg/scheduler/scheduler_test.go`: removes 4 `featureGates` entries in `TestSchedule`. Other gates in those cases stay unchanged.
- `pkg/scheduler/scheduler_residual_tas_test.go`: removes 1 `SetFeatureGateDuringTest` call in `TestPartialAdmissionWithResidualTASPods`. The table-driven gate in that test and the `FlavorFungibilityPreserveScanProgress` entries stay unchanged.
- `test/integration/singlecluster/tas/tas_test.go`: removes 1 explicit gate enablement in the alternate-flavor integration test.

No exported declarations change.
