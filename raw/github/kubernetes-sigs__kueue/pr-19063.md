## Description

#### What type of PR is this?

/kind bug
/area dashboard

#### What this PR does / why we need it?

The ClusterQueue detail page renders each LocalQueue link inside its reservation resource rows. A LocalQueue with no reservation resources disappears from the table. If its first flavor has no resources, the remaining resource rows appear without the queue link.

Show a fallback row with the namespace-qualified queue link and “No reservation data.” When resources are present, attach the link to the first populated flavor and span the displayed resource rows.

Related to #17780, which introduced namespace-qualified LocalQueue links.

#### Useful notes for your reviewer

- Added two regression tests in `MissingNameLinks.test.jsx`. One covers same-named queues in different namespaces when one has no reservation data. The other covers a queue whose first flavor has no resources.
- Both regression tests failed against the original component and passed with the fix. `npm test` passed all 139 frontend tests. `npm run build` passed.
- The full `make verify` retry timed out. Docker was unavailable for containerized checks.
- Generative AI assisted with investigation, implementation, testing, and drafting this description.

#### Release note

```release-note
KueueViz: The ClusterQueue detail page now shows LocalQueue links even when reservation data is empty.
```

## AI summary

This PR changes the LocalQueue table on the KueueViz ClusterQueue detail page (`cmd/kueueviz/frontend/src/ClusterQueueDetail.jsx`). It also adds regression tests in `cmd/kueueviz/frontend/src/MissingNameLinks.test.jsx`.

Behavior changes:
- Reservation flavors with no resources are filtered out before rendering. They no longer produce rows.
- A LocalQueue with no resource-bearing reservations now renders one row. The row shows the namespace-qualified LocalQueue link and the text "No reservation data" across the remaining four columns. Previously, such a queue produced no row.
- For a LocalQueue with resources, the queue link appears in the first resource row of the first populated flavor. Its `rowSpan` equals the total number of resource rows across populated flavors.
- Flavor and resource rows keep their reservation and usage values. Queue links use the same `namespace/name` path.

Test changes:
- `renderClusterQueueDetail` accepts an optional `queues` argument that defaults to an empty list. The existing namespace test uses this helper.
- New test: a LocalQueue with no reservations stays visible, and its link points to the correct namespace-qualified path.
- New test: when the first flavor has no resources, the queue link cell uses the correct `rowspan` on the first populated resource row.

Not verified in this review: the test and build results reported in the PR objectives. No completed CI results were available.
