## AI summary

This change passes caller contexts through controller event handlers, the scheduler candidate order cache, and classical preemption candidate iteration. It replaces `context.Background()` in these paths. It addresses `#19079`.

- **Scheduler cache:** `CandidateOrderCache.Warm` takes a `ctx`. If cancellation leaves entries unbuilt, `Warm` skips them. `Get` builds missing entries on demand.
- **Controllers:** LocalQueue, ClusterQueue, Cohort, StatefulSet, and LeaderWorkerSet event logic moves into context-aware `handle*` methods. Typed event handlers call these methods and enqueue reconcile requests when they return true.
- **Logs:** ClusterQueue create, update, and delete events, and Cohort delete events, log at verbosity 2 instead of 3.

**Public API changes:**
- `CandidateOrderCache.Warm` and `classical.NewCandidateIterator` gain a leading `ctx context.Context` parameter.
- The exported predicate methods on the LocalQueue, ClusterQueue, and Cohort reconcilers are removed.

Observability: Kueue logs ClusterQueue create, update, and delete events, and Cohort delete events, at verbosity level 2 instead of 3.
