#### What this PR does / why we need it?

Cherry-pick of #19026 to release-0.19, replacing the cherry-pick robot's #19086, which did not compile.
The production change and the unit tests are the same as on main. The last commit adapts the integration tests:
- It adds the `ExpectLQAdmittedActiveWorkloadsGaugeMetric` test helper, which release-0.19 does not have (it came with #13635).
- It sets `Metrics` through `ControllerManager`, as the other tests on this branch do, because release-0.19 builds with Go 1.26.

#### Useful notes for your reviewer

#### Release note

```release-note
Observability: Fixed a bug where `kueue_local_queue_admitted_active_workloads` and `kueue_local_queue_reserving_active_workloads` could be missing, and the admitted gauge could later become negative, after a single LocalQueue update changed `spec.stopPolicy` together with a custom metric label value or a label matched by `metrics.localQueueMetrics.localQueueSelector`.
```
