#### What this PR does / why we need it?

Adds guidance to the PR workflow skill to address review feedback with additional commits once review has started. Avoiding force pushes, rebases, and squashes during review lets reviewers inspect incremental changes and retain comment context.

I have already suggested avoiding force pushes in review comments on two Kueue PRs:

- [PR 16175](https://github.com/kubernetes-sigs/kueue/pull/16175#issuecomment-6227071006): avoiding force pushes makes it easier for reviewers to follow changes.
- [PR 17646](https://github.com/kubernetes-sigs/kueue/pull/17646#issuecomment-6995409114): avoiding force pushes lets reviewers see the changes.

Recording this guidance in the skill makes the expectation available before contributors update a PR under review.
