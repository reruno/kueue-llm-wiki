## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Cherry-pick of the contextcheck enablement from #18934 onto `release-0.19`.

The automated cherry-pick failed because the original branch history touched `go.mod`, `go.sum` and `vendor/modules.txt` for a ruleguard part that was later dropped from the PR. This cherry-pick applies only the squashed change of the merged PR, so the dependency files are untouched.

#### Useful notes for your reviewer

- Applies cleanly, no conflicts.
- Same 6-file change as the merged PR: enable `contextcheck` in `.golangci.yaml`, pass the operation context in the scheduler cache tests, keep the controller-lifetime context in the MultiKueue and Workload handlers, and use `context.WithoutCancel` in the KueueViz backend.
- `go build` and `go test ./pkg/controller/core ./pkg/controller/admissionchecks/multikueue ./pkg/cache/scheduler` pass, and `go build ./...` in `cmd/kueueviz/backend` passes.
