## Description

#### What type of PR is this?
/kind cleanup
/area testing

#### What this PR does / why we need it?
In `TestCacheClusterQueueOperations`, `operation` and `setup` took only a `logr.Logger`, while the context they used was captured from the parent test. The context and the logger therefore came from different tests.

This PR changes `operation` and `setup` to take `ctx context.Context`, created from the subtest's own `t` via `utiltesting.ContextWithLog(t)`. Where a logger is needed, it is obtained with `ctrl.LoggerFrom(ctx)`. The unused parent-level `ctx` is removed.

Fixes #19027

#### Useful notes for your reviewer
Test-only change, with no behaviour change. Other tests in the file with the same pattern (for example `TestCacheWorkloadOperations`) are left untouched to keep this PR focused, and can be handled in a follow-up if desired.
