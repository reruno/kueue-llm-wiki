## AI summary

This PR refactors MultiKueue remote Workload synchronization in `pkg/controller/admissionchecks/multikueue/workload.go`. It adds test cases in `workload_test.go`.

- `reconcileGroup` calls `updateRemoteWorkload` when a remote Workload exists and either its comparable spec is out of sync or its priority boost differs.
- `updateRemoteWorkload` applies eligible in-place updates and adds tolerations. It returns whether an update occurred. An error stops reconciliation. A successful update keeps the remote Workload. It is not deleted for recreation.
- `addRemoteTolerations` returns early when `AllowAddingPodTemplateTolerations` is disabled. The gate check moved into this function.
- The tests cover elastic scale-down, scale-up, priority and toleration updates, and update errors.
