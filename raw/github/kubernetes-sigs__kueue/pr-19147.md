#### What this PR does / why we need it?
`pull-kueue-test-e2e-certmanager-main` failed before tests started. `go list -m` hit a TLS handshake timeout while resolving `github.com/mikefarah/yq/v4@v4.54.3`. Make ignores a failed `$(shell)`, so the installer ran as `install.py yq ""`, requested `mikefarah/yq@`, and then retried a source build with an empty version.
Tool and external-controller versions are now read from `go.mod` with `go mod edit -json`, which does not download module metadata. If that lookup fails, Make stops. The installer and `source.sh` also reject an empty version.
Fixes #19146
