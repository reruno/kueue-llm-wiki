#### What this PR does / why we need it?

`AGENTS.md` imports `cmd/experimental/skills/reviewer/README.md`, which `@`-imported all ~60 review skills (~60 KB). Every agent that loaded `AGENTS.md` read all of them, and `code-eval` always ran all 5 domains. This makes the review skill expensive, especially for contributors on free agent tiers and for rate-limited reviewers such as CodeRabbit.

This PR:
- Replaces the 60 `@` imports in `reviewer/README.md` with a "Choosing what to review" menu. Options: first pass (architectural-decisions, the default), correctness, security, style, comments, tests, targeted skills, and the full scored report.
- Runs exactly the areas the request names, without asking. When the agent can't ask (for example a bot), it runs the first pass only and reports what it skipped.
- Makes `code-eval` ask which domains to run, spawn subagents only for the selected ones, and add a `Domains not run` line to the report. A subset score is noted as not comparable to a full-run score.

Fixes #13228
