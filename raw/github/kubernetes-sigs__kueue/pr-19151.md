#### Useful notes for your reviewer
- Bumps yq from v4.53.6 to v4.54.3 in `hack/tools`, the same as `main`. The script and `kustomization_add_patch` use `if/else`, which v4.53.6 does not support. The other `go.mod` changes are the versions yq v4.54.3 needs.
- The conflicts were in lines that differ on this branch. I kept this branch's `verify-checks` list and added the new test to it, and kept the `apiservice_insecure_removal.yaml` patch, which is only on this branch.
- The script, its test and the README are the same as on `main`.
- `config/components/kueueviz/kustomization.yaml` has no `ingress.yaml` on this branch, so only the blank lines are removed there.
