#### What this PR does / why we need it?

Tool installers could reuse a binary replaced by another branch while its version marker remained unchanged. Store and validate a SHA-256 digest alongside the installation identity before reusing release binaries, source-built tools, or the custom API linter. Legacy markers without a digest cause a rebuild or reinstall.

Keep custom linter build and move failures separate from digest failures so their original exit status is preserved.

Fixes #18410

Replaces #18471 after recreating the fork. The restored change includes the previous review fix for custom linter build failures and is based on current main.

## AI summary

This PR stops tool installers from reusing a cached binary when only its version marker matches. A marker now stores the installation identity and the binary's SHA-256 digest. A cached binary is reused only when both values match. Markers without a digest are cache misses.

### Changes by file

- **`hack/tools-installer/install.py`**: Identifies cached binaries by version, host OS/architecture, and SHA-256 digest. Adds helpers `binary_digest(path)`, `marker_contents(identity, digest, source=False)`, and `marker_matches(marker, identity, digest, source=False)`. A matching source-build marker triggers a rebuild, and the digest is refreshed afterward. `install_source` gets a docstring only; its implementation is unchanged.
- **`hack/tools-installer/source.sh`**: Reuses a source-built tool only when the executable exists, the marker's first line matches the module, package, version, Go identity, and CGO setting, and the second line matches the executable's digest. The digest uses `sha256sum`, with `shasum -a 256` as fallback. A failed calculation or a non-64-character hex result fails the script.
- **`hack/make/deps.mk`**: The `golangci-lint-kal` target applies the same identity-and-digest check. A failed build or move exits with that command's status. A failed post-build digest calculation prints an error and exits with status 1.
- **`hack/tools-installer/install_test.py`**: Adds offline tests for replaced binaries, unchanged binaries, legacy markers without digests, and failed digest calculation. Custom-linter tests cover distinct build and move failures.
