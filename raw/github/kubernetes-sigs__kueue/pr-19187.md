#### What this PR does / why we need it?
For example, suppose an administrator configures a `ClusterQueue` custom metric label in the Kueue Configuration (sourceKind defaults to ClusterQueue when omitted):

```
apiVersion: config.kueue.x-k8s.io/v1beta2
kind: Configuration
metrics:
  customLabels:
    - name: team
```

When multiple nodes running a TAS `Workload` fail and trigger `tas_node_controller` to evict the Workload, Kueue should record the eviction metric with the custom label value along with the eviction Event.

for example: `kueue_evicted_workloads_total{..., reason="NodeFailures", custom_team="<team label value on ClusterQueue>"}`

In practice, this path omits all custom label values when reporting the metric. `tas_node_controller` panics during that reconcile, and `kueue-controller-manager` logs `panic: inconsistent label cardinality ... [recovered]`. The controller framework recovers from the panic, so the process does not exit. Because the eviction status is written to the Workload before the panic happens, later retries treat the Workload as already evicted and skip it. The metric and Event for that eviction are permanently lost.

## AI summary

This PR fixes a panic in the TAS node controller. The panic occurs when a Workload is evicted after several of its nodes fail and custom metric labels are configured. The eviction path did not pass the custom label values. The eviction metric and Event were then not recorded.

- The node reconciler accepts and stores optional custom metric labels.
- Workload eviction receives those labels instead of `nil`.
- `SetupControllers` passes the configured custom labels to the node reconciler.
- `WithCustomLabels` is documented as setting TAS controller metric labels.
- Unit and integration tests cover eviction with custom labels.

## Suggested release note

```text
TAS: Fixed a bug that caused a panic in the TAS node controller when a Workload was evicted after multiple nodes failed and custom metric labels were configured. Now Kueue evicts the Workload and records the eviction metrics and Events with the configured custom label values. This behavior is gated by the custom metric labels feature gate.
```
