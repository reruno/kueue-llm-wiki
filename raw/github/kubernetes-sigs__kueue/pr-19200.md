#### What type of PR is this?

#### What this PR does / why we need it?

The AdmissionCheck concept page documents fields that are absent from the v1beta2 API. This can lead users to configure checks through an obsolete ClusterQueue field or look for check state at the wrong Workload status path.

Document `spec.admissionChecksStrategy.admissionChecks` on ClusterQueue and `status.admissionChecks` on Workload. Remove the obsolete `retryDelayMinutes` reference. Update the ClusterQueue example to show a flavor-specific check and a queue-wide check, and declare the flavor referenced by `onFlavors` in `resourceGroups`.

#### Useful notes for your reviewer

- Validated all four YAML examples against the v1beta2 CRD schemas and verified that the updated page renders in Hugo.
- Related to #18170, which documented per-check retry delays and retry counts.
- Generative AI assisted with investigation, editing, and validation.
