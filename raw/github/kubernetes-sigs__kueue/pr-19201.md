> **Exit explicitly when the kubectl checksum fails.**
> 
> The recipe relies on `.SHELLFLAGS = -ec` to stop after a checksum mismatch. GNU Make 3.81 ignores `.SHELLFLAGS`, as the comment in `hack/make/verify.mk` notes. On that version, the failed check does not stop the recipe, so `install` copies the unverified binary to `$(KUBECTL)`, and the `prometheus` prerequisite can run it. Add an explicit exit to each checksum command so the check fails the recipe on every make version.
> 
> <details>
> <summary>Suggested fix</summary>

> <dd>

> +		(cd "$$tmp_dir" && echo "$$(cat kubectl.sha256)  kubectl" | sha256sum --check -) || exit 1; \
