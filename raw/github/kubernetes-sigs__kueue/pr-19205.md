#### What this PR does / why we need it?
Aligns logging in `pkg/cache/scheduler` and `pkg/cache/queue` with the [Kueue Logging Policy](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/logging_policy.md):

- **Verbosity alignment:**
  - Moves per-object/cache operational diagnostics from `V(2)` to `V(3)`–`V(5)` (`ensureTASIsSynced`, `updateWorkloadTASUsage`, DRA node exclusion, simulator fallback/restore, TAS cache self-healing/removal, workload requeue/bulk-move, inadmissible workload movement, and per-comparison `queueOrderingFunc`).
  - Moves unexpected negative pod count anomalies (`tas_non_tas_pod_cache.go`) and DRA reconcile channel wiring (`manager.go`) from `V(0)` to `V(1)`.
  - Moves missing WAS annotation log (`cache.go`) from `V(1)` to `V(3)` and `RebuildHeap` / replacement assignment logs to `V(4)`.
- **Performance guards & error handling:**
  - Adds `logV.Enabled()` guards before logging-only allocations/sorting in `TASFlavorCache.snapshot`, `TASFlavorSnapshot.findTopologyAssignment`, and `queueOrderingFunc`.
  - Removes double-logged `log.Error` before returning in `Cache.AddClusterQueue` (returns wrapped error instead).
- **Structured key & ObjectRef consistency:**
  - Normalizes keys to canonical `lowerCamelCase`: `flavor`/`tasFlavor` -> `resourceFlavor`, `queue` -> `localQueue`, `topologyName` -> `topology`, `domain` -> `domainID`, `clusterqueue` -> `clusterQueue`, `"missing annotation"` -> `annotation`, `oldStatus`/`newStatus` -> `previousStatus`/`status`, `existingAssignment`/`newAssignment` -> `previousAssignment`/`assignment`, `qExists` -> `localQueueExists`.
  - Uses `klog.KObj` / `klog.KRef` consistently for `clusterQueue`, `localQueue`, `cohort`, `rootCohort`, `resourceFlavor`, `topology`, `node`, `pod`, and `workload` (omitting `cohort` in `Snapshot.Log` when a ClusterQueue has no parent cohort to avoid string-vs-ObjectRef type collisions).
- Updates log-asserting unit tests (`snapshot_test.go`, `tas_flavor_snapshot_test.go`, `manager_test.go`) and benchmark (`tas_overlapping_flavor_bench_test.go`), and adds `TestSnapshotLogCohortRef`.

Part of #9801

- Keeps `SIGUSR2` dump logs in `Snapshot.Log` and `Manager.LogDump` at `V(0)`.
- Keeps `unhealthyNode` in `tas_flavor_snapshot.go` as a hostname string (not `klog.KRef`) since it carries the `kubernetes.io/hostname` label value.
