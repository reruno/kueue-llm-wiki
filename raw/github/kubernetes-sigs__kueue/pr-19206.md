#### What this PR does / why we need it?
Aligns logging across shared packages (`pkg/config`, `pkg/debugger`, `pkg/features`, `pkg/podset`, `pkg/util`, `pkg/workload`) with the [Kueue Logging Policy](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/logging_policy.md):

- **Verbosity alignment:**
  - Moves startup/lifecycle/anomaly logs from `V(0)` to `V(1)` (`pkg/config/metrics.go`, `pkg/podset/podset.go`, `pkg/util/cert/cert.go`, `pkg/util/roletracker/tracker.go`) and `LogFeatureGates` from `V(2)` to `V(1)` with an `Enabled()` guard before map allocation.
  - Moves unexpected admissionless eviction warning in `pkg/workload/evict/evict.go` from `V(3)` to `V(1)`.
  - Moves `ExpectUIDs`/`ObservedUID` traces in `pkg/util/expectations/store.go` from `V(3)` to `V(4)`.
- **Post-write logging & error handling:**
  - In `pkg/workload/workload.go` (`FinalizeOrphanedWorkload`), logs orphaned workload completion at `V(3)` after `workloadfinish.Finish` succeeds and replaces double-logged `log.Error` calls with wrapped returned errors (logged once by controller-runtime at the `Reconcile` boundary).
  - Switches `BootstrapCerts` in `pkg/util/cert/cert.go` from global `ctrl.Log` to `ctrl.LoggerFrom(ctx)`.
- **Structured key & ObjectRef consistency:**
  - Renames `"Assigned AdmissionChecks"` -> `"admissionChecks"` (`pkg/workload/workload.go`) and `oldValue`/`newValue` -> `previousValue`/`value` (`pkg/podset/podset.go`).
  - Uses `klog.KRef` for flavor references (`pkg/podset/podset.go`), `localQueue` (`pkg/util/admissionfairsharing`), and `key` (`pkg/util/expectations/store.go`).
- Updates `pkg/config/metrics_test.go` for `Verbosity: 1`.

Part of #9801

- Strictly logging-only changes; leaves `SIGUSR2` dump `V(0)` logs in `pkg/debugger/debugger.go` and global `replica-role` in `pkg/util/roletracker/logger.go` untouched.
- Verified with `go test -count=1 ./pkg/config/... ./pkg/debugger/... ./pkg/features/... ./pkg/podset/... ./pkg/util/... ./pkg/workload/... ./pkg/controller/core/... ./pkg/controller/jobframework/...` and `golangci-lint` (0 issues).

#### Release note
```release-note
Observability: Aligned shared package (`config`, `debugger`, `features`, `podset`, `util`, `workload`) logs with the logging policy. Startup, feature-gate, certificate bootstrap, leader-transition, and unexpected-state logs moved to level 1, orphaned workload completion is logged after the write at level 3, expectation traces moved to level 4, duplicate error logs were removed, object references use structured `klog` formatting, and log keys were renamed (`Assigned AdmissionChecks` to `admissionChecks`, `oldValue`/`newValue` to `previousValue`/`value`).

ACTION REQUIRED: If your dashboards, alerts or log queries depend on Kueue log messages, keys or verbosity levels, review them before upgrading. For the complete list of logging changes, see #19206. To keep the per-object logs, set the log level to 3 or higher.
```
