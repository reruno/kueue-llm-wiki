**AI summary**

This PR adds the alpha `v1alpha1` API for time-based preemption candidate filters. It adds `timeConstraints` to `PreemptionConfigPreemptionCandidateSelector`, with `execution` and `sinceCreation` duration constraints. Each constraint supports `minSeconds`, `maxSeconds`, and `comparison`. The PR also updates the CRD schemas, deepcopy and applyconfiguration code, and API reference docs. It adds no filtering behavior. The PR objectives state that implementation is planned for a follow-up PR.
