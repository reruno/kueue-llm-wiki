## Description

#### What type of PR is this?
/kind cleanup

#### What this PR does / why we need it?
Renames the `replica-role` structured log key emitted by `pkg/util/roletracker` (`WithReplicaRole`, `NewLogConstructor`, `WebhookLogConstructor`) to `replicaRole` to match the `lowerCamelCase` key convention in the [Kueue Logging Policy](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/logging_policy.md).

Updates unit tests in `pkg/util/roletracker/logger_test.go` accordingly.

Part of #9801

#### Useful notes for your reviewer
- Isolated in its own PR because `roletracker` attaches this key to every controller and webhook log record.
- Verified with `go test -count=1 ./pkg/util/roletracker/...` and `golangci-lint` (0 issues).
- AI-assisted.

#### Release note
```release-note
Observability: Aligned the `roletracker` structured log key with the logging policy by renaming `replica-role` to `replicaRole` across controller and webhook logs.

ACTION REQUIRED: If your dashboards, alerts or log queries filter on the `replica-role` log key, update them to `replicaRole` before upgrading.
```
