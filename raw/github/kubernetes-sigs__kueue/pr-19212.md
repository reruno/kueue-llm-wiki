#### What this PR does / why we need it?
Links the [Kueue Logging Policy](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/logging_policy.md) from contributor entry points and aligns stale logging guidance with the current policy:

- Adds a link to the Logging Policy in `CONTRIBUTING.md`, `site/content/en/community/contribution_guidelines/_index.md`, and `AGENTS.md`.
- Updates `### Logging` in `site/content/en/community/contribution_guidelines/coding_guidelines.md` to match the Logging Policy's intended-use levels (`Error`, `V(0)`–`V(6+)`), error-logging rules, `lowerCamelCase` key convention, and `V(3)` reconcile example.
- Updates the `wrong-log-verbosity` reviewer skill (`cmd/experimental/skills/reviewer/code-style/wrong-log-verbosity/SKILL.md` and its references in `code-style/SKILL.md` and `reviewer/README.md`) to match the Logging Policy (`V(3)` for main per-object diagnostics, `V(4)` for decision details/pre-write logs, `V(5)` for implementation traces, and flagging `V(n).Error(...)`).

Part of #9801
