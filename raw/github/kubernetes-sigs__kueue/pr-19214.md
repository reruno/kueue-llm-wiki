## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Manual cherry-pick of #19011 onto `release-0.20`; the automatic cherry-pick failed on a conflict in the integration test.

`release-0.20` does not have the PreemptionConfig priority class selector (#16684), so the integration test uses a candidate label selector instead: a high-priority workload stays pending while the rule only allows preempting `tier=low` workloads, and is admitted after the PreemptionConfig is updated to allow `tier=mid`. Product code and unit tests are unchanged from #19011.

Part of #18726
