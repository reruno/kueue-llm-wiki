```release-note
Observability: Aligned remaining job webhooks (`JobSet`, `MPIJob`, `RayJob`, `SparkApplication`, `TrainJob`), `DisaggregatedSet`, `jobframework`, and core/scheduler logs with the logging policy. Job webhook validation logs moved from level 0 to level 5, startup notices moved to level 1, per-object annotation parse and `DisaggregatedSet` Workload lifecycle logs moved to level 3 (post-write), duplicate error logs were removed, object references use structured `klog` formatting, and log keys were renamed (`disaggregatedset` to `disaggregatedSet`, `localQueueName` to `localQueue`, `oldManagedBy` to `previousManagedBy`, `oldLimits`/`newLimits` to `previousLimits`/`limits`, `oldWorkloadSlice`/`newWorkloadSlice`/`oldClusterQueue` to `previousWorkloadSlice`/`workloadSlice`/`previousClusterQueue`, `queueA`/`queueB` to `localQueueA`/`localQueueB`).

ACTION REQUIRED: If your dashboards, alerts or log queries depend on Kueue log messages, keys or verbosity levels, review them before upgrading. For the complete list of logging changes, see #19210. To keep the per-object logs, set the log level to 3 or higher.
```
