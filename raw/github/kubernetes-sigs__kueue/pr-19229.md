#### Useful notes for your reviewer
- Alpha CRDs, `config/networkpolicy` and `config/kueueviz-single-host` are not on this branch, so their steps and targets are left out, and the artifacts list keeps this branch's entries, switched to `$(KUBECTL) kustomize`.
- `upgrade_test_flow` in `e2e-common.sh` is only on this branch and also used `$KUSTOMIZE build`, so it now uses `kubectl kustomize`.
- `ENVIRONMENT_DEPENDENCIES_POLICY.md` is not on this branch, so it is not changed.
- In `hack/tools`, `go mod tidy` also drops `kustomize/cmd/config` and `sergi/go-diff`, which only the kustomize pin needed.
- All 33 kustomizations on this branch build the same with its pinned kustomize v5.8.1 and with kubectl 1.35.5, 1.36.1 and 1.37.0, the versions the e2e jobs use.
