#### What this PR does / why we need it?

MultiKueue support for SparkApplication needs `spec.managedBy`, which spark-operator v2.5.2 does not have. v2.6.0 has the field but does not build with k8s.io v0.37, so this pins a commit on the spark-operator main branch that has both.

That commit has no Helm chart or controller image, so the Spark e2e installs the v2.6.0 release.

Part of #18107
