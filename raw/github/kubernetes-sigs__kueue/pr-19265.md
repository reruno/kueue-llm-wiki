## Description

Cherry pick of #18823 on release-0.19.

The automated cherry-picks (#18894, #19121) didn't compile, because `workload.Usage.Quota` on release-0.19 is a `FlavorResourceQuantities` rather than a `ResourceUsage`. The only change from #18823 is the expected `Usage` in the three new `TestAssignFlavors` cases. On release-0.19, the new cases fail without the fix and pass with it, and `pkg/scheduler/...` passes.

/assign mimowo

```release-note
FlavorFungibility: Fixed a bug where a Workload that needed to borrow one resource and preempt for another in the same flavor was never admitted with `preference: PreemptionOverBorrowing`, because no lower-priority Workloads were preempted. With `whenCanPreempt: MayStopSearch`, such a flavor also no longer stops the search when a later flavor fits without borrowing.
```

/kind bug
