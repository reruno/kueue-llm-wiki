#### What this PR does / why we need it?

The Kueue chart had no `NOTES.txt`, so `helm install` and `helm upgrade` printed nothing about the result. With structured manager configuration, the most common surprise is silent. When `managerConfig.mode` is unset, `controllerManagerConfigYaml` takes precedence and `structuredOverrides` are ignored. This includes YAML kept from an earlier chart version by `--reuse-values`.

This PR:
- Adds `NOTES.txt`. Every install or upgrade prints commands to check the controller manager rollout and view the manager configuration. The notes add a message only when part of the configuration is ignored:
  - a warning when `structuredOverrides` are ignored, because YAML takes precedence (even an empty string) or because `mode: yaml` is set
  - a note when `mode: structured` ignores YAML, so YAML settings not copied into `structuredOverrides` do not apply, with how to remove the YAML
- Adds a `kueue.managerConfigSource` helper that returns the selected input (`yaml`, `structured` or `defaults`). `kueue.managerConfig` and the notes both use it, so the notes always match the rendered configuration. Rendered output is unchanged.
- Updates the chart README:
  - the migration example uses `--reset-then-reuse-values` (Helm 3.14 or later), and says why `--reuse-values` is a problem when moving to a new chart version
  - a per-option table for `null` over a saved override
  - what removing a field or setting the YAML to `""` falls back to
  - the notes
- Changes the Dynamic Quota Orchestration page's `helm upgrade` example from `--reuse-values` to `--reset-then-reuse-values`.

Example output when YAML takes precedence over structured overrides:

```
Kueue has been installed in namespace kueue-system.

WARNING: managerConfig.structuredOverrides is ignored because
managerConfig.controllerManagerConfigYaml is set and takes precedence.
To use your structured overrides, set managerConfig.mode to "structured".

To check that the controller manager is running, run:
  kubectl -n kueue-system rollout status deployment/kueue-controller-manager
To view the manager configuration, run:
  kubectl -n kueue-system get configmap kueue-manager-config -o yaml
```
