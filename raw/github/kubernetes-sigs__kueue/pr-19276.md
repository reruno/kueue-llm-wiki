#### What this PR does / why we need it:
Adds the remaining core Kueue CRDs to `passThroughTypes` in `cmd/kueuectl/app/passthrough/passthrough.go`:
- `admissioncheck` (`ac`)
- `workloadpriorityclass` (`wpc`)
- `multikueuecluster` (`mkc`)
- `multikueueconfig` (`mkconf`)
- `provisioningrequestconfig` (`prc`)

This allows users to use pass-through commands (`get`, `describe`, `edit`, `delete`, `patch`) for all Kueue CRDs directly via `kueuectl`. Also adds unit and integration test coverage and fixes a minor grammar error in the error message.

#### Which issue(s) this PR fixes:
Fixes #19274
