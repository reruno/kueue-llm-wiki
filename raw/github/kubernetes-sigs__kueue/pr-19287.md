## AI summary

This test-only change replaces the `ginkgo.DescribeTable` in `tas_zero_count_group_test.go` with two `ginkgo.It` blocks inside a `ginkgo.When("only the smaller node is available")` block. A `BeforeEach` in that block deletes the larger node, so both cases run with only the smaller node available. A shared `expectLeaderAdmittedOnSmallFlavor` closure, marked with `ginkgo.GinkgoHelper()`, holds the common admission assertions. The non-elastic case builds its workload with preferred topology requests. The elastic case enables the feature gate in the test body and builds its workload with the `Annotation` and `UnconstrainedTopologyRequest` builder methods, instead of mutating PodSet fields after creation. No production code changes.
