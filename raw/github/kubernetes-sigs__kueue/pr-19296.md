## Description

#### What type of PR is this?

/kind bug
/area dra

#### What this PR does / why we need it?

An `AdminAccess` request with `allocationMode: All` has a count of zero. The first pass of Kueue's CEL device matcher treated zero matching devices as satisfying that count. This allowed a Workload to reserve quota even though kube-scheduler requires at least one matching device.

Require at least one match in the first pass so Kueue reports a retryable device shortage when no devices match. Add a regression test for a standalone `All` request whose CEL selector matches none of the available devices.

Related to #19172.

#### Useful notes for your reviewer

- The new regression test failed on upstream `main` and passed with the fix. The full `pkg/dra` unit suite passed.
- Full `make verify` was blocked because Docker and Podman were unavailable.
- Generative AI assisted with investigation, implementation, and validation.

#### Release note

```release-note
DRA: Workloads with an AdminAccess request using allocation mode All report a retryable shortage when the CEL device check finds no matching devices.
```

## AI summary

Fixes DRA allocation for `allocationMode: All` requests whose CEL selector matches no devices. Before this change, zero matches satisfied the first pass, so a Workload could reserve quota that kube-scheduler would not allocate.

- `pkg/dra/cel_device_matcher.go`: `takeFirstMatch` requires at least one matching device for `All` requests (`max(alt.count, 1)`). When an `All` request has no match, `shortageError` returns a field internal error at the selector path. The message states that `All` requires at least one matching device. The `firstUnusedMatches` doc comment no longer describes the zero-count case.
- `pkg/dra/claims_test.go`: Adds a `Test_GetResourceRequests` case for an `AdminAccess` `All` request whose selector matches no available device.

## Suggested release note

```text
DRA: Fixed a bug that caused a Workload with an AdminAccess request using allocationMode All to reserve quota when its CEL selector matched no devices. Now Kueue requires at least one matching device before it reserves quota.
```
