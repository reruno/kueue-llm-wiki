## Description

#### What type of PR is this?

/kind cleanup

#### What this PR does / why we need it?

Cherry-pick of #19284 to `release-0.19`.

The automated cherry-pick (#19294) failed all required jobs: `errMultipleActiveFlags` is defined in `cmd/kueuectl/app/list/helpers.go` only after `release-0.19` branched, so the package did not compile. This PR includes that one-line definition, and the rest is the original change.

#### Useful notes for your reviewer

- `go build ./cmd/kueuectl/...` and `go test ./cmd/kueuectl/app/list/...` pass.
- The only addition beyond the original diff is `errMultipleActiveFlags` in `helpers.go`. `release-0.19` has no `LocalQueueOptions.Validate`, so nothing else uses it there.

@mbobrovskyi

#### Release note

```release-note
CLI: Fixed `kueuectl list clusterqueue` and `kueuectl list localqueue` to report unexpected positional arguments as errors.
```
