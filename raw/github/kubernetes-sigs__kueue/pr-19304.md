## Description

#### What type of PR is this?
/kind feature

#### What this PR does / why we need it:
Expands shell autocompletion in `kueuectl`:
- Adds `CohortNameFunc` and `ResourceFlavorNameFunc` in `cmd/kueuectl/app/completion/completion.go`.
- Fixes loop variable naming in `completion.go` (`wl` -> `ns`, `cq`, `lq`).
- Registers completion choices for `--dry-run` (`none`, `server`, `client`).
- Registers completion choices for `--active` (`true`, `false`) in `kueuectl list`.
- Registers completion choices for `--status` (`all`, `pending`, `quotareserved`, `admitted`, `finished`) in `kueuectl list workload`.
- Registers flag completion for `--cohort` (dynamic Cohort lookup), `--queuing-strategy`, `--reclaim-within-cohort`, and `--preemption-within-cluster-queue` in `kueuectl create clusterqueue`.
- Adds unit tests in `completion_test.go`, `create_clusterqueue_test.go`, `flags_test.go`, and `list_test.go`.

#### Which issue(s) this PR fixes:
Fixes #19303

#### Special notes for your reviewer:
All registered flag completions return `cobra.ShellCompDirectiveNoFileComp` to prevent falling back to local file path suggestions when completing option values.

#### Does this PR introduce a user-facing change?
```release-note
CLI: Added shell completion for the --dry-run, --active, and --status flags, and for the --cohort, --queuing-strategy, --reclaim-within-cohort, and --preemption-within-cluster-queue flags of kueuectl create clusterqueue.
```
