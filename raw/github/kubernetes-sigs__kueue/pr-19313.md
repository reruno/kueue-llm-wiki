#### What this PR does / why we need it?

Cherry-pick of #19308 to `release-0.19`.

The automated cherry-pick failed with a conflict in `cmd/kueuectl/app/list/list_pods_test.go`, because it applies the two commits one by one. Applying the squashed change avoids that.

Two small adjustments for this branch:

- `release-0.19` is on Go 1.26, so the new pods test case spells out `TypeMeta` and `ObjectMeta`; the promoted-field literal used on `main` needs Go 1.27.
- It builds on the `#19284` backport, which is already merged (#19299).

#### Useful notes for your reviewer

- `go build ./cmd/kueuectl/...` and `go test ./cmd/kueuectl/app/list/...` pass with Go 1.26.

CLI: `kueuectl list workload`, `kueuectl list resourceflavor`, and `kueuectl list pods` now report unexpected positional arguments as errors.
