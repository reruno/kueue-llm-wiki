#### What this PR does / why we need it?

Cherry-pick of #19147 onto release-0.19.

A failed `go list -m` left the tool version empty, so the installer requested `mikefarah/yq@` and the job failed before tests started. Tool and external-controller versions are now read from `go.mod` with `go mod edit -json`. Make stops when that lookup fails, and the installer rejects an empty version.

This branch has no `ENVIRONMENT_DEPENDENCIES_POLICY.md`, so that documentation sentence is not included. gopherage and gojq are not on this branch, and ClusterProfile stays pinned from `hack/tools/go.mod`.

Related: #19146

#### Useful notes for your reviewer

Cherry-pick of #19147. The installer tests from that PR are selected by `verify-ci-tools` (`python3 hack/tools-installer/install_test.py`). Local result: 37 passed. The conflict resolution keeps this branch's existing tool list.
