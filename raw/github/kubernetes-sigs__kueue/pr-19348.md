## AI summary

This PR adds the alpha `PreemptionLimit` API (`kueue.x-k8s.io/v1alpha1`, cluster-scoped). It includes:

- Go API types in `apis/kueue/v1alpha1/preemptionlimit_types.go`, registered in `groupversion_info.go`.
- CRD manifests in `config/components/crd/alpha/bases/`, included by the alpha kustomization, and in `charts/kueue/templates/crd/`. The Helm CRD renders only when `enableAlphaAPIs` is true.

This PR does not add controller logic. The limits are not enforced by this change.
