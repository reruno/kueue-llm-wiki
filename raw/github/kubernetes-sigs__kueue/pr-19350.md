## AI summary

This PR moves the per-strategy target search out of `Preemptor.getTargets` into `PreemptionStrategy.searchTargets` in `pkg/scheduler/preemption/preemption.go`. `getTargets` returns the first non-empty result from a strategy. It logs "no suitable targets" once, after all strategies fail. `accepts` now uses a pointer receiver. The search logic is unchanged. A nil `partialPlan` skips partial preemption.
