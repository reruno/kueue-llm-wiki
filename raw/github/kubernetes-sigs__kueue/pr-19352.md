## AI summary

This PR refactors the candidate iterator in `fairPreemptionStrategy` (`pkg/scheduler/preemption/fair_strategy.go`). The iterator closure is renamed to `iterateCandidates` and takes a caller-supplied `[]*workload.Info`. A new `candidatesFor(wls)` function wraps that slice as an `iter.Seq[*Target]`.
