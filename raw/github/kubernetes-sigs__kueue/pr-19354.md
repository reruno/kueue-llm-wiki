#### Useful notes for your reviewer

The cherry-pick had conflicts in 37 files on `release-0.19`:
- 13 files that do not exist on the branch, because the tests in them were not backported: `pkg/controller/unscheduledpods/tracker_test.go`, `pkg/scheduler/assignment/native/native_test.go`, `pkg/scheduler/assignment/native/tas_elastic_accounting_test.go`, `pkg/scheduler/scheduler_refill_tas_test.go`, `test/integration/singlecluster/scheduler/was/was_test.go`, `test/integration/singlecluster/tas/tas_workload_slice_refill_test.go`, `test/integration/singlecluster/webhook/core/elastic_partial_scaleup_test.go`, `test/integration/singlecluster/controller/jobs/rayclusterwebhook/elastic_partial_scaleup_test.go`, and the `*_partial_scaleup_test.go` files for Job, RayCluster, RayJob, RayService and SparkApplication. I dropped them.
- The other 24 conflicting files: the conflicting hunks carry test cases from `main` that are not on the branch. I kept the branch's code and removed the `ElasticJobsViaWorkloadSlices` enabling lines from it. In 6 of these files the branch has no enabling lines, so they have no changes: `pkg/controller/admissionchecks/provisioning/controller_test.go`, `pkg/controller/jobframework/reconciler_internal_test.go`, `pkg/controller/jobs/rayservice/rayservice_multikueue_adapter_test.go`, `pkg/controller/jobs/sparkapplication/sparkapplication_controller_test.go`, `test/integration/multikueue/kuberay_test.go` and `test/integration/singlecluster/webhook/jobs/rayservice_webhook_test.go`.
- `test/integration/singlecluster/controller/jobs/raycluster/raycluster_controller_test.go`: on the branch the elastic jobs `Describe` enables the gate with `SetFromMap` in `BeforeAll` instead of `SetFeatureGateDuringTest`. I removed that call and the `utilfeature` import, which became unused.
- `pkg/controller/jobs/raycluster/common_test.go` and `test/integration/singlecluster/webhook/core/workload_test.go`: I removed the `features` import, which became unused on the branch.

`make ci-lint` (0 issues) and `make verify` passed. Unit tests: `go test -count=1` passed for all 20 changed `pkg/` packages. Integration tests: `INTEGRATION_TARGET="<the 6 changed singlecluster packages>" make test-integration` passed 774/774 specs across 13 suites, and `make test-multikueue-integration` passed 91/91 specs across 3 suites.
