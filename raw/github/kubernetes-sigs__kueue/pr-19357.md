#### What this PR does / why we need it?

`normalizeListenAddress` only added the default port when the value had no colon, so `--listen ::1`, `::` or `[::1]` reached `net.Listen` unchanged and the backend failed to start ("too many colons in address" / "missing port in address"). Now any bare IP, with or without brackets, is joined with the default port, so "::1" becomes "[::1]:8080". Values that already have a port, hostnames and bare ports behave as before.

Fixes #19356

#### Useful notes for your reviewer

New `TestGetServerAddress` cases for "::", "::1", "[::1]" and "[::1]:9000". On main, `go test ./config/...` in cmd/kueueviz/backend fails with:

```
GetServerAddress() = "::", want "[::]:8080"
GetServerAddress() = "::1", want "[::1]:8080"
GetServerAddress() = "[::1]", want "[::1]:8080"
```

With the change all of `go test ./...` in the backend module passes, and `net.Listen` succeeds on the new addresses.

#### Release note

```release-note
KueueViz: Fix the backend failing to start when `--listen` is an IPv6 address without a port, such as `::1`. The default port is now appended.
```

AI-assisted; I reviewed the change and ran the tests myself.
