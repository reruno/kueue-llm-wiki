#### What this PR does / why we need it?
Adds the `ConfigurablePreemptionLimits` feature gate for KEP-16925 (https://github.com/kubernetes-sigs/kueue/pull/17277) so follow-up PRs implementing the controller and scheduler changes can be gated behind it:

- Register `ConfigurablePreemptionLimits` as an Alpha (`v0.21`) feature gate, disabled by default.
- Require `ConfigurablePreemptions` to be enabled whenever `ConfigurablePreemptionLimits` is enabled, with unit test coverage for the dependency check.
