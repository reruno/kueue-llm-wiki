#### What this PR does / why we need it?

Manual cherry-pick of #17876 to `release-0.19`, after the automated cherry-pick PR #19319 was closed.

This change reuses LocalQueue, ClusterQueue pending Workload, and API discovery reads across pages of `kueuectl list workload`.

Related: #17876

AI assistance was used to prepare this cherry-pick.

#### Useful notes for your reviewer

- Cherry-picked merged commit `9b6d3d1968deefa4dc281a1f45dd5ab48b997669`; it applied without conflicts.

- `go test ./cmd/kueuectl/app/list/...` passed.
- `git diff --check` passed.
