AI summary

- Fixes Fair Sharing verification for partial-preemption targets.
- `verifyFairSharingTarget` now restores only the usage that a target releases (`Target.PreemptedUsage()`) when it computes the target ClusterQueue's pre-preemption share. Before, it restored the Workload's full usage, which double-counted Pods that remained after a shrink.
- Adds `Target.PreemptedUsage()` in `pkg/scheduler/preemption/policy/types.go`.
- Adds tests for a partial-preemption Fair Sharing case and a scheduler case that expects no shrink.

Suggested release note

The PartialPreemption feature is not yet released, so this change has no user-facing impact in a released version.
