## AI summary

This test-only change replaces the table-driven `ginkgo.DescribeTable` in `elastic_flavor_test.go` with two `ginkgo.It` specs:

- Feasible case: GPU quota is `"4"`. The zero-count Job is admitted on `gpu` with no fallback warning. The scale-up slice is admitted on `gpu`.
- No-capacity case: GPU quota is `"0"` in both flavors. The Job falls back to `cpu` with one fallback warning. The scale-up slice stays unadmitted, and the root workload stays admitted and unfinished.

Namespace and flavor setup moved to `BeforeEach`. Each spec keeps its steps inline. The spec names no longer include "at zero parallelism." The `Describe` text is unchanged.

No production code changes.
