#### What this PR does / why we need it?

Replaces the four `ginkgo.DescribeTable` in `test/integration/singlecluster/kueuectl/resume_test.go` with four `ginkgo.It` blocks, one per table. Each spec checks its two former entries in separate `ginkgo.By` steps: a queue stopped with `HoldAndDrain` and one stopped with `Hold` for `resume`, and the `client` and `server` strategies for `--dry-run`. The `--dry-run` specs now run both strategies against one queue. The [test guidelines](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/writing_tests.md) keep the table-driven style for unit tests only.
