## Description

Cherry pick of #16742 #19249 on release-0.20.

#16742: Elastic partial scale-up: Workload scale-down below minCount fails API validation
#19249: Elastic partial scale-up: lower minCount of a pending scale-up slice on scale-down

For details on the cherry pick process, see the [cherry pick requests](https://git.k8s.io/community/contributors/devel/sig-release/cherry-picks.md) page.

The [`/cherry-pick release-0.20` run for #19249](https://github.com/kubernetes-sigs/kueue/pull/19249#issuecomment-7104109708) conflicted because #19249 builds on #16742 (`CanReduceMinCountOnScaleDown`), whose [cherry-pick](https://github.com/kubernetes-sigs/kueue/pull/16742#issuecomment-7002274993) also failed. This PR picks both, in order, one commit each.

Conflicts on `release-0.20`:
- `keps/12100-partial-scaleup-for-elasticjob/README.md`: took the new `minCount` text from #16742, but kept the branch's list of job kinds (RayJob/RayCluster/RayService), because `batch/v1 Job` partial scale-up isn't on this branch.
- `pkg/webhooks/workload_webhook.go`: `AllowAddingPodTemplateTolerations` isn't on this branch, so I kept the branch's code and dropped "added tolerations" from the two updated doc comments.
- `test/integration/singlecluster/controller/jobs/job/job_controller_partial_scaleup_test.go`: this file isn't on the branch (#17013 isn't here), so I dropped the #19249 spec for it. The RayCluster spec from #19249 covers the same case.

`go test` of `./pkg/workload/...` and `./pkg/webhooks/` passed. Integration tests: `./test/integration/singlecluster/controller/jobs/raycluster/...` (37/37) and `./test/integration/singlecluster/webhook/core/...` (321/321) passed.
