## Description

#### What type of PR is this?

#### What this PR does / why we need it?

Consolidates the separate feature gate dependency tests in `pkg/features/kube_features_test.go` into a single table-driven `TestFeatureGateDependencies` function to reduce duplication and make adding new dependency tests easier.

Replaced functions:
- `TestAnchorAtQuotaReservationRequiresAdmissionFairSharing`
- `TestTASReplaceMultipleFailedNodesDependencies`
- `TestSchedulerLibraryDeepIntegrationDependencies`
- `TestDQOMultiKueueCapacityProviderDependencies`

All existing test coverage is preserved, including default states, valid configurations, missing dependency rejections, and special cases.

Fixes #19371

#### Useful notes for your reviewer

- #19358 (`ConfigurablePreemptionLimits`) is not yet merged on `main`, so its dependency test cases can be folded into `TestFeatureGateDependencies` when #19358 rebases or in a follow up PR once it lands.
