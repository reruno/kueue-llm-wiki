#### What this PR does / why we need it?

Adds the opt-in `ColocationTieBreaker` alpha feature gate. When TAS bin-packing has equally tight placements, it prefers the domain with the highest resource allocation share from Workloads at the incoming Workload's effective priority, including priority boosts.

The score sums same-priority reserved resources divided by total domain allocatable capacity, with equal weight for each resource requested by the incoming PodSet group. Pod-count limits and unrequested resources are excluded. Fit capacity, preferred node affinity, and topology spreading retain precedence; colocation precedes ancestor-capacity and alphabetical ties.

Tracks priority-attributed usage through snapshot construction, overlapping hostname-level ResourceFlavors, within-cycle reservations, and simulated preemption removal/restoration. Includes documentation and generated feature-gate references. The default-off path preserves existing placement.
