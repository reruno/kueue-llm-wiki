#### What this PR does / why we need it?

`build_images()` in `hack/testing/image-build_test.py` passes `os.environ` unchanged to the nested `make`.

Under `make -k verify`, the inherited `MAKEFLAGS=k` keeps the nested `make` building after the failure that the test injects, so `test_failed_build_stops_remaining_images_and_removes_builder` fails with `AssertionError: 8 != 4`.

This PR drops `MAKEFLAGS`, `GNUMAKEFLAGS`, and `PLATFORMS` from that environment. 

`GNUMAKEFLAGS=k` in the shell has the same effect as `MAKEFLAGS=k`, and `PLATFORMS` changes the platforms of the manager build.

A new test runs the failed build with all three set and checks that the Docker stub still records 4 commands and that the manager build still targets all four platforms.
