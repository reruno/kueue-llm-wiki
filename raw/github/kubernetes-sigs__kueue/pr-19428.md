#### What this PR does / why we need it?

Converts the `TestLoad`, `TestTLSOptions` and `TestEncode` test tables in `pkg/config/config_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines, as requested in https://github.com/kubernetes-sigs/kueue/pull/19384#discussion_r4672978515.

`TestTLSOptions` and `TestEncode` were the remaining slice-based tables in the same file, so they are converted here as well for consistency.

Fixes #19407
