#### What this PR does / why we need it?

Converts the inline `TestStrictFIFO` test table in `pkg/cache/queue/cluster_queue_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. Existing cases and assertions are preserved. This was the only remaining slice-based table in the file, and follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest creates its own ClusterQueue.

Part of #19429
