#### What this PR does / why we need it?

Converts the `TestInadmissibleWorkloads_Get`, `TestInadmissibleWorkloads_Insert`, `TestInadmissibleWorkloads_Delete`, `TestInadmissibleWorkloads_Len` and `TestInadmissibleWorkloads_Empty` test tables in `pkg/cache/queue/inadmissible_workloads_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest copies its initial state into a fresh `inadmissibleWorkloads` map and does not modify the shared `workload.Info` values.
