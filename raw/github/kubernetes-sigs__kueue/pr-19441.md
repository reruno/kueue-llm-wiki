#### What this PR does / why we need it?

Converts six test tables in `pkg/cache/scheduler/cache_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestCacheClusterQueueOperations`, `TestCacheWorkloadOperations`, `TestClusterQueuesUsingFlavor`, `TestClusterQueuesForResources`, `TestCachePodsReadyForAllAdmittedWorkloads` and `TestIsAddedCheckWorkload`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest creates its own cache, and the shared fake clients are only read.
