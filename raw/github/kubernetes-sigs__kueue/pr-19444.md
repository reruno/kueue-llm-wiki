#### What this PR does / why we need it?

Custom manual cherry-pick of #19377 to `release-0.20`.

Consolidates the feature gate dependency tests present on `release-0.20` in `pkg/features/kube_features_test.go` into a single flat table-driven `TestFeatureGateDependencies` function.

Replaced functions:
- `TestAnchorAtQuotaReservationRequiresAdmissionFairSharing`
- `TestTASReplaceMultipleFailedNodesDependencies`

Part of #19377

#### Useful notes for your reviewer

- Scoped strictly to the feature gates available on `release-0.20` (excludes gates introduced after `0.20` such as `SchedulerLibraryDeepIntegration`, `DQOMultiKueueCapacityProvider`, and `ConfigurablePreemptionLimits`).
