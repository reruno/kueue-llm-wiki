#### What this PR does / why we need it?

Converts four test tables in `pkg/cache/scheduler/cohort_metrics_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestRecordCohortMetrics_Guards`, `TestAddOrUpdateCohort_Table`, `TestUpdateClusterQueue_Table` and `TestDeleteClusterQueue_Table`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest creates its own cache and first clears the metric series it asserts on.

Part of #19429
