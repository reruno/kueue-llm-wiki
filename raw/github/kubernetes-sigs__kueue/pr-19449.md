#### What this PR does / why we need it?

Converts the `TestPriorityInfo` test table in `pkg/scheduler/preemption/preemption_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own Workload, and each subtest sets its feature gates with `features.SetFeatureGatesDuringTest`.

Part of #19429
