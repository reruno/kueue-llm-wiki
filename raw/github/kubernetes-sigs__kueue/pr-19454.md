## Description

#### What type of PR is this?
/kind cleanup

#### What this PR does / why we need it?

Replaces error message string matching (`strings.Contains`) in `TestFeatureGateDependencies` (`pkg/features/kube_features_test.go`) with direct error comparison using `cmp.Diff(tc.wantErr, err, cmpopts.EquateErrors())` and `cmpopts.AnyError`.

This avoids making the dependency tests brittle against upstream error wording changes while preserving full coverage for default states, valid configurations, and missing dependency rejections.

Fixes #19446

#### Useful notes for your reviewer

- Checked `k8s.io/component-base/featuregate`: `SetFromMap` returns a plain formatted error for missing dependencies and does not export a sentinel error or custom error type, so `cmpopts.AnyError` with `cmpopts.EquateErrors()` is used.
- Each negative test case isolates a single disabled dependency while keeping other required dependencies enabled, so individual dependency coverage is preserved.
