#### What this PR does / why we need it?

Converts five test tables in `pkg/webhooks/clusterqueue_webhook_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestValidateClusterQueue`, `TestValidateClusterQueueUpdate`, `TestValidateTotalFlavors`, `TestValidateTotalCoveredResources` and `TestValidateFlavorResourceCombinations`. The last three tables use positional literals, so `{"name", 10, false}` becomes `"name": {10, false}`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: the validation functions do not mutate their inputs, and feature gates are set per subtest.

Part of #19429
