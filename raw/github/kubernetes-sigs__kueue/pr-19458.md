#### What this PR does / why we need it?

Converts the `TestValidateResourceFlavor` test table in `pkg/webhooks/resourceflavor_webhook_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. The table variable is renamed from `testcases` to `testCases`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own ResourceFlavor, and the validation function does not mutate its input.

Part of #19429
