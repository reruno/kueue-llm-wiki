**Build the test mapper from `mappings` alone.**

The runner builds the mapper only when `lookup` is non-nil. It never calls `lookup`. A case that sets `mappings` without `lookup` gets an empty mapper, so its mapping is ignored without any error. Future cases can then pass without exercising the mapping they declare.

Make `mappings` the only input for mapper setup:

- Remove the `lookup` field and its `tc.lookup != nil` gate. Remove `defaultLookup` and `noLookup` when they become unused.
- Build the mapper from `tc.mappings` when it is non-nil. Otherwise, build it from the default res-1/res-2 mappings.
- Use a non-nil empty slice for a case that needs no mappings. Cases that currently rely on the empty mapper need this explicit value. Without it, they receive the default mappings.
- Use a populated slice for overrides, such as the `cpu` mapping in the CPU cases.
