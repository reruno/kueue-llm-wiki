#### What this PR does / why we need it?

Converts the `TestCohortEventHandlersUpdateCacheWithoutReconcile` test table in `pkg/controller/core/cohort_controller_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. The ordered `steps` table in `TestCohortReconcileNotifiesClusterQueuesOnQuotaChangesOnly` stays a slice, because each step builds on the previous one. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest builds its own client, cache and reconciler, and passes deep copies of the shared Cohort objects to the event handlers.

Part of #19429
