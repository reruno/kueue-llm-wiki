#### What this PR does / why we need it?

Converts three test tables in `pkg/controller/admissionchecks/multikueue/externalframeworks/adapter_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestAdapter_IsJobManagedByKueue`, `TestAdapter_GetEmptyList` and `TestAdapter_WorkloadKeysFor`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own objects, and feature gates are set per subtest.

Part of #19429
