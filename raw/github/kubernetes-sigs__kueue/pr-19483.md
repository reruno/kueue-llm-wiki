#### What this PR does / why we need it?

Converts three test tables in `pkg/controller/jobs/jobset/jobset_webhook_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestValidateCreate`, `TestValidateUpdate` and `TestDefault`. The table variable is renamed from `testcases` to `testCases`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own JobSets, and each subtest builds its own client, cache and queue manager and sets its feature gates.

Part of #19429
