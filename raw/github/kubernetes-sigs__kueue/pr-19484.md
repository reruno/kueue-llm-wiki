#### What this PR does / why we need it?

Converts two test tables in `pkg/controller/jobs/mpijob/mpijob_webhook_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestValidateCreate` and `TestDefault`. The table variable is renamed from `testcases` to `testCases`. The comment above one `TestDefault` case moves above its map key. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own MPIJobs, and each subtest builds its own client, cache and queue manager and sets its feature gates.

Part of #19429
