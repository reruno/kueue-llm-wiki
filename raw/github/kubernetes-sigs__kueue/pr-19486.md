#### What this PR does / why we need it?

Converts four test tables in `pkg/controller/tas/pod_usage_controller_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestBelongsToNonTASCache`, `TestPodUsageReconcilerCreate`, `TestPodUsageReconcilerDelete` and `TestPodUsageReconcilerUpdatePredicate`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own Pods, the shared `PodUsageReconciler` is stateless, and feature gates are set per subtest.

Part of #19429
