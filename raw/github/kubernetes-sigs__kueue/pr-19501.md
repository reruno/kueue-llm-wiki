#### What this PR does / why we need it?

Cherry pick of #19296 on `release-0.20`.

An `AdminAccess` request with `allocationMode: All` could reserve quota even when no device matched its CEL selector. The matcher now requires at least one matching device and reports a retryable shortage when there are zero matches.

#### Useful notes for your reviewer

- Resolved the cherry-pick conflict by applying the minimum device count to the release branch’s CEL matcher.
- The regression test reproduced the bug on unpatched `release-0.20`. The full DRA unit suite passed with the backport (`go test -p 4 -count=1 ./pkg/dra`).
- Full `make verify` was blocked because Docker and Podman were unavailable.
- Generative AI assisted with conflict resolution, validation, and drafting this PR.

#### Release note

```release-note
DRA: Fixed a bug where a Workload with an AdminAccess request in allocationMode All could reserve quota when no device matched its CEL selector.
```
