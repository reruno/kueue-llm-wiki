#### What this PR does / why we need it?
Adds `preemptionLimitMatcher` for KEP-16925 (https://github.com/kubernetes-sigs/kueue/pull/17277) to match `PreemptionLimit` objects against a `PreemptionConfig` and ClusterQueues, and resolve the aggregation key a preemption counts against:

- Compile `spec.configSelector` (required) and optional `spec.preemptorClusterQueueSelector` / `spec.preempteeClusterQueueSelector` (defaulting to match everything when omitted), returning `nil` if the limit does not select the config and a typed `selectorError` on invalid selectors.
- Add `matchesClusterQueues` to check both preemptor and preemptee ClusterQueue labels.
- Add `aggregationKey` supporting all four Alpha aggregations (`Global`, `ByPreemptorClusterQueue`, `ByPreempteeClusterQueue`, and `ByPreempteeWorkload`).

Part of #16925

## AI summary

This PR adds a preemption-limit matcher for KEP-16925 in `pkg/scheduler/preemption/limits/matcher.go`. The matcher:

- Returns `nil` when the limit's `configSelector` does not match the config labels.
- Treats omitted preemptor and preemptee ClusterQueue selectors as matching all ClusterQueues.
- Returns a typed `selectorError` for invalid selectors.
- Selects the aggregation key: `Global`, `ByPreemptorClusterQueue`, `ByPreempteeClusterQueue`, or `ByPreempteeWorkload`.

The PR also adds unit tests and test wrappers in `pkg/util/testing/v1alpha1/wrappers.go`. The limiter and scheduler integration follows in later PRs.

+// selectorError reports an invalid selector on a PreemptionLimit.
+type selectorError struct {
+	PreemptionLimit string
+	Selector        string
+	Err             error
+}
+
+func (e *selectorError) Error() string {
+	return fmt.Sprintf("preemptionLimit %q %s: %v", e.PreemptionLimit, e.Selector, e.Err)
+}
+
+func (e *selectorError) Unwrap() error {
+	return e.Err
+}
+
+// newPreemptionLimitMatcher returns the matcher for limit, or nil if limit
+// doesn't apply to config. It returns an error if a selector it needs is invalid.
+func newPreemptionLimitMatcher(limit *kueuealpha.PreemptionLimit, config *kueuealpha.PreemptionConfig) (*preemptionLimitMatcher, error) {
+	configSelector, err := metav1.LabelSelectorAsSelector(&limit.Spec.ConfigSelector)
+	if err != nil {
+		return nil, &selectorError{PreemptionLimit: limit.Name, Selector: "configSelector", Err: err}
+	}
+	if !configSelector.Matches(labels.Set(config.Labels)) {
+		return nil, nil
+	}
+	preemptorClusterQueueSelector, err := selectorOrEverything(limit.Spec.PreemptorClusterQueueSelector)
+	if err != nil {
+		return nil, &selectorError{PreemptionLimit: limit.Name, Selector: "preemptorClusterQueueSelector", Err: err}
+	}
+	preempteeClusterQueueSelector, err := selectorOrEverything(limit.Spec.PreempteeClusterQueueSelector)
+	if err != nil {
+		return nil, &selectorError{PreemptionLimit: limit.Name, Selector: "preempteeClusterQueueSelector", Err: err}
+	}
+	return &preemptionLimitMatcher{
+		limit:                         limit,
+		preemptorClusterQueueSelector: preemptorClusterQueueSelector,
+		preempteeClusterQueueSelector: preempteeClusterQueueSelector,
+	}, nil
+}
+
+// selectorOrEverything is metav1.LabelSelectorAsSelector, except that nil selects everything.
+func selectorOrEverything(ls *metav1.LabelSelector) (labels.Selector, error) {
+	if ls == nil {
+		return labels.Everything(), nil
+	}
+	return metav1.LabelSelectorAsSelector(ls)
+}

+}
