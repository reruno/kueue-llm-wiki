## Description

#### What this PR does / why we need it?
Adds user-facing RBAC ClusterRoles and E2E RBAC tests for `PreemptionLimit` from KEP-16925 (https://github.com/kubernetes-sigs/kueue/pull/17277):

- Add `preemptionlimit-editor-role` (aggregated into `batch-admin`, full CRUD on `preemptionlimits`, `get`-only on `preemptionlimits/status`) and `preemptionlimit-viewer-role` (aggregated into `batch-admin` and `admin`, read-only on `preemptionlimits` and `preemptionlimits/status`), along with their generated Helm templates.
- Add E2E RBAC tests covering `kueue-batch-admin-role` (including status write denial), `kueue-preemptionlimit-viewer-role`, `kueue-batch-user-role`, and unprivileged subjects.
- Extract shared ClusterRole binding and readiness-probe helpers so `PreemptionConfig` and `PreemptionLimit` RBAC E2E tests reuse them.

Part of #16925

#### Useful notes for your reviewer
- Manager RBAC for `preemptionlimits` is left to the follow-up controller PR that adds the kubebuilder markers.

## AI summary

This PR adds RBAC roles for `PreemptionLimit` objects:

- `preemptionlimit-editor-role` ClusterRole: create, delete, get, list, patch, update, and watch on `preemptionlimits`. Get on `preemptionlimits/status`. Aggregated into `batch-admin`.
- `preemptionlimit-viewer-role` ClusterRole: get, list, and watch on `preemptionlimits`. Get on `preemptionlimits/status`. Aggregated into `batch-admin` and `admin`.
- Adds Helm templates and Kustomize RBAC resources for both roles.
- Adds E2E RBAC tests for these roles and for `kueue-batch-user-role`. Extracts shared helpers for ClusterRole binding and readiness probes.

Manager controller RBAC for `preemptionlimits` is not part of this PR.
