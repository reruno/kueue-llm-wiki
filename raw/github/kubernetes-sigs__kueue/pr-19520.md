## Description

#### What type of PR is this?

/kind failing-test
/kind flake
/area testing

#### What this PR does / why we need it?

Increases the per package unit test timeout from Go's default `10m` to `11m` by introducing `UNIT_TEST_TIMEOUT ?= 11m` in `hack/make/test.mk` and passing `-timeout=$(UNIT_TEST_TIMEOUT)` to `gotestsum` in the `test` target.

Under CI's `-race -count 3` flags, `pkg/scheduler` occasionally hits the default `10m0s` timeout while still actively running. This provides a short term mitigation until unit test sharding/balancing is improved.

Fixes #19517

#### Useful notes for your reviewer

`-timeout=$(UNIT_TEST_TIMEOUT)` is placed before `$(GO_TEST_FLAGS)` so it still applies when Prow overrides `GO_TEST_FLAGS`, while allowing callers to override it via either `UNIT_TEST_TIMEOUT` or `GO_TEST_FLAGS`.
