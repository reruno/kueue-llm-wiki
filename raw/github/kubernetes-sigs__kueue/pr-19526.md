## AI summary

This PR consolidates two duplicated nominal-quota checks in classical preemption candidate iterators into one helper, `isAnyNodeBelowAncestorWithinNominal`. The helper checks the ClusterQueue and cohorts below the ancestor, not the ancestor itself. This is preparatory work for partial preemption. No behavior change is intended.

- `pkg/scheduler/preemption/classical/candidate_generator.go`: `candidateIsValid` calls the helper and negates the result.
- `pkg/scheduler/preemption/classical/cache_candidate_generator.go`: `advanceToEligible` calls the helper to prune non-same-queue buckets. The `cqIsPruned` method is removed.
