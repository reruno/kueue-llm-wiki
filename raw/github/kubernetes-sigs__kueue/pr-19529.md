#### What this PR does / why we need it?

Cherry-pick #19365 onto `release-0.19`, as requested in https://github.com/kubernetes-sigs/kueue/pull/19365#issuecomment-7129434418.

Overlap MultiKueue test compilation with cluster setup, deploy Kueue concurrently where shared files are not mutated, skip the unused old agnhost image, and bound baseline compiler concurrency. Preserve source-based Ginkgo execution, existing test coverage, replicas and explicit compiler overrides.

#### Useful notes for your reviewer

Source commit: `8e50a8c365495a12a897c12f1624b5a8b8885e69`. The source PR passed its presubmits and three baseline observations (18/18 specs each); those timings are not measurements of release-0.19.

Conflict resolutions preserve release-0.19 behavior:
- Scope the image compiler defaults to MultiKueue baseline only; release-0.19 does not have main's KueueViz compiler defaults.
- Apply image selection to the existing inline image-loading code, retaining its upgrade-image path without importing main's helper refactor.
- Adapt the image-loading mocks and compiler-scope regression matrix to those branch differences. The MultiKueue runner and its regression test match the source PR.
