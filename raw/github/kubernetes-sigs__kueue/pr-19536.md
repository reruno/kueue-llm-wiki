## Description

#### What type of PR is this?

  /kind cleanup
  /area testing

  #### What this PR does / why we need it?

  Follow-up to #17012. Uses ClusterQueue wrappers in the ClusterQueue webhook tests instead of hand-built structs and callback-based setup:

  - `pkg/util/testing/v1beta2/wrappers.go`: adds `ClusterQueueWrapper` helpers `EmptyConcurrentAdmissionPolicy()` (leaves the migration mode nil), `ResourceGroupWithCoveredResources()` (sets explicit `coveredResources`, so it can build invalid ResourceGroups) and `Finalizers()`.
  - `pkg/webhooks/clusterqueue_webhook_test.go`: replaces the remaining `func() *kueue.ClusterQueue {...}()` callbacks in `TestValidateClusterQueue` with wrapper chains. The map conversion and `testCases` rename were already done in #19456.
  - `test/integration/singlecluster/webhook/core/clusterqueue_test.go`: adds a `defaultedClusterQueue()` helper for the webhook-defaulted ClusterQueue and builds the expected objects with wrappers. Inputs to the defaulting table stay plain structs, because `MakeClusterQueue` pre-fills fields the webhook is expected to default.

  Validation and defaulting coverage stay the same, including the nil migration mode cases.

  Part of #18324

  ```release-note
  NONE
  ```
