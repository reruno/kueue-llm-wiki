## Description

#### What this PR does / why we need it?

Makes the aggregated unit coverage discoverable from the README, as suggested in https://github.com/kubernetes-sigs/kueue/pull/18136#issuecomment-7095649802.

Since #18136, the unit coverage profile that the Prow postsubmit `post-kueue-test-unit-coverage-main` merges is uploaded to Codecov, but nothing in the repository links to the reports. This PR adds:

- a Codecov badge under the title, linked to the [Codecov dashboard](https://app.codecov.io/gh/kubernetes-sigs/kueue). It is centered to match the existing title and navigation;
- a short "Test coverage" section linking the Codecov dashboard, the [Prow job history](https://prow.k8s.io/job-history/gs/kubernetes-ci-logs/logs/post-kueue-test-unit-coverage-main), and the [TestGrid tab](https://testgrid.k8s.io/sig-scheduling-kueue#post-kueue-test-unit-coverage-main).

Fixes #19381
Part of #11173
