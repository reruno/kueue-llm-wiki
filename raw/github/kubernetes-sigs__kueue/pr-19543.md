#### What this PR does / why we need it?

`UnadmittedWorkloadsObservability` has been Beta and enabled by default since v0.20, but many tests still turn it on explicitly.

This PR removes:
- 10 `SetFeatureGateDuringTest(..., true)` calls and 4 `featureGates` entries set to `true` in `pkg/` unit tests,
- 10 `SetFeatureGateDuringTest(..., true)` calls in `test/integration`.

Part of: #18993

#### Useful notes for your reviewer

I kept the entries that change the result:
- the per-case `true` entries in `TestReconcile` and `TestReconcileInadmissible` (`pkg/controller/core`). Their runner tries each case with the gate off and on, and a case's own `true` skips the gate-off runs,
- the calls that set the gate to `false`, to a per-case value, or loop over off and on (`pkg/scheduler`, `pkg/scheduler/flavorassigner`, `pkg/scheduler/assignment/was`, `pkg/cache/queue/manager_test.go`, `pkg/controller/concurrentadmission`, `pkg/controller/jobframework`, `pkg/controller/jobs/statefulset`).

Tests only, no product code changes. Following the one-gate-per-PR approach discussed in #18993. The gate is off by default in v0.19, so this should be cherry-picked to release-0.20 only.
