#### What this PR does / why we need it?

Cherry-pick of #19329 to release-0.20.

Conflicts were resolved for code that is not on release-0.20:
- `ray_autoscaling_test.go` takes the shared `rejectUpdatesOnWorker` and `prebuiltWorkloadMarkerCEL` helpers from #19329. The new spec sets the autoscaler options inline, because the `fastAutoscalerOptions` helper only exists on main.
