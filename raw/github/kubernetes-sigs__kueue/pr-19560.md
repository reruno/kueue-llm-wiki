#### What this PR does / why we need it?

The CapacityBufferConfig validation table selected its assertions with a `wantErr` string. Each entry now passes a Gomega matcher, as suggested in https://github.com/kubernetes-sigs/kueue/pull/19412#discussion_r4679203437 and https://github.com/kubernetes-sigs/kueue/pull/19412#discussion_r4679214125: `gomega.Succeed()` for accepted configs, and an invalid error with the expected message for rejected ones. A created config is still deleted, as in the AdmissionCheck and ResourceFlavor validation tables.

Fixes #19518
