#### What this PR does / why we need it?
Manual cherry-pick of #19187 to `release-0.20`, as the automated cherry-pick hit a merge conflict in `test/integration/singlecluster/tas/suite_test.go`.

Related: #19187

#### Useful notes for your reviewer
- Production changes in `pkg/controller/tas/controllers.go` and `pkg/controller/tas/node_controller.go`, and unit tests in `pkg/controller/tas/node_controller_test.go`, applied cleanly.
- Resolved conflict in `test/integration/singlecluster/tas/suite_test.go` by keeping `scheduler.WithCustomLabels(customLabels)` without `scheduler.WithFailedTASReplacementRecoveryTimeout`, which does not exist on `release-0.20`.
- Enabled `features.CustomMetricLabels` explicitly in `test/integration/singlecluster/tas/tas_custom_metric_labels_test.go` because the gate defaults to `false` on `release-0.20`.

```release-note
TAS: Fixed a panic and missing eviction metrics during multi-node failure eviction when custom metric labels are configured.
```
