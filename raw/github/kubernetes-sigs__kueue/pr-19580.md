#### What this PR does / why we need it?

Increases the subprocess timeout in `hack/testing/kueueviz-e2e_test.py` from `15s` / `30s` to a shared `SUBPROCESS_TIMEOUT = 60` and captures diagnostic context on `subprocess.TimeoutExpired`.

`verify-e2e-common-test` runs `kueueviz-e2e_test.py` under `make -j 8` concurrently with `golangci-lint` and other verification targets. Each subtest spawns `bash` plus multiple `python3` stub processes, which can exceed the 15-second limit on a busy Prow node and cause `test_backend_tests_overlap_setup_preserve_failure_and_stop_compilers` to flake.

Fixes #19359

#### Useful notes for your reviewer

- Audited `e2e-kueueviz-backend.sh` and `kueueviz-e2e_test.py` for signal/cleanup races in the `suite_int` / `suite_term` cases: both `make` (`VIZ_TEST_TESTS_STARTED`) and `docker start` (`VIZ_TEST_FRONTEND_STARTED`) synchronize over FIFOs before `cluster_create` sends the signal, and `cleanup()` terminates the full worker process group (`kill -- "-${BACKEND_TEST_PID}"`).
- On `TimeoutExpired` in `run_suite`, partial `exc.stdout`, `exc.stderr`, recorded `events`, and `commands` are included in the failure message (without re-calling `communicate()`, so it cannot block before `finally:` kills any remaining process groups).

## AI summary

This change updates only `hack/testing/kueueviz-e2e_test.py`. It addresses the timeout flake in `#19359`.

- Adds the constant `SUBPROCESS_TIMEOUT = 60`.
- Adds the helper `timeout_output(output, encoding)`. It decodes bytes with `errors="replace"` and returns an empty string for other falsy values.
- Uses `SUBPROCESS_TIMEOUT` in three places: the `process.communicate` timeout in `run_suite` (previously 15 seconds), the Make test `subprocess.run` timeout (previously 15 seconds), and the frontend `process.communicate` timeout (previously 30 seconds).
- Adds an `except subprocess.TimeoutExpired` branch in `run_suite`. It fails the test with the timeout duration, recorded events, recorded commands, and partial stdout and stderr. It does not call `communicate()` again.
