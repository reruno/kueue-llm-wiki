#### What this PR does / why we need it?

Converts the slice-based test tables in `pkg/dra` to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`:

- `capacity_test.go`: `TestRoundToValidValues`, `TestRoundToValidRange`, `TestComputeCapacityCharge`
- `claims_test.go`: `Test_GetResourceRequests`
- `counters_test.go`: `TestComputeCounterCharges`, `TestSelectorErrorPaths`
- `extended_resources_test.go`: `TestIsExtendedResourceName`, `TestResolveExtendedResourceQuota`, `TestNeedsDRAReconcile`
- `mapper_test.go`: `TestDRAResourceMapper_Lookup`, `TestDRAResourceMapper_PopulateFromConfiguration`, `TestCreateMapperFromConfiguration`
- `pools_test.go`: `TestEligibleSlices`, `TestCounterAndCapacityChargesSkipIneligiblePools`

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines. The files are in one package, so they are converted in one PR.

The cases do not depend on execution order: each subtest builds its own mapper, cache and fake client, and sets its feature gates.

Part of #19429
