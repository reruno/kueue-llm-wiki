#### What this PR does / why we need it?

Converts the slice-based test tables in `pkg/util/roletracker` to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`:

- `logger_test.go`: `TestWithReplicaRole`, `TestNewLogConstructor`
- `tracker_test.go`: `TestRoleTracker_StartLeaderElection`, `TestOnElected`, `TestGetMetricsRole`

The files are in one package, so they are converted in one PR.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own `RoleTracker`, and `TestNewLogConstructor` restores the global `ctrl.Log` with `t.Cleanup`.

Part of #19429
