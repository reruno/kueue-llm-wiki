#### What this PR does / why we need it?

Converts the `TestTaintKeyExists` test table in `pkg/util/taints/taints_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run` and in the error message.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: the function under test is pure.
