#### What this PR does / why we need it?

Converts the slice-based test tables in `pkg/util/tas` to maps keyed by test case name, and updates the runners to use the map key:

- `tas_assignment_test.go`: the package-level `bothWaysTestCases` and `oneWayTestCases` become `map[string]testCase`, and the `name` field is removed from `testCase`. The five tests that ranged over `slices.Concat(bothWaysTestCases, oneWayTestCases)` now range over a new `allTestCases()` helper, which merges the two maps with `maps.Clone` and `maps.Copy`. The two maps have no common keys. The inline tables in `TestHasNodeInPodSetAssignment` and `TestHasTASAssignmentOnNode` are converted too.
- `tas_assignment_performance_test.go`: `performanceTestCases` becomes `map[string]performanceTestCase`, used by `TestByteSizeLimit` and `BenchmarkV1Beta2From`.

The files are in one package, so they are converted in one PR.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: the functions under test do not mutate the shared test cases.

Part of #19429
