#### What this PR does / why we need it?

Converts the four test tables in `pkg/util/tlsconfig/tlsconfig_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestParseTLSOptions`, `TestConvertCipherSuites`, `TestConvertTLSMinVersion` and `TestBuildTLSOptions`.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: the functions under test are pure.
