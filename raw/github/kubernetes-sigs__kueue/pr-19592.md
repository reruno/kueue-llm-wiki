#### What this PR does / why we need it?

Converts the three test tables in `pkg/util/wait/backoff_test.go` from slices to maps keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestUntilWithBackoff` (its local `TestCase` type loses the `name` field), `TestBackoff_WaitTime` and `TestBackoff_WaitTime_Consecutive`.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each case has its own `Backoff` and timer.

Part of #19429
