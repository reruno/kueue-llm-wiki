#### What this PR does / why we need it?

Converts the `TestCreateVisibilityServerOptions` test table in `pkg/visibility/server_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest resets the package globals with `setVisibilityServerTestGlobals`, and the runner only changes its own copy of the case.

Part of #19429
