#### What this PR does / why we need it?

Converts the slice-based test tables in `pkg/workload` to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`:

- `flavor_scan_state_test.go`: `TestFlavorScanStateOutdated`
- `workload_test.go`: `TestEvictionPendingLatency`

The files are in one package, so they are converted in one PR.

Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: the functions under test only read their inputs, and feature gates are set per subtest.

Part of #19429
