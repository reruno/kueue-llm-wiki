#### What this PR does / why we need it?

Converts the `TestPodCmd` test table in `cmd/kueuectl/app/list/list_pods_test.go` from a slice to a `map[string]podTestCase` keyed by test case name, removes the `name` field from `podTestCase`, and updates the runner to use the map key in `t.Run`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest builds its own REST mapper, fake REST client and command.

Part of #19429
