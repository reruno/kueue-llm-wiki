#### What this PR does / why we need it?

Converts the two test tables in `cmd/kueueviz/backend/middleware/cors_test.go` from slices to `map[string]struct` keyed by test case name, and updates the runners to use the map key in `t.Run`: `TestValidateWebSocketOrigin` and `TestCanonicalizeOrigin`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each `TestValidateWebSocketOrigin` subtest sets both the gin mode and `KUEUEVIZ_ALLOWED_ORIGINS` before it runs, and `canonicalizeOrigin` is pure.

Part of #19429

The tests are selected by `make test-kueueviz-backend`, which `hack/testing/e2e-kueueviz-backend.sh` runs.
