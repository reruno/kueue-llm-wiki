#### What this PR does / why we need it?

Converts the `TestCreatePredicate` test table in `test/performance/scheduler/runner/controller/controller_test.go` from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. Existing cases and assertions are preserved.

Until now no CI job ran this test: `hack/testing/filter-unit-test-packages.sh` drops every package under `test/` except `test/performance/multikueue/...` and `test/performance/scheduler/runner/generator`. `TestCreatePredicate` guards the informer relist fix from #9543 and runs in under a second without a cluster, so this PR adds `test/performance/scheduler/runner/controller` to the filter with the same exact match as the generator. `unit-test-selection_test.sh` now expects the controller package and also lists `runner/recorder` in its input to show that the exact match keeps other runner packages out.

The cases do not depend on execution order: `Create` only calls `RecordWorkloadState` on a recorder that is not running, which is a no-op.

Part of #19429
