#### What this PR does / why we need it?

Converts the `ValidationRejections` test table in `TestRBACManifests` (`test/util/behavioral/rbac_manifests_test.go`) from a slice to a `map[string]struct` keyed by test case name, and updates the runner to use the map key in `t.Run`. Existing cases and assertions are preserved. This follows the repository's map-based table-driven unit test guidelines.

The cases do not depend on execution order: each subtest builds fresh RBAC resources with `makeBaseResources()` before it mutates them.

Part of #19429
