#### What this PR does / why we need it?

`make generate-kueuectl-docs` changes the `--cache-dir` default on all kubectl-kueue command pages when the UID has no `/etc/passwd` entry, or when `$HOME` and `/etc/passwd` name different home directories.

cli-runtime builds the default from `homedir.HomeDir()`, so the generator replaces that home directory prefix with `$HOME` instead of the one from `user.Current()`. 

Other paths stay unchanged, including the relative `.kube/cache` from an empty `$HOME`.
An AI coding assistant wrote this change, its test, and this description.
