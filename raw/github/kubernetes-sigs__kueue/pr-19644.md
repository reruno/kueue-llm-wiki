#### What this PR does / why we need it?
Adds `PreemptionLimiter` for KEP-16925 (`PreemptionLimits`, https://github.com/kubernetes-sigs/kueue/pull/17277), building on #19509 and #19510:

- Filters a `PreemptionLimitsSnapshot` down to the `PreemptionLimit` matchers that apply to a given `PreemptionConfig`.
- Resolves the `policy.ConsumedLimits` for a candidate preemption using the matching ClusterQueue selectors and aggregation keys.
- Skips targets whose eviction is already in progress (already evicted or with unsatisfied preemption expectations), and treats a `nil` limiter as imposing no limits.

A follow-up PR will add the per-pass budget (`PreemptionLimitBudget`) on top of `PreemptionLimiter`.

Part of #16925

## AI summary

This PR adds `PreemptionLimiter` in `pkg/scheduler/preemption/limits/limiter.go` for KEP-16925 (`PreemptionLimits`).

- `NewPreemptionLimiter` keeps only the snapshot's named limits whose config selectors match. It returns an error if matcher creation fails.
- `consumedLimits` returns no limits when the limiter is `nil` or the target's eviction is in progress. Otherwise, it returns each matching limit with its aggregation key.
- An eviction is in progress when the target is already evicted or its preemption expectation is unsatisfied.

The PR adds unit tests in `limiter_test.go` for limiter construction, selector errors, consumed limits, and `nil` limiter behavior. The per-pass `PreemptionLimitBudget` is a follow-up change.
