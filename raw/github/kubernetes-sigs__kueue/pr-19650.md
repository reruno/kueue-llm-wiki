#### What this PR does / why we need it?
Manual cherry-pick of #19633 to `release-0.20`, as the automated cherry-pick (#19643) failed `verify` due to RBAC rule ordering differences in `config/components/rbac/role.yaml` and `charts/kueue/templates/rbac/role.yaml`.

Related: #19633

/assign tenzen-y

#### Useful notes for your reviewer
- Production changes in `pkg/controller/admissionchecks/provisioning/controller.go` and integration tests in `test/integration/singlecluster/controller/admissionchecks/provisioning/` applied cleanly.
- Regenerated `config/components/rbac/role.yaml` and `charts/kueue/templates/rbac/role.yaml` via `make update-helm` so `provisioningrequests/finalizers` is placed in canonical order between `provisioningrequests` and `provisioningrequests/status`.
