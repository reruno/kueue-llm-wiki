#### What this PR does / why we need it?
Manual cherry-pick of #19633 to `release-0.19`, as the automated cherry-pick (#19641) failed `verify` and integration tests due to Go 1.26 compatibility in `provisioning_rbac_test.go` and RBAC rule ordering in generated manifests.

Related: #19633

/assign tenzen-y

#### Useful notes for your reviewer
- Production changes in `pkg/controller/admissionchecks/provisioning/controller.go` and `test/integration/singlecluster/controller/admissionchecks/provisioning/suite_test.go` applied cleanly.
- Updated `test/integration/singlecluster/controller/admissionchecks/provisioning/provisioning_rbac_test.go` to set `ObjectMeta: metav1.ObjectMeta{...}` explicitly on `ServiceAccount` and `ClusterRoleBinding` literals for Go 1.26 compatibility (`go.mod` on `release-0.19` targets `go 1.26.0`).
- Regenerated `config/components/rbac/role.yaml` and `charts/kueue/templates/rbac/role.yaml` via `make update-helm` so `provisioningrequests/finalizers` is placed in canonical order between `provisioningrequests` and `provisioningrequests/status`.

#### Release note
```release-note
Fixed 403 Forbidden errors when updating ProvisioningRequest PodTemplate ownership on clusters with OwnerReferencesPermissionEnforcement enabled.
```
