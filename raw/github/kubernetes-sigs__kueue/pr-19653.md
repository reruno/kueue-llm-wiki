#### What this PR does / why we need it?

Reduce scheduler unit-test overhead while retaining every scheduling scenario, feature-gate combination, assertion, race check, repetition, and coverage flag.

- Restore only affected feature gates and their original explicit/unset state. Restoring the entire registry after ordinary overrides makes unrelated defaults explicit and causes subsequent updates to reprocess them. Empty and aggregate overrides retain full-registry snapshots; aggregate inheritance, caller precedence, fail-fast errors, and GinkgoTB cleanup remain supported.
- Build private scheduler fake-client schemes with the core, resource v1, and Kueue APIs used by the tests. Preserve the standard indexes, managed-fields type converters, SSA/merge-patch paths, and independent per-case clients and storage. The general-purpose builder retains full registration and delegates index setup to `NewClientBuilderWithScheme`.
- Stably sort conditions on private expected copies and List results before full workload comparisons. Restrict the existing `EquateEmpty` value filter to slice/map paths. All condition fields and existing ignore/nil-empty rules remain checked.

Part of #19535. The reference baseline is the 600-second scheduler timeout under `-race -count 3` in #19517. The timeout increase is already covered by #19520; package shard balancing remains separate in #17190.
